## ⌨️ 一、 每日高频快捷键（贴在桌面上看）

| 动作 | 快捷键 | 效果说明 |
| :--- | :--- | :--- |
| **插入演算画布** | `Alt + I` | 自动按「笔记名_题号」在 `Ink/` 生成手写画布，默认折叠不卡顿 |
| **抽取本章错题** | `Ctrl + Shift + E` | 自动扫描 `#错题` 归档至 `08.错题与重测库/`，原文变为 `#已归档错题` |
| **错题随机组卷** | `Ctrl + Shift + R` | 从错题库加权随机抽 10~15 题（剥离手稿与解析）生成纯净重测卷 |

| **网课截图打点** | `Ctrl + Q` | Media Extended 一键生成当前视频帧截图 + 精细时间戳 |
| **网课批量转写** | `Ctrl + Shift + A` | 调用小米 MiMo ASR 按 1min 切片转写网课，输出至 `10.转写结果/` |

## 🔥 二、 每日刷题与错题复盘“极简 3 步法”

### 第 1 步：单窗口沉浸刷题（在 `03.数二题库` 或 `04~07`）
1. **数二 & 408 大题**：看题干 -> 按 `Alt + I` 插入画布 -> 用数位板手写推导。
2. **408 选择题（80分）**：纯概念题**不插画布**，直接敲字写答案；需要画图计算的题（如红黑树、IEEE754、Cache映射）才按 `Alt + I` 插画布。
3. **只对答案，不看过程**：整节做完后对照 `09.答案库/` 只看结果。做对的收起画布直接过；**做错的在标题后打上 `#错题`**（如果原题缺图，用 `Ctrl + Shift + D` 去 PDF 框选补上）。

### 第 2 步：一键抽离错题
* 整章刷完后，直接按 **`Ctrl + Shift + E`**，所有 `#错题` 自动按科目汇入 `08.错题与重测库/数二错题` 或 `408错题` 下的 `<笔记名>_错题集.md`。

### 第 3 步：AI 答疑与定位思维分叉点（打开错题集呼叫 Claudian）
* **常规错题（90% 场景）**：直接让 AI 结合 `09.答案库/` 输出标准解题过程与考点分析。自己对照草稿看一眼哪步算错，跟 AI 说一句卡点，让它把【做题缺陷与思路分叉点】总结写进错题下方。
* **疑难算错题（10% 场景）**：看不出自己哪步算错时，展开自己的 Ink 画布，直接按 `Win + Shift + S` 截图粘贴给 AI（或让 AI 读取手稿），让它一针见血指出第几步出现概念偏差或计算失误。

## 🛠️ 四、 底层维护备忘（平时不用管）

1. **Ink 魔改源码备份**：位于 `.obsidian/plugins/ink/` 下，含官方原版 `main.js.original-v0.3.4.bak` 与魔改版备份 `main.js.bak`。万一插件误升级导致自动命名失效，用备份覆盖 `main.js` 即可恢复。
2. **ASR 环境依赖**：`pip install requests` + `winget install Gyan.FFmpeg`，通过环境变量 `MIMO_API_KEY` 注入密钥。
3. **隐私提醒**：若未来需将本仓库上传至公开 GitHub，请先清空 `scripts/mimo_asr_batch.py` 及 `.obsidian/plugins/quickadd/data.json` 中的 API Key。
