## 📝 视频简介
我把两个 Claude Code 实例放进同一个对话框，让它们互相提问。
一千轮之后，窗口塞满了，它们开始压缩表达——先省略主语，再合并句子，最后每个字都被压成几个像素方块。到第 1000 轮，它们已经不说人话了。
更离谱的是：这套"像素字"有固定读音，每个字都有自己的音高和时长，像一门真正的语言。
