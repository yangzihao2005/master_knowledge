## 📝 视频简介
Windows 里有两个长得很像的命令行窗口：黑色的 CMD 和蓝色的 PowerShell。CMD 是从 DOS 时代一路继承下来的老前辈，而 PowerShell 不只是“更蓝了”，它是一个完整的脚本语言运行环境。本期讲透两者的区别：Cmdlet 的动词-名词命名规则、纯文本和对象的本质差异、别名机制如何同时讨好 CMD 和 Linux 用户、管道流水线有多好用，最后再对比一下 .bat 和 .ps1 脚本，看完你就知道该用哪个了。
