# 一、两个句式

英语只认两个基本句式，可以统一掉传统语法的"五种简单句"。

## 句式 1：某人做某事（动作/状态，陈述事实）

```
Somebody do something
I study.                    主谓
I am studying English.      主谓宾
I find studying English easy.   主谓宾 + 宾补
```

- 表达**动作或状态**，陈述事实、描述情况。
- 阅读中只考**事实细节**，三个方向：谁做的（somebody）、和这事什么关系（动词）、做了什么（宾语）。
- 名词后面再加形容词/名词 → 那个成分叫**宾补**。
- **关键判断**：形容词比名词更重要。因为形容词给的是褒贬（好/不好），而名词本身从主语就能推出来。

## 句式 2：某人/某物是什么（A is B）

```
A is B      B = 形容词 / 名词 / (形容词+名词)
She is beautiful.            她很漂亮
She is a girl.               她是个女孩
She is a beautiful girl.     A is B 的扩展
```

- 系动词 is 表示"判断是什么"；形容词 beautiful 是褒贬，比 girl 更重要。
- **A = B，所以认识一半就够**：这类结构用于解释说明某个概念。
- 阅读考点：**文章主旨、作者观点、某人态度**几乎都用这个结构表达。

> 记住这两句就够了，不用背五个句型。

# 二、八种句子成分

| 类别 | 成分 | 能否省略 |
|---|---|---|
| **主干成分** | 主、谓、宾、表 | 缺一个就不成句 |
| **非主干成分** | 定、状、同、补 | 可以没有 |

## 1. 主语 / 宾语

- 主语：发出动作的人或物，位于**谓语动词前面**。
- 宾语：承受动作的人或物，位于**动词或介词后面**。
- 由**名词性成分**充当：名词、代词、动名词（doing）、不定式（to do）、句子。

## 2. 表语

- 就是 `A is B` 里的 B，位于**系动词（am/is/are…表示"是"的词）后面**。
- 由：形容词、名词、介词短语、句子（→ 表语从句）充当。
  - `You are beautiful.`（形容词）
  - `I am a teacher.`（名词）
  - `You are at school.`（介词短语）

## 3. 谓语动词（最容易搞错的一类）

**谓语动词一定是动词，但动词不一定是谓语。** 三个条件：

1. 前面有主语
2. 体现**时态**（一般现在/过去/完成…），**或**
3. 体现**情态**（must/should/can + 动词原形）

- 位置：主语后面。
- ⚠️ **单独的 doing / to do / done（过去分词）都不能作谓语**。
  - doing 前面加 am/is/are 才构成谓语
  - done 前面要有体现时态的 be 动词才构成谓语

## 4. 定语（≈ 汉语的"白勺的"）

- 修饰**名词**，位置在名词前后，规则如下：

| 修饰成分 | 位置 | 例 |
|---|---|---|
| 单个形容词 / 单个名词 | **前置** | `beautiful flower`、`history book` |
| 形容词短语、介词短语、非谓语短语（doing/done/to do）、句子 | **后置** | `a girl in yellow shirt` |

- 一句话：**单词修饰→前置（前置定语）；短语/句子修饰→后置（后置定语）**。

## 5. 状语（≈ 汉语的"土也的"）

- 修饰**动词、形容词、副词**，甚至修饰**整个句子**。
- 由：副词（多为形容词 + ly）、介词短语、句子（→ 状语从句）充当。
- 位置灵活：可在被修饰词前、后，也可整句首尾。

## 6. 同位语

- 两个**名词性成分之间完全画等号**，就是同位语。
- 两个识别公式：
  1. **名词 , 名词**（逗号隔开）
  2. **A of B**（A 与 B 相等）
- 例：`小帅，我们班最好看的人`；`the city of Shanghai`

## 7. 补语

- **补充说明宾语** → 宾补，位置在宾语后面，由形容词或名词充当。
- 补充说明**主语**的不叫补语，叫**表语**。
- 例：`I find studying English easy.` —— easy 说明的是 studying English（宾语），所以是宾补。

# 三、三大从句

## 0. 为什么要学从句

- 阅读题干在原文中**定位到的句子 = 主句 + 若干从句**。
- **干扰选项**通常藏在**定语从句和状语从句**里，或者是两个不重要句子的杂糅。
- 学从句的目的：**把从句剔除，剩下的主句出正确答案**。

## 1. 从句判定三件套（核心工具）

```
谓语动词个数 = 连词个数 + 1
```
（主句也要有一个谓语，而主句前面没有连词。）

**分析长难句的固定动作：**

1. **找谓语动词**：前面有主语 + 体现时态或情态。
2. **从后往前找连词**：哪个谓语动词前面有连词，它就是**从句**的谓语；没有连词的就是主句谓语。
3. **定从句终点**，三个标志：
   - 到**下一个连词**之前结束
   - 到**下一个标点符号**之后结束
   - 到**第二个谓语动词**之前结束（说明从句插在主句主谓之间）

## 2. 名词性从句（主 / 宾 / 表 / 同）

作用等于一个名词，因此可以占主语、宾语、表语、同位语的位置。

| 从句类型 | 位置 | 判断标志 |
|---|---|---|
| 主语从句 | 谓语动词**前** | 整句在谓语前 |
| 宾语从句 | 动词 / 介词**后** | 在及物动词或介词后 |
| 表语从句 | **系动词后** | 在 is/was 等后面 |
| 同位语从句 | 抽象名词**后** | 与抽象名词完全等号 |

**引导词选法：**

| 原句类型 | 引导词 |
|---|---|
| 陈述句 | that |
| 一般疑问句 | whether |
| 特殊疑问句 | 特殊疑问词（how/what/why…） |

### 形式主语 / 形式宾语

英语**不喜欢头重脚轻**。主语从句或不定式太长时：

```
It + 谓语 + ... + 真正主语(从句/不定式) 置于句末
```

- `It` 替代原来那个长主语，真主语移到句子最后，主句结构不变。形式宾语同理。

### 同位语从句公式

```
抽象名词 + that/whether/特殊疑问词 + 完整句子
```

- 因为**从句与抽象名词完全画等号**，所以从句的成分**必须完整**（这是与定语从句的关键区别）。
- 常见抽象名词：`theory`（理论）、`dream`、`fact`、`news`、`possibility`。

## 3. 定语从句

修饰名词（或代词），是"形容词性从句"。

| 引导词 | 成员 | 从句是否完整 |
|---|---|---|
| **关系代词** | which, that, who, whom, whose, as | **不完整**（缺主语或宾语） |
| **关系副词** | when, where, why（+ whereby） | **完整** |

**为什么关系代词引导的从句缺成分？**
关系代词属于代词，代词在句中作主语或宾语 → 所以从句必须给它**留出主/宾位置** → 从句成分不完整。

**为什么关系副词引导的从句完整？**
关系副词属于副词，副词不作主干成分（主谓宾表）→ 主谓宾表都齐 → 成分完整。

### 公式 1（最常用）

```
名词/代词 + 关系代词 + 不完整句子（缺主或缺宾）
```

- 关系代词**作宾语时可以省略**：
  ```
  名词 + 主语 + 谓语          ← 省略了 which/that
  名词 + 名词 + 谓语动词       ← 两个名词间无标点，第二个名词后接谓语
  ```

### 公式 2（非限定性）

```
完整句子 , which + 不完整句子
```
- `which` 指代前面**一整句话**或前面某个名词/代词。

### 限定 vs 非限定（逗号）

- `He has a girlfriend who is in Beijing.` → 他有一个**在北京的**女朋友（可能别处还有）
- `He has a girlfriend, who is in Beijing.` → 他有一个女朋友，**她在北京**（独一无二）
- **一句话原则：加逗号是因为"只有一个 / 独一无二"，不需要限定。**

翻译差异：
- 限定性 → 翻成"……的 + 名词"，前置
- 非限定性 → 断开成并列分句

### 特殊结构（分割结构）

定语从句**不必紧挨**被修饰词，可以隔开一段距离。
例：`the interaction between mother and child, where ...` —— where 指代的是 `interaction`（虚拟地点，不必是 place/room）。

### when / where / why 的翻译

| 引导 | 定语从句 | 状语从句 |
|---|---|---|
| when | 当时 / 在那时 / 届时 | 当……的时候 |
| where | 在那里（可还原介词短语） | 在……的地方 |
| why | 原因 / 为什么 | —— |

> 只要译文能写成"……的 + 名词"，就是定语从句。

## 4. 状语从句

修饰**整个主句**，共九种：时间、地点、原因、结果、目的、条件、让步、比较、方式。

| 语义 | 引导词 |
|---|---|
| 条件 | if, unless, as long as |
| 让步 | though, although, even if |
| 比较 | as...as, than |
| 方式 | as if |

**核心特征：状语从句可以与主句互换位置**（从句在前或主句在前都行）。

### 状语从句的省略

> 从句主语与主句主语**一致**时 → 省略从句主语，并把谓语改成**非谓语**。

例：`While holding its nose, the Supreme Court has overturned ...`
= `While (the Supreme Court was) holding its nose, ...`（英语不喜欢重复）

### when / where / why：定语从句 vs 状语从句

三个判断步骤：

1. 前面有没有**表示时间/地点/原因的名词**？有 → 可能是定语从句
2. 从句修饰**前面的名词**还是**整个句子**？修饰名词 → 定语从句
3. **能否与主句互换位置**？能 → 状语从句；不能 → 定语从句

# 四、非谓语动词（重点）

> 非谓语 = **不能作谓语的动词**。除了谓语，其余七个成分（主宾表定状同补）都能做。
> 四六级/考研**只重点考两种：做定语、做状语**。其余成分"考了也认识"即可。

## 公式 1：非谓语作前置定语（单词修饰名词）

```
doing / done + 名词
a running bus      正在跑的车      （doing → 主动）
a misled woman     被误导的女性    （done → 被动）
```
- 作用相当于形容词，**单个词修饰名词 → 放名词前**。

## 公式 2：非谓语短语作后置定语（短语修饰名词）

```
名词 + doing something
名词 + done by somebody
名词 + to do something
```
- `a person driving a car` 一个开车的人
- `a woman misled by commercial advertisements` 一个被商业广告误导的女性
- `a lot of work to be done` 许多要被做的工作
- **短语修饰名词 → 放名词后**。

## 公式 3：非谓语短语作状语

```
Doing sth / Done by sb / To do sth , 句子
（也可：句子 , 非谓语短语）
```
- 用**逗号**与句子隔开，位置可前可后。
- **逻辑主语 = 句子的主语**（谁主动、谁被做、谁要做，都是句子主语）。
- 具体是什么状语（时间/原因/结果/目的/伴随），靠**翻译**判断逻辑关系。

例：
- `Driving a car, the person met her Mr. Right.` → **时间**状语（开车时）
- `Misled by commercial advertisements, the old lady bought lots of milk.` → **原因**状语（因为被误导）
- `To finish the work ahead of time, I always work overtime.` → **目的**状语（to do 基本表目的）

## 公式 4：独立主格结构

```
名词 + doing sth / done by sb / to do sth , 句子
```
- 与公式 3 的唯一区别：**非谓语前面保留了一个名词**。
- 原因：**非谓语的逻辑主语 ≠ 句子主语**，所以不能省略，必须保留。
- 位置同样可前可后，用逗号隔离。

例：
- `A person driving a car, an accident happened.` → 时间状语（人在开车时，事故发生了）
- `A grandmotherly woman misled by ads, many others persuaded her not to buy...` → 原因状语
- `A lot of work to be done, I am always the first to get to the office.` → 原因状语

**错误示范（重要）**：
- ❌ `Waiting for a bus, a brick fell on my head.` → 逻辑主语变成「砖在等公交」
- ✅ `I waiting for a bus, a brick fell on my head.` → 独立主格（我等公交时）
- 另外：**不能**在独立主格的名词后补 is/was，否则变成两个完整句子，逗号连不起来。

## 状语从句 → 非谓语短语：三个步骤

1. **去掉连词**（不再是句子，不能用连词引导）
2. **处理从句主语**：
   - 与主句主语**一致** → 去掉
   - **不一致** → 保留（→ 独立主格结构）
3. **谓语改非谓语**：

| 形式 | 含义 |
|---|---|
| doing | 主动、进行 |
| to do | 目的、将来 |
| done | 被动、完成 |

### 四个练习

| 原句 | 改写 |
|---|---|
| `Now that we have all the materials ready, we should start a new task.` | `Having all the materials ready, we should start a new task.`（主语一致，去掉 we，have→having，原因状语） |
| `As long as a doctor prescribes a drug for a legitimate medical purpose, the doctor has done nothing illegal.` | `Prescribing a drug for a legitimate medical purpose, the doctor has done nothing illegal.` |
| `When the spaceship leaves the earth at very high speed, the astronauts feel as if they are being crushed against the spaceship floor.` | `The spaceship leaving the earth at very high speed, the astronauts feel as if ...`（主语不一致 → **独立主格**，时间状语） |
| `When it is seen from the top of the mountain, the lake looks more beautiful.` | `Seen from the top of the mountain, the lake looks more beautiful.`（被动 → done；过去分词短语常置于句首表条件） |

# 五、长难句实战（3 例）

## 例 1

> I have discovered, **as** perhaps Kelsey will (discover) after her much publicized resignation from the editorship of *She* after a build-up of stress, **that** abandoning the doctrine of "juggling your life" and making the alternative move into downshifting brings with it far greater rewards than financial success and social status.

**拆解**
- 谓语：`have discovered`（主句）、`will`（省略了 discover，前面出现过故省略）、`brings`（从句谓语）
- `as` 引导**方式状语从句**，插在主句动词和宾语从句之间 → 这就是 `that` 前有逗号的原因（正常情况 that 前后有逗号都不正常，说明插入了成分）
- `that` 引导**宾语从句**，本可紧跟 discovered；为了句子平衡/不重复，挪到后面，as 从句借用同一个 that 从句。
- `than ...` 是比较状语；`with it` 中 it 指代前面"抛弃信条、转向简单生活"这件事。

**译文**：我已经发现——正如凯尔西在因压力日增而公开辞去《She》杂志编辑职位之后可能也会发现的那样——放弃"为生活疲于奔命"的信条、转而选择更简化的生活方式，会带来比经济成功和社会地位大得多的回报。

## 例 2

> The emphasis **on data gathered first-hand**, **combined with** a cross-cultural perspective **brought to the analysis of cultures past and present**, makes this study a unique and distinctly important social science.

**拆解**
- 全句**只有一个连词都没有** → 无从句 → **只有一个谓语**：`makes`
- `gathered` / `combined` / `brought` 都是**过去分词**，不是谓语（前面是介词短语 on data、逗号、名词，不满足"前面有主语"）
- `on data gathered first-hand` → 介词短语后置定语修饰 emphasis；gathered 后置定语修饰 data
- `combined with ...` → 过去分词短语作**伴随状语**（可移到句首或句末）
- `brought to the analysis ...` → 后置定语修饰 perspective
- `makes this study a ... social science` → makes + 宾语 + **宾补**

**译文**：对收集到的第一手数据的重视，加上用于分析过去与现在文化的跨文化视角，使这项研究成为一门独一无二且至关重要的社会科学。

## 例 3

> Behaviorists suggest **that** the child **who** is raised in an environment **where** there are many stimuli **which** develop his or her capacity for appropriate responses will experience greater intellectual development.

**拆解**（嵌套：宾语从句里套三个定语从句）

| 层级 | 内容 |
|---|---|
| 主句 | `Behaviorists suggest`（suggest 此处 = 认为） |
| 宾语从句 | `that the child ... will experience greater intellectual development` |
| 定语从句① | `who is raised in an environment` → 修饰 child（关系代词作主语） |
| 定语从句② | `where there are many stimuli` → 修饰 environment（关系副词，从句完整） |
| 定语从句③ | `which develop his or her capacity` → 修饰 stimuli（关系代词作主语） |
| 后置定语 | `for appropriate responses` → 修饰 capacity |

- 宾语从句的**主语 the child 与谓语 will experience 之间插入了三个小从句** —— 这是长难句之所以"长"的典型手法。

**译文**：行为主义者认为，在有许多刺激物、且这些刺激物能促进其恰当反应能力发展的环境中成长的孩子，会获得更高水平的智力发展。

# 速查清单

**看到长句，按这个顺序做：**

1. 找**谓语动词**（前面有主语 + 时态/情态）
2. 数一下：谓语数 = 连词数 + 1，对不上就说明有省略/并列
3. **从后往前**找连词，锁定每个从句的谓语
4. 定从句终点：下一个连词前 / 下一个标点后 / 第二个谓语前
5. 剩下没连词的部分 = **主句** = 答案来源
6. 剔除修饰成分（定语、状语、同位语、插入语），只留主干主谓宾

**高频陷阱**

- doing / to do / done 单独出现 → **不是谓语**
- ed 结尾不一定是谓语，要看前面是不是主语（`the`、介词短语都不能作主语）
- 关系代词引导的从句**缺成分**，关系副词引导的从句**完整**
- 同位语从句 = 抽象名词 + that + **完整句子**
- 逗号不能连两套主谓
- 非谓语作状语的逻辑主语 = 句子主语；不一致就必须用**独立主格**
- `and` 是并列连词，不引入新从句；两个谓语可**共享**同一个引导词
