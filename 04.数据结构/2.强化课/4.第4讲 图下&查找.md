# 数据结构强化课 第4讲 图下&查找

## 图的基本概念与术语辨析

[00:00:00 - 00:09:00]

图的基本名词是选择题高频考点，必须逐条分清。图的顶点集 V 不能为空，边集 E 可以为空，最简单的图就是一个孤立顶点；而树可以是空树，两者要对照记忆。边集用尖括号还是小括号可以直接判断图是有向还是无向：`<A,B>` 是有向边，`(A,B)` 是无向边。408 图这一章只考简单图（无自环、无重边）。完全图是任意两个顶点之间都有边，共 n(n-1)/2 条无向边。

> **定义**：简单路径——路径的顶点序列中顶点不重复；简单回路——只有起点与终点重复的路径。
> **易错点**：题干不给"有向/无向"时，看边集用的是尖括号还是小括号来判断，不要凭图猜。

## 连通分量、极大连通子图与极小连通子图

[00:09:00 - 00:12:00]

在非连通的无向图中，每一块"极大连通子图"就是一个连通分量。极大的含义是：原图中这些顶点之间原有的边一条都不能少，即边集完整保留。无向连通图本身既是自己的极大连通子图；单个孤立顶点既是一个极大连通子图，也是一个极小连通子图。极小的含义是：在连通子图的基础上，去掉任意一条边就不再连通——这正是生成树。所以**连通分量 ↔ 极大连通子图，生成树 ↔ 极小连通子图**。

> **易错点**："极大/极小"比的是边的数目，且都必须建立在"连通子图"这一前提上讨论，不是比顶点数。

## 图的四种存储结构

[00:12:00 - 00:16:00]

邻接表 = 顶点表 + 每个顶点挂一条边表单链表。有向图空间 O(V+E)，无向图每条边存两次为 O(V+2E)；适合稀疏图；表示不唯一，取决于边表的输入顺序。邻接矩阵 = 顶点表 + 二维矩阵，空间与遍历均 O(V²)，与有向无向无关；适合稠密图，表示唯一，无向图的邻接矩阵一定是对称矩阵。十字链表（有向图）与邻接多重表（无向图）近两年真题开始考，要求会"图→表"和"表→图"双向转换，也要会不还原图、直接读表求度或边数。

> **易错点**：题目只给一个矩阵时，别忘记邻接矩阵表示法其实还包含一个顶点表。

## 图的基本概念选择题辨析

[00:16:00 - 00:20:00]

"回路"与"简单回路"是两个概念，判断序列类选项前先明确定义，否则容易被混淆视听。稀疏图用邻接矩阵更省空间是错的（矩阵里有大量零元）。拓扑排序是判断有向图是否存在回路最常规的方法，这一说法正确。无向连通图中所有顶点的度之和为偶数，因为每条边在两端各被计一次，总和 = 2E。

> **易错点**：断言中含"至少有一个……"时，只要能举出一个反例（如单顶点图度数为 0、完全图各顶点度不为 1）该选项即错；含"可能……"时，能举出一个成立的例子即为对。

## 由邻接矩阵求顶点的度

[00:20:00 - 00:22:00]

先看矩阵是否对称：不对称则一定是有向图。有向图中第 i 行元素之和是顶点 i 的出度，第 i 列之和是入度，二者相加即顶点的度，逐行逐列加即可，不需要还原原图。这里要纠正一个常见误解：无向图的邻接矩阵一定对称，但矩阵对称的图不一定是无向图，两者不是充要关系（有向图中成对的对称弧也会产生对称矩阵）。

> **易错点**："邻接矩阵对称 ⇔ 无向图"是错的，只有"无向图 ⇒ 矩阵对称"成立。

## 图的遍历：DFS / BFS 与生成树、复杂度

[00:22:00 - 00:24:00]

DFS 类比二叉树的先序遍历，BFS 类比层序遍历。连通图做一次遍历得到一棵生成树，非连通图得到多棵生成树即生成森林。时间复杂度取决于存储结构：邻接表 O(V+E)，邻接矩阵 O(V²)。空间复杂度两者都是 O(V)：DFS 是递归栈深度最坏为顶点数，BFS 是队列最多容纳一层顶点。

> **公式**：DFS/BFS 时间——邻接表 O(V+E)、邻接矩阵 O(V²)；空间均为 O(V)。

## DFS 序列判断题的应试方法

[00:24:00 - 00:26:00]

此类题没有技巧，只能逐个选项模拟，但真题答案常藏在后两个选项，可从最后一个开始倒着验证。判定依据只有两条：只有走到死胡同（无未访问邻接点）才能回溯；到达某顶点后，只要它还有未访问的邻接点，下一步就必须走它。该真题的 D 选项在 V1→V2 之后接 V3 不可行，因为 V2 只有一条指向 V5 的出边，下一步只能是 V5。

> **易错点**：不要一看到"走不通"就允许回溯，回溯的前提是当前顶点确实已无未访问邻接点。

## DFS 的代码实现

[00:26:00 - 00:31:00]

visited 数组应声明为全局变量，因为写在递归函数内部每次调用都会重新声明，是临时变量，无法保留遍历结果；全局变量必须写注释说明用途（bool 置 false，也可用 int 置 0/1）。主函数 DFS_Traverse 先初始化 visited，再对每个顶点判断"未访问则调用一次 DFS"。递归函数进入后立刻 visit、置 visited=true，然后取 first neighbor（取决于输入顺序），只要返回值 ≥0 就循环：未访问的邻接点递归调用，之后取 next neighbor；返回 -1 表示无邻接点。

> **易错点**：first neighbor 返回 -1 表示没有邻接点，循环条件写成 `w >= 0`，不要写成 `w > 0`。

## visit 的位置与逆拓扑序列

[00:31:00 - 00:34:00]

visit 写在递归入口，等价于"遇到顶点立刻访问"，得到的是 DFS 序（先序）；把 visit 改到递归退出（回溯）时执行，对有向无环图得到的就是逆拓扑排序序列。该真题中从 A 出发：A→B→D→E，E 无邻接点先退栈输出 E，随后 D、B 依次输出；回到 A 后走 C，C 无路可走输出 C，最后输出 A，故为逆拓扑序，选 A。

> **易错点**：输出时机决定序列性质，做题前先确认 visit 是在入栈前还是退栈时执行。

## BFS 的代码实现与访问顺序

[00:34:00 - 00:40:00]

BFS 借助队列，是迭代写法，结构同二叉树层序遍历。主函数初始化 visited、声明并初始化队列，对每个未访问顶点调用一次 BFS。BFS 内：进入即访问、置 true、入队；while 队列非空则出队取 v，遍历 v 的全部邻接点，凡未访问就访问、置 true、入队。同一层内的展开顺序由入队顺序决定：B、F、C 入队后必须先展开队首 B 的邻接点 D，不能先访问 E；入队顺序又由边的输入顺序决定。

> **易错点**：同一层内不是"谁先访问都行"，取队首的顺序严格由入队先后决定，这也是 BFS 序列题的唯一判据。

## 算法题：省份数量（DFS 求连通分量）

[00:40:00 - 00:48:00]

题目给 n×n 的 isConnected 矩阵，要求省份数量，本质是求无向图连通分量的个数。核心结论：对每个未访问顶点从外层调用一次 DFS，外层调用次数就等于连通分量数。实现上声明 visited 数组（C++ 可用 memset，C 用循环初始化），用 provinces 变量计数；DFS 内遍历 j，满足 `matrix[i][j]==1 && !visited[j]` 才置标志并递归。

> **易错点**：计的是外层遍历中 DFS 的调用次数，不是递归函数内部被调用的总次数；连通图只会调用 1 次。

## 解法二：并查集求连通分量

[00:48:00 - 00:56:00]

并查集视角下，每个连通分量就是一个集合，集合个数即省份数。三步走：初始化 `parent[i]=i`（每个元素自成一个集合）；遍历矩阵，凡 `matrix[i][j]==1` 就 union，把两个顶点并入同一集合；最后遍历 parent 数组，`parent[i]==i` 的即为代表元，计数即得连通分量数。find 采用路径压缩（查找过程中顺手更新代表元），union 未按秩或集合大小优化。并查集的两个函数是固定模板，做题只需改最外层与统计部分。

> **易错点**：若 parent 初始化为 -1（非显式表示），统计代表元的条件要同步改成 `parent[i]==-1`。

## 最小生成树（Prim / Kruskal）

[00:56:00 - 01:00:00]

最小生成树是在不破坏连通性的前提下边最少、且边权之和最小的生成树，本质是一棵极小连通子图。性质：MST 的形状可能不唯一，但最小权值之和唯一——这是选择题常考点。Prim 每次选与当前结果点集最近的顶点并入，O(V²)，适合稠密图；Kruskal 按权值从小到大选边、用并查集判环，O(E log E)，适合稀疏图。

> **易错点**：并查集用于 Kruskal 而非 Prim；"存在多条相同权值的边则 MST 一定不唯一"是错的——若这些等权边都不进入最终 MST，形状仍可唯一。

## 最短路径三大算法

[01:00:00 - 01:02:00]

Dijkstra 求单源最短路径，贪心策略，边权为负时得不到正确结果，O(V²)；对每个顶点各跑一次即得全源，O(V³)。Floyd 求任意顶点对之间的最短路径，O(V³) 且常数系数小，但存在负权回路时会一直在环里打转，得不到结果。BFS 可用于无权图的单源最短路径，每向外扩一层路径长度加一。

> **公式**：Dijkstra O(V²)（全源 O(V³)）；Floyd O(V³)。

## 拓扑排序的概念、逆拓扑与复杂度

[01:02:00 - 01:14:00]

拓扑排序针对有向无环图（AOV 网：顶点表示活动），因此也可用来判断有向图是否有环。逆拓扑排序有三种做法：DFS 中把 visit 移到退出递归时输出；把"找入度为 0"改成"找出度为 0"倒着生成；或把拓扑序列压栈后倒序弹出。复杂度取决于存储结构：邻接矩阵 O(V²)，邻接表 O(V+E)。

> **易错点**：图这一章习惯用 V、E 而不是统一写成 n，因为复杂度同时与顶点、边相关，写 O(V+E) 更精确。

## 拓扑排序的代码实现（邻接表）

[01:14:00 - 01:25:00]

算法思想：反复找出入度为 0 的顶点输出，并删除它的出边，重复至结束。实现需要三样额外结构：inDegree 数组记录各顶点入度（否则每次都要全表重扫）、栈存放入度为 0 的顶点、result 数组记录序列。四步：初始化 inDegree 为 0；遍历邻接表用 `p->adjvex` 累加入度；把当前所有入度为 0 的顶点全部入栈；while 栈非空则弹栈写结果，沿边表把邻接点入度减 1，减到 0 就顺手入栈。最后用 count 与顶点数比较：相等返回 true，小于则存在环返回 false。

> **易错点**：入度为 0 的顶点是"全部"入栈，不是只入一个；更新入度时减到 0 要立即入栈，不必再写一轮全表扫描。

## 拓扑排序的三个追问：容器、唯一性与复杂度

[01:25:00 - 01:30:00]

第一，存放入度为 0 顶点的栈可以换成队列，二者都正确，差别只在同一时刻多个入度为 0 顶点时的输出次序：栈为逆序、队列为顺序，因此会得到不同的拓扑序列，这正是选择题考点。第二，拓扑序列唯一的充要条件是任一时刻待处理的入度 0 顶点都只有一个，实现上在 push 后判断栈/队列大小是否大于 1，大于 1 即不唯一。第三，空间 O(V)，时间看存储结构（邻接表 O(V+E)、邻接矩阵 O(V²)）。

> **易错点**：判唯一要卡在"每一时刻"，不是最后检查序列长度；前年真题就在这段代码上加问了唯一性。

## 关键路径与 AOE 网

[01:30:00 - 01:32:00]

AOE 网用边表示活动、顶点表示事件。求关键路径靠四个量：事件最早发生时间 ve、事件最晚发生时间 vl、活动最早开始时间 e、活动最迟开始时间 l，关键活动就是 l-e=0 的活动，它们连成关键路径（源点到汇点的最长路径）。关键路径可能不止一条；只加快某一个关键活动，工期不一定缩短。

> **公式**：关键活动判据 l(i) - e(i) = 0。

## 关键路径真题：多条关键路径下的缩短工期

[01:32:00 - 01:35:00]

选择题不必列 ve/vl 表格，直接穷举所有路径取最长者即可。该真题有三条长度相同的关键路径（1-3-5-6、1-3-2-5-6、1-3-2-4-6），此时必须缩短"公共关键活动"或覆盖所有分支：B 是公共活动但选项中没有；D 覆盖其中两条、F 覆盖第三条，故答案选 C。若只缩短 G，某条路径不再是最长，工期根本不缩短。

> **易错点**：少写一条关键路径必然做错；加快工期必须让所有关键路径同时变短。

## 用拓扑排序判断图中是否有环

[01:35:00 - 01:38:00]

有向图：不断把入度为 0 的顶点入队，出队后删其出边（邻接点入度减 1），队列空后比较已访问顶点数是否等于 n，小于 n 说明有环。无向图不能用入度，因为一条无向边在两端都会被计数，改为把所有度 ≤ 1 的顶点入队，后续处理与有向图完全一致。

> **易错点**：无向图判环的入队条件是"度 ≤ 1"（含度为 0 的孤立顶点），不是"度 = 0"。

## DFS 判环（一）：三色状态与边的分类

[01:38:00 - 01:48:00]

把顶点分成三种状态：尚未发现（镂空/白）、已发现但邻接点未遍历完（绿，等价于在递归栈中）、全部遍历完成（蓝），同时记录 discover time 与 finish time 两个时间戳。据此把边分成三类：指向已完成后代（disc 更小）的是前向边，不构成环；指向尚未完成顶点（祖先）的是回边，构成环；指向已完成的非后代（disc 更大，堂兄弟关系）的是跨边，不构成环。

> **定义**：有向图存在环 ⇔ DFS 过程中出现回边。前向边与跨边都不能作为有环的证据。

## DFS 判环（二）：无向图与代码状态判定

[01:48:00 - 01:51:00]

无向图的判环条件更宽松：出现跨边同样说明有环，回边当然也算。代码中用 -1/0/1 表示三种状态（也可用 0/1/2，自定义即可）：初始全 -1；访问到顶点置 0；遇到邻接点为 -1 则置 0 递归；有向图中遇到 0 说明存在回边（有环），遇到 1 是跨边（不算环）；无向图中遇到 0 或 1 都说明有环。

> **易错点**：判断依据是"邻接点的状态"，不是"是否访问过"；已访问但状态为 1 与状态为 0 结论完全不同。

## 用有向无环图表示表达式（最少顶点数）

[01:51:00 - 01:55:00]

思路与表达式树一致：找中间的运算符作根，把表达式一分为二递归划分，只是边改为有向边。DAG 的独特之处是可以共享重复子表达式——把重复出现的 a+b、a 等冗余节点删除，把边改指向已有节点复用其结果，本例去重后只需 5 个顶点。该思想即"删除冗余节点、复用已算结果"，与大模型推理中的图编译（算子融合、消除冗余）同源。

> **易错点**：判断"谁除以谁"要按原中缀表达式从左到右读，不要被 DAG 的箭头方向带偏。

## 顺序查找、折半查找与分块查找

[01:55:00 - 01:58:00]

顺序查找对无序表从头查到表尾，对有序表可在值越界处提前判失败，O(n)。折半查找要求顺序存储的有序表，每次与子表中间位置比较后缩半，O(log n)，是有序表查找中最快的方法，见到"有序表查找"应第一时间想到二分。折半查找失败时的比较次数等于折半查找树的树高（与空结点比较的那次不计）。分块查找（索引查找）块内无序、块间有序，效率取决于索引表用折半还是顺序查找。

> **易错点**：ASL 失败时"与空比较"是否计入因结构而异——折半查找树不计，哈希表与顺序表计入，需按题目约定。

> ⚠️ **需回看视频 [01:57:00]**：ASL 失败时与空比较是否计入的规则转写表述跳跃，"顺序表和空比的那次又是算的"与前文并列出现，疑似混入哈希表结论 —— "对于这个折半查找的这个折半查找树来讲，和空节点比的那次是不算的。而这里的顺序表和空比的那次又是算的"

## 折半查找树高度与失败比较次数（真题）

[01:58:00 - 01:59:00]

长度 16 的有序表，二分查找失败的最多比较次数就是折半查找树的高度。折半查找树近似完全二叉树，高度按完全二叉树公式计算，n=16 时得 5，故最多比较 5 次。

> **公式**：折半查找树高（= 查找失败最多比较次数）≈ ⌈log₂(n+1)⌉，n=16 时为 ⌈log₂17⌉ = 5。

> ⚠️ **需回看视频 [01:58:00]**：公式口述与 ASR 均有残缺，"取一个指数"应为"取对数"，需确认写法的准确形式 —— "就是一个 log n 加一向上取整……那你就是对十七啊去取一个指数"

## 二分查找代码题：查找失败时返回插入位置

[01:59:00 - 02:06:00]

题目的关键转化：待插入位置之前的元素都小于 target，之后都大于等于 target，所以问题等价于"在有序数组中找第一个 ≥ target 的下标"。标准模板：`while(left<=right)` 中取 mid，若 `nums[mid] >= target` 则记录 answer=mid 并令 `right=mid-1`，否则 `left=mid+1`，循环结束返回 answer。answer 其实可以省略，直接返回 left。left 必须更新为 mid+1，写成 mid 会死循环。

> **易错点**：`mid = left + (right-left)/2` 防两 int 相加溢出，可用 `>>1` 代替除法（位运算更快）。

## 二叉排序树（BST）

[02:06:00 - 02:10:00]

中序遍历 BST 一般得到升序序列；若题干说得到降序，说明该树是"左大右小"，但仍符合排序树性质。插入分两步：先查找失败的位置，该位置必在叶子处，再插入。删除分三种：叶子直接删；单分支节点用其孩子顶替；双分支节点用中序直接前驱或直接后继替换，转化为前两种情况。查找时间最好 O(log n)，最坏 O(n)（退化为单链）。

> **易错点**：删除某关键字后再插入同一个关键字，树不一定还原——删叶子则 T1=T2；删双分支节点（如 10）则形状改变，须按具体节点分类讨论。

## 平衡二叉树 AVL 与旋转调整

[02:10:00 - 02:12:00]

AVL 的平衡条件是任一节点左右子树高度差绝对值 ≤ 1。失衡分四型：LL 型右单旋一次、RR 型左单旋一次、LR 型先左后右两次、RL 型先右后左两次。更省事的做法是三次重构：定位最小不平衡子树的根、高儿子、高孙子三个节点及夹在其中的四棵子树，按中序重排即可一步到位，无需判型。由于严格平衡，查找、插入、删除均为 O(log n)。

> **公式**：LL→右旋，RR→左旋，LR→先左后右，RL→先右后左；平衡因子 |BF| ≤ 1。

## 最小不平衡子树与删除后的向上传递

[02:12:00 - 02:16:00]

调整以"最小不平衡子树"为单位，即最矮、离操作位置最近的那棵不平衡子树。删除节点后，局部调整完可能使上层重新失衡（例中删 25 后局部调平衡，但根的左子树高 4、右子树高 2），必须继续以新的最小不平衡子树向上调整，直至整棵树平衡。最坏情况下调整沿树高逐层传递到根，删除调整时间为 O(log n)。

> **易错点**：局部子树调整平衡 ≠ 全树平衡，删除操作要一路向上检查到根（像多米诺骨牌）。

## B 树的定义与性质

[02:16:00 - 02:18:00]

B 树是为降低树高、并让单节点存更多关键字而对平衡树做的改进。m 阶指节点最多有 m 个分支（m 个孩子）；节点内指针数 = 关键字数 + 1。非根节点指针数范围为 ⌈m/2⌉ ~ m，对应关键字数 ⌈m/2⌉-1 ~ m-1；根节点特殊，最少 1 个关键字、2 个分支。节点内关键字有序，p_{i-1} 所指子树的所有关键字都小于 k_i。n 个关键字的 m 阶 B 树高度有明确上下界（可由外部节点数 n+1 推出）。

> **公式**：m 阶 B 树非根节点关键字数 ∈ [⌈m/2⌉-1, m-1]，指针数 ∈ [⌈m/2⌉, m]；根节点关键字数 ∈ [1, m-1]。

## B 树的查找与插入（分裂）

[02:18:00 - 02:23:00]

查找只能沿树形结构逐层下行，查找失败必定发生在外部（叶子下一层的空指针）节点。插入两步：先找到外部节点位置插入，再检查是否上溢（关键字数 > m-1）；上溢则分裂，把第 ⌈m/2⌉ 个关键字上移到双亲，左右两半各成新节点。偶数阶时同样取第 ⌈m/2⌉ 个上移。上移可能使双亲继续上溢，一路传递到根；根再分裂则树高加一。例：3 阶 B 树关键字范围 1~2，插入 90 后为 2 个关键字，仍合法。

> **易错点**：三阶 B 树上界是 m-1=2，插入后变 3 个才需分裂；分裂上移的关键字是第 ⌈m/2⌉ 个。

> ⚠️ **需回看视频 [02:21:00]**：偶数阶 B 树分裂上移哪一个关键字的口述残缺（"d二分之m向上取整"疑为"第 ⌈m/2⌉ 个"） —— "我们是让二分之m向上取整，d二分之m向上取整个这个关键字上去"

## B 树的删除（借关键字、合并、过继）

[02:23:00 - 02:28:00]

删除非终端节点的关键字时，用其前驱或后继替换，转化为删除终端节点。终端节点删后若关键字数仍 ≥ ⌈m/2⌉-1，直接结束。下溢且兄弟富余（兄弟关键字数 ≥ ⌈m/2⌉）：向兄弟"借"——双亲关键字下移、兄弟中满足大小关系的那个关键字上移补位（借右兄弟取其中最小者 90，借左兄弟取其中最大者），本质是还给双亲。下溢且兄弟也到下界：双亲关键字下移作粘合剂，与兄弟合并成一个节点，可能引发下溢向上传递。合并后若指针数与关键字数不匹配（如三支只剩一关键字），需从相邻节点过继子树以保证排序树性质。

> **易错点**："兄弟够借"是还给双亲一个关键字、由双亲下来补位，不是兄弟直接把关键字塞给下溢节点；上移的关键字必须满足排序树的大小关系，否则结构非法。

> ⚠️ **需回看视频 [01:43:00]**：删除 60 时对下界关键字与上移关键字的表述前后不一致（先说"下界的关键字是八十，不是九十"，随后又确定把 90 还上去） —— "其实下界的关键字是八十，不是九十啊，这里需要注意"

## AVL 树最少结点数与树高（递推）

[02:28:00 - 02:33:00]

求"n 个节点的 AVL 树最高多少层"，等价于让每个节点的左右子树高度差恒为 1（尽量稀疏）。设 N(h) 为高度 h 的 AVL 树最少节点数，则 N(h) = N(h-1) + N(h-2) + 1，边界 N(0)=0、N(1)=1、N(2)=2。依次得 N(3)=4、N(4)=7、N(5)=12、N(6)=20，故 20 个节点的 AVL 树最高为 6 层。反过来，n 个节点的高度最低就是完全二叉树高度。

> **公式**：N(h) = N(h-1) + N(h-2) + 1，N(1)=1、N(2)=2；n 个节点的高度最低 = ⌊log₂n⌋+1（完全二叉树）。

## B 树结点数与关键字数的极值计算

[02:33:00 - 02:38:00]

这类题没有技巧，只能按定义穷举，关键是根节点特殊（可只 1 个关键字）。高度 2 的 5 阶 B 树最少关键字：根 1 个、第二层每节点 ⌈5/2⌉-1=2 个，共 1+2×2=5。高度 3 的 5 阶 B 树最多关键字：每节点 4 个，三层分别 4、5×4=20、25×4=100，合计 124。54 个关键字的 5 阶 B 树：高度 2 最多 24（不够）；高度 3 最少 17、最多 124（可）；高度 4 最少 53（可）；高度 5 不可能，因为受节点关键字下界与平衡性限制，不能只在底层挂一个节点。

> **易错点**：B 树关键字数 = 指针数 - 1（B+ 树才是相等）；求"最多"时要按上界逐层乘分支数，别漏掉根层。

## B+ 树

[02:38:00 - 02:40:00]

B+ 树是 B 树的变种，关键数量关系是节点内关键字数 = 指针数（严格相等）。所有关键字都集中在最后一层叶子，叶子按序组成单链表；非叶节点只存索引信息。查找有两条路径：沿树形索引自上而下，或直接到叶子层沿链表从左到右顺序扫描。

> **易错点**："叶子层所有关键字都在非叶节点至少出现一次"是错的——B+ 树非叶节点只存分界索引，大量关键字不会出现在上层（这一点与 B 树不同）。

## 红黑树的定义与性质

[02:40:00 - 02:44:00]

红黑树的性质：根节点为黑、外部空节点（NIL）为黑；从任一节点到其所有外部节点的路径上黑节点数相同（黑高平衡）；不允许两个红节点相邻，黑黑相邻允许。全黑的红黑树是合法的。树高介于 log n 与 2log n 之间，属于"适度平衡"而非严格平衡，查找性能略逊于 AVL。它的最大优势是调整时拓扑结构变化为 O(1)，不像 AVL 删除调整最坏 O(log n)。任意合法红黑树都可等价转化为一棵四阶 B 树（每节点 1~3 个关键字）。

> **公式**：红黑树高 h ∈ [log₂(n+1), 2log₂(n+1)]；等价四阶 B 树。

## 红黑树的插入与双红修正

[02:44:00 - 02:47:00]

新插入节点一律染红；若双亲为黑，直接插入即合法。若双亲为红则出现双红相邻：双红修正一做 1~2 次旋转加 2 次染色，修正后立即完成；双红修正二不发生旋转，只染色，可能沿树高向上传递到根。旋转次数为"1 或 2"的原因是局部失衡可能是 LL/RR（转 1 次）或 LR/RL（转 2 次），所以三次重构要会，四种类型的判断也要会。

> **易错点**：双红修正一修完立刻结束；双红修正二只是染色，必须继续向上检查是否仍有双红。

## 红黑树的删除与双黑修正

[02:47:00 - 02:51:00]

删红节点直接删，不影响黑高。删黑节点时若其孩子为红，让孩子顶上并继承颜色，黑高与排序性质均保持。若孩子也是黑（双黑）则分四种：BB1（1~2 次旋转 + 3 次染色，修完即止）、BB2（无旋转 + 2 次染色，修完即止）、BB3（1 次旋转 + 1 次染色，可能继续传递，最坏 O(log n)）、BB4（1 次旋转 + 2 次染色，转化为 BB1 或 BB2）。总体上删除最多 3 次旋转（BB4 一次 + BB1 两次）、最少 0 次。BB1RR 是特殊情况，不能转 B 树，必须直接在红黑树上做三次重构。

> **易错点**：只要发生旋转，修正通常随即完成；只有纯染色（BB2/BB3）才可能继续向上传递。

## 红黑树插入大题（转四阶 B 树）

## 散列表的构造与冲突处理

[03:02:00 - 03:04:00]

散列函数四种：直接定址法、除留余数法（H(k)=k mod p，最常用）、平方取中法、数字分析法。冲突分同义词冲突（散列地址相同）与非同义词冲突。处理冲突两大类：开放定址法（线性探测、平方探测、再散列/双散列、伪随机序列）与拉链法。装填因子 α = 表中元素个数 / 表长。开放定址法会产生聚集现象（鸠占鹊巢）——非同义词抢占地址导致探测链变长，降低效率。

> **公式**：α = n / m；失败 ASL 的分母是可映射地址个数（即 p），不是表长也不是元素个数。

> **易错点**：计算哈希地址时模 p，处理冲突探测时模表长 m，两者不能混。

## 散列表大题：构造散列函数与 ASL

[03:04:00 - 03:12:00]

由 n=7、α=0.7 得表长 m=10；p 要取"小于等于表长的最大素数"，故 p=7。依次插入 20、15、9、33、16、19、22，线性探测解决冲突：16 与 9 冲突属同义词冲突（H 值都为 2），19 探测到 6 号位与 20 冲突属非同义词冲突（线性探测造成）。ASL 成功按每个元素的比较次数求和除以关键字数，本例 = (1+1+1+1+2+3+4)/7 = 13/7。ASL 失败则对每个可映射地址（0~6）按同一探测规则走到空位置为止计比较次数，再除以 p。

> **公式**：ASL成功 = Σ比较次数 / n；ASL失败 = Σ(每个散列地址的探测长度) / p。

## 散列表的删除（逻辑删除）与失败判定陷阱

[03:12:00 - 03:20:37]

散列表删除必须用逻辑删除（打删除标记），不能像顺序表那样物理清空或前移元素，否则后续关键字仍可复用该地址。查找时遇到删除标记不能判失败，必须继续沿探测序列向后走，直到遇到真正的空位置才能确认查找失败。例：删掉 33 后查 19，5 号位是删除标记，需继续探测到 7 号位才找到，查找长度 3；查 11 时从 4 号位起依次比较，直到第 5 次遇到空位才判定失败。只有散列地址本身就是空位（从未存过同义词）才能立即返回失败。

> **易错点**："删除标记"与"空"语义完全不同：删除标记意味着后面可能还有同义词，空则意味着链在这里断了。
