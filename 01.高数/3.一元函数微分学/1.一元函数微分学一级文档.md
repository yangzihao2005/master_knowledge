# 第3讲 一元函数微分学的概念

## 【视频01】第3讲定位：导数与微分的定义

[00:00:00 - 00:03:00]

第3讲是"一元函数微分学"五讲（第3～7讲）的起点，只讲两个概念：**导数的定义**与**微分的定义**。导数的最基本定义是**比值的极限**：`Δy/Δx`，令 `Δx→0` 看该极限是否存在，存在则称导数存在——老师强调"这个太重要了"，是每一届对考生的最起码要求：**看到比值的极限，就要想到导数定义**。比值的极限在几何上反映为割线的极限位置是切线，从而引出切线斜率问题（导数的几何意义）；一阶导数再推广到二阶、三阶直至 n 阶导数。微分的概念同样是重要知识，本讲必须认真掌握。

> **定义**：导数 = 比值的极限——`Δy/Δx` 在 `Δx→0` 时的极限。
> **易错点**：看到"比值的极限"必须条件反射到导数定义，这是每届考生的起码要求，也是命题人的固定出题点。

## 【视频01】一元函数微分学体系：是什么—怎么算—怎么用

[00:03:00 - 00:05:41]

第3～7讲构成完整的一元函数微分学，按"**是什么 → 怎么算 → 怎么用**"三段式展开：第3讲概念（是什么）；第4讲计算（十个点、八种题型，从复合函数一直到高阶导数）；第5～7讲三种应用（怎么用）——应用一几何应用，应用二逻辑（证明）应用，应用三专业应用（数学一、二为物理应用，数学三为经济应用）。复习完这五讲要回到这个总体系融会贯通，清楚每个知识点落在框架的哪个位置。

> **易错点**：知识体系不是开场白——复习完第3～7讲后要能自述"是什么、怎么算、怎么用"的完整框架，把各讲内容挂回体系。

## 【视频02】引例：位移—时间曲线与平均变化率

[00:00:00 - 00:07:00]

引例（小明/公主赶高铁）：位移函数 f(t) 分三段——打车去高铁站（越来越快，曲线由平缓变陡）、到站发现忘带文件（位移停滞一段时间）、事情办砸后匀速走回家（位移匀速减到零），这是实际问题的数学化。取 t 到 t+Δt，`[f(t+Δt)−f(t)]/Δt` 称为位移关于时间的**平均变化率**（例：1 公里 / 10 分钟 = 100 米/分钟）。平均变化率对线性函数有意义（任何区间倾角相同、比值恒定），但刻画不了非线性函数的整体变化：从出家门到回到家首尾同值，平均变化率为 0，什么也看不到；教室温度"今年 20 度、明年还是 20 度"的年平均变化率也是 0。平均变化率是**粗糙的概念**（牛顿当年从温度变化的角度谈起）。

> **定义**：平均变化率 = `[f(t+Δt)−f(t)]/Δt`，函数增量与自变量增量之比。
> **易错点**：整体平均值会掩盖全部中间变化（首尾同值时恒为 0），不能用它刻画变化快慢。

## 【视频02】瞬时变化率与导数的三种记号

[00:07:00 - 00:11:00]

有了极限工具后令 `Δt→0`，若比值极限存在（设为 a），称 a 为函数在该点的**瞬时变化率**；微积分中约定"**变化率**"一词专指瞬时变化率（"瞬时"二字省略不写），不是平均变化率。三种记号：拉格朗日 `f'(t)`（一撇，定义为 t 点的导数）、莱布尼兹 `df/dt`（微商——f 的微分对 t 的微分做商，不是朋友圈那个"微商"）、牛顿 `f 一点 t`。牛顿记号在微积分中基本不用（物理中偶见），拉格朗日、莱布尼兹两种随便用。

> **定义**：瞬时变化率 = `lim(Δt→0) [f(t+Δt)−f(t)]/Δt`；微积分中"变化率"即指瞬时变化率。
> **易错点**：题目说"变化率"不要理解成平均变化率；牛顿记号不在微积分中使用。

## 【视频02】变化率的图像解读：极限、连续与导数的分工

[00:11:00 - 00:14:00]

从图像读变化率：线性函数任意区间倾角相同、变化率恒定；常函数变化率为 0（分子恒为 0，"真正的零"而非无穷小）；下降段变化率为负、上升段为正；切线由平缓到陡峭说明变化率在增大（出租车在加速——同样的 Δt，增量越来越大）。三者分工不同：**极限**只研究函数的变化趋势（趋向于几）；**连续**是最起码要求（现实中位移函数不可能出现跳跃间断，除非"瞬间移动"）；**导数**研究变化的**快慢**——是增、是减还是不变，快怎么增、慢怎么减。

> **易错点**：导数比极限、连续多承担一个任务——刻画变化的快慢（变化率本身还在变），三者不要混为一谈。

## 【视频02】导数的定义：比值的极限

[00:14:00 - 00:18:00]

定义：设 `y=f(x)` 定义在区间 I 上，`x0∈I`，自变量增量 `Δx` **可正可负**（时间不可逆，但其他量如钱可负；Δx→0⁺ 讲"下一刻"，Δx→0⁻ 讲"上一瞬时"，都能研究）。若 `lim(Δx→0) Δy/Δx = lim(Δx→0) [f(x0+Δx)−f(x0)]/Δx` 存在，则称 f 在 x0 **可导**，该极限值称为导数值，记 `f'(x0)`。可导的含义就是**变化率存在**：自变量增加一个单位，函数值大约增加 `f'(x0)` 个单位——这正是微分思想的预告（用这一段代替真实的一段，误差可忽略）。老师强调：导数是什么？**变化率**——"微积分这半壁江山都是变化率的问题"，命题人必在此出题。

> **定义**：`f'(x0) = lim(Δx→0) [f(x0+Δx)−f(x0)]/Δx`，极限存在时称 f 在 x0 可导。
> **易错点**：Δx 可正可负，不是只有正值；"在一点可导"的全部含义就是"这一点的变化率存在"，答题时先落脚到变化率。

## 【视频02】注：增量的广义化与定义的两种等价形式

[00:18:00 - 00:21:00]

注1（增量广义化，老师戏称"狗"记号）：定义中的增量不限于 Δx，**任何趋于 0 的量**都行——`−Δx`、`Δx²`（此时增量恒正）等，考题常在这里做替换。一个量一旦写"趋于 0"，它就**一定不是 0**，作分母完全合法（超实数视角下的 super dog）。注2（两种等价形式）：`[f(x0+Δx)−f(x0)]/Δx` 与 `[f(x)−f(x0)]/(x−x0)` 只差一个平移换元，互为充要；差商式有对称美（分子 f−f、分母 x−x0），实际考试两种各占一半，证明抽象函数时 Δx 式更常用。

> **公式**：`lim(Δx→0) [f(x0+Δx)−f(x0)]/Δx = lim(x→x0) [f(x)−f(x0)]/(x−x0)`。
> **易错点**：趋于 0 的量可放分母（它不是零）；增量位置出现 `−Δx`、`Δx²` 等要能认出这就是导数定义。

## 【视频02】可导的充要条件：左导数与右导数

[00:21:00 - 00:25:00]

注3：三个说法完全等价——"f 在 x0 可导" = "f 在 x0 的导数存在" = "`f'(x0)` 存在"。注4（几乎必考）：**可导 ⇔ 左导数存在、右导数存在且相等**。引例中 t1 点：上一瞬时速度很快（变化率大且为正），下一瞬时突然停下（变化率为 0），变化率发生突变、左右导数不等，故该点变化率不存在——本质是导数用极限定义，极限存在要求左右极限相等。几何上：可导点必有切线（斜的或水平的），但**铅垂切线对应变化率无穷大**，在高等数学中视为导数不存在。故"有切线而导数不一定存在；导数存在一定有切线"。

> **定义**（充要条件）：`f'(x0) 存在 ⇔ f'₋(x0) = f'₊(x0) 都存在且相等`。
> **易错点**：分段点、尖点判别可导必须分左右导数各算一遍；铅垂切线（斜率无穷大）处导数不存在。

## 【视频02】可导必连续：证明与恒等变形手法

[00:25:00 - 00:29:00]

必要条件：**一点可导 ⇒ 该点连续**（反之不然，尖点连续但不可导）。证明正好练导数定义与恒等变形：`f(x0+Δx)−f(x0) = [f(x0+Δx)−f(x0)]/Δx · Δx → a·0 = 0`，即 `lim(Δx→0) f(x0+Δx) = f(x0)`，正是连续的定义。两个高频恒等变形（"没有条件创造条件"）：`a = (a/b)·b`（b≠0）、`a = (a−b)+b`——把未知与已知联系起来，在考试中用过无数次。连续只要求"极限值 = 函数值"，不要求左右变化率一致，故推不出可导。

> **公式**：可导 ⇒ 连续；连续 ⇏ 可导。
> **易错点**：`a=(a/b)·b` 与 `a=(a−b)+b` 是解题基本变形；"可导必连续"是单向箭头，反例就是尖点。

## 【视频02】注：莱布尼兹记号与导数正负的直观理解

[00:29:00 - 00:36:00]

`dy/dx` 型记号（莱布尼兹）比牛顿记号含义更深：牛顿的变化率局限于物理背景，莱布尼兹的研究背景是几何，可扩展到更多实际背景（今天已为"莱布尼兹抄袭牛顿"的冤案平反）。老师用"**对你的努力求导**"作类比（成绩关于努力的变化率）：导数 > 0 时成绩随努力上升，说明努力还不够，应当乘胜追击、继续努力；导数 < 0 时努力增加而成绩下降，说明精力已不足或方法出了问题，应停下来反思、总结、调整方法，而不是盲目加时间；导数 = 0 的最优点很难找到，但可根据正负及时调整。这一段借导数符号理解"客观规律"，与考试无直接关系，但要建立概念。

> **易错点**：莱布尼兹记号 `dy/dx` 是"微分的商（微商）"，普适性强；导数的正负是客观信号，不能凭主观感觉解释。

## 【视频02】注：可导是"点信息"，推不出邻近可导

[00:36:00 - 00:41:00]

一点可导只能推出该点连续，推不出该点附近连续，更推不出附近可导——**连续、可导都是"点信息"**，不能从一个点推广到区间；"区间上可导"是由区间上每个点都可导所组成的。经典反例：`f(x) = x²（x 为有理数）、0（x 为无理数）`，用狄利克雷函数写成 `f(x) = x²·D(x)`，在 0 点：`f'(0) = lim(x→0) f(x)/x = lim(x→0) x·D(x) = 0`（无穷小乘有界仍为无穷小）——0 点可导且连续，但其余点连连续都保证不了。方法提醒：不能用"看得见的趋向方式都相等"穷举验证极限，要借助狄利克雷函数的有界性统一处理。

> **易错点**：`f'(x0)` 存在推不出 `f'(x)` 在 x0 附近存在；区间性质（单调、奇偶等）必须逐点论证后才能下结论。
> ⚠️ **需回看视频 [00:39:00]**：疑似 ASR 识别错误 —— "我这个它实际上是等于这个 x 方乘上 dx 的"（疑为 `x²·D(x)` 狄利克雷函数，由"狄利克雷的办法""有界性"可印证）

## 【视频02】例3.1～例3.2：奇偶性、周期性在求导下的传递

[00:41:00 - 00:51:00]

例3.1(A)：可导偶函数的导函数是奇函数——在泛指点 −x 处写导数定义，凑增量 `−Δx`（"三个狗的位置要一样"），内外恒等变形添负号，得 `f'(−x) = −f'(x)`；(B) 可导奇函数的导函数是偶函数（同理，留作业）。结论：**可导的奇偶函数求导一次，奇偶性互换**。(C)：可导周期函数的导函数仍以 T 为周期——定义中 `f(x+T)=f(x)` 直接把 T 消掉。例3.2：f 二阶可导、以 2 为周期的奇函数，`f(1/2)>0`、`f'(1/2)>0`，比较 `M=f(−1/2)`、`N=f'(3/2)`、`K=f''(0)`：`M=−f(1/2)<0`；`N=f'(3/2)=f'(−1/2)=f'(1/2)>0`（先用周期性减 2，再用奇函数求导为偶函数）；f 奇 ⇒ f'' 奇 ⇒ `f''(0)=0=K`；故 `N>K>M`（选 C）。

> **公式**：可导偶函数的导函数为奇函数；可导奇函数的导函数为偶函数；可导周期函数的导函数同周期。
> **易错点**：证明中的 x 是"泛指点"（区间内任一点）不是特指点；`f''(0)=0` 用到"奇函数在原点有定义则值为 0"；例3.2 是周期性 + 奇偶性的联合使用，一步不能省。

## 【视频02】例3.1(D)：函数有界与导函数有界互不相推

[00:51:00 - 00:55:00]

(D)"可导的有界函数导函数必有界"是**错误命题**：`f(x)=√x` 在 (0,1) 上有界，但 x→0⁺ 处切线铅垂、导数为无穷大，导函数无界。反过来也不成立：导函数有界推不出函数有界——`y=x` 的导数恒为 1 有界，函数却走向正无穷（变化率不高但"日积月累"跑到无穷）。补充结论：可导函数在**闭区间**上导函数有界 ⇒ 函数有界（用拉格朗日中值定理证明，后面讲）。

> **易错点**：函数有界 ⇏ 导函数有界；导函数有界 ⇏ 函数有界。加上"闭区间"条件后才有"导函数有界 ⇒ 函数有界"。

## 【视频02】注：具体函数奇偶性的识别与高阶导数零点

[00:55:00 - 01:02:53]

抽象结论要落到具体函数上：① `f(x)=ln(1−x)−ln(1+x)=ln[(1−x)/(1+x)]` 是奇函数（结构即 `g(x)−g(−x)` 型，也可直接化简验证）；② `f(x)=1/(2^x+1)` 本身无奇偶性，但**减去 1/2 就是奇函数**（图像下移 1/2 个单位），用"减一个加一个"恒等变形：`f(x) = [1/(2^x+1) − 1/2] + 1/2`，求高阶导时加的常数消失，故 `f⁽⁴⁾(0)=g⁽⁴⁾(0)=0`；③ `f(x)=sin(cos x)+cos(sin x)`："内偶则偶、内奇同外"，两项都是偶函数，和仍为偶函数 ⇒ 五阶导为奇函数 ⇒ `f⁽⁵⁾(0)=0`，又由 sin、cos 的 2π 周期性 ⇒ `f⁽⁵⁾(2π)=0`。一般规律：奇函数的偶数阶导、偶函数的奇数阶导（在原点有定义时）在原点为 0。

> **公式**：奇函数在原点有定义 ⇒ f(0)=0；奇函数的偶数阶导数、偶函数的奇数阶导数在原点为 0。
> **易错点**：`1/(2^x+1)−1/2`、`ln[(1−x)/(1+x)]` 这类"表面无奇偶、变形后有奇偶"的函数要积累成条件反射；求高阶导时后加的常数对结果无贡献。

## 【视频03】例3.3：夹逼准则与导数定义求点信息

[00:00:00 - 00:11:00]

f(x) 在 x=0 某邻域有定义，且 `|f(x)| ≤ 1−cos x`，判断 f 在 0 点的性态。解题分三个层次：① **夹逼准则找极限**：`0 ≤ |f(x)| ≤ 1−cos x → 0` ⇒ `|f(x)|→0` ⇒ `f(x)→0`（`lim|f|=0 ⇔ lim f=0` 是充要；若极限是非零常数则不能向右推）；② **特殊点找函数值**：x=0 代入关系式 `|f(0)| ≤ 1−cos0 = 0` ⇒ `f(0)=0`（绝对值 ≤ 0 只能是 0）；两者结合得 `lim f(x) = f(0)` ⇒ f 在 0 点连续；③ **夹逼 + 导数定义找导数**：`0 ≤ |f(x)−f(0)|/|x−0| ≤ (1−cos x)/|x| ~ (x²/2)/|x| = |x|/2 → 0` ⇒ `f'(0)=0`。结论：f 在 0 点**可导且导数为 0**（选 C）。此题老师打 double/triple star，建议背下来。

> **公式**：`lim|f(x)| = 0 ⇔ lim f(x) = 0`；`1−cos x ~ x²/2`。

## 【视频04】微分的引例：正方形面积与线性主部

[00:30:00 - 00:36:00]

微分引例（建议记在心里）：正方形边长由 1 增加 Δx（热胀冷缩、形状不变的假设），面积增量 `ΔS = 2Δx + (Δx)²`——两块细条（各 `1·Δx`）之和 `2Δx` 是**主要部分**，角上小方块 `(Δx)²` 是误差。关键在无穷小比阶：`(Δx)²` 是比 Δx **高阶的无穷小**（不是几倍的关系，是无穷倍地小——`Δx/Δx²` 为无穷大），Δx→0 时可以忽略 ⇒ `ΔS ≈ 2Δx`。增量 = **线性主部**（关于 Δx 的线性运算，只有数乘）+ 高阶无穷小误差，这正是微分概念的原型。

> **易错点**：主要部分必须是 Δx 的**线性**函数（`a·Δx` 形式）；误差必须是 Δx 的高阶无穷小，才能"忽略不计"。

## 【视频04】微分的定义：Δy = aΔx + o(Δx)

[00:36:00 - 00:39:00]

定义：`y=f(x)` 在 x0 及附近有定义，增量 `Δy = f(x0+Δx)−f(x0)`；若存在常数 a 使 `Δy = a·Δx + o(Δx)`，称 f 在 x0 **可微**，线性主部 `a·Δx` 称为 f 在 x0 的**微分**，记 `dy|_{x=x0} = a·Δx`。由导数定义可证 a 就是导数：`Δy/Δx = a + o(Δx)/Δx → a`，而按导数定义 `Δy/Δx → f'(x0)`，故 `a = f'(x0)`，即 **`dy = f'(x0)dx`**。由此得：一元函数**可微 ⇔ 可导**，互为充要。

> **定义**：`Δy = a·Δx + o(Δx) ⇔ f 在 x0 可微`；`dy = f'(x0)Δx = f'(x0)dx`。
> **公式**：一元函数可微 ⇔ 可导。
> **易错点**：微分是"线性主部" `a·Δx`，其中 a 必须是确定常数（即 `f'(x0)`），不能含 Δx。

## 【视频04】Δy 与 dy 的区分：dx = Δx

[00:39:00 - 00:42:00]

`Δy = dy + o(Δx)`，故 **Δy ≠ dy**（差一个高阶无穷小误差），不能把 Δy 写作 dy。取特例 `y=x` 验证：`Δy = Δx`，而 `dy = y'·Δx = 1·Δx = Δx`，此时误差为 0（0 也是高阶无穷小）⇒ **`dx = Δx`**：自变量的微分等于自变量的增量。于是 `dy|_{x=x0}` 既可写 `f'(x0)Δx` 也可写 `f'(x0)dx`；`dy/dx = f'(x0)` 就是导数（切线斜率）。

> **公式**：`dx = Δx`；`Δy = dy + o(Δx)`。
> **易错点**：Δy 与 dy 只差高阶无穷小但不相等；只有自变量才有 `dx = Δx`，函数值增量 Δy ≠ dy。
> ⚠️ **需回看视频 [00:42:00]**：口误/识别错误 —— "所以在微分学里面，我们认为 dx 是等于 dy 的"（应为 `dx = Δx`，紧接的"delta x 呢，就写成了 dx"可印证）

## 【视频04】注：可微的判别三步与几何意义

[00:42:00 - 00:49:00]

判别：首要方法是**看导数**——可微 ⇔ 可导，`f'(x0)` 存在即可微、不存在即不可微。若只给增量信息，用三步法：① 写真实增量 `Δy = f(x0+Δx)−f(x0)`；② 写线性增量 `f'(x0)·Δx`（或先设 `a·Δx`）；③ 验证 `lim(Δx→0) [Δy − aΔx]/Δx = 0`——为 0 则可微（即 `Δy = aΔx + o(Δx)`，充要条件），不为 0 则不可微。含义：用**线性增量代替真实增量**，替代误差是 Δx 的高阶无穷小——用简单量代替复杂量，误差可忽略不计。几何意义（回到本讲开头的图）：切线把 Δy 切成两段，切线上的增量是 `dy = f'(x0)dx`（线性主部），剩下一段是 `o(Δx)`；`dy/dx` 即切线斜率。可微/可导的本质就是"以直代曲、以线性代替真实"。

> **公式**（可微判别）：`lim(Δx→0) [Δy − aΔx]/Δx = 0 ⇔ f 在 x0 可微`。
> **易错点**：三步法第③步的分母是 Δx（不是 (Δx)²）；"可微"的全部含义是线性主部 + 高阶无穷小误差。

## 【视频04】例：由增量表达式求微分

[00:49:00 - 00:52:00]

例：`Δy = y·Δx/(x+√(x²+y²)) + o(Δx)`，且 `f(0)=1`，求 y=f(x) 在 x=0 处的微分。由表达式直接读出线性主部：`dy = y·Δx/(x+√(x²+y²))`，转成更熟悉的形式 `dy/dx = y/(x+√(x²+y²))`（把微分概念推回导数）；代 x=0、y=f(0)=1：`f'(0) = 1/(0+1) = 1`；故 `dy = f'(0)dx = dx`（选 B）。概念题：没有复杂计算，关键是把增量式中的线性主部读出来并转成导数。

> **易错点**：增量表达式中不含 `o(Δx)` 的那个 Δx 线性项就是 dy；题目求"微分"别只答导数。

## 【视频04】例：复合函数的线性主部求 f'(1)

[00:52:00 - 00:55:00]

例：`y = f(x²)`（f 可导），自变量在 x=−1 处取得增量 `Δx = −0.1` 时，Δy 的线性主部为 0.1，求 `f'(1)`。注意 a 是 **y 的导数**不是 f 的导数（y 是 f 与 g(x)=x² 的复合）：`y' = f'(x²)·2x`，故 `y'(−1) = f'(1)·(−2)`。线性主部 `= y'(−1)·Δx = f'(1)·(−2)·(−0.1) = 0.2·f'(1) = 0.1` ⇒ `f'(1) = 1/2`（选 C）。

> **易错点**：线性主部是 `y'(x0)·Δx`，复合函数必须先用链式法则求 y'，千万别直接套 `f'(x0)Δx`。

## 【视频04】例：lim [Δf(1)−df(1)]/Δx = 0

[00:55:00 - 00:58:12]

例：f 在 x=1 可导，Δf(1) 是增量为 Δx 时的函数增量，求 `lim(Δx→0) [Δf(1) − df(1)]/Δx`。`Δf(1)/Δx → f'(1)`（导数定义）；`df(1) = f'(1)dx = f'(1)Δx`，故 `df(1)/Δx = f'(1)`；两者相减极限为 0（答案选 D）。含义要懂：分子是真实增量与线性主部之差 = `o(Δx)`（Δx 的高阶无穷小），除以 Δx 极限为 0 **不代表 Δf(1) 与 df(1) 相等**，只说明差是高阶无穷小。真懂概念的话答案可直接看出。

> **易错点**：极限为 0 的含义是"误差为高阶无穷小"，不是"Δf = df"；dx 与 Δx 混写不影响结果。
