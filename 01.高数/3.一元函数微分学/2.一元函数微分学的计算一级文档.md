# 第4讲 一元函数微分学的计算

## 【视频01】第4讲总览：十个点、八种题型

[00:00:00 - 00:03:00]

第4讲讲**计算**，把考试大纲的要求分成**十个点、八种题型**：十个点 = 两个基本要素 + 八种题型。第一个基本要素是**基本求导公式**，要求"熟稔于心、倒背如流"——这里不是修辞而是事实：积分是求导的逆运算，求导公式倒着走就是积分公式。例：`[ln(x+√(1+x²))]' = 1/√(1+x²)`，倒过来 `∫dx/√(1+x²) = ln(x+√(1+x²)) + C`（积分号与 +C 以后再讲）。第二个基本要素是**四则运算法则**。

> **易错点**：求导公式要"倒背如流"——正着是求导、逆着是积分，现在背熟后面受益。

## 【视频01】八种题型与复习要求

[00:03:00 - 00:05:10]

掌握两个要素后是**八种题型**：①复合函数、②分段函数、③反函数、④隐函数、⑤参数方程确定的函数、⑥对数求导法、⑦幂指函数求导法、⑧高阶导数——考试不会超出这个范围，全是复习的重中之重，八种都重要、排不出轻重。要说**最难、区分度最高的是高阶导数**。

> **易错点**：八种题型不分主次、都要拿稳；高阶导数最难，是区分度所在。

## 【视频02】基本求导公式（一）：幂、指、对与"视绝对值而不见"

[00:00:00 - 00:06:00]

基本求导公式：`(x^α)' = αx^(α−1)`（α 为实数即可，不限正整数）；`(a^x)' = a^x ln a`（a>0 且 a≠1），每求一阶导多带一个 ln a，故 **`(a^x)^(n) = a^x (ln a)^n`**（归纳即可得）；a=e 时 `(e^x)' = e^x`，n 阶导仍是 e^x（"不忘初心、始终如一"）。对数：`(log_a x)' = 1/(x ln a)`，`(ln x)' = 1/x`。关键结论：`ln(−x)` 按复合求导结果也是 1/x，故统一记 **`(ln|x|)' = 1/x`（x≠0）**——口诀"**视绝对值而不见**"，真题直接考过（大题第一项就是 ln|x|），命题人要求不要分情况讨论。

> **公式**：`(ln|x|)' = 1/x (x≠0)`；`(a^x)^(n) = a^x (ln a)^n`；`(e^x)^(n) = e^x`。
> **易错点**：ln 求导"视绝对值而不见"，见到 `ln|u|` 直接写 `u'/u`，分开讨论既慢又易错。

## 【视频02】基本求导公式（二）：三角、反三角与常用补充

[00:06:00 - 00:10:00]

推广：`(ln|u(x)|)' = u'(x)/u(x)`（u≠0），同样视绝对值而不见。三角与反三角：`(sin)'=cos`、`(cos)'=−sin`、`(arcsin)'=1/√(1−x²)`、`(arccos)'=−1/√(1−x²)`、`(tan)'=sec²`、`(sec)'=sec·tan`、`(cot)'=−csc²`、`(arctan)'=1/(1+x²)`、`(arccot)'=−1/(1+x²)`、`(csc)'=−csc·cot`。补充常用（第一讲的重要函数）：`[ln(x+√(x²+1))]' = 1/√(x²+1)`、`[ln(x+√(x²−1))]' = 1/√(x²−1)`。老师鼓励在做题中把常用公式不断加进自己的基本公式表，计算起点会更高。

> **易错点**：`(cos)'=−sin`、`(arccos)'=−1/√(1−x²)`、`(cot)'=−csc²` 都带负号；`(tan)'=sec²` 与 `(sec)'=sec·tan` 最易记混，计算中经常出错。

## 【视频02】四则运算法则：和差、积、商

[00:10:00 - 00:22:00]

和差：`(u±v)' = u'±v'`，微分形式 `d(u±v) = du±dv`（一撇即 d/dx）。积：**(uv)' = u'v + uv'**，`d(uv) = u dv + v du`；重要性有二——计算上比和差复杂、且以后常**逆用**。**2015 年真题考过证明乘积求导公式**：用导数定义 + 恒等变形——在 `u(x+Δx)v(x+Δx) − u(x)v(x)` 中加减 `u(x)v(x+Δx)` 一项，两组分别凑出 u'、v' 的定义式，再用"乘积的极限 = 极限的乘积"与"可导必连续"，得 `u'v + uv'`（建议盖住答案自己写一遍，体会定义与恒等变形的作用）。三项相乘按"**不患寡患不均**"：轮流一项求导、其余不动，再相加。商：**除法看成乘法** `u/v = u·(1/v)`，由 `(1/v)' = −v'/v²` 得 **`(u/v)' = (u'v − uv')/v²`**。

> **公式**：`(uv)' = u'v + uv'`；`(u/v)' = (u'v − uv')/v²`；`d(uv) = u dv + v du`。
> **易错点**：乘积求导公式的**证明**考过真题，不能只会套公式；商的导数分子是"上导下不导 − 上不导下导"，符号别反。

## 【视频02】例4.1：百项乘积求导与"经典形式"转化

[00:22:00 - 00:31:00]

例：`f(x) = ∏_{k=1}^{100} [tan^k(πx/4) − k]`，求 `f'(1)`。一百项是"纸老虎"：**因式超过三个一般不要直接求导**，要往课本经典形式（两项乘积）转化。抓特立独行的一项：代 x=1 后只有第一项 `tan(π/4) − 1 = 0`，其余 `1^k − k ≠ 0`；令后 99 项为 g(x)，则 `f(x) = (tan(πx/4) − 1)·g(x)`，成为两项乘积。求导代 x=1：第二项因前因子为 0 整体消失（g'(1) 不用算）；`f'(1) = sec²(πx/4)·(π/4)|_{x=1} · g(1) = (π/2)·(−1)(−2)···(−99) = −(π/2)·99!`。

> **公式**：`sec²(π/4) = 2`；`g(1) = (−1)^99 · 99! = −99!`。
> **易错点**：多项相乘先找"该点为 0 的因子"，其余打包成 g(x)；包装再复杂也往两项乘积转化，不要蛮干一百项。

## 【视频02】复合函数求导的链式法则与记号辨析

[00:31:00 - 00:39:00]

设 `u=g(x)` 在 x 处可导、`y=f(u)` 在 u 处可导，则 **`[f(g(x))]' = f'(g(x))·g'(x)`**：对自变量 x 求导 = 对中间变量求导 × 中间变量对 x 求导。记号辨析（必须分清）：**撇在整个表达式最外头** = 整个复合函数对 x 求导（即 d/dx）；**撇在 f 与 g 之间** = 对中间变量 g(x) 求导（把 g(x) 整体当 u，即 df(u)/du）。形式上 `dy/dx = (dy/du)·(du/dx)`（除一个乘一个）。可用链式求导图（F→U→V→X）辅助书写：三层复合就是三项连乘。考研只需两层、三层（"一层一层剥开它的心"）。

> **公式**：`[f(g(x))]' = f'(g(x))·g'(x)`；三层：`[f(g(h(x)))]' = f'(g(h(x)))·g'(h(x))·h'(x)`。
> **易错点**：撇的位置决定对谁求导；多层复合每层都要乘上内层导数，不能漏。

## 【视频02】一阶微分形式不变性

[00:39:00 - 00:47:00]

由链式法则：`d[f(g(x))] = f'(g(x))g'(x)dx = f'(g(x))d(g(x))`——无论括号里是**自变量还是中间变量**，`df(□) = f'(□)d□` 都成立，这叫**一阶微分形式的不变性**（一元中用得不多，多元中是重点，先认清规则）。练习三例：`d(x²) = 2x dx`；`d(e^{x²}) = e^{x²}d(x²)`；`d((ln x)²) = 2ln x·d(ln x)`——往框里填什么变量都对。

> **定义**：`df(u) = f'(u)du`，u 既可以是自变量也可以是中间变量。
> **易错点**："形式不变"要求框内是同一个整体变量；换元时框与 d 后面的量必须一致。

## 【视频02】例4.2：ln(x+√(x²+a²)) 的导数

[00:47:00 - 00:51:00]

例：`y = ln(x+√(x²+a²))`（a≠0），求 y'(0)。链式求导：`y' = [1 + x/√(x²+a²)]/(x+√(x²+a²))`，通分约分后 = **`1/√(x²+a²)`**；代 x=0 得 `y'(0) = 1/|a|`（`√(a²) = |a|`，要带绝对值）。a=1 时就是第一讲反双曲正弦的导数公式，这次正式推导了一遍。计算要**一气呵成**（"自行车骑得快才稳"），停停写写反而易错。

> **公式**：`[ln(x+√(x²+a²))]' = 1/√(x²+a²)`。
> **易错点**：`√(a²) = |a|` 不是 a；结果先化简（分子分母约掉 x+√(x²+a²)）。

## 【视频02】例4.3：分段 + 复合的链式求导

[00:51:00 - 00:55:00]

例：y = f(f(x)) 型复合（f 为分段函数，一支 `2x−1`、一支 `ln√x`），求 `y'(e)`。不必先复合展开，直接链式：`dy/dx = f'(f(x))·f'(x)`。代 x=e：`f(e) = ln√e = 1/2`；`f'(1/2) = 2`（走 2x−1 支，求导恒为 2）；`f'(e) = (1/2)·(1/x)|_{x=e} = 1/(2e)`（ln√x = (1/2)ln x）。故 `y'(e) = 2·1/(2e) = 1/e`。这类"分段 + 复合"是典型的 5 分填空题：先代值落到具体点，再按分支用公式。

> **易错点**：`f'(f(e))` 要先算 f(e) 判断走哪个分支；`ln√x = (1/2)ln x` 求导别丢系数 1/2。
> ⚠️ **需回看视频 [00:51:00]**：题干缺失/ASR 乱码 —— "y等于f f e比f f x啊，问你y对x求导在x等于e"（分段函数 f 的定义未出现在转写中，据解法推断含 `2x−1` 与 `ln√x` 两支，需对照原题）

## 【视频02】例4.4：三层复合求微分

[00:55:00 - 00:56:51]

例：`y = e^{sin(ln x)}`，求 dy。三层复合一层层剥：`dy/dx = e^{sin(ln x)}·cos(ln x)·(1/x)`，乘上 dx 得 **`dy = e^{sin(ln x)}·cos(ln x)·(1/x) dx`**。也可借一阶微分形式不变性逐层写微分。考试不限定方法，做对即可，核心是链式求导熟练。

> **易错点**：三层复合三个导数因子一个不能少；题目求 dy 记得乘 dx。

## 【视频03】分段函数的导数法则与例4.5（ln|x|）

[00:00:00 - 00:04:00]

分段函数求导两条规则：**分段点用导数定义**——左、右导数分别用两侧表达式各算一遍，都存在且相等才可导；**非分段点用导数公式**——各分支直接求导。例4.5：`y = ln|x|`（x>0 时 ln x，x<0 时 ln(−x)）；x=0 无定义（连定义都没有，谈不上可导）；两侧求导都是 1/x，故 `(ln|x|)' = 1/x`，即"视绝对值而不见"。

> **易错点**：分段点必须左右导数分别计算，不能直接套公式；无定义点直接排除。

## 【视频03】例4.6：含绝对值函数的分段求导与二阶导

[00:04:00 - 00:11:00]

例：`y = |x|·e^{−x}`（e^{−x} 恒正，绝对值只看 x 的符号），求 y''。去绝对值成分段：x>0 时 `x e^{−x}`，x<0 时 `−x e^{−x}`，x=0 时为 0。分段点：`y'₋(0) = lim(−xe^{−x})/x = −1`，`y'₊(0) = +1`，不相等 ⇒ **y'(0) 不存在**，y''(0) 也不存在（一阶导不存在则二阶导必不存在）。非分段点：x>0 时 `y' = (1−x)e^{−x}`；x<0 时 `y' = (x−1)e^{−x}`；再求导：x>0 时 `y'' = (x−2)e^{−x}`，x<0 时 `y'' = (2−x)e^{−x}`。带绝对值的求导是考研命题人的偏好考法。

> **易错点**：别忘了单独讨论分段点的左右导数；两支表达式只差一个负号时导数也只差一个负号，可用此省一半计算。

## 【视频03】反函数的导数：一阶倒数关系

[00:11:00 - 00:14:00]

设 `y=f(x)` 单调、可导且 `f'(x)≠0`，则存在反函数 `x=φ(y)`，且 **`dy/dx = 1/(dx/dy)`**，即 `φ'(y) = 1/f'(x)`——就是恒等变形 `da/db = 1/(db/da)`，导数不为 0 保证分母有意义。注例：`y=arcsin x` 的反函数是 `x=sin y`，`(arcsin x)' = 1/(sin y)' = 1/cos y = 1/√(1−x²)`，一举推出基本公式表里的这条。

> **公式**：`f'(x)·φ'(y) = 1`。
> **易错点**：倒数关系发生在同一点处、对不同自变量的两个导数之间，别把变量张冠李戴。

## 【视频03】反函数的二阶导数公式

[00:14:00 - 00:18:00]

一阶导只是倒数，太简单；**二阶导才有区分度**。`d²y/dx² = d/dx(dy/dx)`，关键一步：`dy/dx = 1/φ'(y)` 是 **y 的函数**，对 x 求导必须先对 y 求、再乘 dy/dx（恒等变形：除以 dy 再乘 dy）。算得 **`y''_{xx} = −x''_{yy}/(x'_y)³`**；同理 **`x''_{yy} = −y''_{xx}/(y'_x)³`**。这两个公式建议背下来——记住就有很高的起点，省去现场推导。

> **公式**：`d²y/dx² = −(d²x/dy²)/(dx/dy)³`；`d²x/dy² = −(d²y/dx²)/(dy/dx)³`。
> **易错点**：`1/φ'(y)` 是 y 的函数，不能直接对 x 求导；公式带负号、分母是三次方。

## 【视频03】例4.7：反函数二阶导数求值
[00:18:00 - 00:23:00]

例：x>0 时 `y = f(x) = 3x² + e^x` 有反函数 x=φ(y)，求 `φ''(3+e)`。不必反解（不好反解、解出来还得再求二阶导）：直接套公式 `φ''(y) = −f''(x)/(f'(x))³`。先换算自变量：`y = 3+e` ⇔ `3x² + e^x = 3+e`，观察得 **x=1**（x>0）；`f'(1) = 6+e`，`f''(1) = 6+e`；代入 **`φ''(3+e) = −(6+e)/(6+e)³ = −1/(6+e)²`**。公式熟就是送分题，记不住就只能现场推、费时且易错。

> **易错点**：`φ''` 的自变量是 y 值，必须先由 y 解出对应 x，再代 f 的各阶导数。

## 【视频03】隐函数求导与例4.8：二阶导求值

[00:23:00 - 00:31:00]

隐函数：`y=y(x)` 由 `F(x,y)=0` 确定，方法是**两边对 x 求导**，凡遇 y 按中间变量复合求导，然后解出 y'。例4.8（"前世今生"，考研特别爱考）：已知 `y'(1)=0`，求 `y''(1)`。步骤：①一阶——方程两边对 x 求导（含 `y³`、`xy²`、`x²y` 类项，乘积与复合并用），代 `y'(1)=0` 后得到关于 y(1) 的方程，解得 `y(1)=0` 或 `−2`；把 y=0、x=1 代回原方程出现"6=0"矛盾，舍去，故 **y(1)=−2**；②二阶——对一阶导式再求导，注意 `(y²)'` 会产生 `(y')²` 项、`xyy'` 是三项相乘"各打一巴掌"，代 x=1、y=−2、y'=0 整理得 `9y''(1) = 4`，即 **`y''(1) = 4/9`**。计算量在考研里只是小菜一碟，考的是快速准确的计算能力。

> **易错点**：二阶求导最易漏 `(y')²`、`xy y''` 这类项；解出 y(1) 后必须代回原方程验根（y=0 是增根）；解完打"#"标记结束。
> ⚠️ **需回看视频 [00:24:00]**：题干缺失 —— "设y等于y(x)由方程所确定啊"（原方程未在转写中出现，据推导含 y³、xy²、x²y 与常数项 6，具体系数未能唯一确定，需对照原题与板书）

## 【视频03】参数方程求导：一阶与二阶（例4.9）

[00:31:00 - 00:38:00]

`x=φ(t)`、`y=ψ(t)` 均可导且 `φ'(t)≠0` 时，求 dy/dx 就把参数 t 当"x、y 的中间人"，**分子分母同除 dt**：`dy/dx = ψ'(t)/φ'(t)`。二阶导：`d²y/dx² = d/dx(dy/dx)`——把已算出的 `dy/dx` 记成 t 的函数 ω(t)（不必写回复杂表达式），再同除 dt：**`d²y/dx² = ω'(t)/φ'(t)`**。例4.9：x=sin t，y=t sin t+cos t，则 `dy/dx = (sin t + t cos t − sin t)/cos t = t`；`d²y/dx² = (t)'/cos t = 1/cos t`，代 t=π/4 得 **`√2`**。

> **公式**：`dy/dx = y'(t)/x'(t)`；`d²y/dx² = [d(dy/dx)/dt] / x'(t)`。
> **易错点**：二阶导**不是** `y''(t)/x''(t)`；必须先把一阶导看成 t 的函数、对 t 求导后除以 x'(t)。
> ⚠️ **需回看视频 [00:35:00]**：题干缺失 —— "设y等于y(x)由参数方程所确定啊，请你求d方y比dx方在t等于四分之派处的值"（具体参数方程未转写出来，据解法推断 x=sin t、y=t sin t+cos t，需对照原题）

## 【视频03】例4.10：参数式与隐式的综合（打星）

[00:38:00 - 00:42:15]

例（打星小综合，真题考过）：x 由参数式给出（`x = arctan t`，`x'(t) = 1/(1+t²)`），y 对 t 却是**隐式**给出——相当于参数式与隐函数表达的综合。思路：`dy/dx = (dy/dt)/(dx/dt)`，其中 dy/dt 用隐函数求导补出——方程两边对 t 求导（y 是 t 的函数）解得 `dy/dt = (y² − e^t)/[2(1−ty)]`，故 **`dy/dx = (1+t²)(y² − e^t)/[2(1−ty)]`**。顺带正名：严格说这叫"参数式"（不含未知量等式），教材习惯叫参数方程。关键是习惯隐函数求导，别被综合形式吓住。

> **易错点**：y 对 t 的导数要按隐函数方法处理；最后别忘除以 x'(t)（即乘 1+t²）。

## 【视频04】对数求导法与例4.11

## 【视频04】高阶导数（一）：归纳法与 sin x 的 n 阶导（例4.14）

## 【视频04】高阶导数（二）：常用高阶导数公式表

[00:24:00 - 00:31:00]

五个常用高阶导数（建议全背；记不住要会快速推导）：`(e^{ax+b})^(n) = a^n e^{ax+b}`；`(sin(ax+b))^(n) = a^n sin(ax+b+nπ/2)`；`(cos(ax+b))^(n) = a^n cos(ax+b+nπ/2)`；`(ln(ax+b))^(n) = (−1)^(n−1)·(n−1)!·a^n/(ax+b)^n`；`(1/(ax+b))^(n) = (−1)^n·n!·a^n/(ax+b)^(n+1)`。共性：复合一层每次多乘一个 a，n 阶共 `a^n`。注意 `ln` 的 n 阶导就是 `1/(ax+b)` 的 n−1 阶导（先撇一次才轮到它）。推导示范（对 `1/(ax+b)` 归纳）：幂次每次降 1、系数依次乘 −1、−2…−n，n 次后得 `(−1)^n n!`，分母升到 n+1 次方。

> **公式**：见上五式，考试不给、自己记。
> **易错点**：`ln` 公式带 `(−1)^(n−1)`、`(n−1)!`、分母 n 次方；`1/(ax+b)` 公式带 `(−1)^n`、`n!`、分母 n+1 次方——两者只差一阶，别对错号。

## 【视频04】例4.15：恒等变形套公式求 y^(n)(0)

[00:31:00 - 00:35:00]

例：`y = (1−x)/(1+x)`，求 `y^(n)(0)`。基本公式只有五个，新函数必须**恒等变形凑向已知公式**：`(1−x)/(1+x) = −1 + 2/(1+x)`；n≥2 时常数 −1 求导消失，只剩 `2·(1/(1+x))^(n) = 2(−1)^n n!/(1+x)^(n+1)`；代 x=0 得 **`y^(n)(0) = 2(−1)^n n!`**（选 A）。这种基本题反而常错、区分度很高——考的是恒等变形意识与公式记忆的准确度。

> **易错点**：先变形再套公式；常数项只影响一阶导，求 n≥2 阶导时自动消失。

## 【视频04】例4.16：抽象函数的递推归纳

[00:35:00 - 00:39:00]

例（抽象型，无具体表达式）：`f'(x) = [f(x)]²`，求 `f^(n)(x)`。不用背公式，**用好关系式反复求导 + 消元**：`f'' = 2f·f' = 2f³`；`f''' = 2·3·f²·f' = 2·3·f⁴`（每步把 f' 换回 f²）；系数是 1、2、3…的连乘即 n!，幂次每次 +1，归纳得 **`f^(n)(x) = n!·[f(x)]^(n+1)`**。注：若出解答题需用数学归纳法严格证明；但这是客观题的考法，考场上归纳出结果即可，不必补证明（命题人不指望）。

> **公式**：`f^(n) = n!·f^(n+1)`（在 `f' = f²` 条件下）。
> **易错点**：递推每一步都要用原关系式消去 f'，否则停留在递推式、出不了通式。

## 【视频04】高阶导数（三）：莱布尼兹公式

[00:39:00 - 00:48:00]

方法二——**莱布尼兹高阶求导公式**（乘积的高阶导）：`(uv)^(n) = Σ_{k=0}^{n} C(n,k)·u^(n−k)·v^(k)`，共 n+1 项，规律"**此消彼长**"：两人求导阶数之和恒为 n（记 `v^(0)=v` 即不求导）。加减平凡：`(u±v)^(n) = u^(n)±v^(n)`。考试中 u、v 选择巧妙：常给一个**低次幂函数**（如 x²，三阶导即为 0），展开只剩前三项，"四两拨千斤"。注1：两函数乘积的高阶导直接用公式；若其中一个不在常用公式表内，就自己做点简单归纳；把困难函数乘一个因子转化成乘积（如 `(arcsin x)'·√(1−x²)=1`，两边求 n−1 阶导得递推）一般只能求某点值，考研很少考，复杂问题以后用泰勒公式（逐项求导/积分）更好。注2：n 不大时系数用**杨辉三角**：1；1 1；1 2 1；1 3 3 1；1 4 6 4 1…

> **公式**：`(uv)^(n) = Σ_{k=0}^{n} C(n,k) u^(n−k) v^(k)`。
> **易错点**：`C(n,k)` 与导数阶数按"此消彼长"配对，一项不落共 n+1 项；选低次幂函数当 v 可截断级数。

## 【视频04】例4.17：(x·e^x)^(n) = (x+n)e^x

## 【视频04】高阶导数（四）：泰勒公式法与展开唯一性

[00:51:00 - 00:57:00]

方法三——**泰勒公式**（泰勒的第二个大用途，第一个是求极限）。三句话：①**抽象展开**：任意阶可导（=无穷阶可导）的函数都能写 `f(x) = Σ_{n≥0} f^(n)(x₀)/n!·(x−x₀)^n`（常在零点展开 `Σ f^(n)(0)/n!·x^n`）——用多项式逼近函数。②**具体展开**：把题目给的具体函数**凑向已知展开式**——`e^x`、`1/(1±x)`、`ln(1+x)`、`sin x`、`cos x`、`(1+x)^α`（记前三项）、`arctan x`、`arcsin x` 等，这是考研对展开式的最高要求，公式不给、必须自己记（每天背一遍、反复记）。③**展开的唯一性**：同一函数展开形式唯一，**比较 `x^n` 的系数**即可解出高阶导数值——抽象展开的系数里正好含 `f^(n)(0)`，具体展开的系数是已知的。

> **公式**：`f(x) = Σ f^(n)(0)/n!·x^n`；系数比较：`f^(n)(0)/n! = [x^n]系数`。
> **易错点**：展开式必须背（考题不给）；比较系数前先把两边幂次对齐（必要时换下标、通项同步改写）。

## 【视频04】例4.19：x²·2^x 的 n 阶导（莱布尼兹 vs 泰勒）

[01:03:00 - 01:10:08]

例：`f(x) = x²·2^x`，n≥1 求 `f^(n)(0)`。**方法一（莱布尼兹）**：u=2^x（`(2^x)^(k) = 2^x(ln 2)^k`）、v=x²，三项截断：`(x²2^x)^(n) = 2^x(ln2)^n·x² + n·2^x(ln2)^(n−1)·2x + C(n,2)·2^x(ln2)^(n−2)·2`；代 x=0 只剩第三项（前两项带 x），`2^0=1`、系数 2 与 1/2 约掉，得 **`f^(n)(0) = n(n−1)(ln 2)^(n−2)`**。**方法二（泰勒）**：`2^x` 没有现成展开式，先写 `2^x = e^{x ln 2} = Σ (ln2)^n x^n/n!`（第一讲例1.11 已铺垫），乘 x² 后幂次变 n+2，比较 `x^n` 系数：`(ln2)^(n−2)/(n−2)! = f^(n)(0)/n!`，同样得 `n(n−1)(ln2)^(n−2)`。两法互验。高阶导数计算量大、复杂度高，是热门考点与区分度所在，务必多下功夫。
