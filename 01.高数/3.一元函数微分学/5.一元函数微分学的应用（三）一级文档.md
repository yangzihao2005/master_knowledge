# 第7讲 一元函数微分学的应用（三）

## 【视频01】本讲定位与数学一、二的物理应用考点

[00:00:00 - 00:03:00]

第7讲是整个一元微分学的最后一小块，不涉及过于专业的问题，只用常识性的物理、经济情境。数学一、二考**物理应用**：①两个基本变化率——速度 = 位移对时间的变化率、加速度 = 速度对时间的变化率，配合牛顿第二定律 `F = ma`；②重点是**相关变化率**。相关变化率本质是形式问题而非概念问题（哪个量与哪个量互称相关变化率不强求），按"**三知二求一**"做题即可；这类考题在研究生考试中出现较多。

> **公式**：`v = ds/dt`，`a = dv/dt = d²s/dt²`，`F = ma`。
> **易错点**：速度、加速度、F=ma 是常识性要求，不能等别人讲；相关变化率抓住"三知二求一"，别纠结命名。

## 【视频01】数学三的经济应用框架：经济函数、边际与弹性

[00:03:00 - 00:05:36]

数学三考**复利与连续复利**（重点）和**导数的经济应用**。常见经济函数：需求函数、供给函数一般以**价格 P 为自变量**（价格升高需求下降、供给上升）；成本、收益、利润函数一般以**产量（销量）Q 为自变量**。在此基础上做**边际分析**（边际 = 一阶导数）与**弹性分析**（elasticity：x 变化引起 y 变化的灵敏程度）。2027 考研这部分要好好学——好久没有单独出题了，反而显得重要。

> **易错点**：需求/供给的自变量是价格，成本/收益/利润的自变量是产量；边际就是一阶导数，弹性是"灵敏程度"的度量。

## 【视频02】物理应用的基本关系与"去 t"公式

[00:00:00 - 00:03:00]

物理应用三条基本关系：`v = ds/dt`、`a = dv/dt = d²s/dt²`、`F = ma`（m 质量、a 加速度）。要记住三个公式中的第三个——题目不含 t 时的**去 t 恒等变形**：`a = dv/dt = (dv/ds)·(ds/dt) = v·dv/ds`（分子分母形式上同乘 ds），把 t 消掉；第十五讲微分方程的大题考的就是这个变形。

> **公式**：`a = dv/dt = d²s/dt² = v·dv/ds`。
> **易错点**：`v·dv/ds` 是高频铺垫公式，单独记；没有 t 的题先把 dt 换成 ds。

## 【视频02】相关变化率：三知二求一

[00:03:00 - 00:07:00]

相关变化率：若 `y = f(x)`，而 x、y 又都随 t 变化（均可导），则 `dy/dt = f'(x)·dx/dt`——`dy/dt` 与 `dx/dt` 由 `f'(x)` 联系，这对相互关联的变化率称为**相关变化率**，f'(x) 是联系两者的纽带/桥梁。形式记忆：`dA/dB = (dA/dC)·(dC/dB)`，**三知二求一**。例：冰块质量随时间的变化率 `dM/dt` 可拆为质量对温度的变化率与温度对时间的变化率之比/之积。微分学的物理应用少，积分学的物理应用多。

> **公式**：`dy/dt = f'(x)·dx/dt`；`dA/dB = (dA/dC)·(dC/dB)`。
> **易错点**：求 `dA/dB` 的题先摆出 `dA/dB = (dA/dC)·(dC/dB)` 的架势，再找题目给的中间变化率；除哪个量看题目给什么。

## 【视频02】例7.1：曲线上动点到原点距离的变化率

[00:07:00 - 00:11:04]

例：动点 P 在曲线 `y = x³` 上运动，`l = |OP| = √(x² + x⁶)`，P 的横坐标对时间的变化率恒为 `v₀`，求 P 运动到 (1,1) 时 `dl/dt`。把 l 看成 x 的函数，用 `dl/dt = (dl/dx)·(dx/dt)` 桥接：`dl/dx = (2x + 6x⁵)/(2√(x²+x⁶))`，代 x = 1 得 `8/(2√2) = 2√2`，故 **`dl/dt = 2√2·v₀`**。方法小结：求 `dA/dB` 就摆 `dA/dB = (dA/dC)·(dC/dB)`，其中 `dC/dB` 用题目所给的量。

> **易错点**：这类题是"小综合"，关键是把文字翻译成 `dx/dt` 这类已知变化率；更综合的物理应用要到第十五讲（微分方程）再解决。

## 【视频03】复利计算公式与三种计息情形

[00:00:00 - 00:05:00]

复利公式：本金 A、每期利率 r，m 期后余额 `A_m = A(1+r)^m`（上一期本息整体作下一期本金，逐期连乘）。考试三种情形：①年利率 r、一年付一次利息：t 年后余额 `A(1+r)^t`；②年利率 r、一年付 n 次利息：每期利率 r/n，一年后 `A(1+r/n)^n`，t 年后 **`A(1+r/n)^(nt)`**（t 年共 nt 期）。做题先辨清题目给的计息方式。

> **公式**：`A_m = A(1+r)^m`；一年付 n 次时 `A(1+r/n)^(nt)`。
> **易错点**：一年付 n 次 = 利率除以 n、期数乘 n；t 年对应 nt 期，指数别漏 t。

## 【视频03】连续复利与现值

[00:05:00 - 00:08:00]

情形③**连续复利**（一年支付无穷多次，每个瞬时都计息）：令 `n→∞`，`(1+r/n)^(nt)` 是 1^∞ 型，极限 `e^{lim(nt·r/n)} = e^{rt}`，故 t 年后余额 **`A·e^{rt}`**。**现值**：若想 t 年后得到 R 元，现在应存入 **`A = R·e^{−rt)`**（由 `A·e^{rt} = R` 两边乘 `e^{−rt}` 解出）；A 称为 R 的现值。连续复利是经济学常识与未定式计算的结合，三种计息方式题目都会明确交代。

> **公式**：连续复利余额 `A·e^{rt}`；现值 `A = R·e^{−rt}`。
> **易错点**：现值公式指数带负号；审题先辨"一年一次 / 一年 n 次 / 连续复利"。

## 【视频03】例7.2：窖藏时间与现值最大（定义式/关系式/约束式）

[00:08:00 - 00:19:52]

例（应用题最高难度）：酒厂新酒若现在（t=0）出售总收入为 R₀；窖藏 t 年按陈酒出售，t 年末总收入 `R = R₀·e^{(2/5)√t}`；银行年利率 r = 6% 且**连续复利**计息；求使总收入现值最大的窖藏时间 t₀。解法是应用题三件套翻译：**定义式**（现值 `A = R·e^{−rt}`）、**关系式**（`R = R₀·e^{(2/5)√t}`）、**约束式**（r = 6%）。联立 `A(t) = R₀·e^{(2/5)√t − rt}`，对 t 求导 `A' = A·(1/(5√t) − r) = 0` ⇒ 唯一驻点 **`t₀ = 1/(25r²)`**；判断 `0 < t < t₀` 时 A' > 0、`t > t₀` 时 A' < 0，先增后减 ⇒ 极大即最大（**一元函数唯一极值必是最值，此结论不能推广到多元**）。代入 r = 0.06：`t₀ = 100/9 ≈ 11` 年。

> **公式**：`A(t) = R₀·e^{(2/5)√t − rt)`；`t₀ = 1/(25r²)`。
> **易错点**：应用题必须做"定义式/关系式/约束式"三件套翻译；"唯一极值即最值"仅对一元函数成立；求出驻点后记得代入约束（利率）算出最终数值。
> ⚠️ **需回看视频 [00:08:00]**：疑似 ASR 识别错误 —— "说A倍的e的rt次方等于r，对了，你欲获得……就是r的这个余额"（应为 `A·e^{rt} = R`：t 年后得到 R 元，求现值 A）
> ⚠️ **需回看视频 [00:13:00]**：疑似 ASR 识别错误 —— "R0乘上e的五分之根号t啊，再减去RT"（指数转写在"五分之根号t"与"五分之二根号t"间摇摆，应为 `(2/5)√t − rt`）
> ⚠️ **需回看视频 [00:17:00]**：口误/识别 —— "先增后减？极大值点，故B是最大值点"（上下文应为"故 t₀ 是最大值点"）

## 【视频04】经济学常见函数：需求、供给、成本、收益、利润

[00:00:00 - 00:09:00]

五类常见经济函数必须分清自变量：①**需求函数** `Q = Q(P)`——需求是欲望与能力的统一（想要且买得起），自变量是价格 P，一般单调减（价升 → 购买力降 → 需求量降）；②**供给函数** `q = q(P)`——自变量是价格 P，一般单调增（价升 → 供给增加）；③**成本函数** `C(Q) = 固定成本 + 可变成本(Q)`——自变量是产量 Q，平均成本 `C̄ = C/Q`（average cost，AC）；④**收益函数** `R(Q) = P·Q`（产销平衡时产量即销量）；⑤**利润函数** `L(Q) = R(Q) − C(Q)`。填空题问需求/供给函数必须以 P 为自变量，问成本/收益/利润必须以 Q 为自变量。

> **定义**：需求 = 欲望与能力的统一；`L(Q) = R(Q) − C(Q)`。
> **易错点**：自变量归属是常考设问点——需求/供给对价格，成本/收益/利润对产量（销量），写错自变量整题丢分。

## 【视频04】边际分析：边际函数与边际值

[00:09:00 - 00:13:00]

f(x) 可导时，`f'(x)` 称为**边际函数**，`f'(x0)` 称为 f 在 x0 的**边际值**。依据是微分近似：`Δy ≈ dy = f'(x0)Δx`，令 `Δx = 1` 得 `f(x0+1) − f(x0) ≈ f'(x0)`——即"已生产 x₀ 件后再多生产一件，函数值大约改变多少"。例：生产 1 万件产品时的边际成本 ≈ 生产第 10001 件产品成本的增加量；导数为正表示同向改变、为负表示反向改变。常用记号：边际成本 `MC = C'`、边际收益 `MR = R'`、边际利润 `ML = L'`。

> **公式**：`f(x0+1) − f(x0) ≈ f'(x0)`。
> **易错点**：边际值的经济解释必须落到"再生产/再销售**一个单位**"（第 x₀+1 件）的口径。

## 【视频04】弹性分析：弹性概念与点弹性的经济意义

[00:13:00 - 00:21:00]

普通变化率 `y'` 不够用，还要看**相对变化幅度**：房价 1000 元/平降 500 是降 50%（震动巨大），10000 元/平降 500 只降 5%。故引入**弹性**（elasticity，弹性系数）：`η = (dy/dx)·(x/y)`——在自变量变化程度的基础上衡量因变量的变化程度，体现 y 对 x 变化的**反应灵敏程度**。点弹性（x₀ 处）的经济意义：**当自变量改变 1% 时，因变量改变 η%**（如 η = 0.54：x 上涨 1%，y 增加 0.54%）。符号也记作 `E_y^x` 或 `E`。

> **公式**：`η = (x/y)·y' = (dy/dx)·(x/y)`。
> **易错点**：弹性是"两个相对变化率之比"，不是普通导数；经济意义统一按"自变量 1% ⇒ 因变量 η%"表述。

## 【视频04】需求、供给、收益的价格弹性

[00:21:00 - 00:24:00]

三类价格弹性都套 `η = (P/y)·y'`：①**需求的价格弹性** `η_d = (P/Q)·dQ/dP`——需求对价格单调减，故按自然公式算一般为**负**；经济意义：提价 1% 则需求量减少 |η_d|%（说"减少 −η_d%"或加绝对值均可）。②**供给的价格弹性** `η_s = (P/q)·dq/dP`——供给单调增，一般为正；提价 1% 供给量增加 η_s%。③**收益的价格弹性** `η_R = (P/R)·dR/dP`——一般为正。

> **公式**：`η_d = (P/Q)·Q'`，`η_s = (P/q)·q'`，`η_R = (P/R)·R'`。
> **易错点**：**若题设声明需求的价格弹性为正，公式里必须补负号**（`η = −(P/Q)·Q'`）——这是命题人埋雷点；按自然公式需求弹性通常是负值。

## 【视频04】例7.3：成本、收益、利润与边际利润

[00:24:00 - 00:31:00]

例：固定成本 6 万元、可变成本 20 元/件、价格函数 `P = 60 − Q/1000`（P 元/件，Q 件）、产销平衡。①`C(Q) = 60000 + 20Q`，`R(Q) = (60 − Q/1000)Q`，`L(Q) = R − C = 40Q − Q²/1000 − 60000`，边际利润 `L'(Q) = 40 − Q/500`。②P = 50 时反解 Q = 10000，`L'(10000) = 20` 元——经济意义：**销售第 10001 件产品时所得利润为 20 元**（数三热门设问，必须会解释）。③利润最大：令 `L'(Q) = 0` ⇒ Q = 20000 ⇒ 单价 **P = 40 元**；`L'' < 0` 的验证可略写（实际问题必有最大值）。

> **易错点**：P = 50 要先反解出 Q 才能代入 L'；经济意义口径是"第 x₀+1 件"；第三问问的是**单价 P**，别答成产量 Q。

## 【视频04】例7.4：dR/dP = Q(1−η) 与收益弹性 1−η

[00:31:00 - 00:38:00]

例：需求量 Q = Q(P) 单调减，需求弹性 η 已知（关系式），`R = R(P)` 为总收益。①证明 `dR/dP = Q(1−η)`：`R = P·Q(P)` 对 P 求导 `dR/dP = Q + P·dQ/dP = Q(1 − η)`（题设 η 取正数，即 `η = −(P/Q)·dQ/dP`）。②收益对价格的弹性 `E_R = (dR/dP)·(P/R) = 1 − η`；代入 `η = 2P²/(192−P²)`、P = 6 得 `E_R = 7/13 ≈ 0.54`——经济意义：价格上调 1%，总收益增加约 0.54%。**结论公式 `dR/dP = Q(1−η)`、`E_R = 1−η` 建议记住**，选择题可直接用。注意题设 `R = R(P)` 是对价格求导——"没有特殊说明时收益是产量的函数"，题设特别声明就按题设。

> **公式**：`dR/dP = Q(1−η)`；`E_R = 1−η`。
> **易错点**：R 对 P 还是对 Q 求导看题设；η 的正负号约定必须与题设一致（正数约定就要补负号）。
> ⚠️ **需回看视频 [00:32:00]**：题干残缺 —— "其中需求弹性是这个，大家看这是不是关系式了"（需求弹性的具体表达式未转写，后文用到 `η = 2P²/(192−P²)`）
> ⚠️ **需回看视频 [00:33:00]**：疑似 ASR 识别错误 —— "一减去eta……那么这就是一加上dQ比dP乘上P比Q"（`Q(1−η)` 的推导步骤转写跳跃、加减号混乱，需对照板书）

## 【视频04】例7.5：弹性决定收益单调性（选择题）

[00:38:00 - 00:40:07]

用 `dR/dP = Q(1−η)` 秒杀选择题：`η < 1` ⇒ `1−η > 0` ⇒ `dR/dP > 0` ⇒ 收益随价格**同向**变动（提价收益增，答案 A）；`η > 1` ⇒ `dR/dP < 0` ⇒ 提价反而收益减少（ΔP > 0 时 ΔR < 0）。记住结论公式，做选择题起点就高。至此一元函数微分学（第 1～7 讲）全部讲完——从函数极限、数列极限到微分学的概念、计算、应用，建议把整个体系整理一遍。

> **易错点**：η 与 1 的大小关系直接决定收益单调性，勿凭"提价必增收"的直觉。
