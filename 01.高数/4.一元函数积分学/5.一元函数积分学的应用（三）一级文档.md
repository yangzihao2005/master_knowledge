# 第12讲 一元函数积分学的应用（三）

## 【视频01】导学：物理应用的考法与命题规律

[00:00:00 - 00:03:00]

物理应用（仅数一、数二）基本考点四个，各是五分小题：变力沿直线做功（或抽水做功）、水压力、引力——四选一挑一个考，不是全考。新大纲后引力、水压力都考过，变力做功、抽水做功是以前考的；命题规律上"去年刚考过"不等于今年不考，可能连考两年，但连考三年可能性小。不要押题（可以预测，做模考卷如八套卷、四套卷），靠实力解决问题。另一个考法是微分学的物理应用——相关变化率：`dA/dB = (dA/dC)·(dC/dB)`。

> **易错点**：四个模型都要复习，别按"刚考过就划掉"的策略取舍；应用题的关键训练是把描述性语言"翻译"成数学语言并引入记号。

## 【视频01】考法补充与新增古鲁金定理、数三经济应用

[00:03:00 - 00:05:18]

物理应用还有第三种可能：微分方程里的物理应用（12 分大题），但太难、得分率低、区分度不高，考的可能性小，仍要复习。新增内容：古鲁金第一定理（数一数二参考，二重积分里还有第二定理）——微元法的示范，过程不必掌握，记结论、好记好用即可。数学三的重点在经济应用：平均值概念，以及边际与总量的关系（用牛顿-莱布尼兹公式处理）；数三真正的重点仍是微分学的经济应用（边际分析、弹性分析）。

> **易错点**：古鲁金定理是应用题，会用公式即可，别背推导；数三的积分学经济应用考得不多，但两个考点（边际→总量、平均值）要清楚。

## 【视频02】变力沿直线做功（仅数一、数二）

[00:00:00 - 00:03:00]

方向沿 x 轴正向、大小随位置变化的力 f(x) 使物体从 x=a 走到 x=b，微元法（以常代变取 dx）得功的微元 `dW = f(x)dx`，总功 `W = int_a^b f(x)dx`。几何上这就是曲边梯形的面积，物理上就是变力沿直线做的功。

> **公式**：`W = int_a^b f(x)dx`，`dW = f(x)dx`。
> **易错点**：微元法的统一操作——取微段、在微段上把变量当常量、累加取极限；应用题第一步是翻译（"A 与 B 成正比"→ `F=kx`）。

## 【视频02】例12.1：铁锤击钉（功相等）

[00:03:00 - 00:08:00]

例：铁钉击入木板，阻力与击入深度成正比（`F=kx`），第一锤击入 1 cm，每次击打做功相等，求第二锤又击入多少。翻译 + 引入记号：`W_1 = W_2` 是联系两次击打的条件；`W_1 = int_0^1 kx dx = k/2`，`W_2 = int_1^(x_2) kx dx = k(x_2²-1)/2`；k、2 约掉得 `x_2² = 2`，即 `x_2 = sqrt(2)`，第二锤又击入 `sqrt(2)-1` cm。要点：把描述性语言翻译成数学语言、适当引入记号后，题目就水到渠成了——训练的是这个前置工作。

> **易错点**："又击入"要减去已有的 1 cm；变力做功问题的积分上下限是深度（位移）区间。

## 【视频02】抽水做功（仅数一、数二）

[00:08:00 - 00:13:00]

将容器中的水（密度 ρ）全部抽出需做功。微元法：在深处 x 取厚度 dx 的水层，近似看成柱体，体积 `A(x)dx`，重力 `ρg A(x)dx`，抽出的位移是 x（提到水面/容器顶），故 `dW = ρg x A(x)dx`，`W = int_a^b ρg x A(x)dx`（常数 ρg 可外提）。关键任务只有一个：确定任意位置 x 处的水平截面面积表达式 A(x)——容器不规则时截面随 x 变，其余都是常量。

> **公式**：`W = ρg int_a^b x A(x)dx`。
> **易错点**：位移是"该层水到抽出位置的距离"（坐标系向下建、从小到大积分更顺）；截面面积表达式是唯一变量来源。

## 【视频02】例12.2：倒圆锥容器抽水做功

[00:13:00 - 00:17:00]

例：倒圆锥容器高 a、上底半径 b，装满水，从容器顶抽出，求做功。建坐标系（原点在顶、向下为 x 正向）；由相似三角形 `r/(a-x) = b/a` 得 `r = b(a-x)/a`，截面 `A(x) = πb²(a-x)²/a²`；代公式 `W = int_0^a ρg x·πb²(a-x)²/a² dx`，算得 `W = (1/12)ρgπ a²b²`。掌握"找截面 + 定位移 + 套公式"这类基本问题就足够了。

> **易错点**：相似三角形把 r 用 x 表示是唯一几何工作；积分 `int_0^a x(a-x)²dx = a⁴/12` 要算准。

> ⚠️ **需回看视频 [00:15:00]**：疑似 ASR 识别错误/公式残缺 —— "所以是 b 的平方 a 的平方 a 一减 x 的平方"，截面面积应为 `A(x) = πb²(a-x)²/a²`。

## 【视频02】静水压力（仅数一、数二）

[00:17:00 - 00:23:00]

水面下平板所受的压力默认是静水压力（动载荷另当别论，表述严谨些）。压力 = 压强 × 面积：在水深 x 处取厚 dx 的水平矩形条，宽为 `f(x)-h(x)`（两侧曲线 `y=f(x)`、`y=h(x)` 之差，注意坐标系铅垂轴是 x、水平轴是 y，曲线写成 y 关于 x 的函数），面积 `dS = (f(x)-h(x))dx`，压强 `ρgx`（该条上视为常数），压力微元 `dF = ρgx·(f(x)-h(x))dx`，`P = int_a^b ρgx(f(x)-h(x))dx`。关键：确定水深 x 处的宽度；压强随深度线性变化。

> **公式**：`P = ρg int_a^b x·w(x)dx`（w(x) 为水深 x 处的宽度）。
> **易错点**：宽度是两曲线横向之差（不是高度）；微元法"以常代变"的合理性来自高阶无穷小 + 取极限。

## 【视频02】例12.3：等腰直角三角形板的水压力

[00:23:00 - 00:27:00]

例（近年数二考过的五分送分题）：斜边长 2a 的等腰直角三角形板铅直沉没，斜边与水面相齐。建系（水面为 x=0 或 y=0 向下），由等腰直角三角形几何关系，水深 y 处的宽度为 `2(a-y)`；`P = int_0^a ρg y·2(a-y)dy = 2ρg(a³/2 - a³/3) = (1/3)ρg a³`。坐标轴记 x 记 y 互换无妨，公式不会写错。

> **易错点**：宽度表达式 2(a-y) 来自对称性 + 斜边斜率 1；积出来是 `ρga³/3`，别漏 ρg 与系数。

## 【视频02】引力：细杆对质点（仅数一、数二）

[00:27:00 - 00:29:50]

长 l、线密度 μ 的均匀细直杆，在距其右端 a 处有质量为 m 的质点 M，求引力。万有引力只对质点成立，故用微元法：取杆上 dx 段（质量 μdx 当质点），`dF = G·μdx·m/(a-x)²`（x 为杆上点的坐标，原点在杆右端、杆在 [-l,0]，故距离是 a-x），累加 `F = int_(-l)^0 Gμm/(a-x)² dx = Gμm·l/(a(a+l))`。这是微元法的经典基本应用。

> **公式**：`dF = G m μ dx/(a-x)²`，`F = int_(-l)^0 dF`。
> **易错点**：距离平方里的 (a-x) 要用坐标算清正负；微元质量 μdx 扮演万有引力公式里的 m₁。

> ⚠️ **需回看视频 [00:27:00]**：疑似 ASR 识别错误 —— "有一个质量是小m的质点大M"，质点记号与质量记号混写（质点记作 M、质量为小 m），公式中只出现小 m。

## 【视频03】三心概念：质心、重心与形心

[00:00:00 - 00:06:00]

质心 = 物体的质量分布中心（物体固有特性，质量分布不变则唯一确定）；重心 = 重力分布中心，均匀重力场（g 是常数）下重心与质心重合，考研中认定"重心 = 质心"（非均匀重力场下可能不重合，不作要求）；形心 = 几何图形的分布中心，是几何量不是物理量。密度 ρ 是常数（均质）时形心 = 质心；但 ρ 未必是常数，故形心不一定等于质心/重心——三心重合需"g 均匀 + ρ 常数"同时成立。

> **定义**：质心（质量分布中心）、重心（重力分布中心，考研中 = 质心）、形心（几何分布中心）。
> **易错点**：形心 = 质心的前提是均质（ρ 常数）；三心概念是古鲁金定理的铺垫，必须分清。

## 【视频03】离散质点系的质心与力矩

[00:06:00 - 00:12:00]

一维两质点（挑扁担模型）：支点 x̄ 处力矩平衡 `(x̄-x_1)m_1g = (x_2-x̄)m_2g`，解得 `x̄ = Σx_i m_i / Σm_i`——离散系统的质心坐标公式（n 个质点同理，二维再加 `ȳ = Σy_i m_i / Σm_i`）。其中分子 `Σx_i m_i`（或含 g）称为该系统对相应轴的力矩。这是形式上的启发：质心 = 力矩 ÷ 总质量。

> **公式**：`x̄ = Σ x_i m_i / Σ m_i`（离散系统）。
> **易错点**：力矩的参照轴要说清（对 y 轴的力矩含横坐标 x_i）；离散公式是连续化推导的模板。

## 【视频03】对任意轴的力矩与物质曲杆（连续系统）

[00:12:00 - 00:21:00]

推广一：对任意直线 `L0: ax+by+c=0` 的力矩——把质点坐标换成点到直线的距离 `r_i = |ax_i+by_i+c|/sqrt(a²+b²)`，`M_L0 = Σ r_i m_i`。推广二：离散变连续（物质曲杆，线密度 ρ(ξ,η)）：微元质量 `dm = ρ ds`，力矩 `M_L0 = int r(s)ρ(s)ds`（分 n 段、取极限的微元法精髓，过程不要求掌握）。质心到轴的距离 `r = M_L0 / M`；ρ 是常数时上下约掉，得到形心（= 质心）到轴距离的纯几何表达式。这套推导是古鲁金定理的预备知识，只需领会形式。

> **公式**：`r(形心到轴) = M_L0 / M`；点到直线距离公式见上。
> **易错点**：ρ 常数才能约掉换成形心；连续化后积分变量改回 x、y，弧微分 ds 与弧长 L 呼应。

## 【视频03】古鲁金第一定理：A = 2πLR

[00:21:00 - 00:30:00]

对比视角：曲线绕 `L0` 旋转一周的侧面积微元 `ΔA_i = 2πr_i Δs_i`，累加得 `A = int 2π r ds`；它与力矩式 `M_L0 = int ρ r ds` 分子一致（差常数 2π），ρ 常数约掉后即得古鲁金第一定理：`A = 2π L R`——旋转曲面的侧面积 = 2π × 曲线段长度 L × 形心到旋转轴的距离 R（形心 (x̄,ȳ)）。条件：知道形心位置与形心到转轴的距离，且弧长好求。例：单位圆 `x²+y²=1` 绕 x=2 旋转一周的表面积——L=2π（周长），形心 (0,0) 到 x=2 的距离 R=2，`A = 2π·2π·2 = 8π²`，比传统切片法快得多。

> **公式**：`A = 2π L R`（L 弧长，R 形心到转轴距离）。
> **易错点**：定理是应用题工具，记结论会用即可（推导过程不做要求）；R 是形心到转轴的距离，不是别的点。

## 【视频03】古鲁金第二定理：V = 2πSR

[00:30:00 - 00:36:00]

推广到平面有界区域 D（连续可求面积）：对轴的力矩 `M_L0 = int ρ r dσ`，体积微元旋转一周 `ΔV_i = 2πr_i Δσ_i`，与第一定理完全同构（ρ 常数约掉面密度后一个是面积、一个是弧长），得古鲁金第二定理：`V = 2π S R`——旋转体体积 = 2π × 平面区域面积 S × 形心到旋转轴的距离 R。两定理对仗记忆：`A = 2π L R`（曲线→侧面积）、`V = 2π S R`（区域→体积）。

> **公式**：`V = 2π S R`（S 平面区域面积，R 形心到转轴距离）。
> **易错点**：适用前提是能算出 S 与 R；R 一律指形心（均质时即质心）到转轴距离。

## 【视频03】例14.16：sin x 所围区域绕 y=-x 的体积

[00:36:00 - 00:39:00]

例：`y=sin x`（0≤x≤2π）与 x 轴所围区域绕直线 `y=-x` 旋转一周的体积。直接算相当困难，用古鲁金第二定理：形心在 (π,0)（两拱关于 x=π 对称），到直线 x+y=0 的距离 `R = π/sqrt(2)`；面积 S = 4（一拱 2、两拱 4）；`V = 2π·4·π/sqrt(2) = 4sqrt(2)π²`。前提是 S 与 R 都能方便地求出来。

> **易错点**：对称性先定形心（两拱正负相抵，形心在对称轴上）；点到直线距离公式 `|x̄+ȳ|/sqrt(2)`。

## 【视频03】例14.17：用古鲁金第二定理求形心

[00:39:00 - 00:42:17]

例（作业，y 拔不做要求）：`(x-1)²+y²=1` 与 `(x-2)²+y²=4` 及 x 轴围出区域 D，求 x̄。反向用古鲁金第二定理：绕 y 轴旋转则形心到转轴距离恰是 x̄，`V = 2πS·x̄`。V 用柱壳法（大减小）算得 `7π²`；`S = (π·2² - π·1²)/2 = 3π/2`；故 `x̄ = V/(2πS) = 7/3`。ȳ 的计算要动用二重积分公式，学有余力再做。这类题是考研常见考法——公式拆出来的小零件都简单。

> **易错点**：绕 y 轴转时 R = x̄；面积是两个半圆之差（除以 2）；求形心是古鲁金定理的反向应用。

## 【视频04】积分学的经济应用（仅数三）

[00:00:00 - 00:02:00]

数三经济应用三块：微分学的经济应用（边际分析、弹性分析）是重中之重；微分方程中的变化率建方程；积分学的经济应用考得不多，主要是两个考点——①边际函数求总量：由牛顿-莱布尼兹公式，`C(x) = C(0) + int_0^x C'(t)dt` 等；②经济量的平均值：`y拔 = (1/(b-a)) int_a^b f(x)dx`。

> **公式**：边际 → 总量（牛顿-莱布尼兹）；`y拔 = (1/(b-a))int_a^b f dx`。
> **易错点**：固定成本即初始条件 C(0)；边际是导数，总量是积分，二者用牛顿-莱布尼兹衔接。

## 【视频04】例12.4：边际成本、需求弹性与最大利润

[00:02:00 - 00:06:38]

例：已知边际成本 `C'(x) = 4 + x/4`、固定成本 `C(0)=1`，需求弹性（产量对价格）`(dx/dp)(p/x) = -p/(8-p)`（p<8；需求随价格递减故添负号，现代考题会明确给出 0<p<8），最大需求量 8（p=0 时 x=8，即微分方程初始条件），求利润最大时的产量与价格。解题链：①牛顿-莱布尼兹求 `C(x) = 1 + 4x + x²/8`；②弹性式分离变量积分（`dx/x = dp/(p-8)`）得 `x = 8-p`（即 `p = 8-x`）；③收益 `R = xp = 8x - x²`；④利润 `L = R - C`，令 `L'(x)=4-(9/4)x=0` 得唯一驻点，`L''<0` 即最大值。现在这类题多为小题（填空），可能只考其中一步，但全过程要清楚。

> **易错点**：弹性公式要带负号并注意 p 的范围；初始条件有两处（C(0) 与 x(0)=8）；利润最大用一阶导零 + 二阶导负 + 唯一性。

> ⚠️ **需回看视频 [00:02:00]**：疑似 ASR 识别错误/符号不清 —— "产品产量对价格求导，再乘上 P 比上 X…等于 P 比上 8 减 P…要添个负号"，需求弹性等式应为 `(dx/dp)·(p/x) = -p/(8-p)`。
