## 【视频02】原函数的定义与不定积分的概念

[00:00:00 - 00:04:00]

设 f(x) 定义在区间 I 上，若存在可导函数 F(x)，使 I 内任意一点都有 F'(x)=f(x)，则称 F 是 f 在 I 上的一个原函数。定义强调"区间上每一点"：一点可导只是点的性质，必须逐点成立才能谈原函数。若 F 是 f 的原函数，则 F(x)+C（C 为任意常数）求导仍为 f(x)，故 F+C 是 f 的全体原函数。全体原函数记作 `int f(x)dx = F(x)+C`，称为 f 在区间 I 上的不定积分；该记号仅是全体原函数的记号，不含定积分的意义。

> **定义**：F 是 f 在区间 I 上的原函数 <=> F 在 I 上可导且 `F'(x)=f(x)` 对 I 内每一点成立；`F(x)+C` 为全体原函数，称不定积分。
> **公式**：`int f(x)dx = F(x) + C`（C 为任意常数）。
> **易错点**：原函数定义必须指明区间并逐点成立；不定积分只是全体原函数的记号，没有后面定积分的含义。

## 【视频02】例8.1：由不定积分定义确定函数 f(x)

[00:04:00 - 00:08:00]

例：设 0<x<1，某表达式的不定积分为 `arcsin x + C`，求 f(x)（选择题）。按原函数定义建立关系：对 `arcsin x` 求导得 `1/sqrt(1-x^2)`，即 F' 等于被积函数，代入已知表达式解出 `f(x)^2 = (1-x^2)^(-3/2)`。再令 `x^2 = t` 得 `f(t) = (1-t)^(-3/2)`（0<t<1），换回自变量即 `f(x) = (1-x)^(-3/2)`，故选 B。同时明确：谈 F 求导等于 f 必须指明区间，本题即在 (0,1) 上成立，没给区间则原函数无从谈起。

> **公式**：`(arcsin x)' = 1/sqrt(1-x^2)`。
> **易错点**：这类题按定义由 F'=f 建立等式即可，不必死记题型；求出 f 关于 x^2 的表达式后必须换元还原自变量；原函数关系必须指明区间。

## 【视频02】例8.2：分段函数原函数的判定

[00:08:00 - 00:15:00]

例：f 为分段函数（带 (1-x²) 因子及复合），选它的原函数（考研常考的概念题）。判定标准两条：①候选 F 必须处处可导，因而处处连续；②F' 必须恰为 f。A 选项在 x=0 处左右极限为 0 与 1，不相等，有跳跃间断点，不连续必不可导，故没有资格做任何函数的原函数。B 选项连续性过关，但求导得 `-(x+1)cos x`，与 f(x)=`(x+1)cos x` 差一负号，故不是它的原函数。C 选项在 0 处左右极限不等，排除；由唯一性选 D（D 在 0 处连续、可导且分别求导等于 f）。

## 【视频02】原函数存在定理

[00:15:00 - 00:20:00]

这是本讲极重要的结论（老师强调 triple star，建议至少听两遍，逐个细节搞清）。结论一：连续函数必有原函数，确定无疑。结论二：含第一类间断点（跳跃、可去）或无穷间断点的函数，在包含该间断点的区间上一定没有原函数。结论三：震荡间断点则不确定——可能有可能没有，何时有何时没有后续详细分析。考纲内点的性质共五种：连续、跳跃、可去、无穷、震荡，可据此列表对照。讨论原函数存在性必须先指明区间，不给区间则拒绝回答。

> **定义**：原函数存在定理——连续必有原函数；含跳跃/可去/无穷间断点（该点在讨论区间内）必无原函数；震荡间断点不确定。
> **易错点**：存在性问题必须指明区间；跳跃、可去、无穷三种间断点一律判"无原函数"，不可混淆；震荡是"不知道"，不能一律判无。

## 【视频02】定积分的几何直观：曲边梯形面积

[00:20:00 - 00:27:00]

为解释"连续函数必有原函数"，先给出 `F(x) = int_a^x f(t)dt` 的几何背景。矩形面积是底乘高；曲边梯形的高逐点变化，黎曼的办法是把 [a,b] 无限细分——分成无穷多段且最长一段的长度趋于零——每小条近似看成小矩形，面积为 `f(t)·dt`，从 a 到 b 累加即 `int_a^b f(t)dt`，称为定积分。对连续函数，这种无限切分近似一定做得到。

> **公式**：`int_a^b f(t)dt` 表示曲边梯形面积（积分记号的严格来源后面正式讲）。
> **易错点**：积分号由面积图形转 90° 而来的说法只是老师临时比划的直观示意，不是记号的真正来源，不要当定义记。

## 【视频02】变上限积分函数

[00:27:00 - 00:30:00]

上限写常数 a、b 时，`int_a^b f(t)dt` 是确定的面积；一旦上限写成变量 x（约定 x 为变量），x 移动则面积随之变大变小，即面积取决于 x，是 x 的函数，称为变上限积分函数，图形上是 a 在下、x 在上的动态面积。它比中学的函数概念复杂：积分的上限就是自变量。这一形式是考研必考内容，试卷上不会只出现一次，务必重视。

> **定义**：`F(x) = int_a^x f(t)dt` 称变上限积分函数，其值随上限 x 变化。
> **易错点**：变上限积分是函数不是数值；该形式为考研必考且反复出现。

## 【视频02】连续函数必有原函数的证明思路（导数定义转化）

[00:30:00 - 00:37:00]

要证：f 在 [a,b] 连续时，`F(x) = int_a^x f(t)dt` 在 [a,b] 上可导且 F'=f（此证明考研真题考过，基础阶段暂不作要求，但回看时必须会）。思路：可导即导数定义的极限存在，`F'(x) = lim_(dx->0) [F(x+dx)-F(x)]/dx`，其中 x 是 [a,b] 内泛指的点。由变限积分的几何意义，`F(x+dx) - F(x) = int_x^(x+dx) f(t)dt`（大矩形面积减小矩形面积，剩窄条），于是待求极限化为 `lim_(dx->0) [int_x^(x+dx) f(t)dt]/dx`。难点：分子是积分（面积），分母是普通长度，二者不可直接比，需要引入积分中值定理。

> **公式**：`F'(x) = lim_(dx->0) [F(x+dx)-F(x)]/dx`；`F(x+dx)-F(x) = int_x^(x+dx) f(t)dt`。
> **易错点**：x 是区间内泛指的点，不要写成固定点 x0；把差值改写为 x 到 x+dx 的积分这一步是证明关键，依赖变限积分的几何意义。

## 【视频02】积分中值定理

[00:37:00 - 00:40:00]

f 在 [a,b] 上连续，则至少存在一点 `xi`（ξ∈(a,b)），使 `int_a^b f(t)dt = f(xi)·(b-a)`。几何解释：曲边梯形面积等于以 b-a 为底、f(xi) 为高的矩形面积——高出的部分与不足的部分相互抵消。该定理是后续常用工具，此处提前引入，用于把积分化为函数值乘区间长度。

> **公式**：`int_a^b f(t)dt = f(xi)*(b-a)`，`xi` 在 (a,b) 内。
> **易错点**：使用前提是 f 连续；中值点 xi 由区间内的点给出，不是事先给定的常数。

## 【视频02】证明完成：中值点的夹逼与连续性的使用

[00:40:00 - 00:45:00]

对窄条用积分中值定理：`int_x^(x+dx) f(t)dt = f(xi)·dx`，其中 `x < xi < x+dx`；约掉 dx 后不能停在 f(xi)。当 dx→0 时，由 `x < xi < x+dx` 夹逼得 xi→x，故极限化为 `lim_(xi->x) f(xi)`。最后才用上连续性：由 `lim_(x->x0) f(x)=f(x0)` 的定义（换字母而已）得该极限等于 f(x)，于是 F'(x)=f(x)，证得连续函数必有原函数。

> **公式**：`int_x^(x+dx) f(t)dt = f(xi)*dx`；`lim_(dx->0) f(xi) = f(x)`（`xi -> x`，由连续性）。
> **易错点**：xi 随 dx 变化，是变量不是常数，约掉 dx 后必须再取极限；连续性条件在最后一步才用，前面全程未用。

## 【视频02】总结：连续必有原函数及不定积分与定积分的联系

[00:45:00 - 00:48:34]

确定性结论：若 f 在区间 I 上连续，则 ①`F(x) = int_a^x f(t)dt` 是 f 的一个原函数，加 C 得全体原函数，即 `int f(x)dx = int_a^x f(t)dt + C`；②该变上限积分对 x 求导恰为 f(x)。不定积分记号没有上下限；有上下限的都归入定积分范畴（反常积分是定积分的推广，变限积分与定积分性质同源）。本讲开头即在连续前提下把不定积分与定积分联系起来，这种转化是解题利器，须熟练到信手拈来。

> **公式**：`int f(x)dx = int_a^x f(t)dt + C`；`d/dx [int_a^x f(t)dt] = f(x)`。
> **易错点**：两种积分号长得一样但含义不同——无上下限是不定积分（全体原函数的记号），有上下限是定积分范畴；此结论要熟记，用到时不能现推。

## 【视频03】可导概念回顾与间断点函数原函数存在性总览

[00:00:00 - 00:04:00]

结论先行：含第一类间断点（可去、跳跃）的函数和含无穷间断点的函数，在包含该间断点的区间内一定没有原函数；震荡间断点则打问号，后面逐一分析。为讲清原函数存在定理，先回顾可导定义：邻点与该点的函数差值除以自变量差值的极限存在，即称该点可导，极限值可为零或非零常数。连续只要求函数差值趋于零（`f(t)-f(x) -> 0` 当 `t -> x`），不问趋近速度；可导则要求 `f(t)-f(x)` 是 `t-x` 的同阶或高阶无穷小，对速度提出要求，条件比连续强得多。形象地说，可导时该点与邻近函数值"挨得更近"。

> **定义**：f 在区间 I 上可导，指对任意 `x∈I`，`lim_{t->x} (f(t)-f(x))/(t-x)` 存在，该极限记作 `f'(x)`。
> **公式**：可导 <=> `f(t)-f(x) = O(t-x)`（同阶或高阶无穷小）；连续仅 <=> `f(t)-f(x) -> 0`。
> **易错点**：连续与可导的差别在"速度"——连续不提速度要求，可导对趋近速度有硬要求，不能混用两个定义。

## 【视频03】函数存在与导函数存在的本质区别

[00:04:00 - 00:07:00]

"函数存在"（有定义）对邻近点毫无要求，各点函数值无牵无挂，这是最低要求；"导函数存在"（处处可导）则要求每点邻近的函数值都靠得极近，几何上曲线上每一点都有切线。课本说"导函数也是函数"固然不错，但导函数所能刻画的原函数性质，与"函数存在"下原函数的性质天差地别。谈 `f` 与 `f'` 的区别（tell the differences between f(x) and f'(x)）是后续所有结论的出发点。

> **定义**：函数存在 = 各点有定义、点与点之间无约束；导函数存在 = 处处可导 = 每点切线斜率存在。
> **易错点**：把"f(x) 有定义"与"f'(x) 存在"混为一谈是根本性错误，二者对 f 的约束强度完全不同。

## 【视频03】导函数极限存在必连续：与函数极限的对比

[00:07:00 - 00:11:00]

普通函数在一点极限存在且函数值有定义，推不出函数在该点连续：极限值 `a` 与函数值 `b` 可以不相等。导函数则相反：只要 `f'(x0)` 存在且 `lim_{x->x0} f'(x)` 存在，两者就必然相等，即 `lim_{x->x0} f'(x) = f'(x0)`，导函数在该点必连续。也就是说，导函数的极限值与该点导数值无须预先假设相等，"只要都存在就一定相等"，这是普通函数不具备的强性质。

> **公式**：`f'(x0) = b` 存在且 `lim_{x->x0} f'(x) = A` 存在 => `A = b`，即 f' 在 x0 连续；对比：`lim_{x->x0} f(x) = a` 且 `f(x0) = b` 存在 ≠> f 在 x0 连续。
> **易错点**：普通函数"极限值 = 函数值"必须单独验证；导函数"两端存在即自动相等"。这一对比是命题热点。

## 【视频03】导函数极限等于导数值的证明与几何解释

[00:11:00 - 00:17:00]

证明分两步：第一步把 `f'(x0)` 写成导数定义（0/0 型），第二步用洛必达法则——零比零型、可导、导后极限存在三条件齐备——得到导数定义式等于 `lim_{x->x0} f'(x)`，于是 `A = B`，一气呵成。这一证明步骤 2009 年考研真题直接考过，必须既会严格证明又能斩钉截铁地陈述结论。几何解释：一点的切线是邻近点切线的极限位置，`f'(x)` 在 x0 附近有极限意味着两侧切线斜率充分靠近 `A`，而最终归宿只能是该点切线斜率 `f'(x0)`，不能靠近别的值。

> **公式**：`f'(x0) = lim_{x->x0} (f(x)-f(x0))/(x-x0)` --（洛必达）--> `lim_{x->x0} f'(x) = f'(x0)`。
> **易错点**：洛必达三条件缺一不可（0/0 或 ∞/∞、可导、导后极限存在），此处第三条恰由"导函数极限存在"提供；结论要会证、会说、会用。

## 【视频03】达布定理：导函数的介值性

[00:17:00 - 00:27:00]

函数存在推不出介值性（跳跃间断点在区间上取不到 1 与 2 之间的值，可去间断点同样取不到某些中间值），介值定理只对连续函数成立。但导函数只要处处存在，就一定有介值性（达布定理）：任取两点导数值 `k1 = f'(x1)`、`k2 = f'(x2)`，其间任何数 μ 都能被某个 `f'(ξ)` 取到；几何上即"看得到的两条切线斜率之间的一切斜率，曲线上必有对应切线"。证明用辅助函数 `F(x) = f(x) - μx`，由两端单侧导数符号排除区间端点取最值，闭区间连续函数最值必在内部取到，内部最值点是极值点，由费马定理 `F'(ξ) = 0` 得 `f'(ξ) = μ`（与例题 6.3 同源）。

> **定义**（达布定理）：f 在区间上可导，则 f' 取到其任意两个导数值之间的一切值（介值性），不要求 f' 连续。
> **公式**：设 `F(x) = f(x) - μx`，证 `F'(ξ) = f'(ξ) - μ = 0`，即 `f'(ξ) = μ`。
> **易错点**：介值性只用到"可导"，不依赖导函数连续；忘记证明思路要回看例题 6.3。

## 【视频03】导数保号性与第一类间断点无原函数

[00:27:00 - 00:33:00]

## 【视频03】震荡间断点函数的原函数存在性：正反例

## 【视频03】导函数性质小结与"处处有切线"的统一认识

[00:46:00 - 00:58:00]

综合前述：可导函数求导后的导函数要么连续，要么含震荡间断点；第一类、无穷间断点都不可能出现。导函数性质三条要记牢：一点的极限存在则在该点必连续；一点处导函数存在则该点不可能是第一类间断点；区间上不等零则保号、原函数必单调。"处处有切线"广义上就是处处可导：如 `y = x^(1/3)` 在 0 点切线铅垂、导数为无穷大，与 `y = x^3`（0 点水平切线）互为反函数，坐标系转 90 度即水平与铅垂互换，故导数无穷大与非零无穷小互为倒数，性质不同于真正不存在；尖点左右切线无法统一才是真不可导。切线斜率不可能突变（介值性保证零与任意小正数之间还有无数个值可取），故导函数无突变，震荡间断点也必须无突变——这正是连续与震荡间断点"统一"的含义。

> **公式**：导函数性质：①`lim_{x->x0} f'(x)` 存在 => f' 在 x0 连续；②f' 无第一类间断点；③区间上 `f' ≠ 0` => f 保号、f 单调。
> **易错点**：导数为无穷大（铅垂切线）与尖点不可导是两回事，前者换视角即"存在"；这些性质辨析正是考研区分度所在。

## 【视频03】震荡间断点的微观本质：sin 型函数的无穷压缩

[00:58:00 - 01:05:00]

`sin x`（`x -> +∞`）与 `sin(1/x)`（`x -> 0`）都是"sin 无穷大"，宏观上没有区别，都无限次取遍 `[-1, 1]`。区别在实现区间：前者在无限延伸的区间上往复，后者把同样的往复压缩进无穷小邻域，在 `x->0+`、`x->0-` 处密集成矩形块状。这种震荡间断点是连续函数无限压缩而来，再压缩也不会断掉，放大无穷倍后依然连续，点点依偎。称其"间断"是不得已：`lim_{x->0} sin(1/x)` 震荡不存在，不能等于该点函数值（如定义为 0），不满足连续定义的等式，故只能叫间断点。

> **公式**：`sin x`（`x->+∞`）与 `sin(1/x)`（`x->0`）同为 `sin(∞)`，实现效果都是在 `[-1, 1]` 间无限次连续取值。
> **易错点**：震荡间断点的"间断"只是不符合连续定义，曲线并未真正断开，这正是它仍可能有原函数的内在原因。

## 【视频04】定积分问题的提出——曲边梯形面积

[00:00:00 - 00:06:00]

定积分与不定积分是两个完全不同的概念，学习时要先把不定积分"放一放"，不要混在一起。规则矩形的面积为底乘高 `S = (b - a) * h`，很好算；若把区间上的常数高换成曲线 `y = f(x)`，则由 `x = a`、`x = b`、x 轴与曲线围成的图形称为曲边梯形，其面积无法用初等的底乘高精确算出。把 `[a, b]` 切成有限段后用小矩形近似，取左端点、右端点或中间点作高结果都不一样，误差不可忽略，因此必须借助微积分的无穷小分析。这正是微积分把"看上去不可能"的事变为可能的地方。

> **定义**：曲边梯形 —— 由曲线 `y = f(x)` 与直线 `x = a`、`x = b` 及 x 轴围成的图形。
> **公式**：矩形面积 `S = (b - a) * h`。
> **易错点**：有限等分后小矩形面积之和只是近似值，误差不能忽略；数学上不允许"大概是多少"式的估计代替精确值。

## 【视频04】定积分的定义：黎曼和四步曲与可积

[00:06:00 - 00:15:00]

定积分定义按"分割、近似、求和、取极限"四步构造。分割：在 `[a, b]` 内插入 n - 1 个分点 `x1, x2, ..., x(n-1)`（记 `x0 = a, xn = b`）分成 n 段，分法完全任意，记 `Δxk = xk - x(k-1)`。近似：在每段 `[x(k-1), xk]` 内任取一点 ξk，以 `f(ξk) * Δxk` 作为该小条的矩形面积（此时误差仍不可忽略）。求和：`Σ(k = 1..n) f(ξk) * Δxk` 得到曲边梯形面积的近似值。取极限：记 `λ = max{Δxk}`，令 `λ -> 0`，所有小段长度同时成为无穷小，若函数连续则相邻函数值也充分靠近，用哪点作高已无区别。若该极限存在且与分法、取点均无关，则称 f(x) 在 `[a, b]` 上可积，此极限值就是定积分。

> **定义**：`f(x)` 在 `[a, b]` 上可积 —— 黎曼和 `Σ f(ξk) Δxk` 在 `λ = max{Δxk} -> 0` 时的极限存在，且与分割方法、ξk 的取法无关。
> **公式**：`∫_a^b f(x) dx = lim_{λ->0} Σ(k = 1..n) f(ξk) * Δxk`，其中 `λ = max{Δxk}`。
> **易错点**：定义中有两处"任意"（任意分法、任取 ξk），极限值必须与两者都无关；λ 是所有小区间长度的最大值，最大值趋于零才能保证每一段都成为无穷小。

## 【视频04】定积分的记号与积分号的来历

[00:15:00 - 00:24:00]

定积分记作 `∫_a^b f(x) dx`：把 `Δxk` 写成微分 `dx`（长度无穷小），ξk 处的函数值就近似写成 `f(x)`（各点无限靠近，取哪点都是 x），`f(x) * dx` 就是底为无穷小、高为 `f(x)` 的小矩形面积——底边长无穷小时"底乘高"是精确的。求和的极限是"无穷项相加"，用拉长 S 形的积分号表示，a、b 是积分的起点与终点。注意：不定积分的 ∫ 只是借用了定积分记号，表示原函数全体，本身没有几何意义；而定积分的积分号才是其真正来源。历史上有"牛顿把 Sorry 拉长成积分号"的轶事，老师明确说这是瞎扯；真正的来源是莱布尼茨——他视积分为求和的升级，把拉丁文 Summa（S-U-M-M-A，求和）的首字母 S 拉长而成，手稿真迹藏于汉诺威莱布尼茨纪念馆。

> **易错点**：同一个 ∫ 记号在不定积分（原函数全体）与定积分（和的极限）中含义完全不同，不能混淆；`dx` 不能漏写。

## 【视频04】定积分的几何意义

[00:27:00 - 00:30:00]

定积分的几何意义随被积函数符号而变。若 `f(x) >= 0`，`∫_a^b f(x) dx` 等于曲线 `y = f(x)` 与 `x = a`、`x = b` 及 x 轴围成的曲边梯形面积；若 `f(x) <= 0`，定积分等于该曲边梯形面积的负值（面积算出 5，积分就是 -5）；若 f(x) 有正有负，定积分是 x 轴上方图形面积减去下方图形面积的代数和。后面有专门针对这一几何意义的例题，需要小心。

## 【视频04】定积分定义的特取形式（n 等分右端点与 [0,1] 常用公式）

## 【视频04】定积分的存在定理（常义可积性）

[00:39:00 - 00:51:00]

定积分的存在性又称常义可积性（黎曼可积），"常义"指区间有限、函数有界。必要条件：积分区间必须有限、函数必须有界——可积必有界。直观解释：若 f 在 `[a, b]` 上无界，则任意分割后至少有一小条上 f 可以任意大，该小条面积可为无穷大，和的极限不存在。考纲规定的两条充分条件：① f 在 `[a, b]` 上连续 ⇒ 定积分一定存在（闭区间连续必有界，且连续使相邻函数值充分靠近，小矩形累加是精确的）；② f 在 `[a, b]` 上有界且只有有限个间断点 ⇒ 定积分存在（有界前提下间断点只可能是可去、跳跃、震荡型，无穷间断点必与有界矛盾；跳跃、抠去一点、有界震荡都不影响面积存在）。老师补充第三条（考纲没有、教材常见）：闭区间上单调函数必有界，也一定可积。总结对比：任意区间上连续 ⇒ 必有不定积分（原函数）；闭区间上连续 ⇒ 必有定积分——连续函数是最理想的条件。

> **定义**：常义可积（黎曼可积）= 区间有限 + 函数有界前提下的定积分存在。
> **易错点**：可积必有界，无穷间断点一定破坏有界性，从而破坏定积分存在；"有界 + 有限个间断点"中的间断点类型不含无穷间断点。

## 【视频04】定积分的两条约定与线性性质

[00:51:00 - 00:54:00]

先记两条规定：上下限相等时积分为零 `∫_a^a f(x) dx = 0`（底边长为零，面积为零，要求 f 有定义）；交换上下限要添负号 `∫_a^b f(x) dx = -∫_b^a f(x) dx`（在两积分都存在的前提下），以后经常用到。性质一：被积函数为 1 的积分等于区间长度 `∫_a^b 1 dx = b - a`（矩形是特殊的曲边梯形）。性质二（线性性质）：常数 `k1, k2` 下，`∫_a^b (k1*f(x) + k2*g(x)) dx = k1*∫_a^b f(x) dx + k2*∫_a^b g(x) dx`，不加证明直接使用。

> **公式**：`∫_a^a f(x) dx = 0`；`∫_a^b f(x) dx = -∫_b^a f(x) dx`；`∫_a^b 1 dx = b - a`；`∫_a^b (k1*f + k2*g) dx = k1*∫_a^b f dx + k2*∫_a^b g dx`。
> **易错点**：换上下限必添负号，漏符号是常见错误；`∫_a^a = 0` 与 `∫_a^b 1 dx = b - a` 是后面积分运算的默认基本事实。

## 【视频04】积分区间可加性与保号性（含绝对值不等式）

[00:54:00 - 00:58:00]

性质三（区间可加性）：无论 a、b、c 大小如何，只要涉及的定积分都存在，就有 `∫_a^b f(x) dx = ∫_a^c f(x) dx + ∫_c^b f(x) dx`——c 不必在 a、b 之间，a、b 谁大谁小也不必管，例如 `∫_5^{-1} f = ∫_5^7 f + ∫_7^{-1} f`。性质四（保号性）：若 `f(x) <= g(x)`，则 `∫_a^b f(x) dx <= ∫_a^b g(x) dx`，即被积函数越大积分越大。常用不等式：`|∫_a^b f(x) dx| <= ∫_a^b |f(x)| dx`。直观理解：左端是有正有负时面积的代数和再取绝对值（如上 5 下 3，得 `|5 - 3| = 2`），右端是先把负部翻正再相加（得 `5 + 3 = 8`），所以右端不小于左端。

> **公式**：`∫_a^b f = ∫_a^c f + ∫_c^b f`（c 任意）；`f(x) <= g(x) ⇒ ∫_a^b f(x) dx <= ∫_a^b g(x) dx`；`|∫_a^b f(x) dx| <= ∫_a^b |f(x)| dx`。
> **易错点**：可加性的 c 位置任意，不必夹在 a、b 之间，也不要求 a < b；`|∫f| <= ∫|f|` 的差别在于"先抵消再取绝对值"还是"先取绝对值再求和"，有正有负时必然是严格不等。

## 【视频04】保号性中等号能否成立的讨论

[00:58:00 - 01:02:00]

回顾极限保号性：带帽法"`f(x) >= 0` 且极限存在 ⇒ `lim f(x) >= 0`"必须保留等号（例：`f(x) = 1/x` 在 `x -> +∞` 时恒正，极限却是 0）；脱帽法"`lim f(x) > 0` ⇒ `f(x) > 0`"不带等号。积分保号性同理要严格区分等号：若 `f(x) - g(x) <= 0` 且不恒为零，令 `h(x) = f(x) - g(x)`，则 h 在某些点处严格小于零，积分是"求和的极限"，面积必有负贡献，故 `∫_a^b f(x) dx < ∫_a^b g(x) dx` 为严格不等号；特例：f(x) 非负连续且不恒为零时 `∫_a^b f(x) dx > 0`。今后用积分保号性时，绝大多数情况不能带等号。老师说明：严格证明放在例题 8.7（下节视频）。

> **易错点**：保号性等号成立当且仅当被积函数之差在区间上恒为零（两函数恒等）；"不恒为零 ⇒ 严格不等号"是命题人常设的陷阱，作答时默认写严格不等号。

## 【视频04】积分估值定理

[01:02:00 - 01:04:00]

设 f(x) 在 `[a, b]` 上有最小值 m、最大值 M，记区间长度 `L = b - a`，则 `m * L <= ∫_a^b f(x) dx <= M * L`。它直接由保号性推出：由 `m <= f(x) <= M` 逐项积分即得。用途是估值——当定积分算不出来时，只要找到 f 的最小、最大值（区间长度很容易算），就能把积分值夹在两个数之间。等号是否成立取决于 f 是否恒等于 m（或 M）。

> **公式**：`m*(b - a) <= ∫_a^b f(x) dx <= M*(b - a)`。
> **易错点**：估值前必须先求 f 在 `[a, b]` 上的最值；f 不恒等于 M（或 m）时，相应一侧应为严格不等号。

## 【视频04】积分中值定理及其证明（变上限积分 + 拉格朗日）

[01:04:00 - 01:08:21]

积分中值定理：若 f(x) 在闭区间 `[a, b]` 上连续，则至少存在一点 ξ，使 `∫_a^b f(x) dx = f(ξ) * (b - a)`。证明要点：闭区间上的连续函数必有原函数，取变上限积分 `F(x) = ∫_a^x f(t) dt` 作为 f 的一个原函数——这是首次用变上限积分表示原函数；再对 F 在 `[a, b]` 上用拉格朗日中值定理，`F(b) - F(a) = F'(ξ) * (b - a)`；其中 `F(b) = ∫_a^b f(x) dx`（把 t 改回 x），`F(a) = ∫_a^a f = 0`（用约定），`F'(ξ) = f(ξ)`（原函数定义），代入即得结论。拉氏定理给出 ξ 属于开区间 `(a, b)`，自然包含于闭区间 `[a, b]`，证明完毕。要点：见到"连续"应立即联想到原函数可写成 `∫_a^x f(t) dt` 形式；该证明方法必须会独立书写。本讲理论部分到此结束，随后进入例题讲解。

> **定义**：积分中值定理 —— f 在 `[a, b]` 连续，则存在 ξ 使 `∫_a^b f(x) dx = f(ξ) * (b - a)`。
> **公式**：`F(x) = ∫_a^x f(t) dt`，`F'(x) = f(x)`；拉格朗日中值定理 `F(b) - F(a) = F'(ξ) * (b - a)`。
> **易错点**：中值定理要求 f 连续（比"可积"强）；ξ 取自开区间 `(a, b)`；证明的关键一步是用变上限积分构造原函数，别只会背结论不会写证明。

## 【视频05】原函数与定积分存在性的判别（例题8.3）

[00:00:00 - 00:06:00]

## 【视频05】和式极限的定积分精确定义与齐次式判别法（例题8.6）

> **定义**：定积分精确定义——`i/n = 0 + (1/n - 0)*i` 是分点，`1/n` 是小区间长度（微分）。
> **公式**：`lim_{n->inf} sum_{i=1}^{n} f(i/n) * (1/n) = int_0^1 f(x) dx`
> **齐次式判据**：$g(n,i)$ 齐次 $\iff$ 把 $n,i$ 同时换成 $tn,ti$ 后 $g(tn,ti)=t^k g(n,i)$，通俗说**每一项中 $n$ 与 $i$ 的次数之和相同**。根号看根号内（$\sqrt{n^2+ni}$ 是 1 次），分式看分子分母各自次数。
> **能凑成定积分的条件**：设分子 $p$ 次、分母 $q$ 次齐次，则 $g=n^{p-q}\Phi(i/n)$；要变成 $\frac1n f(i/n)$ 必须 $q=p+1$（**分母比分子高一次**）。

> **易错点**：判别的对象是 `g(n,i)` 的分子分母关于 n、i 是否齐次；根号式要看根号内的式子，不能带着根号谈次数。

## 【视频05】非负连续不恒为零则积分严格大于零（例题8.7）

## 【视频05】同区间上定积分比大小（例题8.9）

[01:10:00 - 01:13:00]

## 【视频06】变限积分的概念及其与不定积分的联系

[00:00:00 - 00:04:00]

定积分 `int_a^b f(x)dx` 的几何意义是曲边梯形的面积；把上限换成变量 x，每个 `x in [a,b]` 都对应唯一确定的面积值，从而构成以 x 为自变量的函数，称为变上限定积分。同理可让下限变动，或上下限同时变动，统称变限积分。变限积分虽然形式上是函数，但概念与性质仍属定积分范畴，是对定积分的简单推广。若 f 在 `[a,b]` 上连续，则 f 必有原函数，其不定积分可写成变上限积分加任意常数。

> **定义**：`F(x) = int_a^x f(t)dt`（`x` 在 `[a,b]` 上变动）称为变上限定积分，简称变上限积分；上下限均可变动时统称变限积分。
> **公式**：`int f(x)dx = int_a^x f(t)dt + C`（`f` 在 `[a,b]` 上连续）。
> **易错点**：变限积分"是函数"却属定积分范畴，判断它的存在性要用"可积"来说，别与不定积分的概念混为一谈。

## 【视频06】变限积分函数的连续性：可积必连续

[00:04:00 - 00:12:00]

可积即定积分存在，也就是不论怎么分割、怎么取点，黎曼和式极限都存在且唯一；可积必有界。只要 f 在区间 I 上可积，变限积分 F(x) 就存在，并且一定连续——"存在即连续"是变限积分与普通函数的根本区别（普通函数在区间上存在只是各点有定义，未必连续）。证明只需看懂不要求掌握：由 `|f(x)| <= M` 放缩 `|F(x+dx) - F(x)| = |int_x^{x+dx} f(t)dt| <= M|dx|`，令 `dx -> 0` 由夹逼准则得 F 在 x 连续。对比记忆：普通函数有蕴含链"可导 ⇒ 连续 ⇒ 可积 ⇒ 有界"，反向都推不回。

> **定义**：可积 = `f` 在区间上定积分存在（和式极限存在且唯一）；可积必有界。
> **公式**：`|F(x+dx) - F(x)| = |int_x^{x+dx} f(t)dt| <= M|dx| -> 0 (dx -> 0)`
> **易错点**：变限积分只要存在就处处连续，图形不会出现间断点，判断 F 的图形先用连续性排除间断选项。蕴含链方向不可倒推：有界未必可积、可积未必连续、连续未必可导。

## 【视频06】变上限积分的可导性与求导公式（原函数存在定理）

[00:12:00 - 00:16:00]

## 【视频06】含跳跃间断点时变限积分的不可导性

[00:16:00 - 00:21:00]

设 f 在 `[a,b]` 上可积，x0 是 f 唯一的跳跃间断点（其余点连续）。此时 f 有第一类间断点，就没有原函数，所以 F 只能叫 f 的变限积分，不是 f 的原函数——"变限积分可以存在，但不一定是原函数"，概念不能混。F 在非 x0 处可导且 `F' = f`；在 x0 处按导数定义考察左右导数，它们分别等于 f 在 x0 的左、右极限，而跳跃间断点左右极限都存在但不相等，故 F 在 x0 不可导。

> **定义**：跳跃间断点 = 左右极限都存在且不相等；第一类间断点（跳跃、可去）处函数没有原函数。

> **易错点**：不要混概念——f 有跳跃间断点就没有任何原函数，写成什么形式都不是它的原函数；F 在 x0 是"连续但不可导"，连续性不丢。

## 【视频06】含可去间断点时变限积分的可导性及几何解释

[00:21:00 - 00:29:00]

若 x0 是 f 的可去间断点（极限存在但不等于函数值），则 F 在 x0 也可导，且 `F'(x0) = lim_{x->x0} f(x)`；但该极限不等于 `f(x0)`，故 F 仍不是 f 的原函数（可去间断点处 f 同样没有原函数）。几何上：跳跃间断点使 F 的左、右切线斜率不等，图像出现尖点，连续但不可导；可去间断点处 F 左右切线重合、确有切线，可导，但切线斜率取极限值而非 `f(x0)`。F 连续的几何原因：区间缩小时面积增量趋于 0，只可能是变化率突变，不会是函数值跳跃。

## 【视频07】反常积分概念的引入：常义积分的必要条件与两类推广

[00:00:00 - 00:04:00]

定积分（黎曼积分，即常义积分）存在有两个必要条件：积分区间有限、被积函数有界。破坏任一条件后定积分一定不存在，但对应曲边梯形的面积仍可能存在，因此需要把定积分概念推广为反常积分（旧教材称广义积分）。破坏区间有限性引出无穷区间上的反常积分，破坏有界性引出无界函数的反常积分。反常积分是否"存在"最终归结为相应极限是否存在，故结果可能收敛、也可能发散。

> **定义**：常义积分（定积分）存在的两个必要条件——积分区间有限、被积函数有界；反常积分（广义积分）是对这两方面的推广。
> **易错点**：区间无限或函数无界时定积分一定不存在，但不能据此断定面积（反常积分）不存在；"底边无限长 ⇒ 面积无穷大"是中学式的错误直觉。

## 【视频07】无穷区间上反常积分的定义与敛散性

[00:04:00 - 00:13:00]

设 `F(x)` 是 `f(x)` 在相应区间上的一个原函数，则 `∫_a^{+∞} f(x)dx = lim_{X→+∞} F(X) - F(a)`：下限代常数值，上限以极限方式代入，这就是带极限号的牛顿-莱布尼茨公式。该极限存在则称反常积分收敛，其值即为该极限减 `F(a)`；极限不存在则称发散。例：`∫_1^{+∞} 1/x^2 dx`，原函数为 `-1/x`，代入得 `0 - (-1) = 1`，即底边无限伸长的曲边梯形面积是有限值 1。几何上这是"无穷大 × 无穷小"未定式，能否收敛取决于 `f(x)→0` 的速度能否抵消区间无限的影响，即曲线趋向 x 轴必须足够快。`∫_{-∞}^{b} f(x)dx` 完全对称处理。

> **定义**：`∫_a^{+∞} f(x)dx = lim_{X→+∞} F(X) - F(a)`；极限存在称收敛，不存在称发散。
> **公式**：`∫_1^{+∞} 1/x^2 dx = 1`（原函数 `-1/x`）。
> **易错点**：收敛不要求区间有限，只要求高度趋于零的速度足够快；关键是无穷小的阶数，属未定式 `∞·0`，不能想当然判为无穷大。

## 【视频07】双无穷限反常积分的拆分与柯西主值

[00:13:00 - 00:22:00]

`∫_{-∞}^{+∞}` 同时含两个奇点（±∞），不能直接讨论，必须任取一点 `x0` 拆成 `∫_{-∞}^{x0} + ∫_{x0}^{+∞}`，使每个积分有且仅有一个奇点；两段都收敛时原积分才收敛，任一段发散则整体发散。例：`∫_{-∞}^{+∞} x^3 dx` 不能因被积函数是奇函数就写成 0——`∫_0^{+∞} x^3 dx = +∞` 发散，故原积分发散。错误根源是把 ±∞ 当成相反数（"正无穷加 8 还是正无穷"，对称性即被破坏）。`lim_{R→+∞} ∫_{-R}^{R} x^3 dx = 0` 才是对称的相反数相消，这叫柯西主值积分；它与反常积分并不总是相等，只有在反常积分收敛时才相等。

> **定义**：含两个及以上奇点的反常积分必须拆成若干个各含一个奇点的积分，全部收敛才称收敛（"发散 + 发散可能收敛"的极限直觉在此不成立）。
> **公式**：`∫_{-∞}^{+∞} f(x)dx = ∫_{-∞}^{x0} f(x)dx + ∫_{x0}^{+∞} f(x)dx`（两段均收敛才收敛）。
> **易错点**：不能用"奇函数在对称区间上积分为零"处理 `∫_{-∞}^{+∞}`；`lim_{R→+∞} ∫_{-R}^{R}` 是柯西主值，与反常积分概念不同，仅收敛时相等。

## 【视频07】无界函数反常积分（瑕积分）：瑕点、定义与敛散性

[00:22:00 - 00:31:00]

使 `f(x)` 在该点邻域内无界的点 `x0` 称为瑕点（也称奇点）；无界不一定是无穷大（如无界震荡型），但考试中几乎都是趋于无穷大的情形，几何上对应铅垂渐近线。若 `a` 是 `[a,b]` 上唯一瑕点，`∫_a^{b} f(x)dx = F(b) - lim_{x→a+} F(x)`；若 `b` 是唯一瑕点，`∫_a^{b} f(x)dx = lim_{x→b-} F(x) - F(a)`；极限存在称收敛，不存在称发散——这是带极限号的牛顿-莱布尼茨公式。若瑕点 `c` 在区间内部，必须拆成 `∫_a^{c} + ∫_c^{b}`，两段都收敛才收敛。几何上把无穷区间的图旋转 90° 即得瑕积分：一个看曲线趋向 x 轴的速度，一个看趋向铅垂渐近线的速度。

> **定义**：瑕点是使 `f(x)` 在其邻域内无界的点；瑕积分是无界函数的反常积分，与要求有界的定积分（常义积分）不是同一概念，故与"定积分存在必有界"不矛盾。
> **公式**：`∫_a^{b} f(x)dx = F(b) - lim_{x→a+} F(x)`（`a` 为瑕点）；`∫_a^{b} f(x)dx = lim_{x→b-} F(x) - F(a)`（`b` 为瑕点）。
> **易错点**：瑕点的准确含义是"邻域内无界"而非"趋于无穷大"；判敛前提是每个积分有且仅有一个奇点，多于一个必须拆分，且拆出的各积分须全部收敛。

## 【视频07】反常积分敛散的本质：趋近速度与无穷小、无穷大比阶

[00:31:00 - 00:35:00]

两类反常积分收敛的判据本质相同：只看曲线"靠得是否足够近"，与前面有限部分的面积大小无关。无穷区间积分看 `f(x)→0` 的速度，即无穷小的阶数，阶数越高、趋向 x 轴越快；瑕积分看 `f(x)→∞` 的速度，即无穷大的阶数，阶数越高、升得越快、离铅垂渐近线反而越远。因此反常积分敛散问题归根结底是无穷小、无穷大的比阶问题，前面学的极限与比阶工具在此综合运用。

> **易错点**：不是"趋于零/趋于无穷"就完了，必须"足够快/足够近"，即比阶足够高；敛散性与曲线在有限段上的面积无关。

## 【视频07】无穷区间反常积分的比较判别法与极限形式

[00:35:00 - 00:42:00]

比较判别法：设 `f、g` 在 `[a,+∞)` 上连续且 `0 <= f(x) <= g(x)`，则 `g` 的积分收敛 ⇒ `f` 的积分收敛（大收敛则小收敛），`f` 的积分发散 ⇒ `g` 的积分发散（小发散则大发散），直观即"更靠近 x 轴者更易收敛"。极限形式（更重要）：设 `lim_{x→+∞} f(x)/g(x) = λ`，则 `λ` 为非零有限常数（`f、g` 同阶无穷小，趋零速度相同）时两者同敛散；`λ = 0`（`f` 是 `g` 的高阶无穷小，`f` 趋零更快）时 `g` 收敛 ⇒ `f` 收敛；`λ = +∞`（`f` 趋零更慢）时 `g` 发散 ⇒ `f` 发散。比较法靠不等式放缩，极限形式靠算极限（零比零型），实际做题算极限更常见。

> **定义**：`0 <= f(x) <= g(x)` 时"大收敛 ⇒ 小收敛，小发散 ⇒ 大发散"；极限形式本质是无穷小比阶。
> **公式**：`lim_{x→+∞} f(x)/g(x) = λ`：`λ ∈ (0,+∞)` 同敛散；`λ = 0` 且 `∫g` 收敛 ⇒ `∫f` 收敛；`λ = +∞` 且 `∫g` 发散 ⇒ `∫f` 发散。
> **易错点**：推断方向不能写反（绝非"小收敛 ⇒ 大收敛"）；使用比较法必须先保证 `f、g` 非负，比较对象要选得恰当。

## 【视频07】无界函数反常积分的比较判别法与极限形式

[00:42:00 - 00:47:00]

瑕积分的比较法与无穷区间完全平行：设 `f、g` 在 `[a,b]` 上连续、同以 `x = a` 为瑕点且 `0 <= f(x) <= g(x)`，则 `g` 的积分收敛 ⇒ `f` 的积分收敛，`f` 的积分发散 ⇒ `g` 的积分发散——`g` 更大、趋于无穷更快却收敛，说明它已"足够近"，更小的 `f` 必收敛。极限形式取 `x→a+` 处的极限 `lim_{x→a+} f(x)/g(x) = λ`，此时是无穷比无穷型：`λ` 为非零有限常数（同阶无穷大）时同敛散；`λ = 0`（`g` 是更高阶无穷大、升得快、离铅垂渐近线远）时 `g` 收敛 ⇒ `f` 收敛；`λ = +∞`（`f` 升得更快）时 `g` 发散 ⇒ `f` 发散。几何上把图转 90° 即化为无穷区间情形，两套结论可互相印证。

> **公式**：`lim_{x→a+} f(x)/g(x) = λ`（无穷比无穷型）：`λ ∈ (0,+∞)` 同敛散；`λ = 0` 且 `∫g` 收敛 ⇒ `∫f` 收敛；`λ = +∞` 且 `∫g` 发散 ⇒ `∫f` 发散。
> **易错点**：无穷大阶数越高"上去"越快、离铅垂渐近线越远，方向与无穷小相反，两套极限形式的结论不要记反；比较仍要求非负、同瑕点。

## 【视频07】比较对象的选取与 p-积分的敛散结论

[00:47:00 - 00:56:00]

## 【视频07】p-积分敛散性的推广：同阶替换命题方式

[00:56:00 - 01:01:45]

考试不会只考 `1/x^p` 本身，而是用极限形式把被积函数与 p-积分比较，凡与 `x` 趋零（或趋无穷）速度相同的函数均可同阶替换。由重要极限 `lim_{x→0+} sin x / x = 1` 知 `sin x` 与 `x` 是同阶无穷小，故 `∫_0^1 1/(sin x)^p dx`（写成 `0` 到 `π/2` 也一样）与 `∫_0^1 1/x^p dx` 同敛散：`p < 1`（且 `p > 0`）收敛，`p >= 1` 发散。同理 `x→+∞` 时 `ax + b`（`a > 0`）与 `x` 是同阶无穷大（`(ax+b)/x → a` 为非零常数），故 `∫_1^{+∞} 1/(ax+b)^p dx` 与 `∫_1^{+∞} 1/x^p dx` 同敛散：`p > 1` 收敛，`p <= 1` 发散；此情形不必另加 `p > 0`（即使 `p <= 0`，被积函数在 `+∞` 处不趋于零，仍是反常积分且发散）。命题人可把 `x` 换成任何同阶函数，题目由此千变万化，核心是比较思想而非背公式。

## 【视频08】反常积分的奇点拆分与无穷小、无穷大等价比较

[00:00:00 - 00:07:00]

反常积分判敛第一步是找出全部奇点（瑕点与无穷远点），并把积分区间拆成每个积分"有且仅有一个奇点"再逐一判敛。例8.15：设 `a>b>0`，讨论 `∫_{0}^{+∞} 1/(x^a + x^b) dx` 的收敛条件——0 是瑕点、`+∞` 是奇点，拆为 `∫_{0}^{1}` 与 `∫_{1}^{+∞}` 两段。`x→0⁺` 时无穷小比阶"次数低者为老大"，`x^a + x^b ~ x^b`，0~1 段等价于 `∫_{0}^{1} 1/x^b dx`，收敛要求 `b<1`；`x→+∞` 时无穷大比阶"次数高者为老大"，`x^a + x^b ~ x^a`，1~+∞ 段等价于 `∫_{1}^{+∞} 1/x^a dx`，收敛要求 `a>1`。故收敛条件为 `a>1 且 b<1`（选 B）。带参数反问题（已知收敛求参数）同理：先把非零因子提出作等价替换，化成熟悉的 p-积分，如某题化为 `x^{2-k}` 量级后由 `2-k>1` 得 `k<1`。

## 【视频08】比较判别法的两种形式与 ln x 因子的"推波助澜"

[00:07:00 - 00:16:00]

## 【视频08】p-积分与 ln x 因子四结论小结及极限形式判敛定理

[00:33:00 - 00:40:00]

判敛知识结构小结：核心思想是比较，手段为放缩法（比大小，靠重要不等式）与计算法（`0/0`、`∞/∞` 极限比阶），另加四个必须记住的常用结论。四个结论：`∫_{0}^{1} 1/x^p dx` 与 `∫_{0}^{1} (ln x)/x^p dx` 均为 `p<1` 收敛、`p≥1` 发散；`∫_{1}^{+∞} 1/x^p dx` 与 `∫_{1}^{+∞} (ln x)/x^p dx` 均为 `p>1` 收敛、`p≤1` 发散——ln x 不改变敛散性。这四个被积函数是比较法的参照物与解题依据。极限形式判敛定理：若 `lim_{x→+∞} x^p f(x) = λ ≥ 0` 且 `p>1`，则 `∫_{1}^{+∞} f(x) dx` 收敛；理由是该极限即 `f(x) / (1/x^p) → λ`，`λ=0` 时分子更小、`λ>0` 时同阶，均与收敛的 p-积分同敛散。该结论正确，可作为定理或选项直接使用。

> **定义**：四个常用结论把 ln x 因子"视为不起作用"，判敛时可直接与 p-积分对照。
> **公式**：`lim_{x→+∞} x^p f(x) = λ ≥ 0`（`p>1`）⇒ `∫_{1}^{+∞} f(x) dx` 收敛。
> **易错点**：四个结论中 0~1 段与 1~+∞ 段的敛散区间恰好互补（`p<1` / `p>1`），极易记混；上述定理默认 `f` 为连续函数。

## 【视频08】联想经典形式与拉格朗日中值定理放缩（例8.17 A）

[00:40:00 - 00:51:00]

考研判敛题的难点在于理解深刻与命题新颖，不必迷信题型套路与"秒杀"技巧，主业是深刻理解概念并掌握解题方法。面对新颖被积函数用"联想经典形式"：把表达式往前倒两步，化到熟悉结构上。例8.17 A：判断 `∫_{1}^{+∞} [ln(1 + 1/x) - 1/(1+x)] dx`——先通分 `ln(1+1/x) = ln(x+1) - ln x`，识别为"f(b)-f(a)"，用拉格朗日中值定理得 `ln(1+1/x) = 1/ξ`（`x<ξ<x+1`），于是 `1/(x+1) < ln(1+1/x) < 1/x`。被积函数大于 0 且小于 `1/x - 1/(1+x) = 1/[x(1+x)] < 1/x^2`，而 `∫_{1}^{+∞} 1/x^2 dx`（p=2>1）收敛，由比较法一般形式得 A 收敛（不是答案）。

> **公式**：`1/(x+1) < ln(1 + 1/x) < 1/x`（`x>0`）；`1/x - 1/(1+x) = 1/[x(1+x)]`。
> **易错点**：放缩比较要求被积函数非负；见到 `ln(x+1) - ln x` 型差值先想拉格朗日中值定理，而不是硬算或套 p-积分结论。

## 【视频08】对数因子的等价化简与 ε 比较法（例8.17 B）

[00:51:00 - 01:03:00]

例8.17 B：`∫_{0}^{+∞} (ln x)/(1+x^2) dx`，0 是瑕点、`+∞` 是奇点，必须拆为 `∫_{0}^{1}` 与 `∫_{1}^{+∞}` 各含一个奇点。0~1 段：`1+x^2` 在 `x→0` 时趋于 1，不起无穷大作用（`∫_{0}^{1} dx/(1+x^2) = π/4` 是常义积分），故该段等价于 `∫_{0}^{1} ln x dx`；由 `lim_{x→0⁺} x^{1/2} ln x = 0` 与 `∫_{0}^{1} dx/x^{1/2}`（p=1/2<1）收敛、比较法极限形式，得其收敛（其值用分部积分可算，属第九讲）。1~+∞ 段：`1+x^2 ~ x^2`，对应 p=2>1，直接收敛（也可乘 `x^{-1/2}` 用 `lim_{x→+∞} x^{-1/2} ln x = 0` 严格证）。故 B 收敛。方法论教训：形似的未必同结构（B 的 0~1 段关键只在 ln x），形不似的（如 A）反而能化到经典形式。

## 【视频08】绝对收敛必收敛与奇函数性质的失效（例8.17 D）

[01:06:00 - 01:13:00]

例8.17 D：`∫_{-∞}^{+∞} (sin x)/(1+x^2) dx`，`-∞` 与 `+∞` 两个奇点，拆为 `∫_{-∞}^{0}` 加 `∫_{0}^{+∞}`。被积函数在对称区间上是奇函数，但反常积分不能直接用"奇函数得 0"，必须先判敛。0~+∞ 段：`|sin x/(1+x^2)| ≤ 1/(1+x^2)`，p=2>1 收敛；注意 `sin x/(1+x^2)` 有正有负，不满足比较法的非负条件，只能对加绝对值后的函数比较。再证"绝对收敛必收敛"：由 `0 ≤ f + |f| ≤ 2|f|` 知 `∫(f + |f|)` 收敛，于是 `∫f = ∫(f + |f|) - ∫|f|` 是收敛减收敛，故收敛。两段对称且均收敛，D 收敛且两块有向面积相消，积分为 0。

> **定义**：`∫ |f|` 收敛称为绝对收敛；绝对收敛必收敛。
> **公式**：`|∫ f| ≤ ∫ |f|`；`0 ≤ f(x) + |f(x)| ≤ 2|f(x)|`。
> **易错点**：变号函数不能直接用比较法一般形式（需非负）；对称区间上"奇函数积分为零"的前提是拆开后各段收敛，否则如 C 选项仍可能发散。加一项减一项再配基本不等式是选择题常考的证明手法。
