# 第10讲 一元函数积分学的应用（一）

## 【视频01】导学：微分学几何应用讲"形态"，积分学几何应用讲"测度"

[00:00:00 - 00:03:00]

第10讲是一元函数积分学的第一个应用——几何应用，与第五讲（微分学的几何应用）对仗而任务完全不同：第五讲研究"形态"（长什么样子）——三种点（极值点、最值点、拐点）、两种性态（单调性、凹凸性）、一种线（渐近线），再结合定义域、奇偶性、周期性画出函数图像；本讲研究"测度"（几何量是多少）——问的是面积、体积、弧长等量的大小，不关心函数形状。

> **定义**：微分学几何应用 = 研究曲线的形态；积分学几何应用 = 研究几何量（测度）的大小。
> **易错点**：两讲任务分门别类，别把"画图找性态"与"算几何量"混在一起；本讲不研究极值、凹凸等性态问题。

## 【视频01】六个考点与测度的含义

[00:03:00 - 00:05:55]

本讲考点口诀（六个）：面积、体积、平均值、弧长、侧面积、形心。其中面积、旋转体体积、函数的平均值（几何上即曲边梯形的平均高）是公共考点（数一、数二、数三都考）；弧长、侧面积、形心是数学三不考、数一数二的内容；另有"平行截面面积为已知的立体体积"，它是旋转体体积的特例/推广，不单列为知识点。这些量都是数（测度）：面积多大、体积多大、平均高多高、弧长多长、形心在哪。

> **易错点**：先按科目范围定位——数三到"面积、体积、平均值"为止；本讲的正确打开方式是六个字：套公式、做计算。

## 【视频02】面积总说与直角坐标下的面积公式

[00:00:00 - 00:06:00]

用定积分表达和计算平面图形的面积（可推广到收敛的反常积分）。图形分三大坐标系：直角坐标、极坐标、参数方程（参数方程经换元化归直角坐标，故公式只有两个）。直角坐标下 y₁(x)、y₂(x)（y₁ 在上）与 x=a、x=b 围成的面积，微元法得 `S = int_a^b [y_1(x)-y_2(x)]dx`，也可理解为大曲边梯形减小曲边梯形；若上下关系在区间内互换（如在 c 点交叉），面积要加绝对值：`S = int_a^b |y_1(x)-y_2(x)| dx`。

> **公式**：`S = int_a^b |y_1(x) - y_2(x)| dx`。
> **易错点**："所围面积"全是正的（不是代数和），上下交叉时必须加绝对值；剩下的工作就是算一个带绝对值的定积分——套公式，做计算。

## 【视频02】极坐标下的曲边扇形面积公式

[00:06:00 - 00:13:00]

极坐标下曲线 `r=r_1(θ)`、`r=r_2(θ)` 与射线 θ=α、θ=β 所围曲边扇形，微元法：用 θ 的分划切出小曲边扇形，顶角 dθ 很小时近似为三角形（底为弧长 `r dθ`、高为 r），大三角形减小三角形得 `dS = (1/2)(r_2²-r_1²)dθ`，积分得 `S = (1/2) int_α^β |r_2²(θ) - r_1²(θ)| dθ`。考场上不必重新推导：写出 r₁、r₂、α、β 套公式，剩下就是做计算；千万别漏掉系数 1/2（三角形面积公式带来的）。

> **公式**：`S = (1/2) int_α^β |r_2^2(θ) - r_1^2(θ)| dθ`（单条曲线 r(θ) 时 `S = (1/2) int_α^β r^2(θ)dθ`）。
> **易错点**：二分之一绝对不能忘；两曲线谁大谁小时加绝对值保证非负；公式的意义就是省去中间思考、限时抢分。

## 【视频02】例10.1：曲线族围成的面积与数列极限

[00:13:00 - 00:22:00]

例：`y=x^n` 与 `y=x^(n+1)` 所围区域面积 a_n，求 `(sum_{k=1}^n 2a_k)^n` 的极限。联立解得交点 x=0、1（0 到 1 上次数越高越靠下），套公式 `a_n = int_0^1 (x^n - x^(n+1))dx = 1/(n+1) - 1/(n+2)`。裂项相消：`sum 2a_k = 2(1/2 - 1/(n+2)) = 1 - 2/(n+2)`，故原式 = `(1 - 2/(n+2))^n`，是 1^∞ 型，用 `u^v = e^(v(u-1))` 得 `e^(-2)`。这类题是"面积作外壳、极限作内核"的典型综合：面积好求时不会只考面积，往往会再挂数列与极限。

> **易错点**：识别 1^∞ 未定式（底趋于 1、指数趋于 ∞）；数列极限计算中归结原则（n 换 x）熟练后可直接书写。

## 【视频02】参数方程下的面积：换元思想（例10.2）

[00:22:00 - 00:34:00]

参数方程 `x=x(t), y=y(t)` 下求面积，本质是定积分换元法的变相考察：曲线确定 y=f(x)（f 复杂到写不出），但 `f(x(t)) = y(t)`（同一对应点函数值相同），于是 `S = int_a^b f(x)dx` 三换（被积函数、dx=x'(t)dt、上下限换成 t 的范围）化为 `S = int_α^β y(t) x'(t)dt`。例10.2（打星）：平摆线一拱 `x=a(t-sin t), y=a(1-cos t)` 与 x 轴围成的面积，由 y=0 定出 t=0、2π（对应 x=0、2πa），得 `S = a² int_0^(2π) (1-cos t)² dt`。摆线图形要自己记住（考试不给图）。

> **公式**：参数方程面积 `S = int_α^β y(t)·x'(t)dt`（换元三换而来）。
> **易错点**：f 写不出来没关系，`f(x(t))=y(t)` 就是换元的意义；上下限要换成 t 的取值；这是历年考试的失分重灾区——变量关系没搞清楚。

## 【视频02】参数方程的变量关系与摆线一拱面积（例10.2 计算）

[00:34:00 - 00:39:00]

变量关系用最简例子讲透：`x=2t, y=t²` 时 `y = (x/2)² = x²/4` 即 f，`f(x(t)) = (2t)²/4 = t² = y(t)`——f 与 x 的复合就是 y，任何对应点的函数值相同，故可放心换元。例10.2 计算：`S = a² int_0^(2π)(1-cos t)²dt = a² int_0^(2π)(1-2cos t+cos²t)dt`，整周期上 cos 积分为 0、cos² 用 0 到 2π 上 4 倍华里士得 π，故 `S = a²(2π+π) = 3πa²`。

> **易错点**：换元后被积函数是 y(t)x'(t)，不是 y(t)；整周期上 sin、cos 的一次幂积分为 0，cos² 用华里士（点火）公式。

## 【视频02】例10.3：伯努利双纽线的面积

[00:39:00 - 00:43:00]

例：伯努利双纽线 `r² = a² cos 2θ` 所围图形面积（考题常直接给极坐标表达式，小填空题）。图形关于极点四象限对称，算第一象限乘 4；第一象限对应 θ 从 0 到 π/4（cos 2θ=0 处），套极坐标公式：`S = 4·(1/2) int_0^(π/4) a² cos 2θ dθ = a²`。

> **易错点**：对称性先简化再套公式；射线角范围由 `r²≥0` 定出（cos 2θ≥0）；记得那个 1/2。

## 【视频02】例10.4：e^(-x)sin x 型无界区域的面积

[00:43:00 - 00:55:27]

例：`y = e^(-x) sin x`（x≥0）与 x 轴所围图形面积。振幅被 e^(-x) 压得越来越小，"所围面积"是各拱面积的绝对值之和（不是曲边梯形的代数和），翻上去全算正的：`S = int_0^(+∞) e^(-x)|sin x| dx`（e^(-x) 恒正不必加绝对值）。带绝对值不好算，按 kπ 到 (k+1)π 拆段取通项（即第八讲例8.5 的圈三写法），每段用 `int e^(ax) sin bx dx` 行列式公式算出 `|(kπ,(k+1)π)| = (1/2)e^(-kπ)(1+e^(-π))`，再对 k 从 0 到 n 求和（等比数列）取极限，得 `S = (1+e^(-π))/(2(1-e^(-π)))`。这是近十年定积分应用里计算量最大的一次，纯考计算能力；2019 年数二以此出过 12 分大题。

> **易错点**："所围面积"全取正，必须绝对值 + 拆段求和取极限；段内积分直接用第九讲的 `e^(ax)sin bx` 公式，别现场推。

> ⚠️ **需回看视频 [00:42:00]**：疑似 ASR 识别错误/口误 —— "它是讲y等于e的x次方乘上sinx"，与题干 "e的负x次方乘以sinx" 矛盾，应为 `e^{-x} sin x`。

## 【视频03】旋转体体积：切片法（绕 x 轴）

[00:00:00 - 00:05:00]

曲线 y=y(x)（x∈[a,b]）绕 x 轴旋转一周得旋转体。微元法垂直于旋转轴切出"小硬币"（薄圆柱，厚度 dx，截面半径 y(x)）：`dV = π y²(x) dx`，累加得 `V_x = π int_a^b y²(x) dx`。这就是"套公式"的对象：定好 a、b，把 y 代进框框算定积分即可。

> **公式**：`V_x = π int_a^b y^2(x) dx`。
> **易错点**：半径是函数值 y(x)，平方别漏；积分限是 x 的范围。

## 【视频03】例10.5：定义域坑与绕 x 轴体积

[00:05:00 - 00:10:00]

例：`y = e^(-x/2) sqrt(sin x)` 在 0 到 2π 部分与 x 轴所围图形绕 x 轴旋转的体积。坑在定义域：`sqrt(sin x)` 要求 sin x≥0，0 到 2π 内只有 [0,π] 有效，π 到 2π 上不存在、不算。套公式：`V = π int_0^π e^(-x) sin x dx`，用 e^(ax)sin bx 型积分公式得 `V = (π/2)(1+e^(-π))`。测度问题比性态问题简单：性态要找全可疑点逐一比较，测度只要套公式做计算。

> **易错点**：先查定义域再定积分限（这类"区间陷阱"是命题常设的坑）；被积函数是 y²，指数与三角的平方各算各的。

## 【视频03】旋转体体积：柱壳法（绕 y 轴）

[00:10:00 - 00:15:00]

曲边梯形绕 y 轴旋转：取竖直小条（厚度 dx）绕 y 轴转出薄壁圆柱壳（果丹皮卷筒），沿母线剪开展平得长方体：高 `|y(x)|`、厚 dx、长（周长）`2πx`，故 `dV = 2πx|y(x)|dx`，累加得 `V_y = 2π int_a^b x|y(x)| dx`。与绕 x 轴的切片公式对照记忆：V_x 代 y² 平方，V_y 代 x·y 乘积。

> **公式**：`V_y = 2π int_a^b x |y(x)| dx`（柱壳法）。
> **易错点**：绕 y 轴是"壳"不是"片"，半径是 x 而非 y；加绝对值避免正负抵消。

## 【视频03】例10.6：求 f 与 x、y 地位互换的综合题

[00:15:00 - 00:25:00]

例：f 满足某关系式（即第一讲例1.2，前世今生要认得），求得 `f(x) = x/sqrt(1+x²)`（x>0）；再求 `y=f(x)` 与 `y=1/2`、`y=sqrt(3)/2` 及 y 轴所围图形绕 x 轴旋转的体积。两个综合点：①先求函数表达式（测度题太简单，必挂前置计算）；②x、y 地位交换——绕 x 轴却以 y 为积分变量，需反解 `x = y/sqrt(1-y²)`（0<y<1），用柱壳式 `V = 2π int y·x(y)dy = 2π int_(1/2)^(sqrt(3)/2) y²/sqrt(1-y²) dy`。令 y=sin t（三换，第一象限不加绝对值，上下限 π/6 到 π/3），`sin²` 降幂积分得 `V = π²/6`（不是 0 到 π/2，华里士公式不适用，老老实实降幂）。

> **易错点**：绕轴对象与积分变量不必相同，先分清"半径是谁"；反解出 x(y) 后代入壳公式；区间非特殊值时不能套华里士。

## 【视频03】绕任意定直线旋转的体积公式

[00:25:00 - 00:32:00]

平面曲线 y=f(x)（x∈[a,b]）与定直线 `l0: ax+by+c=0`（过 l0 的垂线与曲线至多交一点）围出的区域绕 l0 旋转的体积，直接记通式（考研偶擦边，给出即套用，不必推导）：`V = π/(a²+b²)^(3/2) · int_a^b (a x + b f(x) + c)² · |a f'(x) - b| dx`。验证：取 l0 为 x 轴（a=0,c=0,b≠0）即化为 `V_x = π int y²dx`，公式自洽；记忆法是朗读两遍即可记住。其他推导方法（点到直线距离等）涉及数一的距离公式，数二数三不必折腾。

> **公式**：`V = π/(a²+b²)^(3/2) · int_a^b (ax+b f(x)+c)² |a f'(x) - b| dx`。
> **易错点**：先由直线方程读出 a、b、c（如 x=1 即 a=1,b=0,c=-1）；被积函数第一项是点到直线距离的分子，第二项是投影伸缩因子。

> ⚠️ **需回看视频 [00:28:00]**：疑似 ASR 识别错误/公式残缺 —— "ax加b f(x)加上c的平方，再乘上a倍的f一撇，它的导住啊，减去b绝对值dx"，公式书写转写混乱，建议对照板书核对（后文复述部分较完整）。

## 【视频03】例10.7（一）：过原点切线与无界区域面积

[00:32:00 - 00:43:00]

例：过原点作 `y=e^x` 的切线，与 x 轴负向、曲线围成无界区域 D。设切点 (x₀,y₀)：斜率 `e^(x₀)`，切线过原点且切点在曲线上，联立解得 x₀=1、y₀=e，切线 `y=ex`。求面积时铅垂切需分段（负无穷到 0 与 0 到 1 高度不同），不如水平切：以 dy 为厚，宽为右 x 减左 x（`y/e - ln y`），`A = int_0^e (y/e - ln y)dy = e/2`（`int ln y dy = y ln y - y`，下端 y→0⁺ 是取极限，`lim y ln y = 0`）。此面积是收敛的反常积分——面积、体积计算可含收敛反常积分。

> **易错点**：切线方程要联立"过原点 + 切点在曲线上"两个条件；无界端点取极限不取值；积分方向选得好能免去分段。

## 【视频03】例10.7（二）：绕直线 x=1 旋转的体积

[00:43:00 - 00:51:00]

第二问：D 绕直线 x=1 旋转的体积。几何直观：大"帐篷"减中间空锥。微元法（水平切片、厚度 dy）：大旋转体半径 `1 - ln y`，`V1 = π int_0^e (1-ln y)² dy`；小锥半径 `1 - y/e`，`V2 = π int_0^e (1-y/e)² dy = πe/3`；`V = V1 - V2 = 5πe/3`。也可直接套上一节通式（x=1 即 a=1,b=0,c=-1，分别对 y=e^x 与 y=ex 代入后相减），结果一致——这就是"套公式做计算"的意义。

> **易错点**：绕非坐标轴旋转时半径是"到转轴的水平距离"，注意大小 x 的次序；两问两种切法，都归结为定积分计算。

> ⚠️ **需回看视频 [00:45:00]**：疑似 ASR 识别错误 —— "x 是等于 y 比上一嘛…就是用 x 等于一减去 y 比一"，应为 `x = y/e`（由切线 y=ex 反解）。

## 【视频03】函数的平均值与例10.8

[00:51:00 - 01:00:37]

函数 y(x) 在 [a,b] 上的平均值（几何上是曲边梯形的平均高）：`y拔 = (1/(b-a)) int_a^b y(x) dx`，即定积分除以区间长度；连续函数时它就是积分中值定理里的 f(ξ)。例10.8：f 连续，`f(x+2)-f(x)=x` 且 `int_0^2 f = 0`，求 [1,3] 上的平均值。两种思路都指向同一辅助函数：①区间长度均为 2，仿周期函数"任给起点"的思考令 `F(x) = int_x^(x+2) f(t)dt`，则 F(0)=0、所求与 F(1) 有关；②"反着写一步"——右端 x 恰是 `int_x^(x+2) f` 的导数。于是 `F'(x)=x`，`F(x)=x²/2+C`，由 F(0)=0 得 C=0，`F(1)=int_1^3 f = 1/2`，平均值 `= (1/2)·(1/2) = 1/4`。

> **公式**：`y拔 = (1/(b-a)) int_a^b y(x)dx`。
> **易错点**：平均值 = 定积分 × 1/(区间长度)，别漏系数；辅助函数 `int_x^(x+2) f` 不是死记的题型，而是由"区间长度不变"与"求导还原"两个观察自然导出的。

## 【视频04】曲边梯形的形心坐标公式（数一、数二）

[00:00:00 - 00:06:00]

曲边梯形 D（0≤y≤f(x)，a≤x≤b）的形心 `(x拔, y拔)`，直接背结论：`x拔 = int_a^b x f(x)dx / int_a^b f(x)dx`，`y拔 = int_a^b (1/2)f²(x)dx / int_a^b f(x)dx`。来源是二重积分的形心公式（第十四讲才讲），数二同学不推导直接记；数一后面在二重、三重积分应用中还会遇到（届时还有质心、重心，注意与形心区分）。例10.9（真题考过）：套公式后是两个纯计算积分，答案很复杂（形心横坐标形如 `3(e²+1)(e²-3)/(4(e³-7))`）也不要怀疑算错——考研答案的复杂程度就是如此。

> **公式**：`x拔 = int_a^b x f dx / int_a^b f dx`；`y拔 = (1/2) int_a^b f² dx / int_a^b f dx`。
> **易错点**：y拔 分子带 1/2（来自矩形面积元的形心高）；复杂答案要敢于写，靠计算准确度拿分。

## 【视频04】弧微分与三种坐标系下的弧长公式（数一、数二）

[00:06:00 - 00:10:00]

弧长微元来自勾股定理：`ds = sqrt(dx² + dy²)`（弧微分），积分得 `s = int ds`。三种坐标系：直角坐标 `s = int_a^b sqrt(1+y'²) dx`；参数方程 `s = int_α^β sqrt(x'(t)² + y'(t)²) dt`；极坐标 `s = int_α^β sqrt(r² + r'²) dθ`。推导只是把 dx、dy 用对应导数表示并提出公因子；积分限都是从小到大，故不加绝对值。

> **公式**：`ds = sqrt(dx²+dy²)`；三系弧长公式见上。
> **易错点**：极坐标公式是 `r² + (r')²`，两项都要平方；弧长公式可整体记忆为"sqrt(dx²+dy²) 在对应变量上的积分"。

## 【视频04】例10.10：直角坐标下的弧长计算

[00:10:00 - 00:14:00]

例：`y = ln(1-x²)` 在 0<x≤1/2 一段的弧长。`y' = -2x/(1-x²)`，`1+y'² = (1+x²)²/(1-x²)²`，开根号取正（x≤1/2 时 1-x²>0）得 `(1+x²)/(1-x²)`；多项式除法拆项 `= -1 + 2/(1-x²)`，再拆 `2/(1-x²) = 1/(1-x) + 1/(1+x)`，积分得 `s = ln 3 - 1/2`。

> **易错点**：通分合并 `1+y'²` 是化简关键（常配成完全平方）；拆项是简单代数运算，凑一凑即可，不必死记拆分顺序。

## 【视频04】例10.11：阿基米德螺线的弧长

[00:14:00 - 00:20:00]

例：阿基米德螺线 `r=θ` 在 θ 从 0 到 2π 的弧长。套极坐标公式：`s = int_0^(2π) sqrt(θ²+1) dθ`——公式套起来容易，积分不简单：令 `θ=tan t` 化为 `int sec³t dt`，分部积分出现"循环建方程"（第九讲方法），解得 `int sec³t dt = (1/2)(sec t tan t + ln|sec t+tan t|)`，回代 t 当锐角画三角形，得 `s = π sqrt(1+4π²) + (1/2) ln(2π + sqrt(1+4π²))`。答案复杂也要敢写，这是真题风格。

> **公式**：`int sqrt(θ²+1)dθ = (θ/2)sqrt(θ²+1) + (1/2)ln(θ+sqrt(θ²+1)) + C`（即 `int dx/sqrt` 基本公式的对偶，可对照记）。
> **易错点**：弧长题的难度常在积分上而非公式上；`sec³` 型积分用分部积分建方程，别硬凑。

## 【视频04】旋转曲面的侧面积公式与例10.12

[00:20:00 - 00:25:00]

旋转体侧面积（旋转曲面面积）：微元必须用弧长 ds 而不能用 dx——用 dx 把 dy 置零，误差不是高阶无穷小，累加后产生有限偏差，极限值就不是真实侧面积（算体积时才可用 dx 代弧长，误差是高阶的）。于是侧面积公式 = 弧长公式 × 周长 `2π|y|`：直角坐标 `S = 2π int_a^b |y| sqrt(1+y'²) dx`；参数方程、极坐标同理分别乘 `2π|y(t)|`、`2π|r sin θ|`。例10.12：曲线在 [1,2] 上绕 x 轴旋转的表面积，套公式整理为 `π int_1^2 sqrt(4x-3) dx`，得 `S = (π/6)(5sqrt(5)-1)`。

> **易错点**：侧面积必须用 ds（弧微分）不能用 dx，这是与体积计算的本质区别；答案带根号、分数很正常。

## 【视频04】例10.14：微元法详解——绕斜线旋转（选读）
