# B 站收藏夹同步 · 使用教程

> 脚本：`scripts/bili_sync.py` ｜ 数据文件：根目录 `收藏夹.md` ｜ 缓存：`scripts/.bili_cache.json`
> 最后更新：2026-10-29

---

## 0. 一分钟上手

```powershell
cd D:\master_knowledge
python scripts\bili_sync.py
```

跑完打开根目录的 `收藏夹.md`：B 站新收藏的视频会出现在对应 `## 分区` 顶部，B 站已取消收藏的条目会被自动清理或标记。日常只需要这一步。

## 1. 环境与配置（已完成，仅供排查）

依赖：`requests`、`pyyaml`、`flask`、`flask-cors`（见 `scripts/requirements.txt`）

```powershell
pip install -r scripts/requirements.txt
```

配置在 `scripts/.env`：

| 变量 | 作用 | 必填 |
|---|---|---|
| `BILI_UID` | 你的 B 站 UID（空间地址 `space.bilibili.com/` 后面那串数字） | ✅ |
| `BILI_SESSDATA` | 浏览器 Cookie 里的 SESSDATA，用于读私密收藏夹、降低风控 | 建议 |
| `DEEPSEEK_API_KEY` | DeepSeek Key，用于分区 + 一句话指南 | ✅ |
| `DEEPSEEK_BASE_URL` / `DEEPSEEK_MODEL` | 默认 `https://api.deepseek.com` / `deepseek-chat` | 可省 |
| `AI_CONCURRENCY` | AI 并发数（1–8，默认 4；当前设为 1 更稳） | 可省 |
| `BILI_SYNC_PORT` | 本地服务端口，默认 5055 | 可省 |

## 2. 三种用法

### 2.1 命令行同步（最常用）

```powershell
cd D:\master_knowledge
python scripts\bili_sync.py
```

每次运行做四件事：

| 步骤 | 行为 |
|---|---|
| 拉取 | 读取你全部 B 站收藏夹（默认 / 力量源泉 / 电子 …，分页也读全） |
| 新增 | 本地没有的视频 → DeepSeek 判分区 + 生成 25 字食用指南 → 插到对应分区顶部 |
| 改区 | 你手动剪切到别的分区的行 → 自动标 `locked:true`，以后同步不再挪它 |
| 清理 | B 站已取消收藏：未勾选且行下无笔记 → 删行；已勾选或有笔记 → 行尾加 `*(B站已取消)*` 永久保留 |

### 2.2 油猴一键同步（浏览器里点按钮）

1. 后台常驻服务（窗口别关）：
   ```powershell
   python scripts\bili_sync.py --serve
   ```
   看到 `http://127.0.0.1:5055` 即成功，`Ctrl+C` 停止。
2. Tampermonkey → 新建脚本 → 粘贴 `scripts/bili_patrol.user.js` → 保存。
3. 打开 B 站收藏夹页或任意视频页，右下角出现悬浮按钮，点一下即可同步并弹结果。
4. 端口被占用：`python scripts\bili_sync.py --serve --port 5056`，同时把油猴脚本里的 `5055` 改掉。

### 2.3 安全模式（试跑 / 不花钱）

```powershell
python scripts\bili_sync.py --dry-run              # 只打印计划，不写文件
python scripts\bili_sync.py --skip-ai               # 不调 DeepSeek，新视频先落 99_电子榨菜与待定
python scripts\bili_sync.py --dry-run --skip-ai     # 完全零副作用、零 API 消耗
```

> 注意：`--dry-run` 仍会调用 AI 对新视频分类，想省钱请叠加 `--skip-ai`。

其他参数：`-v` 调试日志、`--uid` / `--vault` 临时覆盖配置。

## 3. `收藏夹.md` 使用规则（重点）

### 3.1 单行格式

```markdown
## 🎯 01_考研408与数学
- [ ] **[视频标题](https://www.bilibili.com/video/BVxxx)** `15min` `@UP主` — 💡 *一句话食用指南* <!-- bvid:BVxxx | locked:false -->
```

一行 = 一个视频：`- [ ]` 状态 + 标题链接 + 时长 + UP主 + AI 指南 + 隐形标识。

### 3.2 日常操作

| 想做的事 | 怎么做 |
|---|---|
| **改分类** | 把整行剪切到另一个 `## 分区` 标题下，脚本会自动记忆并写 `locked:true`，以后绝不挪回 |
| **标记已看** | 把 `- [ ]` 改成 `- [x]`，之后即使 B 站取消收藏也永久保留 |
| **写笔记** | 在视频行**下面缩进**写，例如 `  - 配合计组第 3 章一起看`；有笔记的行永久保留 |
| **加自定义分区** | 自己新建 `## 📌 06_xxx` 即可，现有条目不会丢，AI 也不会主动往里塞 |
| **手工加视频** | 可以，但必须在行尾补上 `<!-- bvid:BVxxx -->` 标识，否则下次同步会被当成新视频重复添加 |

### 3.3 不要动的东西

- 行尾 `<!-- bvid:BVxxx | locked:false -->`：唯一标识，删了/改坏会导致重复添加或误删。
- `locked:true`：脚本的锁定记号，不用管，也不要在 AI 对话里让它改。
- `*(B站已取消)*`：脚本标记，留着即可；视频若重新收藏，下次同步会自动撤销。
- 全文不要手动重排，脚本按「分区标题 + 缩进」解析。

### 3.4 状态语义

- `- [ ]` 未看
- `- [x]` 已看 / 已完成（同时具备"防清理"保护）
- 行下缩进内容 = 你的手写笔记（同样具备"防清理"保护）

## 4. 脚本内部逻辑

1. **解析**：只读根目录 `收藏夹.md`，提取每行的 `bvid`、勾选状态、所在分区、下方缩进笔记。
2. **查缓存**：`scripts/.bili_cache.json` 记录上次每个 `bvid` 的分区；发现分区变了 → 判定为手动移动 → 写 `locked:true`。
3. **拉云端**：B 站收藏夹全量（分页）→ 得到 `bvid` 集合。
4. **清理**：本地有、云端没有的条目，按勾选/笔记情况删除或加标记。
5. **补全**：AI 分类失败的条目（`pending`）重试；云端新增条目分类后插入分区顶部。
6. **写回**：更新文件开头的「最后同步」时间，原子替换写入 `收藏夹.md`，并刷新缓存。

安全机制：

- 云端一条都没读到 / 数据不完整时，**跳过删除**，不会误清空。
- 同一 `bvid` 出现两次时，保留第一条，删掉后出现的重复行。
- 写文件用「临时文件 → 替换」，中途崩溃不会写坏唯一的数据文件。

## 6. 常见问题

| 现象 | 原因与处理 |
|---|---|
| `code=-352 / -412` | B 站风控或限流：重新获取 `BILI_SESSDATA`，或降低频率后再跑 |
| `code=-101` | SESSDATA 过期，重新登录 B 站复制 Cookie |
| 新视频全掉进 `99_电子榨菜与待定` | 没配 `DEEPSEEK_API_KEY`，或 AI 调用失败（看日志）；下次同步会自动重试补分类 |
| 某个视频被误删了 | 去 `.trash/收藏夹_迁移快照.md` 或 git 历史里找；只有「未勾选 + 行下无笔记 + B 站已取消」的行才会被删 |
| 悬浮按钮点了没反应 | `--serve` 服务没开，或端口不是 5055；先访问 `http://127.0.0.1:5055/health` 验证 |
| 明明取消了收藏，行还在 | 该行已勾选或有缩进笔记，属保护行为；行尾会带 `*(B站已取消)*` |
| 手动换的分区又被挪回去 | 检查该行 HTML 注释里是否已写 `locked:true`；正常应在下一次同步时自动写入 |
| 想彻底重置 | 删掉 `scripts/.bili_cache.json` 再跑一次（会丢失"手动移动"的历史判断，慎用） |

## 7. 推荐节奏

- **收藏完随手同步**：点油猴按钮，或跑一次命令行。
- **每周整理一次**：在 Obsidian 里拖动行改分区、勾掉已看、给重点视频补一行笔记。
- **不需要每天跑**：脚本是幂等的，重复运行不会产生重复条目。
