## 二、 四大核心显示问题修复逻辑

在按顺序处理每篇 `.md` 文件时，请严格执行以下 4 步修复：

### 1. 代码块修复与 408 语法高亮自动补全（最先处理，随后将其用占位符保护起来）
- **修复围栏粘连：** 确保多行代码块 ` ``` ` 的开启行和闭合行各自独立占一行，且前后与正文保留合理换行。
- **自动识别并补全语言标识：** 针对没有标注语言类型的裸代码块（即仅有 ` ``` ` 开头），检测其内部代码特征：
  - 若包含 `#include`、`int main`、`struct `、`typedef `、`malloc`、`printf`、`scanf`、`ElemType`、`LNode`、`BiTree`、`vector<`、`cout` 等 C/C++ 或 408 数据结构特征，自动将开头补全为 ` ```cpp `。
  - 若包含 `def `、`import `、`print(`，自动补全为 ` ```python `。
  - 若包含 `<html`、`<div`、`<!DOCTYPE`，自动补全为 ` ```html `。
- **保护隔离：** 处理完多行代码块后，连同 YAML Frontmatter（顶部 `---` 区）、行内代码（`` `...` ``）、Obsidian 双链与嵌入（`![[...]]` 和 `[[...]]`）以及 URL 链接一并用临时占位符（Placeholder）替换隔离，防止后续的正则误伤代码或破坏 `PDF++` 坐标链接。

### 2. LaTeX 数学公式渲染修复（在非保护区执行）
- **统一分隔符：**
  - 将 `\((.*?)\)` 替换为 `$...$`（去除首尾多余空格）。
  - 将 `\[([\s\S]*?)\]` 替换为独立成行的 `\n$$\n...\n$$\n`。 - **剥离行内公式 `$` 内侧首尾空格（Obsidian 不渲染头号原因）：**
  - 匹配单行内成对的 `$`（排除 `$$`），将 `$x^2 + 1$` 修复为紧贴的 `$x^2 + 1$`。
  - *安全校验：* 仅当两个 `$` 之间包含数学符号/字母/反斜杠且不跨段时才触发，避免误伤普通文本。 - **规范块级公式 `$$`：** - 若 `$$...$$` 内部包含换行符或 `\begin{...}`（如 `cases`、`aligned`、`pmatrix` 矩阵），强制让前后的 `$$` 各自独占一行，并与上下正文之间保留空行，解决多行公式在阅读视图下坍塌为源码的问题。 - **清理公式末尾混入的中文标点：** - 将 `$x=1。$` 或 `$x=1，$` 末尾误包进公式内的中文全角标点移至 `$` 外侧（即 `$x=1$。`）。

### 3. 表格、标题与列表的渲染粘连修复（在非保护区执行）
- **修复 `#` 标题粘连：** 将正文中形如 `###标题`（`#` 号后紧跟中文字符或字母且无空格，注意排除 `#标签`）或标题前紧挨着正文没有换行导致无法渲染的情况，规范为 `#` 后带一个空格，且标题上方保留空行。*(注：区分 Markdown 标题与 Obsidian 标签，仅修复行首明显作为章节标题的结构如 `## 第一讲`、`### 1.`)*。
- **修复 Markdown 表格失效：** Obsidian 要求表格（以 `| ... |` 构成的连续行）上方必须有一行空行才能正常渲染成表格视图。请检测所有表格块，若其第一行上方紧贴着普通正文文本，自动在表格上方插入一个空行。
- **修复列表符号缺失空格：** 将行首形如 `-内容`（无空格导致变成普通横线文本）修复为 `- 内容`（注意避开 `---` 分隔线和负数）。

### 4. 还原保护区与清理多余空行
- 将第 1 步隔离的 YAML、代码块、行内代码、双链占位符原样还原。
- 将连续超过 3 行的冗余空行压缩为标准的 1~2 行空行。
