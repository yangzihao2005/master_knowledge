# 错题复盘总结（Math Mistake Retro）

把一章错题的批改结果 + 用户的追问，提炼成**可复用的方法论复盘**，写回该章错题集文末。

## 何时使用

- 用户说：总结做题缺陷 / 思路分叉点 / 复盘这一章 / 更新到错题 md 后面
- 一轮"批改 → 追问 → 讲透"结束后需要沉淀（**先确认要不要写文件**；本 skill 保证"怎么写好"，不代表可以擅自扩写）
- 已有旧复盘需要按新结构重写，或需要迁移位置（文首 → 文末）

不用于：单纯讲题答疑（直接回答）、网课转写整理（用 `kaoyan-notes`）、重测卷组卷。

## 输入

| 来源 | 用途 | 限制 |
|---|---|---|
| `08.错题与重测库/{数二错题,408错题}/<章名>_错题集.md` | 题干、`> 我的错误结果`、已有解析 | 不改题干/标记/备注 |
| `09.答案库/…/<章名>.md` | 标准解法与答案 | 用户要求"按答案库"时只留该路线 |
| **本轮对话的追问记录** | 「认知缺口」的**唯一合法来源** | 不许编造通用套话 |
| 用户手稿截图（仅当用户主动发图） | 定位"错在第几步" | 绝不读 `Ink/` 目录 |

## 推荐区块（**按需取用，数量不设上限也不设下限**）

下面只是可用积木，不是必须逐条填满的表格。**本章没有对应内容就不写这一节**；有几个就写几个，不为了对称或"好看"凑数。

**速查表**（题号｜主要工具｜答案）——题多时有用，三四道题可以直接略过。

**LaTeX 档案**（每题：题干 $\Longrightarrow$ 答案 + 题库/答案库双链）——用户要求"LaTeX 化"或题目需要回看公式时写。

**认知缺口**——复盘的主体。**数量由实际暴露的问题决定**：
- 一条缺口必须能溯源到"用户问过的那句"或"手稿里可定位的那一步"；
- 只有 2 个真问题就写 2 条，不要凑到 5 条；有 7 个就写 7 条，不要砍到"五大类"；
- 每条建议包含：一句话结论 → 现象/错在第几步 → 正确图景（LaTeX，尽量 3 行内）→ 自检或反例；
- 严重度标记（★）按实际判断，可省略。

**可复用法则**——跨题可迁移的判断规则，条数按需（常见 2~5 条，没有就不写）。

**动作清单**——下次做题的执行顺序，几条流水就写几条；重点保留"自检"这一步。

**必背清单**——公式/结论型缺口才需要；纯概念题（如间断点分类）可省略。

**关联**——源题库、标准答案、标签；有需要才加双链与标签。

各区块的**排列顺序**建议固定（速查 → LaTeX 档案 → 认知缺口 → 法则 → 清单 → 关联），便于跨章对照；但**区块本身可以缺省**。

## 三条硬规则

1. **缺口必须可溯源**：写成"审题要仔细"这类空话即失败。
2. **每条缺口给"第几步 + 自检"**：配阶错 → 给"极端 $n$ 是否发散"的自检；型判错 → 给"两因子各自趋向什么"的判型动作。
3. **用户说"按答案库来"后**：删除自创替代解（差角公式、第二法、额外结论），只保留标准路线；可留一句"更短的等价路线"旁注，但不得喧宾夺主。

## 写入规则（关键：防止污染重测卷）

`scripts/random_exam.js` 的 `collectMistakeBlocks()` 会把**最后一个 `<!-- mistake: -->` 之后的全部内容**当成最后一题的题干。所以：

```markdown
...最后一题的 🎯 核心考点标签行...

---

<!-- mistakes-end -->

## 【第X章错题复盘 · 缺陷与思路分叉点】
```

- 复盘一律追加在**文末**，其前放 `<!-- mistakes-end -->` 哨兵（`random_exam.js` 已支持：遇哨兵即结束当前错题块）。
- **幂等**：已存在哨兵则不重复追加，改为替换"哨兵之后"的内容。
- 若旧文件把复盘放在文首，迁移到文末 + 补哨兵，保持各章一致。
- frontmatter（科目/章节/错题数/tags）**只在用户要求时**加。

## 强制校验（写完必须跑）

```js
const fs = require("fs");
const { collectMistakeBlocks, stripForRetest } =
  require("D:/master_knowledge/scripts/random_exam.js")._internal;
const text = fs.readFileSync(错题集路径, "utf8");
const blocks = collectMistakeBlocks(text);
let leak = 0;
for (const b of blocks) {
  const stem = stripForRetest(b.lines).join("\n");
  if (/答案|思维分叉|复盘|认知缺口|可复用法则|动作清单|必背清单/.test(stem)) leak++;
}
console.log("blocks=" + blocks.length + " leaks=" + leak); // 要求 leaks=0
```

验收：`blocks` 等于该章错题数，且 `leaks=0`；否则说明哨兵缺失或解析段没被剔除。

## 反模式

- ❌ 固定"五大缺陷/四条法则/七节结构"然后硬凑内容
- ❌ 把复盘写成"逐题复述"（那是批改区，不是复盘）
- ❌ 未经要求就新增 frontmatter、标签体系、改脚本——先问
- ❌ 用"多总结、多练习"这类不可执行的话
- ❌ 把标准答案写进 `08.错题与重测库/抽测组卷/`
- ❌ 在复盘区改题干、`<!-- mistake: -->`、`> 我的错误结果`、Ink 注释

## 质量示例（缺口写法）

> **缺口｜配阶方向反了：$x\to0$ 抓最低阶，不是"最高阶"**（第 7 题）
> - 现象：两次洛必达都对，最后一步把 $(2+x)\sin x$ 取成 $x\sin x\sim x^{2}$，丢掉主导的 $2\sin x\sim2x$，算出 $n=4$。
> - 正确：$(2+x)\sin x\sim2x$ 是 1 阶 ⇒ $n-2=1$ ⇒ $n=3$，$C=\frac{1}{12}$。
> - 自检：若 $n=4$，原式 $\sim\frac{2x}{48x^{2}}\to\infty$，与"$=C$ 有限"矛盾。
