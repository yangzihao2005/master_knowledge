# 计算机组成原理强化课 第4讲 内存系统总线综合

## 存储器在 408 大题中的地位（考情梳理）

[00:00:00 - 00:10:00]

强化课的存储器部分不含新知识点，基础课已全部讲完，本讲只做真题梳理与重点回顾，核心是摸清出题人"考什么、怎么考"。2010—2024 年共 15 次统考中，纯粹考察存储器的大题出现 10 次（2024 年第 2 题主体考指令、只综合了部分存储内容，未计入），是组成原理大题中出现频率最高的章节。存储大题风格固定、重复率高，因此本章优先级要放到最高，不能有知识漏洞。本讲按"真题梳理—基本知识—Cache—DRAM—多模块—存储与总线综合"六部分展开。

> **易错点**：不要因为存储器"入门难"就降低投入；过一两轮后，存储大题恰恰是组原中最容易拿满分的题。

## 高频考点一：虚拟存储（地址格式与页表替换）

[00:10:00 - 00:14:00]

虚拟存储与操作系统的虚拟存储合并考察，是选择题和大题都高频的点；机组侧分配时间少（主要由操作系统课承担），但绝不代表不重要。大题最爱考虚拟地址格式及每个字段的长度与含义，以及它与页表/快表的对应关系——2021 年真题前两问就是纯字段题。第二高频是页表替换，与 cache 替换并列，直接映射、全相联、组相联三种方式及相应替换算法都必须掌握。

> **定义**：虚拟存储器——由主存—辅存层次构成，通过页表把虚拟地址映射为物理地址，缺页时按替换算法换入换出页。

## 高频考点二：cache 的地址字段、命中率与缺失过程

[00:14:00 - 00:22:00]

2020 年真题纯考 cache：标记阵列各字段的计算、命中率、缺失与访问过程；2023 年真题在其上叠加了缺页次数、时间/空间局部性，以及虚实地址转换后求 cache 组号。命中率大题的出题方式高度固定：给一段 C 语言 for 循环访问数组，从"读数组 / 写数组 / 修改数组"三个角度切入。这类题在 2010、2020、2023 等年份反复出现、思路几乎相同，只是细节微调，所以复习应以吃透真题为主，而不是盲目刷题。

> **易错点**："写"（a[i]=x）只有一次写操作；"修改"（a[i]+=x）是读—改—写，访问次数和命中率都不同。

> ⚠️ **需回看视频 [00:20:00]**：讲述真题年份时前后口误（2010/2020/2022 混用），影响"同类题考过几次"的判断 —— "二零二零年真题可以发现，哎，它和二零二三年的又非常像……你看二零一零年就考察过类似的这种内容了"

## 2019/2018/2016 真题：虚实地址转换叠加 cache 字段

[00:22:00 - 00:26:00]

这三年真题仍是"虚实地址转换 + cache 字段"的组合：问某程序段或数组被分到哪个页、是否同页，给定组相联与块大小后问地址映射到哪个组、哪部分是 tag、哪部分是块内偏移，或问物理地址位数、TLB 的映射方式。单独看每个知识点都不难，难在它们在同一道题里被串起来，需要通过真题练习熟悉综合方式。

## 2013 真题：主存—Cache 数据传输过程（第二类命题）

[00:26:00 - 00:30:00]

2013 年真题换了切入方向：主存与 Cache 之间通过总线传输一个主存块的过程，综合了多模块存储器（内存条）与突发传送总线事务（同时启动/轮流启动），难度明显高于地址转换类。据此可把存储大题分成两类：一类是虚实地址转换、cache 映射与命中率计算（基础、固定、必须拿分）；另一类是数据传输过程，往往与总线章节综合。

## 外存的两类：ROM 与磁盘；三级存储结构

[00:30:00 - 00:33:00]

408 中的外存只有 ROM 与磁盘两类，二者在用途和存取方式上都不同，是选择题常考点。计算机存储为三级结构：CPU 内是寄存器；主存由 DRAM（芯片或内存条）构成；外存由磁盘与 ROM 构成。磁盘即机械硬盘；ROM 早期用于主板上存放 BIOS，也用作 U 盘、固态硬盘等移动介质，还用作微程序控制器的控制存储器 CS（存放微程序，称固件）。

> **易错点**：主存 = ROM + DRAM，其中 DRAM 是主体，ROM 只保存 BIOS 等少量程序。

## ROM 家族的技术演变

[00:33:00 - 00:37:00]

掩膜 ROM 出厂写入一次且只能存常量；PROM 仍只可出厂写一次，但能存程序；EPROM 可改写，但改一个字节也要整片擦除后重写，浪费大；EEPROM 支持按字节擦写，代价是速度慢、容量小；闪存按扇区擦写，速度提升但写仍慢于读；固态盘在闪存基础上进一步提升容量与存取速度。

> **易错点**：EPROM 是整片擦除，EEPROM 是按字节擦写，两者区别常考；闪存常被等同于 U 盘。

## 三种存取方式与辨析题

[00:37:00 - 00:42:00]

随机存取按地址访问任一单元的时间为常数（RAM，类比数组下标）；顺序存取的时间取决于信息存放位置，越靠后越慢（磁带）；直接存取先随机定位到某个区域，再在区域内顺序查找，典型是磁盘——先寻道定位磁道（平均寻道时间近似固定），再从扇区头顺序读到目标扇区。例题（不定项）："主存由 RAM 和 DRAM 构成 / 磁盘与固态均采用直接存取 / 固态属于 RAM / 固态也是闪存"的四个判断中，答案为 A、C、D。

> **公式**：磁盘读一个扇区时间 ≈ 平均寻道时间 + 平均旋转延迟 + 传输时间
> **易错点**：固态硬盘是半导体存储器，不具备磁盘"寻道 + 顺序读扇区"的直接存取特征。

> ⚠️ **需回看视频 [00:41:00]**：选项"固态硬盘属于 RAM"被判为正确，与"固态基于闪存"相矛盾，疑似 ASR 把 ROM 误识为 RAM —— "第三个，说固态硬盘属于RAM，没问题"

## cache 的五类考法与标记阵列组成

[00:42:00 - 00:45:00]

大题对 cache 的考法可归为五类：①给主存地址，问各字段如何映射到 cache；②计算主存地址与 cache 地址格式；③计算 cache 总容量（数据区 + 标记阵列）；④结合 C 程序访问序列算命中率；⑤结合硬件逻辑问比较器个数、多路选择器路数。此外必须掌握含 cache 的访存过程：先访问 cache，命中则 CPU 直接取数；未命中则由主存提供数据，同时把该主存块调入 cache。标记阵列由有效位、脏位、替换算法位、tag 四部分组成。

## 脏位与写策略

[00:45:00 - 00:47:00]

脏位只在采用回写法时才需要：直写法在写 cache 的同时写主存，两者始终一致，无需脏位；回写法只改 cache，被改过的行成为脏块，必须在该行被替换时写回主存。

> **易错点**：是否有脏位取决于写策略（直写/回写），而不是"是否存在写操作"。

## 替换算法位与有效位

[00:47:00 - 00:50:00]

替换算法位只出现在全相联和组相联中，用于在组（或整个 cache）装满时选出被替换的块；直接映射位置唯一，不需要。常用算法是 FIFO 与 LRU（随机替换基本不考），LRU 要对候选块排序，n 个候选块需 ⌈log2 n⌉ 位。有效位标示该行数据是否有效，题目通常不会显式给出，是计算总容量时最容易漏掉的字段。

> **公式**：LRU 替换位位数 = log2(候选块数)：4 块 2 位，8 块 3 位，16 块 4 位。
> **易错点**：算 cache 总容量漏掉有效位，是最常见的失分点。

## 直接映射与全相联下的 tag、总容量

[00:50:00 - 00:53:00]

tag 长度取决于映射方式。直接映射：总容量 = 行数 ×（数据块 + tag + 有效位 [+ 脏位，若回写]），不需替换位；比较器只需 1 个，命中判断就是把地址中的 tag 与该行保存的 tag 比较一次。全相联：每行还要加替换算法位，位数由总行数决定（4 行 2 位、16 行 4 位），若采用回写法再加脏位。

> **公式**：Cache 总容量 = 行数 ×（块大小 + tag 位数 + 有效位 + 替换位 + 脏位）

## 全相联比较器个数与快表（2016 真题）

[00:53:00 - 00:54:00]

全相联 cache 的比较器有两种设计：只设 1 个则需串行比较 N 次，速度慢；每行一个则并行一次完成，但硬件开销大。由于教材标准不统一，全相联 cache 的比较器个数一般不会考。但快表（TLB）若采用全相联，2016 年真题给出的结构是每行一个比较器，答题要按真题图来。

## 组相联映射的容量与比较器

[00:54:00 - 00:57:00]

组相联是三种映射中考得最多的（组内全相联、组间直接映射）。总容量 = 组数 × 路数 ×（数据块 + tag + 有效位 + 替换位 [+ 脏位]）；替换位位数由路数决定，比较器个数 = 路数。

> **公式**：替换位 = log2(路数)；比较器个数 = 路数。
> **易错点**：组相联的替换位看"路数"而不是"组数"。

## 例题：比较器个数与比较次数

[00:57:00 - 00:59:00]

主存 4GB、按字节编址、主存块 64B、cache 数据区 32KB、8 路组相联：比较器 8 个，主存地址需要在 cache 中比较 8 次——8 个比较器并行完成，所以"次数是 8、耗时仍是 1 次比较的时间"。若改为直接映射，比较器 1 个、比较 1 次。

> **易错点**：组相联"比较次数 = 路数"与"并行所以只花一次比较时间"并不矛盾，问次数答路数。

## 例题：二维数组的 cache 命中率（行优先/列优先）

[00:59:00 - 01:18:00]

二维数组 24×64、int 型共 24×64×4B = 6144B，块 64B。行优先访问时每个主存块只在首次访问缺失，块内其余元素全部命中，命中率 =（块内元素数 − 1）/ 块内元素数。把 i、j 循环对调成列优先后能否维持命中率，关键看数据区能否装下整个数组：本题数据区 8KB > 6144B，不发生替换，命中率与行优先相同；一旦数据区装不下而发生替换，列优先会反复把前面用过的块换出，第二轮访问同一块又要重新调入，命中率可能降到 0。因此做这类题先算"数组字节数 / 块大小 = 主存块数"，再判断数组总大小与 cache 数据区的相对关系。

> **公式**：数组字节数 = 行数 × 列数 × 元素字节数；主存块数 = 数组字节数 ÷ 块大小。

## 答疑：cache 行数、主存构成与访存过程（教材差异）

[01:18:00 - 01:26:00]

若干概念澄清：cache 的行数在 CPU 出厂时由硬件固定，不可更改；完整的主存由 ROM（存 BIOS）与 DRAM（存数据，为主体）构成；全相联 cache 每行一个比较器速度快，只设一个虽能运行但很慢。含 cache 的访存过程存在两种教材表述：唐朔飞教材是"访问 cache 未命中 → 主存更新 cache → 再从 cache 读给 CPU"；袁春风教材是"主存把数据给 CPU 的同时并行地把主存块调入 cache"。2020 年真题该小问两派答案都能见到，老师建议按袁书作答。

> ⚠️ **需回看视频 [01:20:00]**：教材名 ASR 识别混乱（"唐书""原书""袁振中老师"），影响"按哪本教材作答"的判断 —— "这个是按照我们这个袁振中老师他对于他的这个啊这个 cache"

## 答疑：列优先命中率、写与修改的区别

[01:26:00 - 01:37:00]

列优先命中率之所以复杂，是因为主存块被反复调入：数据区装得下整个数组时不发生替换，行优先与列优先命中率一致；装不下时第一轮就把先前用过的块换出，第二轮再访问同一块必须重新调入，命中率极差甚至为 0。还要区分"写"和"修改"：a[i]=x 只需一次写操作（命中则直接写 cache，未命中按写分配/非写分配策略处理）；a[i]+=x 是读—改—写，包含两次 cache 访问。

> **易错点**：题目说"写数组"时不要按"读—改—写"计算访问次数，否则次数和命中率都会算错。

## cache 一致性的含义与全写法/回写法

[01:37:00 - 01:40:00]

cache 一致性指同一地址的数据在 cache 与主存中是否相同，不一致只可能由写操作造成。全写法（写直达）：写命中时同时写 cache 与主存；写不命中时可配写分配法（先更新主存中相应单元，再分配行并把更新后的主存块装入）或非写分配法（只写主存，不调入 cache）。回写法：写命中只改 cache 并置脏位，待该行被替换时才写回主存。

> **定义**：cache 一致性——同一存储地址的数据在 cache 副本与主存之间保持一致。

## 多 CPU 下的不一致与写分配法、一致性辨析题

[01:40:00 - 01:49:00]

单 CPU 下回写法没有问题，多 CPU 各自带 cache 时就会出错：CPU1 用回写法把 0001H 改成 11H 却没写回主存，CPU2 访问该地址时自身 cache 未命中而去主存读，读到的仍是旧值 10H。所以多 CPU 系统通常采用全写法；"写分配法先更新主存、再把更新后的主存块装入 cache"也能缓解不一致。一致性判断题结论：写命中用全写法同时更新 cache 与主存（对）；写未命中用写分配法先装入 cache 再更新（错）；非写分配法只更新主存（对）；写分配法需要脏位（错，脏位只属于回写法）。

> **易错点**：脏位与写分配法无关，只与回写法配套。

## DRAM 芯片的访问过程与地址引脚减半

[01:49:00 - 01:51:00]

CPU 与内存的五种连接结构：单 CPU + 单 DRAM 芯片、单 CPU + 多 DRAM 芯片（内存条）、单 CPU + 多内存条、单 CPU + cache + 单 DRAM 芯片、单 CPU + cache + 多 DRAM 芯片；其中"多内存条"几乎不考。访问一个存储单元时，内存控制器把地址拆成行、列地址分两次送入：先送行地址选中整行读入行缓冲寄存器，再送列地址从行缓冲中取出该单元。因此 DRAM 芯片的地址引脚数要减半（行列复用），这是常考点。

> **公式**：DRAM 地址引脚数 = log2(行数)（行、列地址复用同一组引脚）
> **易错点**：题目给出 r 行 × c 列时，引脚按 r（或 c）算，不能按 r × c 算。

## DRAM 刷新原理与刷新周期

[01:51:00 - 01:54:00]

DRAM 靠电容存电荷，电荷会缓慢泄漏，必须在失效前周期性读出并重写，每次对一行充电称一次刷新；读出是破坏性的，所以刷新 = 把整行读入行缓冲 + 重新写入。刷新周期定义为"上一次对全部存储单元刷新完毕"到"下一次对全部单元刷新一遍"之间的间隔（如 2ms）；一次刷新时间近似等于一个存取周期；刷新地址由芯片内部计数器自动产生，计数器位数与行数有关。

## 三种刷新方式与辨析题

[01:54:00 - 02:00:00]

异步刷新把刷新周期按行数均分，相邻两行刷新起点的间隔 = 刷新周期 ÷ 行数（如 64ms ÷ 4096 = 15.625μs），死时间被分散。集中刷新在刷新周期开头用一段时间集中刷新所有行，其余时间正常读写，存在较长的"死区"。分散刷新把存储周期延长一倍，前半用于正常读写、后半刷新一行，因此没有死时间，代价是存取周期变长。判断题结论：只有异步与集中存在死时间；分散刷新每个周期都能读写；一次完整刷新只占一个存取周期；单端口存储器刷新某行时不能同时读写其他行（答案 B、C）。

> **公式**：异步刷新行间隔 = 刷新周期 ÷ 行数。

## 多模块存储器（内存条）的结构与两种考法

[02:00:00 - 02:02:00]

内存条由一块 PCB（内存主板）与若干 DRAM 芯片（也称存储体）构成，408 范围内只需知道这两个要素。考法只有两种：一是内存条的基本性质（容量、编址、引脚、行缓冲、突发传送条件），常作选择题或大题某一小问（2022 年真题首次正式出现"内存条"）；二是内存条向 cache 传送一个主存块的过程，必须结合突发传送总线事务（如 2013 年真题）。

## 内存条容量、字节编址与交叉编址

[02:02:00 - 02:09:00]

内存条容量 = 单芯片容量 × 芯片数；"按字节编址"意味着每个存储单元正好 1B。多个存储体拼成内存条地址空间有两种方案：交叉编址（横着排）——各芯片的同一行地址轮流充当内存条的连续单元，即地址低位为体号、高位为体内地址；顺序编址（竖着排）——先排满 0 号芯片再排 1 号。2022 年真题中，8 片 8192×8192×8 位芯片总容量为 512MB，且题干给出"突发传送"即可判定为交叉编址。

> **定义**：多模块交叉编址——主存地址的低位表示存储体号，高位表示体内地址。

> ⚠️ **需回看视频 [02:05:00]**：交叉编址的译码表述前后颠倒（应为高位作体内地址送模块内译码、低位作体号选模块），转写不通顺 —— "交叉编址方式下总是把高位的地址送到了由低位这个体号存这个所确定的模块进行一个译码"

## 内存条 + 突发传送 ⇒ 交叉编址（408 结论）

[02:09:00 - 02:13:00]

在 408 范围内，只要题目给出"内存条"并说明采用突发传送总线事务，就可以直接断定它采用多模块交叉编址，可以当已知条件用（2022 年真题即如此）。原理上把单个芯片的整行读入行缓冲后再连续读出也能突发传送，但那只在 SDRAM 上才能实现，属考纲之外。因此这个点上不要与出题人较劲，记住 408 的固定结论即可。

## 内存条地址引脚、行缓冲与 MDR 宽度

[02:13:00 - 02:18:00]

2022 年真题：8 片 8192×8192×8 位芯片，每片 8192 行 × 8192 列即 2^13 × 2^13，故地址引脚 13 位（不是 26 位，因行列复用），行缓冲器 = 8192 列 × 8 位 = 8KB/片。同类题：16M×8 位、按字节编址 ⇒ 4K 行 × 4K 列，行缓冲 4KB/片、8 片共 32KB，地址引脚 12 位 + 数据引脚 8 位 = 20 位。MDR 宽度取决于存储器总线宽度（总线 8 位则 MDR 8 位），与机器字长无关。

> ⚠️ **需回看视频 [02:15:00]**：例题缺少"按字节编址"这一已知条件，老师现场补充，题干不完整 —— "这个少了一个，少了个已知啊，就是按字节编址啊"

## 答疑：MDR 拼接、引脚数与非写分配法

[02:18:00 - 02:32:00]

非写分配法只写主存、不调入 cache，若反复访问同一数据就会一直 cache miss，这是它的固有代价。编址单位与存储单元位数通常由出题人设计成一致，不必担心二者不匹配。关于引脚：老师认可"内存条地址引脚 = 单芯片地址引脚 × 芯片数"的说法；MDR 位数 = 存储器总线宽度，若想要 64 位数据而总线只有 8 位，则由 CPU 内的寄存器分多次拼装（8 位一次装入 64 位寄存器的不同字节）。

> ⚠️ **需回看视频 [02:29:00]**："内存条地址引脚 = 单芯片引脚 × 芯片数"与位扩展时各芯片地址线并联共享相冲突，需确认适用前提 —— "如果问内存条内的地址引脚是不是单个芯片引址，那个地址引脚乘上内存条里面第二个芯片的个数啊，是的啊"

## 非突发传送下读取主存块的时间

[02:32:00 - 02:35:00]

不支持突发传送时，一次总线只能传一个总线宽度的数据，读一个主存块要拆成多次传输，且每次都要重新发地址。2023 年题：总线宽 64 位（8B）、时钟 1GHz、地址与数据各占 1 个时钟周期、主存准备 64 位数据需 6ns、块 32B ⇒ 需 4 次传输，总时间 = 4 ×（1 周期 + 6ns + 1 周期）。

> **公式**：T =（块大小 ÷ 总线宽度）×（发地址时间 + 准备时间 + 传数据时间）

## 突发传送：同时启动方案

[02:35:00 - 02:38:00]

同时启动：所有存储体同一时刻启动、各自准备一个字，再并行送到总线，一个存取周期即可送出整个主存块。适用条件是存储器总线宽度 = 存储体个数 × 每个存储体的字长（如 8 体 × 8 位 = 64 位总线，需 64 根数据线）。2017 年真题：4 个存储体按字节编址、总线 32 位，正好 4 × 8 = 32，故采用同时启动。

> **公式**：存储器总线宽度 = 体数 × 体字长 ⇒ 同时启动
> **易错点**：同时启动要求"总线一次能吃下所有体"，宽度不够就只能轮流启动。

> ⚠️ **需回看视频 [02:38:00]**：数据线根数出现"七百六十四根"的乱码，应为 64 根 —— "但缺点呢，就是存储器总线需要七百六十四根数据线"

## 突发传送：轮流启动方案

[02:38:00 - 02:43:00]

轮流启动：各存储体错开一个总线传输周期依次启动，以流水线方式连续送出；充分流动后总线只需一个体字长的数据线，速率即可接近同时启动。适用条件是存储器总线宽度 = 单个存储体的字长。例：8 体、体字长 1B、存储周期 40ns、总线传输周期 5ns ⇒ 每 5ns 启动一个体（0、5、…、35ns），数据在 40、45、…、75ns 依次就绪，每 5ns 送出一字节，MDR 宽度为 8 位。

> **公式**：相邻体启动间隔 = 存储周期 ÷ 体数（且不小于总线传输周期）
> **易错点**：轮流启动下 MDR 只有总线宽度那么宽，靠 CPU 内部拼装成整块。

## 存储周期的两种口径

[02:43:00 - 02:47:00]

完整存储周期含五步：送地址并译码定位、读出整行（破坏性读出，电荷清零）、经读出放大器送 CPU（先入行缓冲再按列选出）、数据再生（重新写回原值）、再生/放大电路恢复。大题计算时为简化只取前三步（收地址、准备数据、读出数据），省略再生与电路恢复时间；选择题则按完整五步判断。

> **易错点**：同一个"存取周期"，大题与选择题的口径不同，先看题型再套步骤。

## 2013 真题：传输时间计算与启动方式判定

[02:47:00 - 02:49:00]

2013 年真题要求算出一个主存块经突发传送总线事务送入 cache 的时间。判定启动方式的依据：题目明说采用突发传送，更关键的是存储器总线宽度是否等于单个存储体字长——相等即轮流启动；若把总线加宽到 32B（= 8 体 × 4B），就可同时启动，8 体并行准备，时间变为 40ns + 5ns = 45ns（不含地址传送）。

## 总线事务与事务分离

[02:49:00 - 02:53:00]

存储器总线上只有 CPU（主设备）和主存（从设备）。未采用事务分离：CPU 取得总线权后送地址，随后必须一直占用总线等主存准备好数据，主存再申请总线权把数据送回，CPU 全程空等。采用事务分离：CPU 送完地址即释放总线去处理别的事务，主存准备好后自行申请总线权送出数据，CPU 只需给出一个 read 信号，总线利用率因此提高。

> **定义**：总线事务分离——主设备发出地址/命令后立即释放总线，由从设备在数据就绪后重新申请总线完成数据传送。

## 总线事务的五个阶段

[02:53:00 - 02:56:00]

一次总线事务（也称总线周期）指从主设备发出地址到取回数据（或写入完成）的全过程，包含请求、仲裁、寻址、传输、释放五个阶段，实现"地址发送—数据准备—数据传送"三个过程。普通总线读/写事务一次只传一个字（一个存储单元）；若从首地址开始连续传送一个主存块，则称突发传送总线事务。总线事务周期长度近似等于一个存储周期。

## DRAM 异步、SDRAM 同步与周期挪用

[02:56:00 - 03:02:00]

传统 DRAM 与 CPU 异步交换数据：CPU 发出地址和控制信号后经一段延迟才读到数据，期间不断采样完成信号，未完成则插入等待周期，相当于未采用事务分离。SDRAM 的读写受系统时钟控制，与 CPU 同步传输，可配合事务分离，CPU 给完地址即可离开。考纲只要求 DRAM，SDRAM 及 DDR2/3/4 的具体特性不考，但 SDRAM 同步、可事务分离这一特性会在总线部分涉及。周期挪用 DMA 的每次传送必须发生在一次总线事务之后。

> **易错点**：题干出现 DDR3-1333 只是给工作频率用于算带宽，不需要掌握其内部特性。

## 异步通信的三种互锁方式

[03:02:00 - 03:10:00]

不互锁：主设备发请求后不等待应答，延时后即撤销请求；从设备应答后也不等待确认，延时后撤销应答，双方无互锁关系。半互锁：主设备必须收到应答才撤销请求，而从设备发出应答后不等确认即撤销，只有单向约束（类似 TCP 四次挥手中服务器发完 FIN 收到确认就关闭）。全互锁：请求和应答都要等到对方确认才撤销，是双向约束（类似 TCP 的确认机制）。

> **易错点**：区分半/全互锁，看"从设备的应答是否需要等主设备再确认"。

## 多通道存储器总线与带宽

[03:10:00 - 03:11:00]

多通道存储器总线指 CPU 与主存之间有多条并行总线，用于提升带宽；三通道即三条存储器总线。带宽计算：先算单通道（工作频率 × 位宽 ÷ 8），再乘通道数。如三通道、1333MHz、64 位：1333M × 64 ÷ 8 × 3。

> **公式**：总线带宽 = 工作频率 × 总线宽度(位) ÷ 8 × 通道数

## 指令与存储综合：a[i] += 1 的汇编实现与地址计算

[03:11:00 - 03:25:00]

C 语句 a[i] += 1 不可能由一条指令完成——一条指令不能同时包含一次访存读和一次访存写；x86 下编译成约五条指令：取 i、按 arr 基址 + i×4 取 a[i]、加 1、再取一次 i、把结果写回 a[i]。例题：arr 基址 0013DFB8H、EBP = 0013F008H，i 存于 EBP − 18H，i = 10H = 16，故 a[i] 地址 = 0013DFB8H + 16 × 4 = 0013DFF8H，该 4 字节内容加 1 后写回。2024 年真题第 44 题用 MIPS 指令考了同样的"读指令 + 算地址 + 改存储"综合。

> **公式**：数组元素地址 = 基址 + 下标 × 元素字节数（int 为 4B）
> **易错点**：一条指令只能完成一次访存读或一次访存写，别把 a[i] += 1 当成单指令操作。

> ⚠️ **需回看视频 [03:24:00]**：老师现场承认 EBP − 18H 的结果算错（0013F008H − 18H 应为 0013EFF0H，课上写成 0013FF0H），例题数据需按更正后重算 —— "0013F，呃，然后这个是F008H减去这个呃减去这个18H，应该是这个0FFE啊"

## 答疑：总线主设备唯一性、事务分离真题与访存次数

[03:25:00 - 03:34:27]

事务分离的考法在 2016 年真题第 21 题第 4 小问出现过（判断"采用事务分离可提高总线利用率"）。a[i] += x 含两次 cache 访问（读 + 写），a[i] = y 只有一次写访问。非突发传送时地址与数据不能并行，因为送地址时 CPU 是主设备、传数据时主存是主设备，而一条总线同一时刻只能有一个主设备（可有多个从设备）。存储器扩展除芯片数计算外基本没有其他考法；未采用事务分离的控制信号可参考 2009 年真题第 44 题的 MARin、MDRinE 等信号。
