# 第1讲 计算机系统概述（绪论）

## 【视频01】课程导学：四零八难点、框架流与四步学习法

[00:00:00 - 00:14:00]

除数据结构外的三门课（计组、操作系统、计算机网络）难度更高，难点有三：一是知识点细碎庞杂，纯靠记忆难以精准覆盖考点；二是缺乏整体理解、知识点之间无法串联，而四零八真题常做跨章节、跨学科的联动大题；三是只停留在"能做某些题"的层面，题目一变就不会，对本质理解模糊。零一采用框架流：先划分主干知识体系的模块，再串联模块，建框架时只关注"有哪些模块、每个模块提供什么功能、模块之间如何联动"，框架成型后再进各模块填细节。零一课程的学法为四步：①预习，用讲义加基础课建立简单认识即可，不求透彻；②听课，录播听原速、不分心，跟着回答随堂提问；③复习，课后凭自己对框架和细节的理解记笔记，再与课程对照修正，不要抄 PPT 或书本；④实践，做课后题，做错或靠排除法/蒙对都算不会，要回看对应内容。任何无法独立解决的问题都应找全年答疑求助。

> **易错点**：复习笔记要凭理解自己写后与课程对照，直接抄 PPT/书不算有效的复习。

## 【视频01】计算机黑盒模型、程序与真值/机器数

[00:14:00 - 00:24:00]

计算机可看成一个处理数据的黑盒子：给定输入就给出输出；加入"程序"后，同一输入可按程序给出不同输出（求和、求最大值等）。以 `ax²+bx+c` 为例，需要输入 a、b、c、x 四个真值并输出结果。但硬件内部只有 0 和 1，而现实真值还有小数（小数点）、负数（负号）和零，因此必须设计一套编码规则，把真值转换成机器数放进计算机。机器数即真正输入到硬件内部、由 0/1 组成、与真值一一对应的二进制编码；运算结束后还要用解码规则把机器数还原为真值。真值之间的加减乘除，也需要在计算机内部有与之对应的机器数运算规则（一一对应）。这部分内容属于第二章"数据的表示与运算"。

> **定义**：机器数 = 计算机硬件内部真实存在、由 0/1 组成、对应真值的二进制编码。

## 【视频01】计算机硬件部件：IO 设备、主存、运算器、控制器与 CPU

[00:24:00 - 00:28:00]

用户数据由输入设备（键盘等）获取，结果由输出设备（显示器等）呈现；此外还有存储型设备（如磁盘），外接于主机作扩展空间。数据编码后先经输入设备进入主存储器保存，运算器负责运算，结果再写回主存并经输出设备输出，整个过程由控制器控制。控制器与运算器合称 CPU。IO 部分需要研究：输入设备如何让数据进入、数据存在何处、主机如何取用、如何把数据交给输出设备，以及存储型设备如何与主机交互。

## 【视频01】主存储器的结构与按地址访问

[00:28:00 - 00:34:00]

四零八中主存储器与内存基本视为一致。内存可看成许多格子，每个存储单元都有地址（指针），通过地址即可访问对应数据，高级语言中的变量就对应一个内存地址。存储体是物理结构，基本单位为"位/存储元"，存 1 位 0/1；但实际访问以"存储单元"为单位（本讲例子为 8 位），一次读出或写入一个存储单元。存储单元的长度称为存储字长，存储体可按地址直接访问。

> **公式**：`存储字长 = 存储单元位数`
> **易错点**：表达式 `ax²+bx+c` 在机器内部会被解析为对内存地址数据的计算（括号相当于解引用），并非直接对真值运算。

## 【视频01】运算器基本结构、寄存器与 ALU

[00:34:00 - 00:38:00]

运算器的具体结构因书、因题而异，本讲只采用一种特例结构：ALU 加通用寄存器、专用寄存器。ALU（算术逻辑单元）只负责运算，给它数据就能做加减乘除。寄存器由触发器组成，读写速度极快、价格昂贵，存在于 CPU 中，用来暂存指令、数据和地址；因为快，才能跟得上 ALU 的速度，又因为贵，所以数量有限。通用寄存器是所有程序都可使用、暂存程序中需要数据的寄存器；专用寄存器只作专门用途，例如累加器、乘商寄存器。寄存器与存储单元一样有位宽，8 位寄存器存放 8 比特。

## 【视频01】MAR 与 MDR 与主存的读写过程

[00:38:00 - 00:42:00]

MAR 是内存地址寄存器（Memory Address Register），MDR 是内存数据寄存器（Memory Data Register）。读操作：给出读信号，并把要读的地址写入 MAR，对应存储单元的数据即被读入 MDR，CPU 再从 MDR 取出数据。写操作：给出写信号，把目标地址写入 MAR，同时把要写的数据写入 MDR，数据便写入该地址单元。MAR、MDR 逻辑上属于主存储器的一部分，但在现代 CPU 中它们集成在 CPU 内，实际应算 CPU 的一部分。

## 【视频01】运算器的加乘运算过程与实例

[00:42:00 - 00:54:00]

累加器 ACC 暂存运算结果，又可作为下一次运算的原操作数（如 `x = x*r`）；乘商寄存器 MQ 辅助乘除；操作数寄存器 X 属通用寄存器、提供原操作数，故参与运算的两个操作数分别放在 ACC 和 X。加法：ALU 取 ACC 与 X 相加，结果写回并覆盖 ACC。乘法：两个 8 位相乘得 16 位，高 8 位放 MQ、低 8 位放 ACC（一个寄存器放不下）；ALU 是组合电路，无存储功能。

例：计算 X+Y+Z（X、Y、Z 存于连续内存单元）。先把 X 的地址写入 MAR、给出读信号，数据经 MDR 送入 ACC；再取 Y 经 MDR 送入 X，执行加法得 X+Y 存入 ACC；再取 Z 送入 X，执行加法得 11（本次结果）；最后给写信号、`MAR=0110`、`MDR=ACC`，把结果写回内存。

例：计算 X×Y（X=64，Y=4），得 256，其 16 位表示为高 8 位 `00000001`、低 8 位 `00000000`；高位在 MQ、低位在 ACC。写回时把地址 0110 写入 MAR、把 MQ 中的数据写入 MDR，高 8 位即存入 0110 号单元。

## 【视频01】总线：地址总线、数据总线、控制总线与内部总线

[00:54:00 - 00:57:00]

系统总线主要分三类：地址总线负责传输要访问的地址，一般单向（由 CPU 指向主存，讲 IO 时可能有例外）；数据总线负责传输数据，CPU 与主存之间的数据进出都靠它；控制总线负责传输控制信号，如控制器发出的读/写命令、中断返回信号等。主存与 CPU 之间、以及 IO 设备与主机之间的地址、数据、控制传输都依靠系统总线完成。CPU 内部还有内部总线（片内总线），用于控制器与运算器之间、各寄存器之间的控制信号和数据传输。

## 【视频01】由表达式到六种基本操作命令

[00:57:00 - 01:05:00]

先用秦九韶算法把 `ax²+bx+c` 改写为 `(ax+b)x+c`，以减少运算次数。完成整个任务需要六种操作命令：①取数（内存→ACC，提供第一操作数）；②存数（把结果写回内存）；③取数并做加法（第二操作数取到 X 并做加，结果入 ACC）；④取数并做乘法（结果高位入 MQ、低位入 ACC）；⑤打印；⑥停机。计算过程就是反复调用这六种命令，而这些操作步骤最终要由控制器依次发出。

## 【视频01】答疑：MQ/ACC 高低位与大小端

[01:05:00 - 01:10:00]

MQ 只在做乘法时才起作用，存乘积的高 8 位，ACC 存低 8 位；原因是两个 8 位相乘得 16 位，一个寄存器放不下，只能分存两个寄存器。本讲"ACC 存低位、MQ 存高位"的结构与某些教材不同，只是本课自设的结构。大小端等属细节，不是本次课重点，按框架流以后再填；除法暂不讲解。

## 【视频01】机器指令：操作码字段与地址码字段

[01:10:00 - 01:20:00]

控制器只懂二进制，所以要用二进制编码来表示操作，这就是机器指令，即控制计算机执行对应操作的二进制编码。以栈的 pop/push/destroy 三种操作为例，需 2 位操作码即可区分（00/01/10），再加若干位给出操作元素的信息。机器指令由两部分组成：操作码字段指出执行什么操作，地址码字段指出源操作数地址、结果地址或下一条指令的地址。本讲六种操作中，取数、存数、加、乘、打印都要访问内存、需要地址码字段；停机不需要任何数据，只需操作码字段。示例采用 4 位操作码 + 4 位地址码：取数 0001、存数 0010、加法 0011、乘法 0100、打印 0101、停机 0110。

> **定义**：机器指令 = 控制计算机执行对应操作的二进制编码，含操作码字段与地址码字段。

## 【视频01】八条机器指令实例与指令/数据在内存中的关系

[01:20:00 - 01:31:00]

按 `(ax+b)x+c` 展开为八条指令（操作码 + 地址码）：①把 X 取到 ACC（`0001 1011`，X 地址 1011）；②乘（`0100 1000`，取 A 入 X 并相乘）；③加（`0011 1001`，取 B 相 加）；④乘（`0100 1011`，与 X 相乘）；⑤加（取 C 相加）；⑥存数（`0010 1100`，结果写回 1100）；⑦打印（`0101 1100`）；⑧停机（`0110 0000`）。指令本身也是二进制编码，与数据以同等地位按顺序存放在内存中，同一内存单元既可放指令也可放数据，存储器无法区分二者。区分取决于把它送到哪里：送 MAR 就当地址用，送通用寄存器/ACC 就当数据用，送控制器（CU）/IR 就当指令用；另有"按指令执行的不同周期区分"的说法。

> ⚠️ **需回看视频 [01:20:00]**：主讲人先说 A 的地址是 0100、取 A 的机器指令为 00010010，但后文乘操作中 A 的地址又为 1000，前后数字不一致 —— "A对应的地址是0100，那么我取A，它对应的机器指令应该是什么？……所以它就是00010010。"
> ⚠️ **需回看视频 [01:29:00]**：疑似 ASR 错字，寄存器应为 MAR 而非 MIR —— "如果它送到了我们前面说的MIR当中去，那它就是一个地址。"

## 【视频01】控制器组成：PC、IR、CU 与取指执行过程

[01:31:00 - 01:41:00]

控制器主要由两个寄存器和控制单元组成：PC（程序计数器）、IR（指令寄存器）和 CU（控制单元）。PC 给出当前要执行指令在内存中的地址，因 PC 与 MAR 之间有直连通路，指令可经 MDR 取出并送入 IR；IR 存放当前要执行的指令。指令的操作码部分由 CU 译码，产生相应控制信号；地址码在本讲中直接对应内存地址（后续章节含义更多）。除非特殊情况，每取出一条指令 PC 就自动加一，所以指令只需顺序存放即可依次取指执行；PC 的初始值由操作系统设置，本次课不必深究。整体执行流程为：PC 给出地址→取指入 IR→CU 译码→发出控制信号，依次完成取数、乘、加等，最后打印并停机。

## 【视频01】冯·诺依曼机结构与运算器/存储器中心辨析

[01:41:00 - 01:49:00]

冯·诺依曼机由运算器、存储器、控制器、输入设备、输出设备五大部件组成。其结构特点是：指令和数据以同等地位存放在存储器内、可按地址寻访，且均用二进制表示；指令由操作码和地址码组成，操作码表示操作性质、地址码表示操作数在存储器中的位置；指令在存储器内按顺序存放、通常顺序执行（特定条件下可跳转改变顺序）；以运算器为中心，输入输出设备与存储器之间的数据传送要通过运算器完成。关键辨析：冯·诺依曼机以运算器为中心，而现代计算机以存储器为中心——因 DMA、总线通道等技术使设备可与主存直接交换数据，无需再借运算器中的通用寄存器作中介，且主存空间更大、可并行完成大量传输。

## 【视频01】计算机系统组成、软硬件分类与软硬件区分

[01:49:00 - 01:54:00]

计算机系统由硬件和软件两大部分组成；主存与 CPU 合称主机，磁盘等属存储型外设。软件是完成特定功能的程序（即一堆指令），分为系统软件和应用软件：应用软件（游戏、QQ、微信、办公软件等）与计算机系统本身无关；系统软件与计算机资源有关，如标准程序库、语言处理程序（汇编/编译程序）、操作系统、数据库管理、网络软件等。特例：数据库管理系统是系统软件，而数据库系统是应用软件。软硬件的区分：由指令直接控制实现的功能属软件，没有指令参与、自动完成的功能属硬件，二者接口是"指令系统"；软件与硬件在逻辑上等效，但并非等价（实现细节不同）。

## 【视频01】计算机系统多级层次结构与 ISA

[01:54:00 - 02:02:00]

多级层次结构自上层到下层依次为：高级语言→汇编语言→机器语言（机器指令）→微指令系统（微程序/微操作）。高级语言须经编译/翻译变成汇编语言，汇编再进一步变成机器语言；汇编用助记符表示操作码，与机器的二进制指令一一对应，可视为机器语言的另一种表示形式。层次中通常还插入"操作系统"层，帮助用户管理底层软硬件资源。另一种分层（袁春风教材）为：上层是软件（系统软件 + 用户软件），下层是与硬件细节、电路特性有关的内容，中间的 ISA（指令集体系结构）就是软硬件接口，由指令系统支持，上层软件只需关注下层提供的指令接口。

> ⚠️ **需回看视频 [01:56:00]**：层次转化的顺序口述混乱、疑似转写缺漏 —— "机器语言再进一步，它变成了一个程序、微指令、微程序、微操作等等这些东西。"

## 【视频01】计算机主要性能指标与例题精讲

[02:02:00 - 02:26:00]

机器字长是通用寄存器的位数，也叫计算机位数，等于 ALU 一次整数（定点数）运算可支持的最大位数，不含浮点运算。指令字长是一条指令的位数，必须是字节（8 位）的整数倍，一般取存储字长的整数倍或一半以便存取。存储字长是一个存储单元的位数，等于 MDR 的位数；数据字长即数据总线的位数，可以不等于 MDR 的位数。存储容量：主存容量 = 存储字长 × 存储单元个数（另有辅存容量）；吞吐量是单位时间内处理请求的数量；响应时间 = 等待时间 + CPU 时间。时钟周期 T 是 CPU 的最小时间单位（节拍），CPU 周期/机器周期已基本淘汰；时钟频率 `f = 1/T`，单位 Hz/MHz。

CPI 是执行一条指令所需的时钟周期数，平均 CPI 为各类指令 CPI 的加权平均。执行时间 `CPU时间 = 时钟周期数 × T = 时钟周期数 / f = 指令条数 × CPI × T`，由主频、CPI、指令条数三者共同决定，不能只归因于其中之一。每秒百万条指令 `MIPS = 主频 / (CPI × 10^6)`，另有 IPC（每时钟周期执行的指令数）；浮点指标有 MFLOPS、GFLOPS、TFLOPS、PFLOPS。单位换算：作速度时 K=10³、M=10⁶、G=10⁹、T=10¹²、P=10¹⁵；作容量时 K=2¹⁰、M=2²⁰、G=2³⁰、T=2⁴⁰、P=2⁵⁰，如 `1KB = 2¹⁰ B`。

例1：缩短程序执行时间的措施——提高时钟频率（降低时钟周期）✓；编译优化（如把 `ax²+bx+c` 改写成 `(ax+b)x+c`，减少指令条数）✓；优化数据通路结构（影响 CPI）✓。

例2：程序运行 100s，其中 CPU 时间 90s、I/O 10s，CPU 提速 50%、I/O 不变。CPU 时间变为 `90 × 2/3 = 60s`，总时间为 70s（陷阱：速度提高 50% 不等于时间减半）。（答案：70s）

例3：主频 1.2GHz，四类指令占比与 CPI 给定，求 MIPS。平均 `CPI = 1 + 0.6 + 0.4 + 1 = 3`；每秒指令数 `= 1.2G / 3 = 0.4G = 400M`，故 `MIPS = 400`。（答案：400，选 C）

例4：与机器字长相同的是 ALU 操作数宽度和通用寄存器宽度；指令寄存器代表指令字长，浮点寄存器与机器字长无关。（选 B）

例5：神威太湖之光浮点峰值约 93.0146 P，换算后约为 9.3 亿亿次/秒。（选 D）

## 【视频01】课程章节规划与答疑

[02:26:00 - 02:38:10]

章节规划：冯·诺依曼计算机分存储器、CPU、IO 三部分，通过系统总线相连；CPU 可细化为 CU、ALU 与寄存器，其中数据通路（片内总线）是学习重点。后续内容包括数据的表示与运算、指令系统、总线（标准/分类/性能/判优仲裁/通信方式）、存储系统（重中之重，含层次化结构、主存结构）、IO 系统（查询、中断、DMA 方式）、运算器（运算规则与电路设计）、控制器（硬布线/微程序）与指令流水线等，约分成八个部分。答疑要点：计算机系统多级层次结构考得不多、以理解为主；乘除法属基础课内容；所有内容都可能考大题，真题考过的点相对更重要，边角知识（如除法器）也可能出十几分大题；计组满分 45 分；浮点寄存器与机器字长无关；性能指标重在理解、多为小学数学式的推导。复习建议：先看讲义与参考书、建立整体理解后再看教材（推荐袁春风教材）。
