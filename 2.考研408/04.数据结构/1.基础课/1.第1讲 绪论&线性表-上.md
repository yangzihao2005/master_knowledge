# 数据结构基础课 第1讲 绪论&线性表-上

## 数据结构的基本概念与三要素

[00:00:00 - 00:26:00]

开头约 19 分钟为课程介绍、往届成绩展示与全年课程安排（基础课 9 讲、一模/二模/三模、强化课 5 讲、冲刺课 3 讲等），不是知识点，只占时间。绪论分两块：数据结构的基本概念，以及算法与算法的评价指标；后者中的时间/空间复杂度是本章唯一的重点。

数据结构是带结构特性的数据元素的集合，只关注元素之间的逻辑关系与物理存储方式，不关注元素本身存的是什么类型；并在此基础上定义增、删、改、查等运算。逻辑结构分线性结构与非线性结构（集合、树、图）；存储结构分顺序、链式、散列、索引，其中散列与索引留到查找一章。

> **定义**：数据结构 = 逻辑结构 + 存储结构 + 数据的运算（三要素）。
> **定义**：数据是对客观事物的符号表示；数据元素是数据的基本单位；数据项是不可分割的最小单位；数据对象是性质相同的数据元素的集合。
> **易错点**：三要素不是数据结构的充要条件——一个 ADT（抽象数据类型）即可完整定义一个数据结构。这是一道经典错题，记住结论即可，不必深究。
> **易错点**：对数据结构做任何运算后都不能破坏它原有的结构特性，否则是非法操作（后面链表"断链"就是违反此原则）。

## 算法的定义与描述方式

[00:26:00 - 00:29:00]

算法是解决问题的具体步骤/过程，必须有准确而完整的描述：对规范的输入，在有限时间内产生所要求的输出。同一任务可由不同算法完成，时间、空间开销更小者更优。描述方式有自然语言、流程图、伪代码和程序代码：伪代码借用 C 的 for/while/if 结构加自然语言，不能被计算机执行；程序代码经编译器或解释器转成机器码后才能执行。例：把大象装进冰箱（开门—塞进去—关门）三步，就是一种算法思想。

> **易错点**：伪代码不可执行，程序才可执行；二者差别在"能否被计算机运行"。

## 算法的五大特征与四大目标

[00:29:00 - 00:32:00]

五大特征：有穷性（有限步、有限时间内结束）、确定性（每步含义唯一、无二义性）、可行性（每步都能分解为可执行的基本操作）、输入（0 个或多个）、输出（至少一个）。四大目标：正确性、可读性、健壮性、高效率（时间/空间复杂度尽量低）。408 对可读性的具体要求是：关键语句（for、while、if 等代码块）后加简短注释，说明该段完成什么功能。健壮性即能处理非法输入与边界条件，复试上机尤其吃这个亏。

> **易错点**：输入可以为 0 个（形参为空），输出至少要 1 个；有穷性是对"步数与时间"的双重要求。

## 时间复杂度与语句频度

[00:32:00 - 00:36:00]

时间复杂度是算法中基本操作重复执行的次数，也叫语句频度 T(n)；求出 T(n) 后忽略低阶、忽略系数、只保留最高阶，记为大 O。计算三步：确定问题规模 n → 数出核心语句的执行次数 T(n) → 保留最高阶。运算规则：并列（顺序执行）的两段取较大者，嵌套的两段相乘。常见阶排序：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < …；408 常考到 O(n²) 左右。

> **公式**：T(n) = 2n² + n + 1 → O(n²)（n 趋于无穷时 n² 增长最快）。
> **公式**：并列 T(n)=T₁(n)+T₂(n)=O(max(T₁,T₂))；嵌套 T(n)=T₁(n)×T₂(n)。

## 空间复杂度与原地工作

[00:36:00 - 00:40:00]

空间复杂度指算法除存储数据本身所需空间之外，还需要的额外辅助空间。例：数组逆置若另开一个等长数组倒着放，辅助空间随 n 增长，为 O(n)；若只用一个 temp 变量两两交换，无论 n 多大都只需常数个变量，为 O(1)，称为原地工作。考研题里"要求原地逆置/原地工作"就是在要求空间复杂度 O(1)，不满足拿不到满分。空间复杂度的优劣次序同样是 O(1) < O(log n) < O(n) < O(n²)。

> ⚠️ **需回看视频 [00:39:00]**：此处结论把"空间复杂度"说成了"时间复杂度"，属口误，按上下文应为 O(1) 的空间复杂度 —— "显然它的时间复杂度就是 O(1) 的，因为它并不会随着我输入的规模变化而变化。"

## 定义法入门：一重循环与 O(n)

[00:40:00 - 00:48:00]

定义法是用求和符号精确统计核心语句的执行次数：T(n) = Σ_{i∈值域} 1，值域由循环变量的实际取值决定，末尾的"1"表示每个取值下核心语句只执行一次。for 循环由四部分组成：循环变量初始化、终止条件、循环体、循环变量自增（小括号里只有前三部分）；while 只有终止条件，初始化写在循环前，自增写在循环体内，二者可等价转换。例：for(i=1;i<=n;i++) count++; 的 i 取 1..n 共 n 个值，T(n)=n，即 O(n)。

> **公式**：T(n) = Σ_{i=1}^{n} 1 = n = O(n)。
> **易错点**：while 循环体里漏写自增会变成死循环，违反有穷性；把 while 改写成 for 时，"初始化 + 条件 + 自增"三件套必须补齐。

## 循环变量倍增：O(log n)

[00:48:00 - 00:54:00]

for(i=1;i<=n;i*=2) 中 i 取 1,2,4,…,2^k，令 2^k=n 得 k=log₂n，项数为 k+1=log₂n+1，故 O(log n)。计数技巧：把每项都写成 2 的幂，问题就变成数指数从 0 到 k 有多少个，答案是 k+1，别漏掉"从 0 开始"这个陷阱。循环变量每次 +1 是线性变化，每次 ×2 是对数变化，增长快慢一目了然。考研中不写底数时，log 默认以 2 为底。

> **公式**：T(n) = Σ_{i=1,2,4,…,2^k} 1 = k+1 = log₂n + 1 = O(log n)。

## 二重循环：线性嵌套线性 O(n²)

[00:54:00 - 01:00:00]

两层 for 都以 +1 变化、上界都是 n 时，外层每取一个 i，内层都要完整执行 n 次，共 n×n 次。定义法写两个求和号：由外向内写（每个求和号对应一层循环），由内向外解。关键细节：每次重新进入内层循环，内层循环变量都要重新初始化，不是接着上一轮继续。

> **公式**：T(n) = Σ_{i=1}^{n} Σ_{j=1}^{n} 1 = n² = O(n²)。

## 内层上界依赖外层：j ≤ i 的等差数列

[01:00:00 - 01:05:00]

内层写成 for(j=1;j<=i;j++) 时，内层执行次数取决于外层当前的 i：i=1 执行 1 次，i=2 执行 2 次……i=n 执行 n 次。解内层得 i（j 从 1 到 i 共 i 个数），再对外层求和即等差数列。仍属"线性嵌套线性"，按规模相乘估算也能得到同样结论。

> **公式**：T(n) = Σ_{i=1}^{n} i = n(n+1)/2 = O(n²)。

## 线性嵌套对数：O(n log n)

[01:05:00 - 01:11:00]

外层 i=1..n 线性，内层 j=1,2,4,… 且 j≤i，则内层执行 ⌊log₂i⌋+1 次。于是 T(n)=Σ(1+log i)=n+log(n!)，用斯特林公式 log(n!) = O(n log n)（只记结论，不考推导），得到 n log n + n，取高阶为 O(n log n)。

> **公式**：T(n) = Σ_{i=1}^{n} (1 + log₂i) = n + log₂(n!) = O(n log n)。
> ⚠️ **需回看视频 [01:10:00]**：转写把结论说成"大 O n"，与上一句"n log n 加 n、忽略低阶取高阶"矛盾，疑为口误或 ASR 漏字，按推导应为 O(n log n) —— "把它写成一个n log n加上n，那咱们是不是可以忽略低阶取高阶，最后它的时间复杂度就是一个大O n了。"

## 对数嵌套线性：O(n)

[01:11:00 - 01:18:00]

外层 i=1; i<=n; i*=2，内层 j=1..i 每次 +1。此时内层执行 i 次，展开求和是等比数列 1+2+4+…+2^k，令最后一次的 2^k=n，得 2^{k+1}-1=2n-1。取高阶去系数后是 O(n)。易错点：不能凭"log 级 × n 级 = n log n"估算，本题答案是 O(n)；外层为非线性变化时只能老老实实用定义法，凭感觉估算必错。

> **公式**：T(n) = 1+2+4+…+2^k = 2^{k+1}-1 = 2n-1 = O(n)。

## 三重循环：O(n³)

[01:18:00 - 01:25:00]

i=1..n、j=1..i、k=1..j 三层均 +1，由内向外解：k 层得 j，j 层得 1+2+…+i=i(i+1)/2，再对 i 求和。用平方和公式后得 n(n+1)(n+2)/6，取最高阶即 O(n³)。此题也说明定义法能给出精确的执行次数，不只是数量级。

> **公式**：1²+2²+…+n² = n(n+1)(2n+1)/6；T(n) = n(n+1)(n+2)/6 = O(n³)。
> **易错点**：定义法最后的门槛是等差、等比、平方和（以及立方和）公式必须熟记。

## 定义法的速算写法与求解步骤

[01:25:00 - 01:37:00]

熟练后不必画表格，直接看 for 头部就能列出定义法：由外向内逐个写求和号，每个求和号看三处——循环变量名、初值（起点）、终值（终点），自增方式决定展开形式（+1 或 ×2）；最内层写 1，表示该取值下核心语句执行一次。求值顺序与列式相反：由内向外。总步骤：确定规模 n → 由外向内列式 → 由内向外求和 → 忽略低阶与系数取最高阶。

## 真题级三重循环：O(n²)

[01:37:00 - 01:43:00]

外层 i=1,2,4,…,2^m=n（非线性），中间 j=1..i，内层 k=1..j。由内向外：k 层得 j，j 层得 i(i+1)/2，再对 i 的等比取值求和，拆成 Σi 与 Σi² 两部分，其中 Σi=2n-1、Σi² 是公比为 4 的等比数列，最终为 O(n²)。求时间复杂度时只需看 i² 那一项，系数 1/2 与低阶的 i 都可直接丢弃。这类题是真题第一道选择题的常见形态，不会定义法基本无法作答。

> **公式**：T(n) = ½(Σi + Σi²) = ½[(2n-1) + (4n²-1)/3] = O(n²)，其中 i = 2^0,2^1,…,2^m，2^m=n。
> ⚠️ **需回看视频 [01:41:00]**：该题等比/平方和部分的转写残缺，"四的平方""二的m的平方"等表述与数列项对不上，需核对板书 —— "这块你展开变成一个四的平方，然后后面就变成了一个八的平方、十六的平方，然后最后变成一个二的m的平方。"

## 两类特殊题型：O(√n) 与循环体内改变外层变量

[01:43:00 - 01:48:00]

第一类：退出条件不是 i<=n 而是含 i 的表达式。如 while((y+1)*(y+1)<=n) y++; 展开后只保留最高阶项 y²≤n，即 y 约到 √n，复杂度 O(√n)，无需定义法。第二类：循环体内修改了外层循环变量。如 for(i=1;i<n;i++) for(j=1;j<n;j++){count++; i++;}，内层每轮都让 i 自增，外层实际只进入一次，复杂度是 O(n) 而不是 O(n²)。判断要点是"循环条件的形式"和"循环体内语句是否影响循环执行次数"。

> ⚠️ **需回看视频 [01:44:00]**：该 while 题的讲解中变量在 y 与 i 之间反复混用，转写前后不自洽（究竟哪个变量在自增），需回看原题条件 —— "它最后就变成了一个i方小于等于n……i的取值呢，又是一个0加上k"。

## 时间复杂度题型的判断总结

[01:48:00 - 01:51:00]

多层 for 分两类处理：最外层是线性变化（+1）时，可按"规模相乘"快速估算，如 n×n、n×log n、n³；最外层是非线性变化（×2 等）时，无论内层怎么套，都必须用定义法。估算前确认三件事：循环是线性还是非线性变化、循环的退出条件、循环体内的语句是否改变循环执行次数。

## 线性表的定义与逻辑特征

[01:51:00 - 01:54:00]

线性表是 n 个具有相同特性的数据元素组成的有限有序序列。逐词理解：n 是表长（元素个数）；"相同特性"指元素数据类型一致，不能 int、float、char 混存；"有限"指长度确定；"有序"指逻辑上有先后次序（像排队），不是按值升序/降序排列。除表头（无直接前驱）与表尾（无直接后继）外，每个元素有且仅有一个直接前驱和一个直接后继。

## 顺序表的定义与结构体

[01:54:00 - 01:57:00]

顺序表是逻辑上相邻的元素在物理内存地址上也相邻的线性表。C 语言描述：typedef struct { ElemType data[MaxSize]; int length; } SqList; data 是存放元素的数组，MaxSize 是容量，length 是当前元素个数。typedef 就是给结构体起别名，408 中仍大量使用。

> **易错点**：length 是当前元素个数（会随插入删除变化），不是数组容量；length == MaxSize 才表示表满。
> **易错点**：ElemType 只是元素类型的占位符（类似泛型），具体是 int 还是 char 不影响结构定义。

## 静态分配、动态分配与顺序表 ≠ 数组

[01:57:00 - 02:01:00]

静态分配在声明时就划好固定容量（data[MaxSize]）；动态分配只给一个首地址指针，用时再 malloc，结构体中多一个 MaxSize 成员。数组与顺序表不是一回事：顺序表是封装了 data 与 length 的结构体，数组在数据结构中算不上一种标准数据结构。取第 i 个元素：数组写 a[i-1]，顺序表写 L.data[i-1]；插入表尾：数组直接赋值，顺序表还要 L.length++。

> **易错点**：顺序表 ≠ 数组，两者存取方式与操作方式都不同（顺序表多一层结构体成员与 length 维护）。

## 动态扩容与 malloc/free

[02:01:00 - 02:05:00]

表满后（length == MaxSize）静态分配会溢出报错，动态分配可以扩容。两种方式：① 原地址后面的空间空闲，直接在其后延伸；② 后续地址已被别的进程占用，则另申请一片更大空间，把原元素整体搬过去、插入新元素，再 free 掉旧空间。方式②除插入外还要额外 O(n) 的搬迁时间。对应 C 的 malloc 申请、realloc 扩容、free 释放；C++ 用 new/delete，必须成对出现，否则内存泄漏（强化班再展开）。

> **公式**：malloc 的大小 = sizeof(ElemType) × 需要的元素个数。
> **易错点**：动态扩容不是零代价，方式②的代价是 O(n) 的元素搬迁。

## 单链表的节点定义与分层定义

[02:05:00 - 02:11:00]

节点定义：typedef struct LNode { ElemType data; struct LNode *next; } LNode, *LinkList; next 是指向同类型节点的指针，所以链表节点在内存中不要求连续。建议把"链表"与"节点"分开定义：链表结构体只含一个头指针（可再加 length），节点只含 data 与 next。若按王道那种合并定义，每个节点都会多带一个 length 字段，浪费空间；分开定义后求表长可 O(1)，合并定义则要遍历整表 O(n)。

> **易错点**：求表长 O(1) 还是 O(n)，取决于 length 是表级成员还是需要遍历统计。

## 头节点、头指针与首元节点

[02:11:00 - 02:14:00]

头节点：data 域不用（可用来存表长等信息）、类型仍是 LNode 的节点，作为链表的第一个节点。头指针：指向链表第一个节点的指针——有头节点时指向头节点，无头节点时指向首元节点。首元节点：第一个真正存放数据元素的节点，无论有没有头节点都这么叫。

> **易错点**："头指针"不等于"头节点指针"；表长按元素个数算，不含头节点，说"元素个数"比"节点个数"更准确。

## 链式存储的物理特性与存储密度

[02:14:00 - 02:17:00]

链式存储中逻辑相邻的节点物理地址不一定相邻，靠 next 指针建立联系；但一个节点内部的 data 与 next 是一次性整体申请的，地址必然相邻。概括为"节点间地址不一定连续，节点内一定连续"。由于每个节点都有一部分空间分给指针域，链表的存储密度小于 1，而顺序表的存储密度为 1。

## 双链表的结构

[02:17:00 - 02:19:00]

双链表节点除 data 外有两个指针域：prior 指向直接前驱，next 指向直接后继。不带头节点时，首元节点的 prior 为空、尾节点的 next 为空。画图时注意 prior/next 指向的是整个节点（struct 类型地址），图中简化为指向节点即可，严格说指向的是节点起始地址。

## 循环单链表、循环双链表与"逻辑结构不变"

[02:19:00 - 02:21:00]

循环单链表：尾节点的 next 不置空，改为指向头节点（无头节点则指向首元节点）。循环双链表：在此基础上再让头节点的 prior 指向尾节点。经典判断题：循环单链表"看起来是个圈，所以不再是线性结构"——错。改变指针只是改变了物理实现，逻辑上仍是一对一有序、首元无前驱、尾元无后继，仍是线性结构。

> **易错点**：循环链表仍是线性结构；"循环"是存储层面的说法，不是逻辑结构层面的说法。

## 静态链表

[02:21:00 - 02:25:00]

静态链表用一维数组模拟链表：每个分量含 data 与 cur（游标，存下一个元素在数组中的下标），-1 表示无后继；一次性申请一片连续空间（如 100 个），下标 0 固定作头节点。按游标链读取：0 → 1(A) → 4(D) → 2(B) → 6(C) → -1。插入、删除只改游标，不移动元素，但需要预先分配较大连续空间。

> **易错点**：静态链表虽借助数组实现，但逻辑相邻元素物理上并不相邻（A 在下标 1、D 在下标 4），属链式存储，不是顺序表。

## 顺序表的插入

[02:25:00 - 02:29:00]

表尾插入：L.data[L.length] = x; L.length++;，靠随机存取直接定位，O(1)。中间或表首插入：必须先把第 i 个位置及其后的元素整体后移一位腾出空位，再写入并 length++，直接赋值会覆盖原元素。移动元素个数为 n-i+1，平均 n/2，故 O(n)，时间全部花在移动上。

> **定义**：随机存取——用下标在 O(1) 时间内定位任意元素并读写，是顺序表的特点。

## 顺序表的删除

[02:29:00 - 02:31:00]

删除第 i 个元素：把其后的所有元素依次前移一位覆盖，再 length--，O(n)。这称为逻辑删除——数据被覆盖、位置被后续元素占用，内存并未归还操作系统。与之相对的物理删除是把该地址交还系统（free），顺序表不用这种方式。

> **易错点**：顺序表的"删除"是逻辑删除（覆盖），不是释放内存；时间复杂度 O(n)，代价在移动元素。

## 顺序表的查找

[02:31:00 - 02:33:00]

按位（号）查找：第 i 个元素存在 L.data[i-1]，随机存取，O(1)。按值查找：事先既不知道值在不在表中，也不知道在哪个位置，只能从表头逐个比较，最坏和平均都是 O(n)。

## 单链表的后插与断链

[02:33:00 - 02:37:00]

在 p 之后插入 s，必须两步：先 s->next = p->next，再 p->next = s。若先执行 p->next = s，则原后继节点的地址丢失，链表被撕成"一条链 + 一个孤点"，这就是断链。若插入位置的前驱与后继地址都已知（另有指针指向后继），两步顺序无所谓；只知道前驱时必须先接后、再断前。只改指针，O(1)。

> **易错点**：断链的本质是"丢掉了后继节点的地址"；口诀——先修改待插入节点的指针域，再修改前驱的指针域。

## 尾插法建立单链表

[02:37:00 - 02:40:00]

用工作指针 p 始终指向当前表尾（初始指向头节点）：申请新节点 s → s->data = a_i → p->next = s → p = s。头指针不能移动（移动就丢了整条链），所以必须用工作指针记录表尾。按数组顺序尾插，得到的链表次序与输入一致，每个节点插入都是 O(1)，建表总体 O(n)。

## 头插法建立单链表

[02:40:00 - 02:46:00]

每次插在头节点之后：s->next = L->next; L->next = s;，不需要额外工作指针。头插法建成的链表次序与输入顺序相反，因此也可用来做链表就地逆置。第一个节点若图省事直接写 L->next = s 也能成立，但后续代码就必须加 if 判断"是不是第一个节点"，失去复用性，故统一用同一套语句。

> **易错点**：头插法插入的是"表首"，逆序输出；尾插法插入的是"表尾"，保持原序。

## 单链表的删除

[02:46:00 - 02:51:00]

删除 p 的后继：先 q = p->next 标记待删节点，再 p->next = q->next（或 q 的 next 的 next），最后 free(q)，O(1)；若题目要求返回被删元素值，先取 q->data 再释放。必须先标记再改指针，否则同样断链；删除与插入的修改顺序正好相反——插入最后改前驱，删除最先改前驱。

> **易错点**：408 中链表题不允许用"交换数据值"假冒插入、删除、逆置，必须修改指针。

## 带头节点 vs 不带头节点：插入删除差异与头节点的作用

[02:51:00 - 03:01:00]

不带头节点时，表首插入/删除都要额外更新头指针 L（L = x 或 L = L->next），并且要 if-else 区分"首节点"与"其他位置"，代码不统一；带头节点后，表首与其他位置的操作代码完全一致，可复用、可读性好，空表与非空表也统一（头指针始终指向一个 LNode，而不是空地址）。选择题约定：说"链表 L""头指针 head"默认不带头节点，只有明确说"带头结点的单链表"才带头节点；算法题若没给头节点，应自行加上。

> **易错点**：不带头节点删除/插入表首时漏更新头指针，链表会被判为非法（返回时看不到新节点）。

## 循环单链表（带头指针/头节点）

[03:01:00 - 03:13:00]

带头节点且只有头指针 L 时：表首插入（x->next=L->next; L->next=x）和表首删除（q=L->next; L->next=q->next; free(q)）都 O(1)。表尾插入/删除都要从头遍历到尾节点（或倒数第二个节点），O(n)；表尾插入后必须补 x->next = L 维持循环结构。复杂度差异的唯一原因是"前驱地址是否已知"。

> **易错点**：表尾插入后忘记闭合循环（x->next=L），结构被破坏，是本节最易错处。

## 循环单链表（带头节点 + 尾指针）

[03:13:00 - 03:20:00]

有尾指针 T 时，表尾节点与其后继（头节点）都已知：表首插入/删除 O(1)（T->next 就是头节点）；表尾插入 O(1)（x->next=T->next; T->next=x; T=x）；表尾删除仍需找倒数第二个节点，O(n)，并要更新 T。尾指针的含义是"永远指向当前表尾"，任何改变表尾的操作后都必须更新它。

> **易错点**：有头节点 ≠ 有头指针，二者是两回事；表尾插入/删除后不更新 T，整条链表在内存中就找不回来了。

## 循环单链表（仅有尾指针）

[03:20:00 - 03:26:00]

只有尾指针 T、不带头节点时：表首就是 T->next，故表首插入（x->next=T->next; T->next=x）和表首删除（q=T->next; T->next=q->next; free(q)）都 O(1)；表尾插入 O(1)（x->next=T->next; T->next=x; T=x）；表尾删除仍需遍历找前驱，O(n)。所以在"表尾插入 + 表首删除"的场景下，这种结构最优，也是选择题常设的正确答案。

## 双链表的插入

[03:26:00 - 03:31:00]

在 p 之后插入 s 要改四个指针：s->next = p->next; p->next->prior = s; s->prior = p; p->next = s;。仍建议先改待插入节点的 next 与 prior，再改 p 一侧，这样任何情况下都不会断链。选择题就是按这套顺序逐句模拟，看哪一项能走通。

> **易错点**：四步中若先执行 p->next = s，p 的原后继地址丢失，后续 p->next->prior 就无从下手。

## 双链表的删除

[03:31:00 - 03:33:00]

删除 p 的后继 q：p->next = q->next; q->next->prior = p; free(q);，改两根指针，O(1)。记忆口诀：无论待删节点的前驱、后继是否已知，永远先修改待删节点前驱的指针域，这样绝不会断链。

## 顺序表与链表的比较

[03:33:00 - 03:37:00]

层级关系：线性表是逻辑结构层面的概念，顺序表与链表是它的两种物理实现，三者不是同级概念，选择题常在此张冠李戴。顺序表：存储密度为 1、支持随机存取 O(1)、插删要移动元素 O(n)、静态分配会浪费空间。链表：存储密度小于 1、不支持随机存取（按位查找 O(n)），但给定位置后插删只改指针 O(1)。

> **易错点**："插入是 O(1) 还是 O(n)"取决于语境：含查找定位则 O(n)，只算指针修改则 O(1)。

## 例题：按操作场景选择存储结构

[03:37:00 - 03:42:00]

场景为"常在表尾插入、在表首删除"，逐个结构模拟：单链表表尾插入 O(n)、表首删除 O(1)；仅有头指针的循环单链表两种操作都要遍历找尾，均 O(n)；双链表表尾插入 O(n)；顺序表删除要移动元素 O(n)；仅有尾指针的循环单链表表尾插入 O(1)、表首删除 O(1)。故答案是"仅有尾指针的单循环链表"。做这类题的唯一方法是画图模拟，题目给什么用什么，没给尾指针就别画尾指针。
