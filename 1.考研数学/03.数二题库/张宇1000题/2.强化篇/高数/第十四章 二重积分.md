# 强化篇·高数·第十四章 二重积分

<!-- 第 97 页 -->

### 1.
$\lim_{n \to \infty} \sum_{i=1}^{n} \sum_{j=1}^{n} \frac{1}{(n+i)\sqrt{n^2 + j^2}} = \underline{\quad}$.

### 2.
设 $D = \left\{ (x,y) \mid |x| + |y| \leq 3 \right\}$，$D_k (k=1,2,3,4)$ 是 $D$ 的第 $k$ 象限部分，$I_k = \iint_{D_k} \sin(x - y) \, dx \, dy$，则（ ）。

(A) $I_1 > 0$ \quad (B) $I_2 > 0$ \quad (C) $I_3 > 0$ \quad (D) $I_4 > 0$

### 3.
设 $M = \iint_{D} \ln(x^2 + y^2) \, dx \, dy$，$N = \iint_{D} [\ln(x^2 + y^2)]^2 \, dx \, dy$，$P = \iint_{D} (x^2 + y^2 - 1) \, dx \, dy$，其中 $D = \left\{ (x,y) \mid 1 \leq x^2 + y^2 \leq 2 \right\}$，则必有（ ）。

(A) $M < N < P$ \quad (B) $N < M < P$ \quad (C) $M < P < N$ \quad (D) $N < P < M$

### 4.
设 $f(x)$ 是 $[0,1]$ 上的连续函数且其在 $[0,1]$ 上的平均值 $\bar{f} = \frac{1}{2}$，满足 $f(x) + a \int_{1}^{x} f(y) f(y - x) \, dy = 1$，求常数 $a$ 的值。

### 5.
设 $I_1 = \iint_{\substack{0 \leq x \leq 1 \\ 0 \leq y \leq 1}} (\sin x^2 + \cos y^2) \, d\sigma$，$I_2 = \iint_{|x| + |y| \leq \frac{1}{2}} \left[ 2 + \ln\left( \sqrt{x^2 + y^2} + \frac{1}{2} \right) \right] \, d\sigma$，则（ ）。

(A) $1 \leq I_1 \leq I_2$ \quad (B) $I_1 \leq I_2 \leq 1$ \quad (C) $I_2 \leq I_1 \leq 1$ \quad (D) $I_2 \leq 1 \leq I_1$

### 6.
$\int_{-1}^{0} dx \int_{\left(1 - x^3\right)^{\frac{2}{3}}}^{\left(1 - x^2\right)^{\frac{1}{2}}} (1 - \sin x \cos y) \, dy + \int_{0}^{1} dx \int_{\left(1 - x^3\right)^{\frac{2}{3}}}^{\left(1 - x^2\right)^{\frac{1}{2}}} (1 - \sin x \cos y) \, dy = \underline{\quad}$.

### 7.
设有界区域 $D$ 是由圆 $x^2 + y^2 = 1$ 和直线 $y = x$ 以及 $x$ 轴所围成的在第一象限的图形，计算二重积分 $\iint_{D} e^{(x + y)^2} (x^2 - y^2) \, dx \, dy$.

### 8.
设 $D = \left\{ (x,y) \mid 4x^2 + y^2 < 1, x \geq 0, y \geq 0 \right\}$，则积分 $I = \iint_{D} (1 - 12x^2 - y^2) \, dx \, dy = \underline{\quad}$.

### 9.
设平面区域 $D = \left\{ (x,y) \mid \frac{1}{\sqrt{3}} x \leq y \leq \sqrt{3} x, 1 \leq x \leq 2 \right\}$，求二重积分 $I = \iint_{D} y e^x \, dx \, dy$.

### 10.
$\int_{0}^{1} \mathrm{d}x \int_{1}^{x} \frac{\tan y}{y} \mathrm{d}y = \underline{\quad}$.

### 11.
设平面区域 $D = \{(x, y) \mid x^2 + y^2 \leqslant 1\}$，则 $\iint_{D} (x - 2y)^2 \mathrm{d}x\mathrm{d}y = \underline{\quad}$.

### 12.
设 $D = \left\{(x, y) \left| \frac{x^2}{a^2} + \frac{y^2}{b^2} \leqslant 1 \right.\right\}$，常数 $a > 0, b > 0, a \neq b$，计算 $I = \iint_{D} \left[ (x - 1)^2 + (2y + 3)^2 \right] \mathrm{d}x\mathrm{d}y$.

### 13.
计算二重积分 $\iint_{D} \frac{x^2 + y^2}{|x| + |y|} \mathrm{d}x\mathrm{d}y$，其中 $D = \{(x, y) \mid 1 \leqslant |x| + |y| \leqslant 2\}$.

### 14.
$\int_{-1}^{1} \mathrm{d}y \int_{-1}^{y} y \sqrt{1 + x^2 - y^2} \mathrm{d}x = \underline{\quad}$.

### 15.
$\int_{-1}^{1} \mathrm{d}x \int_{x^2}^{\sqrt{2 - x^2}} (x + 1) \mathrm{d}y = \underline{\quad}$.

### 16.
计算二重积分 $\iint_{D} |x - y| \mathrm{d}\sigma$，其中 $D = \{(x, y) \mid x^2 + y^2 \leqslant 2x, x \leqslant 1\}$.

### 17.
计算二重积分 $\iint_{D} |x^2 + y^2 - \sqrt{2}(x + y)| \mathrm{d}x\mathrm{d}y$，其中 $D = \{(x, y) \mid x^2 + y^2 \leqslant 4\}$.

### 18.
设 $D = \{(x, y) \mid 0 \leqslant x \leqslant 2, 0 \leqslant y \leqslant 2\}$，计算 $\iint_{D} |xy - 1| \mathrm{d}\sigma$.

### 19.
设平面区域 $D = \{(x, y) \mid (x - 1)^2 + y^2 \geqslant 1, (x - 2)^2 + y^2 \leqslant 4, y \geqslant x\}$，计算 $\iint_{D} (x^2 + y^2) \mathrm{d}\sigma$.

### 20.
$\int_{-\sqrt{2}}^{0} \mathrm{d}x \int_{-x}^{\sqrt{4 - x^2}} (x^2 + y^2)^{\frac{1}{2}} \mathrm{d}y + \int_{0}^{2} \mathrm{d}x \int_{\sqrt{2x - x^2}}^{\sqrt{4 - x^2}} (x^2 + y^2)^{\frac{1}{2}} \mathrm{d}y = \underline{\quad}$.

### 21.
设 $D = \{(x, y) \mid 0 \leqslant x \leqslant \sqrt{\pi}, 0 \leqslant y \leqslant \sqrt{\pi}\}$，计算二重积分 $\iint_{D} \sin(\max\{x^2, y^2\}) \mathrm{d}\sigma$.

### 22.
$\int_{0}^{1} \mathrm{d}y \int_{\sqrt{y}}^{1} \sqrt{x^4 - y^2} \mathrm{d}x = \underline{\quad}$.

### 23.
$\int_{0}^{1} x^2 \mathrm{d}x \int_{x}^{1} \mathrm{e}^{-y^2} \mathrm{d}y = \underline{\quad}$.

### 24.
设 $D = \{(x, y) \mid x^2 + y^2 \leqslant 4, (x - 1)^2 + y^2 \geqslant 1, y \geqslant 0\}$，计算 $\iint_{D} (xy + y^2) \mathrm{d}\sigma$.

### 25.
设平面区域 $D = \{(x, y) \mid (x - 1)^2 + (y - 1)^2 \leqslant 1\}$，则 $\iint_{D} (x^2 + y^2) \mathrm{d}\sigma = \underline{\quad}$.

### 28.

### 29.

### 30.

### 31.

### 32.

### 33.

### 34.
设 $f(x,y)$ 在 $D = \{(x,y) \mid x^2+y^2 \leqslant 1\}$ 上连续，$f(x,y) = e^{x^2+y^2} - \iint_D \frac{(2x^2+1)f(x,y)}{x^2+y^2+1} dxdy$，求 $\iint_D f(x,y) dxdy$。

### 35.

### 36.

### 37.

### 38.

### 39.

### 40.
设 $a=\int_{0}^{1}e^{-t^2}\mathrm{d}t$，$b=\int_{0}^{\frac{1}{2}}e^{-t^2}\mathrm{d}t$，求整数 $m$，$n$ 使得
$$2\int_{\frac{1}{2}}^{1}\left(\int_{0}^{x}e^{-y^2}\mathrm{d}y\right)\mathrm{d}x = ma - nb + \frac{1}{e} - \frac{1}{\sqrt[4]{e}}.$$

### 41.
设平面区域 $D=\left\{(x,y)\left|2x^2+y^2\leqslant 2\sqrt{x^2+y^2}, y\geqslant x\geqslant 0\right.\right\}$，若 $\iint_{D}\frac{f(x,y)}{\sqrt{1-x^2}}\mathrm{d}\sigma = a>0$，$f(x,y)$ 是 $D$ 上的连续函数。
(1) 计算 $\iint_{D}\frac{1}{\sqrt{1-x^2}}\mathrm{d}\sigma$；
(2) 证明：存在 $(\xi,\eta)\in D$，使得 $|f(\xi,\eta)|\geqslant \frac{\sqrt{2}}{\pi}a$。
