# 第5讲 特征值与特征向量

## 【视频01】本讲知识结构：特征值与特征向量

[00:00:00 - 00:03:00]

本讲是代数应用篇的开头，是考研代数必考的一讲，强化阶段又称"相似理论"。整讲分两大块：先讲特征值与特征向量，再讲相似。特征值与特征向量部分要依次掌握定义、求法、性质与重要结论。相似部分的三个考点是矩阵的相似（含定义、性质、判别、反求参数）、相似对角化、实对称矩阵的相似对角化。

> **公式**：`A ~ B`（A 相似于 B）；`P^{-1}AP = Lambda`

## 【视频01】相似、相似对角化与实对称矩阵三个层次

[00:03:00 - 00:06:21]

矩阵相似 `A ~ B` 中 A、B 无需特殊；相似对角化 `A ~ Lambda`（Λ 为对角阵）是它的特殊情形。相似对角化要研究条件，基础阶段掌握两个充要条件、两个充分条件。再特殊化到实对称矩阵（`A^T = A`）的相似对角化，是考研极重要考点。

> **易错点**：讲课中对角阵 Λ 也念作 lambda，容易与特征值 lambda 混淆。

> ⚠️ **需回看视频 [00:03:00]**：讲课用 lambda 指代对角阵 Λ，与特征值 lambda 记号冲突，需确认 —— "而矩阵的相似对角化却是A相似于lambda。大家注意这个lambda是什么？这个lambda叫对角阵"

## 【视频02】特征值与特征向量的定义

[00:00:00 - 00:03:00]

本讲起往后所有矩阵都取 n 阶方阵；非方阵可借助转置（如 Gram 矩阵 `A^T A`）化为方阵，故方法通用。定义：设 A 是 n 阶矩阵，λ 是一个数，若存在 n 维非零列向量 ξ，使 `A xi = lambda xi`，则称 λ 是 A 的特征值，ξ 是 A 的属于 λ 的特征向量。

> **定义**：`A xi = lambda xi`（`xi != 0`）
> **易错点**：特征向量必须是非零列向量。

## 【视频02】特征值的几何意义与"n 个特征值"

[00:03:00 - 00:06:15]

几何理解：A 作用在非零向量 ξ 上，效果等同于用数 λ 对 ξ 做伸缩（放缩），λ 是反映 A 性质的一个指标（如数据的最值、亲近程度）。因此求 λ 与 ξ 的目的是用一个数刻画一个大矩阵的关键特性。n 阶矩阵一定有 n 个特征值，重根按重数计（k 重根算 k 个）。

> **结论**：n 阶矩阵有 n 个特征值（重根按重数计）。

## 【视频03】特征值求法的推导：特征方程

[00:00:00 - 00:04:00]

由 `A xi = lambda xi` 移项得 `(lambda E - A) xi = 0`，ξ 非零说明该齐次方程组有非零解。方阵系数矩阵秩小于 n 等价于行列式为零，即 `|lambda E - A| = 0`，此即特征方程。特征方程是关于 λ 的 n 次多项式方程，其根即为全部特征值（重根按重数计）。求特征值是"自产自销"：A 给定即可直接写 `lambda E - A` 算行列式。

> **公式**：`|lambda E - A| = 0`（特征方程）

## 【视频03】求特征值、特征向量的步骤与例题（特征值）

[00:04:00 - 00:17:00]

求特征向量：把每个 λ 代回 `(lambda E - A) x = 0`，解齐次方程组的基础解系，其非零线性组合即该 λ 的特征向量。写 `lambda E - A` 的口诀是：A 的九个元素先添负号，再在主对角线上加 λ。得到三次多项式后要因式分解，常先用行列式的倍加等变换凑出 `lambda - lambda_i` 因式，把问题降为二次式。例题（打星、必考）：三阶矩阵求特征值，得 `lambda_{1,2} = 1`、`lambda_3 = 10`。

> **易错点**：整个过程只是移项、提公因式、方程组理论等基本运算的组合，应能独立推导。

## 【视频03】求特征向量的例题（用概念解题）

[00:17:00 - 00:28:00]

对每个 λ 解 `(lambda E - A) x = 0`：λ=1（二重）时基础解系有两个向量，特征向量为 `k_1 xi_1 + k_2 xi_2`（k_1、k_2 不同时为零）。λ=10 时，因 `|10E - A| = 0` 且有两行不成比例，可判定系数矩阵秩恰为 2，直接把多余的第三行写成零行，简化阶梯化。这种"用概念定秩再解题"是基本技能，比死算更快。

> **公式**：`A xi_i = lambda_i xi_i`；特征向量 `k_1 xi_1 + k_2 xi_2`（不全为零）
> **易错点**：求出的通解要排除零解，特征向量必须非零。

> ⚠️ **需回看视频 [00:20:00]**：本段数学符号的 ASR 转写极不统一（"可塞/可c/可C"即 ξ，"牛姆达/兰姆达/那么的"即 λ），原文照读会打断理解 —— "所以呢，我们说对于牛姆达等于一的特征向量啊，所有的特征向量，它就等于k一倍的可c一加上k二倍的可c二"

## 【视频03】求 λ 的一般方法：行列式性质、试根法与长除法

[00:28:00 - 00:45:28]

用行列式性质凑因式（常把某行/某列倍加，凑出 `lambda + 2` 这类因子）能较快分解；凑不出来时就直接展开成 λ 的三次多项式。试根法三句：常数项为 0 ⇒ 0 是根；所有系数和为 0 ⇒ 1 是根；偶次项系数和等于奇次项系数和 ⇒ −1 是根。找到一根后用多项式带余除法（长除法）降次，余下二次式易分解。有理根定理：整系数多项式 `f(x)=0` 的有理根均为整数且是常数项的因子，例如常数项为 2 就只在 ±1、±2 中试。

> **公式**：试根判别 0 / 1 / −1；有理根必为常数项因子
> **易错点**：常数项非零时 0 一定不是根，试根要落在常数项的因子上。

## 【视频04】特征值的性质（一）：特征方程根、可逆性与反求参数

[00:00:00 - 00:05:00]

`lambda_0` 是 A 的特征值 ⇔ `lambda_0` 满足特征方程（充要），据此可由已知特征值反求 A 中的未知参数。若 `lambda_0` 不是特征值，则 `|lambda_0 E - A| != 0`，即 `lambda_0 E - A` 可逆。常见命题形式 `|aA + bE| = 0`，可把 `aA + bE` 写成 `bE - (-a)A` 并提出 `(-a)`，得 A 的一个特征值 `lambda_0 = -b/a`（也记为"负的 a 前系数分之 b 前系数"）。

> **公式**：`|aA + bE| = 0 => lambda_0 = -b/a`；`|lambda_0 E - A| = 0`

## 【视频04】特征值的性质（二）：特征值之和等于迹、之积等于行列式

[00:05:00 - 00:20:00]

n 个特征值之积等于 |A|；有零特征值则 |A| = 0，A 不可逆，反之不可逆矩阵必有零特征值。n 个特征值之和等于 tr A（主对角线元素之和）。更一般地，k 阶主子式之和等于任意 k 个特征值乘积之和，其中一阶主子式之和即迹、n 阶主子式之和即行列式，证明中其实只用首尾两项。

> **公式**：`sum lambda_i = tr A`；`prod lambda_i = |A|`
> **定义**：k 阶主子式——取行、列下标相同的 k 行与 k 列，交叉元素按原相对位置构成的行列式。
> **易错点**：二阶子式不一定是主子式，只有行列下标对应相同才是。

## 【视频04】特征向量的性质与重要结论（五条）

[00:20:00 - 00:45:00]

① k 重特征值至多只有 k 个线性无关的特征向量（单根必恰有一个）。② 属于不同特征值的特征向量一定线性无关。③ 属于同一特征值的特征向量的任意非零线性组合仍是该特征值的特征向量。④ 属于不同特征值 λ_1、λ_2 的特征向量 ξ_1、ξ_2，当 k_1、k_2 全不为零时，`k_1 xi_1 + k_2 xi_2` 不是 A 的任何特征值的特征向量。⑤ 一个特征向量不能属于两个不同的特征值（特征值与特征向量专属配对）。每条都可用"λ 只在自己特征向量张成的空间内做放缩"来直观理解。

> **易错点**：特征值不同 ⇒ 特征向量线性无关；但线性无关不能推出特征值不同（重根也能给出线性无关的特征向量）。

## 【视频04】常用矩阵的特征值与特征向量（表格）

[00:45:00 - 01:05:00]

设 `A xi = lambda xi`，则：`f(A)`（A 的多项式）的特征值为 `f(lambda)`，特征向量不变；`A^{-1}`（A 可逆）的特征值为 `lambda^{-1}`，特征向量不变；`A^*` 的特征值为 `|A|/lambda`，特征向量不变（三阶可逆时 A^* 的特征值即任意两个特征值之积）；`P^{-1}AP` 的特征值不变（仍为 λ），但特征向量变为 `P^{-1}xi`。补充：若 f(x) 是多项式且 `f(A) = O`，则 A 的任一特征值满足 `f(lambda) = 0`。`A^T` 与 A 特征值相同，但因不是由原始定义推出，其特征向量无法由 A 的特征向量表示，须单独计算，故不列入表格。

> **公式**：`f(A): f(lambda)`；`A^{-1}: lambda^{-1}`；`A^*: |A|/lambda`；`P^{-1}AP: lambda 不变，特征向量 P^{-1}xi`
> **易错点**：多项式/逆/伴随是"特征值变、特征向量不变"，相似变换 `P^{-1}AP` 却是"特征值不变、特征向量变"。

## 【视频04】秩一矩阵的特征值结论（例 5.2）

[01:05:00 - 01:18:00]

n 阶方阵秩为 1 ⇔ 可写成一列乘一行，即 `A = alpha beta^T`（α、β 均为非零向量）。秩一矩阵的 n 个特征值中，n−1 个为 0，剩下一个等于 `tr A = beta^T alpha`。该结论可直接用于快速求特征值，也配合"秩一矩阵的 n 次幂等于 (tr A)^{n-1} A"求高次幂。

> **公式**：`A = alpha beta^T`；`lambda_{1..n-1} = 0`，`lambda_n = beta^T alpha = tr A`

> ⚠️ **需回看视频 [01:09:00]**：此处"七减二是五"与所举矩阵 `[1,2,3; -1,-2,-3; 2,4,6]` 的主对角线和（1−2+6=5）数字对不上，疑为口误或转写有误 —— "那 lambda 三呢就是主对角线元素之和，是多少？那么就是说七减二是五"

## 【视频04】幂等阵、伴随与行和（例 5.3–5.5）

[01:18:00 - 01:31:55]

例5.3：幂等阵 `A^2 = A`，即 `f(A) = A^2 - A = O`，故 λ 满足 `lambda^2 - lambda = 0`，A 的特征值只能取 0 或 1（注意这只是"特征值必须满足的约束/可能取值集合"，不是特征方程）。由此 `E + A` 的特征值为 1 或 2，均非零，故 `E + A` 可逆。例5.4：`A^*` 的主对角线之和（tr A^*）等于 A^* 三个特征值之和，即 `sum |A|/lambda_i`，代数值算出为 11。例5.5：A 每行元素之和均为同一常数时，该常数就是 A 的特征值（特征向量取 `(1,1,1)^T`），再由 `A^* xi = (|A|/lambda) xi` 求 A^* 的行和。

> **公式**：`A^2 = A => lambda in {0,1}`；`A^* xi = (|A|/lambda) xi`
> **易错点**：`A^2 = A` 得到的是"约束"而非特征方程，它只给出特征值的可能取值集合。

## 【视频05】矩阵相似的定义、与等价的区别及六个性质

[00:00:00 - 00:25:00]

定义：A、B 为同阶方阵，若存在可逆矩阵 P 使 `P^{-1}AP = B`，称 A 相似于 B（记 `A ~ B`）。与等价 `PAQ = B` 相比，相似要求左右所乘矩阵互为逆矩阵，是更强的条件：相似必等价，等价（即使同阶）不一定相似。相似具有反身性、对称性、传递性。设 A~B，则六个性质成立：① |A| = |B|；② r(A) = r(B)；③ tr A = tr B；④ 特征值（特征多项式）相同；⑤ `r(lambda E - A) = r(lambda E - B)`；⑥ 各阶主子式之和对应相等。

> **公式**：`P^{-1}AP = B`；`|A|=|B|`、`tr A=tr B`、`r(lambda E-A)=r(lambda E-B)`

## 【视频05】相似矩阵的特征向量关系

[00:25:00 - 00:42:00]

若 `P^{-1}AP = B`，A 属于 λ 的线性无关特征向量为 ξ_i，则 B 属于 λ 的线性无关特征向量为 `P^{-1}xi_i`，个数相同。推导关键：在 `A xi = lambda xi` 两边左乘 `P^{-1}`，并用 `E = P P^{-1}` 在 A 与 ξ 之间插入单位阵，凑出 `P^{-1}AP`。因此相似变换是"特征值不变、特征向量变为 P^{-1}ξ"，恰与多项式/逆/伴随相反。

> **公式**：`B (P^{-1}xi) = lambda (P^{-1}xi)`
> **易错点**：矩阵乘法无交换律，不能在两个相乘矩阵中间随便插入矩阵，只能插入单位阵 E。

## 【视频05】相似的重要结论、变换手段与判别方法

[00:42:00 - 01:12:05]

重要结论：A~B ⇒ `A^k ~ B^k`、`f(A) ~ f(B)`、`A^{-1} ~ B^{-1}`（A 可逆时）、`A^* ~ B^*`，并且这些变换所用的可逆矩阵都是同一个 P。例外是转置：`A^T ~ B^T` 成立，但所用手段为 `P^T`（不是 P），故把转置与其他项叠加组合时通常不再相似（例5.8 的 D 选项即错在此）。判别方法：定义法（构造 `P^{-1}AP=B`，如例5.6 用反证法）、传递性（都相似于同一对角阵则互相相似）、用性质否定（必要条件不满足则不相似）、反问题（已知相似反求参数，如例5.7 联立迹与行列式）。注意六个性质全是必要条件，全成立也不能断定相似。

> **公式**：`A^k~B^k`、`f(A)~f(B)`、`A^{-1}~B^{-1}`、`A^*~B^*`（同手段 P）；`A^T~B^T`（手段为 P^T）

## 【视频06】相似对角化的定义与充要条件

[00:00:00 - 00:16:00]

定义：若存在可逆矩阵 P 使 `P^{-1}AP = Lambda`（Λ 为对角阵），称 A 可相似对角化，Λ 称为 A 的相似标准型（区别于非方阵也可、手段不限的等价标准型）。推导：`P^{-1}AP = Lambda` ⇔ `AP = P Lambda`；把 P 按列分块为 (ξ_1,…,ξ_n)，得 `A xi_i = lambda_i xi_i`（i=1..n）。结论（充要）：A 可相似对角化 ⇔ A 有 n 个线性无关的特征向量。构成上：手段 P 由 A 的 n 个线性无关特征向量拼成，Λ 由对应的特征值拼成。

> **公式**：`P^{-1}AP = Lambda`，`P = (xi_1,...,xi_n)`，`Lambda = diag(lambda_1,...,lambda_n)`
> **易错点**：λ_i 的位置必须与 ξ_i 的列位置一一对应，顺序可以变但要同步变。

> ⚠️ **需回看视频 [00:00:00]**：定义处口误/转写缺漏，把 `P^{-1}AP` 说成 `P^{-1}P`，需据上下文确认 —— "如果存在n阶可逆矩阵P，使得P逆P等于lambda"

## 【视频06】相似对角化的判别条件

[00:16:00 - 00:25:00]

充要条件②：A 可相似对角化 ⇔ 每个 k 重特征值都恰有 k 个线性无关的特征向量（须实际算 `r(lambda_i E - A)` 来验证，即 `n - r(lambda_i E - A) = k`）。充分条件：A 有 n 个互不相同的特征值，则必可相似对角化；实对称矩阵必可相似对角化。理解：单根一定带一个线性无关特征向量，关键看每个重根是否"恰好"带够 k 个；少一个就凑不齐 n 个，A 就不能相似对角化。

> **公式**：`n - r(lambda_i E - A) = k`（k 重根）

## 【视频06】相似对角化的运算步骤及应用

[00:25:00 - 00:32:45]

步骤：① 求 A 的全部特征值；② 对每个特征值求线性无关的特征向量；③ 把它们拼成 P，则 `P^{-1}AP = Lambda`。反向应用：已知特征值、特征向量且 A 可相似对角化时，可反求 `A = P Lambda P^{-1}`。求幂：`A^n = P Lambda^n P^{-1}`，对角阵的 n 次幂只需主对角线元素取 n 次幂，能大幅降低计算量；对多项式同理 `f(A) = P f(Lambda) P^{-1}`。这正是相似对角化的核心价值（传统大题常就是一个 A 矩阵求高次幂/化二次型）。

> **公式**：`A^n = P Lambda^n P^{-1}`；`f(A) = P f(Lambda) P^{-1}`

## 【视频07】例题 5.9、5.10：相似对角化的判别

[00:00:00 - 00:10:00]

能相似对角化的三种典型：① 实对称矩阵；② 有 n 个互不相同的特征值；③ 每个重根的线性无关特征向量个数恰等于重数。例5.9 用排除法：A 对称、B 特征值 1、2、3 互异、C 秩一且 0 有两个线性无关特征向量，均可对角化；D 只有三重根 −1，但 `r(-E - D) != 0`，不能对角化。例5.10：`|E + A| = 0`、`(3E - A)x = 0` 有非零解、`E - 3A` 不可逆，得特征值 −1、3、1/3，三个互异，故必可相似对角化。

> **公式**：`|aA + bE| = 0 => lambda = -b/a`

## 【视频07】注：扰动法（摄动法）

[00:10:00 - 00:25:00]

问题：`|A^*| = |A|^{n-1}`、`(AB)^* = B^* A^*` 等结论原先只在 A（或 AB）可逆时证明过，不可逆时是否仍成立？方法：取 `t > 0`，用可逆的 `tE + A` 代替 A；`tE + A`、`(tE + A)^*` 都是 t 的多项式（连续函数），令 `t -> 0^+`，由连续性得极限值等于函数值，从而结论对不可逆情形也成立。这是把"可逆结论"推广到"不可逆情形"的有力工具，属超出基础要求但很实用的方法。

> **公式**：`|A^*| = |A|^{n-1}`；`(AB)^* = B^* A^*`

## 【视频07】例题 5.11–5.13：利用"良好局面"与构造 P^{-1}AP

[00:25:00 - 00:43:00]

"良好局面"即 `P^{-1}AP = diag(lambda_1,...,lambda_n)`，P 的第 i 列就是 λ_i 对应的特征向量，填空选择时按位置对应即可。例5.11：同一特征值(λ=1)下对应列可取该特征向量的任意非零线性组合，不同特征值必须各配自己的特征向量，答案 D。例5.13：把 P=(ξ_1,ξ_2,ξ_3) 换成 Q=(ξ_1+ξ_2, ξ_2, ξ_3)，则对角阵为 diag(1,1,2)，本质是基变换/过渡矩阵。例5.12：`A^2 - A = 2E`，P=(α, Aα)（α 非特征向量），先证 `|P| != 0`；由 `A^2 = A + 2E` 得 `AP = P B`，故 `P^{-1}AP = B`，B 的特征值 2、−1 互异 ⇒ A 可对角化。

> **公式**：`AP = PB => P^{-1}AP = B`

## 【视频08】实对称矩阵的特征值与特征向量性质

[00:00:00 - 00:06:00]

实对称矩阵（`A^T = A`、元素为实数）的特征值必为实数，特征向量必为实向量。实对称矩阵属于不同特征值的特征向量相互正交；普通矩阵只保证线性无关。同一重特征值下，普通矩阵的特征向量可能线性相关，而实对称矩阵的特征向量仍线性无关。因此实对称矩阵把普通矩阵的性质整体"加强一级"：普通矩阵的"线性无关"升级为"正交"，"可能相关"升级为"必无关"。

> **公式**：`A^T = A`
> **易错点**：正交一定线性无关，但线性无关不一定正交，别把两套结论混用。

## 【视频08】实对称矩阵必可（正交）相似对角化

[00:06:00 - 00:27:00]

由上述性质，实对称矩阵必有 n 个线性无关特征向量，故必可相似对角化。更强结论：存在正交矩阵 Q（满足 `Q^T = Q^{-1}`），使 `Q^{-1}AQ = Q^T A Q = Lambda`；做法是把特征向量组经施密特正交化、单位化后拼成 Q，这一过程不改变对应的特征值（重新组合出的向量仍属于同一特征值）。反证：若非对称阵 A（`A^T != A`）也存在 Q 使 `Q^T A Q = Lambda`，则可反推出 `A^T = A`，矛盾，故非对称阵一定不能正交相似对角化。

> **公式**：`Q^{-1}AQ = Q^T A Q = Lambda`（Q 为正交矩阵）
> **易错点**：普通矩阵一般只能相似对角化，不能保证用正交矩阵；只有实对称矩阵才一定可以。

## 【视频08】例题 5.18、5.19：正交相似对角化的应用

例5.18：由正交矩阵 Q 的第一列（即某个特征值的特征向量，方向可取自 `(1,2,1)^T`）反求 A 的元素与该特征值，得 `lambda_1 = 2`、`a = -1`；再求 A 的全部特征值 2、5、−4 及特征向量，因不同特征值的特征向量已正交，只需单位化即可拼得正交矩阵 Q。例5.19：先证 A ~ diag(2,5,−4)；若 B 的特征值也是 2、5、−4 且互异（⇒ B 可对角化），则由传递性得 A ~ B。一般规律："特征值相同 + 两者都可相似对角化"是判定相似的有效途径。

> **公式**：`Q^T A Q = Lambda`
