## 【视频02】行列式的本质定义：二阶=两个向量拼成的平行四边形面积

[00:00:00 - 00:11:00]

`a_ij` 中下标的 i 表示所在行、j 表示所在列；二阶行列式由两个二维向量（两行）组成。
以这两个向量为邻边作平行四边形，其（有向）面积就是行列式的值。
由面积公式 `S = l*m*sin(theta)`（`theta` 为两向量夹角）展开，恰好得到 `a11*a22 - a12*a21`，说明"主对角减副对角"只是巧合。
面积可为正可为负（定向）；两向量重合（成比例）或含零向量时面积为0，对应行列式为0。

> **定义**：二阶行列式 = 以其两个行向量为邻边的平行四边形的有向面积。
> **公式**：`|a b; c d| = a*d - b*c`，`S = l*m*sin(theta)`
> **易错点**：几何面积带符号；"一捺减一撇"仅二阶成立。

## 【视频02】三阶与n阶行列式：平行六面体体积与n维体积

[00:11:00 - 00:27:31]

三阶行列式 = 三个三维向量张成的平行六面体的（有向）体积。
三阶用"划线法/叉子法"计算：三条"捺"方向串接取正、三条"撇"方向串接取负，共6项。
一般n阶行列式由n个n维向量组成，结果是n维体积（测度）；低维图形在高维中测度为0。
三阶及以上"一捺减一撇"不再成立，它只是二阶的特例巧合。

> **公式**：三阶 `D_3 = a11a22a33 + a12a23a31 + a13a21a32 - a13a22a31 - a11a23a32 - a12a21a33`（共6项）
> **易错点**：正负项各三条，顺序别错；不要把二阶算法搬到三阶。

## 【视频03】行列式的测度意义与性质一：行列互换（转置）其值不变

[00:00:00 - 00:13:00]

行列式本质上是线性变换的测度（体积）刻画；`|AB| = |A||B|` 表示复合变换的测度等于各变换测度之积。
性质一：行列互换（转置）其值不变，即 `|A| = |A^T|`。
转置是把行竖写成列（躺着的站起来），记 `A^T`；一般 `A ≠ A^T`。
由此行列式中行与列地位完全等价，行上成立的性质列上也一定成立（"行列式"也可叫"列行式"）。

> **定义**：转置 `A^T`：把A的第i行竖写成第i列。
> **公式**：`|A| = |A^T|`；`|AB| = |A||B|`
> **易错点**：转置后矩阵一般变了，但行列式不变；对称阵 `A=A^T` 是二次型（末章）的核心。

## 【视频03】性质二、三：零行（列）与提取公因子（倍乘）

[00:13:00 - 00:20:00]

性质二：某行（列）元素全为0，行列式为0（该行向量退化，测度为0）。
性质三：某行（列）有公因子 `k`，则 `k` 可提到行列式外；其逆用称为"倍乘"，主要用于消去分母。
反用即：`k` 乘行列式时只能乘到某一行（列）上。

> **定义**：倍乘——把数 `k` 乘到（或提自）某一行/列。
> **公式**：`|... k*a_i ...| = k*|... a_i ...|`
> **易错点**：`k|A|` 只乘某一行；n阶时 `|kA| = k^n|A|`，切勿只乘一个元素。

## 【视频03】性质四、五、六：单行可拆、互换变号、成比例为零

[00:20:00 - 00:31:00]

性质四（单行可拆/可加）：只有当**一行（列）**是两数之和时，才能拆成两个行列式之和；两行列式相加必须是"对应那一行（列）不同、其余全同"。
性质五（互换）：两行（列）互换，行列式变号；互换 `n` 次即乘 `(-1)^n`。
性质六：两行（列）元素相等或对应成比例，行列式为0（两向量重合，无面积/体积）。

> **公式**：`|... a_i+b_i ...| = |... a_i ...| + |... b_i ...|`
> **易错点**：绝不能写 `|A|+|B| = |A+B|`；两行列式相加仅限单行（列）不同。

## 【视频03】性质七：倍加（某行的k倍加到另一行）行列式不变

[00:31:00 - 00:43:11]

性质七：把某行（列）的 `k` 倍加到另一行（列），行列式值不变。
倍加是化零、化简最常用的手段，用于配合展开定理。
三大初等变换归纳为六个字：互换（添负号）、倍乘（要除回）、倍加（无代价，最常用）。

> **定义**：倍加——某行 + `k`×另一行，值不变。
> **易错点**：只有倍加不改变行列式的值；互换变号、倍乘记得除回 `k`。

## 【视频04】排列、逆序与逆序数

[00:00:00 - 00:05:00]

n级排列：由 `1,2,...,n` 组成的一个有序数组，共 `n!` 个。
逆序：排列中前面的大于后面的，即构成一个逆序（大在前、小在后）。
逆序数 `tau`：一个排列中所有逆序的总数；从左往右数每个数右边比它小的个数再求和。
逆序数为奇数称奇排列，为偶数称偶排列。

> **定义**：`tau(i1...in) = #{ (p,q) : p<q 且 i_p > i_q }`
> **易错点**：数逆序时"看每个数右边比它小的个数"再累加，别数反。

## 【视频04】行列式的逆序数法定义（第二种定义）

[00:05:00 - 00:18:59]

n阶行列式展开成 `n!` 项之和，每项写全：`D_n = Σ (-1)^tau * a_{1j1} a_{2j2} ... a_{njn}`。
三要素：①共 `n!` 项；②每项取自不同行不同列的 `n` 个元素之积；③符号由列下标排列 `j1...jn` 的逆序数决定，奇取负、偶取正。
用二阶、三阶验算即得 `|a b; c d| = ad - bc`。
注：一阶行列式规定 `|a11| = a11`（不是绝对值）；判断项符号时先将行下标顺排成 `1,2,...,n`，只算列下标排列的逆序数。

> **定义**：`D_n = Σ_{j1...jn} (-1)^{tau(j1...jn)} a_{1j1} a_{2j2} ... a_{njn}`
> **易错点**：一阶行列式等于元素本身，与绝对值符号区分；符号判断统一用"行下标顺排"。

## 【视频05】降阶思想、余子式与代数余子式

[00:00:00 - 00:08:00]

展开定理的指导思想是"降阶"：把n阶降成若干个n-1阶。
余子式 `M_ij`：划去元素 `a_ij` 所在的行与列后，剩下元素按相对位置不动构成的 n-1 阶行列式。
代数余子式 `A_ij = (-1)^{i+j} M_ij`，即余子式前面加符号。
记住：子式一定是行列式，子矩阵才是矩阵，不要混。

> **定义**：余子式 `M_ij`；代数余子式 `A_ij = (-1)^{i+j} M_ij`
> **公式**：`M_ij = (-1)^{i+j} A_ij`（因 `(-1)^{i+j}` 自逆）
> **易错点**：`M_ij` 与 `A_ij` 只差符号 `(-1)^{i+j}`，不可混用。

## 【视频05】展开定理与例题1.1

[00:08:00 - 00:20:19]

展开定理（展开公式）：行列式等于某行（列）各元素与其代数余子式乘积之和：`D = Σ_k a_{ik} A_{ik}`。
展开原则：挑零元素最多的那一行（列）展开，代价最小。
例题1.1（四阶行列式）：先用性质化出零，按含零最多的行/列展开，再识别右上三角/左下三角直接出结果（答案选B）。

> **公式**：`D = Σ_{k=1}^n a_{ik} A_{ik} = Σ_{k=1}^n a_{kj} A_{kj}`
> **易错点**：展开务必乘**代数**余子式（带 `(-1)^{i+j}`），不能只乘余子式。

## 【视频06】主对角线、上下三角与副对角线行列式

[00:00:00 - 00:05:00]

主对角线（左上→右下）：以它为界，右上方或左下方全为0时（上/下三角、对角），值 = 主对角线元素连乘。
副对角线（右上→左下，方向 `y=x`）：左上三角或右下三角全为0时，值 = 副对角线元素连乘，再乘符号因子 `(-1)^{n(n-1)/2}`。
用逆序数法可证：只有不碰到零元素的那一项能保留。

> **公式**：主对角/三角 `= a11 a22 ... ann`；副对角 `= a1n a2,n-1 ... an1 * (-1)^{n(n-1)/2}`
> **易错点**：副对角线结果多一个符号系数 `(-1)^{n(n-1)/2}`。

## 【视频06】拉普拉斯展开式（分块矩阵）

[00:05:00 - 00:22:00]

分块矩阵：用若干横、竖线把矩阵切成若干子块，子块可当作元素参与运算；注意"零块"的阶数可以不同。
拉普拉斯展开式：设 A 为 m 阶、B 为 n 阶，
`|A 0; 0 B| = |A C; 0 B| = |A 0; C B| = |A||B|`；副对角分块 `|0 A; B 0| = (-1)^{mn}|A||B|`。
系数 `(-1)^{mn}` 来自把副对角线一列列换到主对角线所换的次数。

> **公式**：`|A 0; 0 B| = |A||B|`；`|0 A; B 0| = (-1)^{mn}|A||B|`
> **易错点**：副对角分块的符号因子 `(-1)^{mn}` 不能漏。

## 【视频06】范德蒙德行列式

[00:22:00 - 00:28:53]

形如第一行全为1、以下依次为 `x` 的1次、2次…`n-1`次方的行列式，称为n阶范德蒙德行列式（记 `V_n`）。
结果 = 第二行各元素"大下标减小下标"遍历连乘：`V_n = ∏_{1≤i<j≤n} (x_j - x_i)`。
首行不全为1时，也可用性质（转置、换行）化成标准形式，注意换行带来的符号。

> **公式**：`V_n = ∏_{1≤i<j≤n} (x_j - x_i)`
> **易错点**：每个因子是"大下标减小下标"；下标以实际列位置为准，未必写作 `x1,x2,...`。

## 【视频07】行列式计算的总体思路小结

[00:00:00 - 00:05:00]

计算三途径：几何画图（定性）、七大性质（主要）、逆序数法（研究单项）；核心是性质配合展开公式。
通用思路：先用性质（倍加等）化出尽可能多的零，再展开；能化成"十二加一"基本型就直接写答案。
优先找"差别不大的行"做变换（如整行都是1、有正负1）；或找规律（行和相等、列和相等、范德蒙德）。
n阶规律问题用递推法（高阶→低阶）或数学归纳法（低阶→高阶）。

## 【视频08】具体型计算的两类问题与例题1.5（X型行列式）

[00:00:00 - 00:06:00]

有规律的行列式（可推广到n阶）必有公式；无规律的通常只考三阶、最多四阶，用互换/倍乘/倍加化到十二加一。

## 【视频08】有规律行列式的公式预告（X型、类对称）

[00:06:00 - 00:15:00]

X型（主对角全 `a`、副对角全 `b`）：二阶 X 型为 `a^2-b^2`，2k阶 X 型 `|D| = (a^2-b^2)^k`。
类对称行列式（主对角全 `a`、左下全 `c`、右上全 `b`）：
当 `b=c`（即行和相等）时，值 `= (a+(n-1)b)(a-b)^{n-1}`；当 `b≠c` 时，值 `= [b(a-c)^n - c(a-b)^n]/(b-c)`。
这些属"有规律典型行列式的基本结论"，可直接套用，不必每次推导。

> **公式**：行和相等 `(a+(n-1)b)(a-b)^{n-1}`；`b≠c` 时 `[b(a-c)^n - c(a-b)^n]/(b-c)`

## 【视频09】抽象型行列式的计算（例题1.10）

[00:00:00 - 00:08:00]

抽象型：只给出由列向量拼成的行列式值（如 `|α1 α2 α3 β| = A`），内部元素未知，用性质求解。
用单列可拆性把待求行列式拆开，再用互换（变号）、成比例（为零）等性质与已知条件对应。
从待求式出发"瓦解敌人、各个击破"，把目标逐步拆成已知行列式的组合。
结果 = `A + B`。

> **公式**：用到的性质——单列可拆；互换变号 `|...αi...αj...| = -|...αj...αi...|`；两列成比例则为0

## 【视频09】用矩阵乘积求行列式（例题1.11）

## 【视频11】克拉默法则

[00:00:00 - 00:11:00]

适用对象：n个方程、n个未知数的（非齐次）方程组，且系数行列式 `D = |A| ≠ 0`。
结论：方程组有唯一解，`x_i = D_i / D`，其中 `D_i` 是把 `D` 的第 i 列换成常数项所得的行列式。
齐次方程组（常数项全为0）：`D≠0` 时只有零解；`D=0` 时至少有一个非零解（无穷多解，后续再讲）。

> **定义**：`x_i = D_i / D`
> **公式**：齐次时 `D≠0 ⇔ 只有零解`；`D=0 ⇔ 有非零解`
> **易错点**：要求方程个数=未知数个数且 `D≠0`；`D=0` 时克拉默法则失效。

## 【视频11】例题1.13：含lambda方程组与反证法证明 |B|=0

[00:11:00 - 00:29:33]

例题1.13：3阶非零矩阵 B，其每列都是方程组的解，即 `Aβ_i = 0`（i=1,2,3）。

> **易错点**：勿忘"B 非零"这一条件；齐次方程组有非零解 ⇔ `|A|=0`。
