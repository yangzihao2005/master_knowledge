# 第2讲 数列极限

## 【视频01】第2讲知识结构与考情导学

[00:00:00 - 00:05:01]

本讲知识结构分五大块：①数列概念（重点落实"整标函数"视角）；②数列极限的定义（ε-N 语言，不直接考证明但必须理解，反面即"极限不存在"）；③极限性质——唯一性、有界性、保号性；④四则运算规则（何时能拆开求和差积商）；⑤三大工具与速度问题。对 2027 考生，**归结原则（海涅定理）、夹逼准则、单调有界准则三个"打星"内容要按 triple star 重视**，"xn 收敛于 a 的速度"打一星（21-25 年真题多有涉及，唯一性、速度均有单独出题的先例）。

> **易错点**：数列题在考卷上一旦出现往往是难题——通常为 5 分客观题但区分度高，也可能出 12 分大题，不能因"只考 5 分"而轻视。

## 【视频02】数列的概念、整标函数与子列

[00:00:00 - 00:03:00]

数列定义：对每个正整数 n 按一定法则对应唯一确定的实数 xn，按 n 从小到大排列得到的序列。从函数观点看，它是**定义在正整数集上的函数（整标函数）**，图像为数轴上一串离散点。记作 {xn}，其中 xn 称为通项（一般项）；不特殊指出时数列默认是无穷的。注：从 {an} 中**选取无穷多项**并保持原有先后顺序组成的新数列称为子列，记 {a_{n_k}}；奇数项、偶数项子列交错出现，二者合并即还原原数列。

> **定义**：子列——从原数列中取无穷多项、不改变相对顺序得到的新数列。
> **易错点**：子列必须是"无穷多项"，有限项不构成子列。

> ⚠️ **需回看视频 [00:01:00]**：口误 —— "数列中的每一个数叫做数列的项，那么第一项我称之为叫通项"（通项应指一般项 xn，非"第一项"）

## 【视频02】等差数列、等比数列与单调数列

[00:03:00 - 00:06:00]

等差数列通项 `a1+(n-1)d`，前 n 项和 `n(a1+an)/2`。等比数列通项 `a1·r^(n-1)`，前 n 项和：r=1 时为 `n·a1`，r≠1 时为 `a1(1-r^n)/(1-r)`——**此公式极重要，考研必用**；首项为 1 时简化为 `(1-r^n)/(1-r)`。单调性分类：`a的(n+1)项≥a(n)项` 单调不减、`a的(n+1)项≤a的(n)项` 单调不增，严格不等号对应单调递增/递减，统称单调数列。

> **公式**：等比求和 `S_n = a1(1-r^n)/(1-r)`（r≠1）；`S_n = n·a1`（r=1）。
> **易错点**：等比求和公式的 r=1 与 r≠1 两分支必须分开写，直接套分母会出错。

## 【视频02】有界数列与证明有界的三个方法

[00:06:00 - 00:09:00]

有界定义：存在 M 使所有 |an|≤M。做题时证有界常用三法：**加绝对值**（同时得上下界）、**放缩法**、**求最值**。理解"有界"是概念，考的是"会证明有界"，需通过做题把方法系统化。单调有界准则（既单调又有界 ⇒ 极限存在）在本讲稍后展开。

> **易错点**：学懂"什么叫有界"不等于"会证有界"——加绝对值、放缩、求最值三个方法要落实到笔头。

## 【视频02】常用求和公式与裂项相消法

[00:09:00 - 00:12:00]

只需记住两个求和：`1+2+…+n = n(n+1)/2`，`1²+2²+…+n² = n(n+1)(2n+1)/6`（高中公式，命题人默认会，其余不必记）。裂项相消法是常考手法：例 `Σ1/(k(k+1))` 裂成 `Σ(1/k - 1/(k+1))`，前 n 项和为 `1 - 1/(n+1) = n/(n+1)`，取极限为 1。

> **公式**：`Σ_{k=1}^{n} 1/(k(k+1)) = n/(n+1)`，`lim(n→∞) = 1`。
> **易错点**：运算顺序不可随意交换——复合运算先算离符号近的、再算远的；交换运算符必须有严格依据，否则会错。

## 【视频02】重要数列 (1+1/n)^n 的性质

[00:12:00 - 00:15:00]

以 `(1+1/n)^n` 为通项的数列两个结论要记住：①单调递增（证明超出考研要求，不必掌握）；②单增趋于 e（e≈2.7）。首项为 2（n=1），全部项落在 2～2.7 之间，是典型的**有界收敛数列**。借此给出极限的直观理解：n 无限增大时 xn 无限接近某个确定值则有极限，否则无极限。数形结合画个示意图有助于理解。

> **公式**：`lim(n→∞) (1+1/n)^n = e`，各项 ∈ [2, e)，单调递增。
> **易错点**：数列的任何一项都不等于 e，只是无限接近。

> ⚠️ **需回看视频 [00:13:00]**：表述非常规（沿用第一讲"超实数"教学法） —— "它不是 e，而是无限靠近 e 的一个超实数……是 e 的周围的无数个光晕里面的其中一个"

## 【视频02】例2.1：用基本不等式证明数列有界

[00:15:00 - 00:18:00]

例：设 `0<x1<3`，`x(n+1)=√(xn(3-xn))`，证明 {xn} 有界。用基本不等式（算术平均 ≥ 几何平均）：`x(n+1)=√(xn·(3-xn)) ≤ (xn+3-xn)/2 = 3/2`，立即得上界 3/2。构造中的"+xn−xn"正是为凑常数服务。此题从完整考研题中拆出的一步，先练"分解积木"。

> **公式**：`√(ab) ≤ (a+b)/2`。
> **易错点**：凑常数是命题人的固定套路——见到根号下两因子之和为常数，立刻想基本不等式。

## 【视频02】数列极限的 ε-N 定义

[00:18:00 - 00:22:00]

定义：若存在常数 a，对任给 ε>0，总存在 N，当 n>N 时恒有 |xn−a|<ε，则称 a 为 {xn} 的极限（称 xn 收敛于 a），记 `lim(n→∞) xn = a`；不存在这样的 a 则称 {xn} 发散。收敛与发散是对立事件。规范写法：n→∞ 不加正号（n 是自然数）；与函数极限的 ε-X 语言本质一致。定义必须能熟练默写——卷面不考直接证明，但它是推导一切结论的依据。

> **定义**（ε-N 语言）：`∀ε>0, ∃N>0, 当 n>N 时 |xn−a|<ε 恒成立 ⇔ lim(n→∞) xn = a`。
> **易错点**：ε-N 语言要能准确默写；N 只需写"N>0"，不必强求是正整数（小 n 是正整数即可）。

> ⚠️ **需回看视频 [00:19:00]**：口误 —— "你X趋正无穷，它代表既有正无穷也有负无穷"（应为 x→∞ 不带正号时才含正负两个方向，x→+∞ 仅正向）

在数列极限中，n趋向于无穷代表着正无穷，这与函数极限不同。

## 【视频02】数列极限与函数极限的性质对比

[00:22:00 - 00:25:00]

唯一性两者一致。**有界性差异**：函数极限是"局部有界"（趋向过程中有界）；数列收敛则是**全局有界**——整个数列都有界（前有限项是确定值）。保号性差异：函数极限是局部保号；数列保号体现为"某个 N 之后的所有项保持符号"，是覆盖无穷多项的"有条件保号"，对应 x→+∞ 的情形。数列与函数极限的深层联系由海涅定理（归结原则）给出，后面详讲。

> **易错点**：数列收敛 ⇒ 整体有界（不是局部）；对比函数极限时不要把"局部有界"的结论直接搬过来。

## 【视频02】无穷小量、无穷大量与发散形态

[00:25:00 - 00:27:00]

极限为 0 的数列称为 n→∞ 时的无穷小量（离散变量同样适用）。发散有多种形态：不收敛到同一确定值；或趋向无穷大（称无穷大量）。定义中写"存在 N>0"即可，N 不必是正整数——小 n 是正整数，N=10000.1 与 N=10000 等效。

> **定义**：无穷小量——`lim(n→∞) xn = 0`；无穷大量——任给 M>0，存在 N，当 n>N 时 |xn|>M。
> **易错点**：发散 ≠ 无穷大，无穷大只是发散的一种形态。

## 【视频02】数列收敛与子列收敛的关系

[00:27:00 - 00:32:00]

定理：**数列收敛 ⇒ 任意子列都收敛且收敛到同一值**。其逆否命题给出两条判发散的路径：①找到一个**发散子列**，则原数列发散；②找到**两个收敛值不同的子列**，则原数列发散。例：{(-1)^n} 的偶数项子列收敛于 1、奇数项子列收敛于 −1，值不同故原数列发散；而 {n^(−1)^n} 型数列可取偶数项子列 2,4,6,…（发散）直接否定收敛性。

> **易错点**："存在收敛子列"什么也证明不了；能否定收敛的只有"发散子列"或"两个不同极限的收敛子列"。

> ⚠️ **需回看视频 [00:29:00]**：ASR 疑似识别错误（通项写法存疑） —— "比如说n的负一的n次方组成的这个……数列"（疑为 n^(−1)^n，与例2.3 一致，但转写无法确认板书）

## 【视频02】例2.2：|an| 的极限与 a=0 的充要条件

[00:32:00 - 00:38:00]

例2.2：若 `an→a`，则 `|an|→|a|`。工具是不等式 `||a|−|b|| ≤ |a−b|`，用 ε-N 定义即可证（留作业）。**逆命题不成立**：如 an=(−1)^n，|an|→1 但 an 发散。**但 a=0 时是充要条件**：`an→0 ⇔ |an|→0`。应用：证 an→0 时常加绝对值后用夹逼——`|sin n/n²| ≤ 1/n² → 0`，故 `sin n/n² → 0`（|an| 天生 ≥0，夹逼只需管住上界）。函数极限同样有此结论。

> **公式**：`||a|−|b|| ≤ |a−b|`；`lim an = 0 ⇔ lim |an| = 0`。
> **易错点**：`|an|→|a|` 推不回 `an→a`，唯一例外是极限为 0 时；证极限为 0 优先想"加绝对值 + 夹逼"。

## 【视频02】例2.3：用发散子列证明极限不存在

[00:38:00 - 00:40:00]

例：证明 `an = n^(−1)^n` 极限不存在。写出奇偶项：奇数项为 `1, 1/3, 1/5, … → 0`；偶数项为 `2, 4, 6, … → +∞`。取偶数项子列发散（→∞ 即发散），由子列定理立即否定原数列收敛性。注意奇数项子列虽收敛于 0 却不能用来"证明收敛"。

## 【视频02】例2.4：无界但不是无穷大

[00:40:00 - 00:46:00]

例：奇偶项各给一个表达式的数列（偶数项 `x2n=1/(2n)→0`，奇数项→∞），判断其趋向形态。**结论：无界，但不是无穷大**（选择题选 D）。按定义说理：无穷大要求某个 N 之后**所有项**的绝对值都超过任意大 X；而该数列任何 N 之后仍夹杂趋于 0 的偶数项，故不满足无穷大定义。它有趋向无穷大的项，故无界；又非无穷小。区分标准就在"所有项"与"存在项"。

> **定义**：无穷大要求 N 后**所有** |xn|>M；只要 N 后总有小项存在，就不是无穷大。
> **易错点**：**无界 ≠ 无穷大**——存在无穷大位置的项只能推出无界，不能推出无穷大。

## 【视频02】收敛数列的性质：唯一性、有界性、保号性

[00:46:00 - 00:49:00]

①唯一性：极限存在则极限值唯一（数列只能"回一个家"）。②有界性：极限存在 ⇒ 数列必有界（第一讲已证，不考证明但要理解）。③保号性（保序性）：若 `lim an = a > b`，则存在 N，n>N 时 `an > b`；若 `a < b`，则 N 后 `an < b`——极限保住不等号方向。

> **易错点**：保号性的 N 是"存在即可"，结论只覆盖 N 之后的项，不是全部项。

## 【视频02】保号性的双向使用：脱帽法与戴帽法

[00:49:00 - 00:53:00]

脱帽法（极限 → 通项，严格不等）：`lim an = a > b ⇒ 存在 N, n>N 时 an > b`。戴帽法（通项 → 极限，带等号）：N 后 `an ≥ b`（或 >b）且极限存在 ⇒ `lim an ≥ b`。理解关键例：`1/n > 0` 但极限可以等于 0——正项数列的极限可以取 0，所以"帽"必须带等号。

> **易错点**：**戴帽法的等号绝不能丢**（`an > b` 只能推 `lim an ≥ b`）；脱帽法是严格不等号。考题的失分点多出在这里。

## 【视频02】例2.5：用保号性讨论数列的最值（⭐真题）

[00:53:00 - 01:07:18]

例：`an = 1 - (−1)^n/n`，判断有无最大/最小值。代入 a1=2、a2=1/2、a3=4/3、a4=3/4 可见无单调性。关键思路：**最值是"比较"出来的**，无穷多项无法穷举比较 ⇒ 用保号性把"N 之后的项"逐出比较资格，只剩有限项比大小。计算：`lim an = 1`（无穷小×有界）；由 `lim(an−a1)=1−2<0` ⇒ N1 后 `an<a1=2`；由 `lim(an−a2)=1−1/2>0` ⇒ N2 后 `an>a2=1/2`；取 `N=max(N1,N2)`，N 后所有项都不能参与最值比较，**前有限项必有最大值与最小值**（答案 A：既有最大值也有最小值）。此题为数学三考研真题改编，近年真题对概念与逻辑要求越来越高，靠套题型已行不通。

> **易错点**：无穷数列讨论最值，先问"N 之后的项有没有比较资格"——保号性是标准工具；一个题的真正解法往往是朴素的道理（"最值是比较出来的"——莱布尼兹），不是花哨技巧。

## 【视频03】极限的四则运算规则与命题特点

[00:00:00 - 00:03:00]

若 `xn→a`、`yn→b`，则和差积商的极限等于极限的和差积商（商要求分母极限不为零）。规则可推广到有限个数列。命题特点：除法出现少（分母非零约束易出错）；不会考偏门公式（如和差化积）——例：18 年 `cos an − cos bn` 型比较，用 cos 单调递减即可，无需和差化积。

## 【视频03】例2.6：和差换元法——不存在的极限不能拆

[00:03:00 - 00:10:00]

## 【视频03】海涅定理（归结原则）：内容与"去心"概念

[00:10:00 - 00:15:00]

海涅定理（归结原则）：f(x) 在 x0 去心邻域内有定义，则 `lim(x→x0)f(x)=A ⇔ 对任意以 x0 为极限的数列 xn（xn≠x0），f(xn)→A`。**"去心"要点：极限与该点本身毫无关系**——该点可以无定义；"去心邻域内有定义/连续/可导"都只约束两侧，不约束该点。极限存在只说曲线无限靠近某个确定值，不等于该点函数值；当极限值恰好等于 f(x0) 时才是连续。

## 【视频03】归结原则的使用方向与特例

[00:15:00 - 00:22:00]

## 【视频03】注二：连续概念辨析（一点连续 ≠ 邻近连续）

[00:50:00 - 00:54:00]

## 【视频04】夹逼准则：内容与两个要点

[00:00:00 - 00:06:00]

夹逼准则（⭐⭐⭐，集中体现**不等思想**）：从某项起 `yn ≤ xn ≤ zn`，且 `yn→a`、`zn→a`，则 `xn→a`（收敛于 a）。两要点：①"夹"+"逼"缺一不可——两端还要**趋于同一目标**（"两边夹/三明治"的叫法丢了"逼近"这层含义）；②不等号**可带等号也可不带，不需要验证等号**。两端极限可以是同一常数，也可以是同号无穷大（同→+∞ 或同→−∞，同样被逼近）。

## 【视频04】放缩方法5-8：三角不等式族与精细放缩原则

[00:19:00 - 00:28:00]

## 【视频05】单调有界准则：内容与定位
