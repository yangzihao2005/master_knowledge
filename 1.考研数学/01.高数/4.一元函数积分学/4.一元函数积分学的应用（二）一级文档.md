# 第11讲 一元函数积分学的应用（二）

## 【视频01】导学：积分等式与积分不等式的方法体系

[00:00:00 - 00:04:12]

积分学的第二个应用是逻辑证明问题，两大块：积分等式与积分不等式。积分等式是重点，重中之重是两类：只带积分号的、带积分号再带极限号的；主要方法有三——中值定理、夹逼准则、积分方法（换元法、分部积分法，实现两个积分之间的转化，打 triple star）。积分不等式的方法：①函数单调性（函数性态）；②拉格朗日中值定理或泰勒公式（考题多，细分两类）；③积分法（凡用积分法处都打 triple star）；④牛顿-莱布尼兹公式。这部分的难度、区分度与命题精彩程度可能超过第六讲（微分中值定理），但因为大家第六讲基础已牢，只是"套个积分号、再套个极限号"，学起来并不更难。

> **定义**：证明题中的换元法与分部积分法不是为了算出积分，而是实现"一个积分与另一个积分"的关系转化（抽象函数往往算不出）。
> **易错点**：先把方法体系立起来再做题；积分法（换元、分部）在证明题中的地位极高，务必重视。

## 【视频02】积分等式解题工具箱

[00:00:00 - 00:09:00]

做综合题前先盘点工具（函数、导数、积分的互化与放缩）：①积分中值定理 `int_a^b f(x)dx = f(ξ)(b-a)`——f 复杂不好积分时把积分形式转成函数形式；上限变量化（b 改 x）即转为函数问题。②牛顿-莱布尼兹：被积函数是 f' 时 `int_a^x f'(t)dt = f(x)-f(a)`，原函数好找就直接带上下限。③`f(b)-f(a)` 有三种来路：拉格朗日 `f'(ξ)(b-a)`、牛顿-莱布尼兹、变限积分求导的逆用（如 `f(x+2)-f(x)` ← `int_x^(x+2) f(t)dt` 求导），看被积/被导情况选择。④放缩手段：积分保号性（f≤g → ∫f≤∫g）；分部积分 + 三角不等式 `|int u dv| ≤ |uv| + |int v du|`；可拆性 `|int_a^b| ≤ |int_a^c| + |int_c^b|`；泰勒甩余项（f''<0 时丢掉非正余项即放大）；整体加绝对值后逐项放缩。⑤难积函数写成幂函数（泰勒展开）再积分估值。

> **易错点**：对比记忆——f 不好积分别想积分中值定理；被积函数是 f' 想牛顿-莱布尼兹；估值题的目标常只是"不超过某个上限"，不是算出精确值。

## 【视频02】例11.1（一）：推广的积分中值定理

[00:09:00 - 00:17:00]

设 f、g 在 [a,b] 上连续，g 在 [a,b] 上不变号，则存在 ξ∈(a,b) 使 `int_a^b f(x)g(x)dx = f(ξ)·int_a^b g(x)dx`。这是真正一般化的积分中值定理：g≡1（恒正的常函数）即课本中的 `int f = f(ξ)(b-a)`，g 恒正或恒负均可用；考试当天若不考证明可直接使用，不扣分。证明：g≡0 显然；不妨设 g>0（g<0 同理），把上限变量化，令 `F(x)=int_a^x f(t)g(t)dt`、`G(x)=int_a^x g(t)dt`，两个函数就用柯西中值定理：`(F(b)-F(a))/(G(b)-G(a)) = F'(ξ)/G'(ξ)`，变限积分求导后约简即得（F(a)=G(a)=0）。

> **公式**：`int_a^b f g = f(ξ) int_a^b g`（g 不变号、f 连续）。
> **易错点**：两个函数出场就想到柯西中值定理（费马、罗尔、拉格朗日、泰勒都只有一个 f）；证明的引擎是上限变量化 + 变限积分求导。

## 【视频02】例11.1（二）：ξ 的依赖性与放缩夹逼

[00:17:00 - 00:30:00]

例：f 在 [1,2] 上连续，求 `lim_(n→∞) int_1^2 f(x)e^(-x^n) dx`。三条要害：①不可随意交换 lim 与 ∫——能交换需要证明（一般很难），也可能根本不可交换，别走这条路。②用推广中值定理：`int_1^2 f e^(-x^n) = f(ξ_n)·int_1^2 e^(-x^n)dx`，注意中值的依赖性：区间与被积函数都确定时 ξ 是常数；区间变动时 ξ 是端点的函数；被积函数随参数变动时 ξ 是该参数的函数——本题被积函数含 n，故中值写 `ξ_n`，能写出这一点说明理解深刻。③不能对 `int e^(-x^n)` 再用中值定理后断言 `e^(-η_n^n)→0`：η_n 是随 n 变的变量，`η_n^n` 极限无定论（如 `(1+1/n)^n → e` 并非无穷大）。正确做法是放缩：`e^u > u+1` 给出 `e^(-x^n) < 1/(1+x^n) < x^(-n)`，`int_1^2 x^(-n)dx = (2^(1-n)-1)/(1-n) → 0`，被积函数为正，夹逼得 `int_1^2 e^(-x^n)dx → 0`；又 f 闭区间连续有界（`|f(ξ_n)| ≤ M`），有界 × 无穷小 = 0，原极限为 0。

> **定义**：中值依赖性——两定则 ξ 为常数；区间动则 ξ 是端点函数；被积函数动则 ξ 是动参数的函数。
> **易错点**：ξ_n^n 型不能想当然；夹逼两侧极限必须相同；最后一步别忘用 f 的有界性。

> ⚠️ **需回看视频 [00:23:00]**：疑似 ASR 识别错误/公式残缺 —— "是 eta 的 eta n 的 n…乘上二减一"，应为对 `e^(-(η_n)^n)·(2-1)` 谈极限（二次使用中值定理的讨论），转写残缺。

## 【视频02】例11.2：积分中值定理 + 罗尔与两次拉格朗日

[00:30:00 - 00:40:00]

例：f 在 [0,π/2] 上二阶可导，`f(0)=2`，`f(π/2)=1`，`int_0^(π/2) f(x)e^(sin x)cos x dx = 2(e-1)`，证明存在 ξ 使 `f''(ξ)<0`。识别 `g(x)=e^(sin x)cos x` 在第一象限恒正，用推广中值定理（凑微分 `cos x dx = d sin x` 算出 `int g = e-1`）得 `f(ξ_1)(e-1) = 2(e-1)`，即 `f(ξ_1)=2=f(0)`——条件设计得很巧妙。随后是中值定理接力：罗尔（[0,ξ_1]，两点函数值相同）→ `f'(ξ_2)=0`；拉格朗日（[ξ_1,π/2]）→ `f'(ξ_3) = (1-2)/(π/2-ξ_1) < 0`；再拉格朗日（[ξ_2,ξ_3]，用两个一阶导数值造二阶导）→ `f''(ξ) = (f'(ξ_3)-f'(ξ_2))/(ξ_3-ξ_2) < 0`。证 f''<0 的常见路线就是多次拉格朗日制造异号一阶导（或一次罗尔 + 两次拉格朗日），三次罗尔只能造出等号不行。

> **易错点**：先用积分中值定理把积分条件翻译成函数值，是全题最关键的一步；中值点依次记 ξ_1、ξ_2、ξ_3，最后的点才叫 ξ。

## 【视频02】例11.3：分部积分 + 夹逼（积分极限）

[00:40:00 - 00:46:00]

例：求 `lim_(n→∞) int_0^1 (n+1)x^n ln(1+x) dx`。识别 `(n+1)x^n dx = d(x^(n+1))`，对数当 u、按"反对幂指三"分部：`= [x^(n+1) ln(1+x)]_0^1 - int_0^1 x^(n+1)/(1+x) dx = ln 2 - 尾项`。尾项不好算但只需极限：`0 ≤ x^(n+1)/(1+x) ≤ x^(n+1)`，`int_0^1 x^(n+1)dx = 1/(n+2) → 0`，夹逼（大喊一声哪里跑）得尾项 → 0，故极限 = ln 2（选择题选 A）。套路：分部积分找对 u、v 后留一个"小尾巴"，尾巴用放缩 + 夹逼处理。

> **易错点**：夹逼准则不验证等号，放缩粗些无妨；0 处的边界项是取极限（`x^(n+1) ln(1+x) → 0`）。

> ⚠️ **需回看视频 [00:41:00]**：疑似 ASR 识别错误 —— "它就是 n加1 x n次方是吧？乘上 ln 1加上x dx"，被积函数应为 `(n+1)x^n ln(1+x)`（据 `d x^(n+1)` 与答案 ln 2 推断）。

## 【视频02】例11.4 与一般结论：x^n f(x) 型积分极限

[00:46:00 - 00:55:00]

例：含 n 的积分 `u_n = int_0^1 [ln(1+t)]^n |ln t| dt`，题目提示"比较两式大小"就是在暗示夹逼。由常识 `0 ≤ ln(1+t) ≤ t`（t∈[0,1]）得 `u_n ≤ int_0^1 t^n |ln t| dt`；右端分部积分（ln t 当 u，`t^n dt` 归入 dv；t→0⁺ 时 `t^(n+1) ln t → 0`）算得 `1/(n+1)² → 0`，又 u_n ≥ 0，故 u_n → 0。夹逼只给一头提示时，另一头先算出极限值再定方向更稳妥。一般结论（常用）：f 在 [0,1] 上连续，则 `lim_(n→∞) int_0^1 x^n f(x)dx = 0`——用 f 的最值 M、m 夹逼为 `m/(n+1)` 与 `M/(n+1)`；x 的幂次写 n、n-1、n-2 都无所谓，都可当 x^n 看。

> **公式**：`lim_(n→∞) int_0^1 x^n f(x)dx = 0`（f 在 [0,1] 连续）。
> **易错点**：反常积分端点取极限（`t^a ln t → 0`）；该一般结论可直接用于"连续函数 × x 的无穷次幂"型积分极限。

## 【视频02】例11.5：小数部分函数与平均值极限

[00:55:00 - 01:02:00]

例：`f(t) = t - [t]`（实数的小数部分，例1.13 详细讲过：周期为 1 的周期函数，锯齿波，每段三角形面积 1/2），求 `lim_(x→+∞) (1/x) int_0^x f(t)dt`。要害：f 有跳跃间断点，没有原函数，含跳跃间断点时变限积分不可导——洛必达法则不能用（求导后 f(x) 也不存在）。改用夹逼（几何意义：面积逐段累加）：n ≤ x < n+1 时 `n/2 = int_0^n f ≤ int_0^x f ≤ int_0^(n+1) f = (n+1)/2`，除以 x（注意 `1/(n+1) < 1/x ≤ 1/n`）得 `n/(2(n+1)) ≤ (1/x)int_0^x f ≤ (n+1)/(2n)`，两端同趋 1/2，夹逼得极限 1/2。也可用周期函数积分性质（`int_0^n f = n int_0^1 f = n/2`）。

> **易错点**：跳跃间断点函数不能用洛必达（无原函数、变限积分不可导）；夹逼时分子分母的放缩要配对（同大同小）。

## 【视频02】例11.6：两次分部积分恒等式与估值 M/12

[01:02:00 - 01:11:02]

例：f 二阶连续导数，`f(0)=f(1)=0`，证 ①`int_0^1 f(x)dx = (1/2) int_0^1 x(x-1)f''(x)dx`；②`|int_0^1 f| ≤ M/12`（M = max|f''|）。第一问是第二问的提示：从 `int f` 出发两次分部积分（f 当 u，dx 凑成 `d(x²/2)`）造出 f''：`int f = -int x f' = -(1/2)f'(1) + (1/2)int x² f''`；再对 `int_0^1 x f'' dx` 分部（用 f(0)=f(1)=0）得 `= f'(1)`，代回即凑出 `(1/2)int x(x-1)f''`。书上的过程是"从结论往回凑"，课上正着推——证明题知道答案，两个方向都能接上，考试要有反向思维。第二问：取绝对值 + 保号性 + `|f''| ≤ M`，`int_0^1 x(1-x)dx = 1/6`，得 `|int f| ≤ (M/2)·(1/6) = M/12`。

> **公式**：`int_0^1 f(x)dx = (1/2) int_0^1 x(x-1) f''(x) dx`（f(0)=f(1)=0）。
> **易错点**：拆项对齐系数是恒等式证明的关键（`-(1/2)f'(1)` 要识别为 `-(1/2)int x f''`）；估值时 `int_0^1 x(1-x)dx = 1/6` 要算准。

## 【视频03】积分不等式：单调性法（上限变量化）与例11.7

[00:00:00 - 00:08:00]

不等式方法一：`int_a^b f` 是常数，把上限变量化为 `F(x)=int_a^x f(t)dt`（只需 f 连续），用导数研究单调性，最后令 x=b 即得。例11.7：f、g 在 [a,b] 连续，f 单调增加，0≤g≤1。①证 `0 ≤ int_a^x g(t)dt ≤ x-a`：保号性直接得（对 0、1 积分）。②证 `int_a^(a+int_a^b g) f(t)dt ≤ int_a^b f(t)g(t)dt`：令 `F(x) = int_a^(a+int_a^x g(u)du) f(t)dt - int_a^x f(t)g(t)dt`（考研史上最复杂的变限积分之一——上限里还带积分号，但本质仍是变上限函数），求导得 `F'(x) = g(x)[f(a+int_a^x g) - f(x)]`；由① `a+int_a^x g ≤ x` 及 f 单增得方括号 ≤ 0，又 g≥0，故 F'≤0，F 单调减少；`F(a)=0`，于是 `F(b) ≤ 0` 得证。

> **易错点**：第一问是第二问的铺垫（提供自变量大小比较）；上限变量化 + 求导 + F(a)=0 是单调性法三部曲；形式再吓人也是纸老虎，多见识才不怯场。

> ⚠️ **需回看视频 [00:03:00]**：疑似 ASR 识别错误/表述残缺 —— "a到a加上积分a到…"，例11.7 第二问待证不等式转写混乱，据证明过程应为 `int_a^(a+int_a^b g) f(t)dt ≤ int_a^b f(t)g(t)dt`。

## 【视频03】拉格朗日中值定理法与例11.8（估值 M/4）

[00:08:00 - 00:18:00]

方法二多用于一阶可导、端点函数值较简单的情形；核心是"联想经典形式"——f 与 f' 的衔接靠拉格朗日（打星）。例11.8：f 具有一阶连续导数（强于可导、弱于二阶可导），`f(0)=f(1)=0`，`M = max|f'|`，证 `|int_0^1 f(x)dx| ≤ M/4`。两个端点都要用、都不特殊，故分两段：[0,x] 上拉格朗日得 `f(x) = f'(ξ_1)·x`；[x,1] 上得 `f(x) = f'(ξ_2)·(x-1)`。取绝对值放缩：`|f(x)| ≤ Mx`、`|f(x)| ≤ M(1-x)`。拆区间 + 三角不等式：`|int_0^1 f| ≤ int_0^x |f| + int_x^1 |f| ≤ M(x²/2 + (1-x)²/2) = M(x²-x+1/2)`；右端对一切 x∈[0,1] 成立，配方 `(x-1/2)²+1/4` 取最小值 1/4，故 ≤ M/4。

> **易错点**：分段估计后带参数 x，结论要取"对一切 x 成立"的最小上界（不是随便代一个 x）；`1-x` 项写回积分限时注意区间方向。

> ⚠️ **需回看视频 [00:10:00]**：疑似 ASR 识别错误 —— "g(m)是一阶导数绝对值的最大值"，应为"记 M 为一阶导数绝对值的最大值"。

## 【视频03】泰勒公式法与例11.9（估值 M/3）

[00:18:00 - 00:28:00]

方法三用于二阶及以上可导、且有简单函数值的估值题，是四种方法里最重要的：f(x) 没法积分，但泰勒展开成多项式后 `(x-x_0)^k` 积分异常容易，余项再用导数最值放缩——这正是泰勒公式的实际价值（把函数写成多项式去积分）。例11.9：f 在 [0,2] 上二阶导数连续，`f(1)=0`，`M = max|f''|`，证 `|int_0^2 f(x)dx| ≤ M/3`。在 x=1 处展开（f(1)=0 是提示）：`f(x) = f'(1)(x-1) + (1/2)f''(ξ)(x-1)²`（二阶导数连续只够写到二阶余项）。积分：`int_0^2 (x-1)dx = 0`（令 x-1=t 即奇函数在 [-1,1] 的对称积分，几何上两块抵消——比硬算更有意义）；于是 `|int f| ≤ (1/2)M int_0^2 (x-1)²dx = (1/2)M·(2/3) = M/3`。

> **易错点**：ξ 依赖于 x（是 1 与 x 之间的点），`f''(ξ)` 绝对不能提出积分号，必须换 `|f''| ≤ M` 放缩；`int (x-1)dx = 0` 用对称性一眼看出。

## 【视频03】积分法（分部积分）与例11.10

[00:28:00 - 00:34:00]

方法四：用分部积分、换元、恒等变形实现积分间的联系并放缩。例11.10：f' 连续且 `f'(x) ≥ 0`，证对任意正整数 n 有 `|int_0^(2π) f(x) sin nx dx| ≤ (2/n)(f(2π)-f(0))`。选元由条件定：题目给的是导数，就要让 f 求导，故 f 当 u、`sin nx dx` 归入 dv（凑出 `-d(cos nx)/n`）：`int f sin nx = -(1/n)[f cos nx]_0^(2π) + (1/n)int_0^(2π) cos nx·f'(x)dx`。边界项代入 cos 2nπ = cos 0 = 1 得 `-(1/n)(f(2π)-f(0))`；积分项放缩：`|cos nx| ≤ 1`、`f' ≥ 0` 去绝对值，`int_0^(2π) f' = f(2π)-f(0)`，两块合计 `2(f(2π)-f(0))/n`。写不等式时盯着结论随时修正（如利用 f 单调增去绝对值），不必一步到位。

> **易错点**：u、v 的选择取决于"题目给函数还是给导数"；带 n 的三角因子凑微分会出 1/n 系数。

## 【视频03】牛顿-莱布尼兹公式法与例11.11

[00:34:00 - 00:37:56]

方法五：f 与 f' 的关系带着积分号时用牛顿-莱布尼兹公式（不带积分号用拉格朗日，f 与 f'' 的积分用泰勒——这组辨析要总结成表）。例11.11：f' 连续，`f(a)=f(b)=0`，证 `|f(x)| ≤ (1/2) int_a^b |f'(t)|dt`。两头各写一个牛顿-莱布尼兹：`f(x) = int_a^x f'(t)dt` 与 `f(x) = -int_x^b f'(t)dt`，各取绝对值放缩为 `int_a^x |f'|`、`int_x^b |f'|`，相加由可拆性合并成 `int_a^b |f'|`，即 `2|f(x)| ≤ int_a^b |f'(t)|dt`。注意 b>x 时积分限要写回 x 到 b（保证从小到大）；结论是定积分（一个数），变量写 t 写 x 都行。

> **易错点**：端点值为 0 时"两头写"是标准动作；拆区间再合并用可拆性，别漏因子 2；区间方向不能反。
