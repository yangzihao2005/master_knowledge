# 第9讲 一元函数积分学的计算

## 【视频01】本讲知识结构与四大积分法导学

[00:00:00 - 00:03:45]

第九讲讲一元函数积分学的计算，与第四讲（一元微分学的题型与计算）地位对仗，是整个考研数学计算的核心。知识结构：先掌握基本积分公式（十组）与基本性质、计算规则，然后展开四大基本积分法——凑微分法、换元法、分部积分法、有理函数积分；其后依次是定积分的计算、变限积分的计算、反常积分的计算，恰好平行于第八讲的四个概念。四大积分法近年一直是考试重点，出成十分以上大题完全可能；学完本讲后要能用简练语言把这张"知识结构纸"复述出来。

> **易错点**：先建框架再听方法：四大积分法 ↔ 不定积分，定积分计算 ↔ 定积分，变限积分 ↔ 变限积分，反常积分（收敛条件下=定积分+极限）↔ 反常积分，不要一上来就陷进题目。

## 【视频02】基本积分公式总说与幂函数积分（第一、二组）

[00:00:00 - 00:03:00]

基本积分公式十组必须牢记、熟稔于心，十组之外常用的好公式也应主动积累。第一组是 k≠-1 的幂函数：`int x^k dx = x^(k+1)/(k+1) + C`；常见情形要直接写出答案，如 `int x^(-2) dx = -1/x + C`、`int dx/sqrt(x) = 2 sqrt(x) + C`，不要每次再心算 k+1。第二组是 k=-1 的特例：`int dx/x = ln|x| + C`，绝对值必须写，这与求导"视绝对值而不见"一致，只要求 x≠0 有意义。

> **公式**：`int x^k dx = x^(k+1)/(k+1)+C（k≠-1）`；`int dx/x = ln|x|+C`。
> **易错点**：k=-1 不能套幂函数公式；`ln|x|` 的绝对值不能漏。

> ⚠️ **需回看视频 [00:02:00]**：疑似 ASR 识别错误/转写缺失 —— "然后因为你加绝对值了，那么只要这个有意义。" 段末与下一段 "来讲的话呢，a的x次方求导" 衔接断裂，第三组开头可能缺字。

## 【视频02】指数函数与三角函数积分公式（第三、四组）

[00:03:00 - 00:10:00]

第三组：由 `(a^x)' = a^x ln a` 逆推得 `int a^x dx = a^x/ln a + C`，系数 `1/ln a` 绝对不能漏，例：`int 2^x dx = 2^x/ln 2 + C`。第四组三角函数六个基本公式：`int sin x dx = -cos x + C`（负号勿漏）、`int cos x dx = sin x + C`、`int tan x dx = -ln|cos x| + C`、`int cot x dx = ln|sin x| + C`。tan 的积分给了两个掌握角度：①拿着答案求导验证（偷懒但有效）；②写成 sin/cos 后把 `sin x dx` 凑成 `-d cos x`，化为 `int du/u = ln|u|+C`——初学时两个角度都要练，角度②正是后面凑微分法的预演。

> **公式**：`int a^x dx = a^x/ln a + C`；`int tan x dx = -ln|cos x|+C`；`int cot x dx = ln|sin x|+C`。
> **易错点**：`1/ln a` 系数易漏；`int sin x dx` 的负号易漏。

## 【视频02】反三角函数与代数式积分公式（第五～九组）

[00:10:00 - 00:16:00]

第五、六组对比记忆：`int dx/(x^2+a^2) = (1/a) arctan(x/a) + C` 与 `int dx/sqrt(a^2-x^2) = arcsin(x/a) + C`——不带根号的提出 `a^2` 后留下 `1/a` 系数，带根号的 `a` 全部进了凑微分、前面没有 `1/a` 系数。第七组：`int dx/sqrt(x^2±a^2) = ln|x+sqrt(x^2±a^2)| + C`，加号情形根号内恒正不用绝对值，减号情形必须加绝对值。第八组部分分式型：`int dx/(x^2-a^2) = (1/2a) ln|(x-a)/(x+a)| + C`，`a^2-x^2` 的情形只差一负号（对数取倒数即可）。第九组是基本公式里最难的一个（打星）：`int sqrt(a^2-x^2) dx = (x/2)sqrt(a^2-x^2) + (a^2/2)arcsin(x/a) + C`，考过直接默写，推导要等三角代换才会，考前突击记忆、平时遇到抄一遍即可。

> **公式**：`int dx/(x^2+a^2)=(1/a)arctan(x/a)+C`；`int dx/sqrt(a^2-x^2)=arcsin(x/a)+C`；`int dx/sqrt(x^2±a^2)=ln|x+sqrt(x^2±a^2)|+C`；`int dx/(x^2-a^2)=(1/2a)ln|(x-a)/(x+a)|+C`；`int sqrt(a^2-x^2)dx=(x/2)sqrt(a^2-x^2)+(a^2/2)arcsin(x/a)+C`。
> **易错点**：arctan 型有 `1/a` 系数、arcsin 型没有；`x^2-a^2` 型对数里必须加绝对值；第九组公式复杂但常考，不能跳过。

## 【视频02】三角函数降幂公式（第十组）

[00:16:00 - 00:17:16]

第十组是课本未必收录但用得极多的降幂公式：`sin^2 x = (1-cos 2x)/2`、`cos^2 x = (1+cos 2x)/2`。据此 `int sin^2 x dx = x/2 - (sin 2x)/4 + C`，`int cos^2 x dx = x/2 + (sin 2x)/4 + C`；再由 `tan^2 x = sec^2 x - 1`、`cot^2 x = csc^2 x - 1` 得 `int tan^2 x dx = tan x - x + C`、`int cot^2 x dx = -cot x - x + C`。看到 sin²、cos² 不必害怕，想到降幂就回到了基本公式。

> **公式**：降幂公式 `sin^2 x=(1-cos 2x)/2`、`cos^2 x=(1+cos 2x)/2`。
> **易错点**：sin² 后面是减号、cos² 后面是加号，可用 α=0 特殊值验证记忆，别记反。

## 【视频03】凑微分法（第一类换元法）

[00:00:00 - 00:14:00]

整个积分计算的核心思想：把题目归结到十组基本积分公式上。凑微分法即把 `h(x)dx` 人为写成 `f(g(x))·g'(x)dx`，令 `g(x)=u` 得 `int f(u)du`；本质是把一个因子往后放成 `d g(x)`，要对"谁微分得到它"反应极快。常用凑微分公式由基本公式两边取微分得到：`x dx=d(x^2/2)`、`sqrt(x) dx=d(2x^(3/2)/3)`、`dx/sqrt(x)=d(2sqrt(x))`、`dx/x^2=d(-1/x)`、`dx/x=d ln|x|`、`e^x dx=d e^x`、`a^x dx=d(a^x/ln a)`、`sin x dx=-d cos x`、`cos x dx=d sin x`、`sec^2 x dx=d tan x`、`csc^2 x dx=-d cot x`、`dx/(1+x^2)=d arctan x`、`dx/sqrt(1-x^2)=d arcsin x`。破题口诀：乘积形式里找长得最复杂的因式，对它求导，若恰好等于剩余部分（差常数倍），凑微分成功。例：`int arcsin^2 x/sqrt(1-x^2) dx` 中 `(arcsin x)'=1/sqrt(1-x^2)`，直接化为 `int u^2 du = (1/3)arcsin^3 x + C`；例9.1：`int sqrt(x)/sqrt(4-x^3) dx`，`sqrt(x) dx` 凑成 `d(x^(3/2))`，化为 `(2/3)int du/sqrt(4-u^2) = (2/3)arcsin(x^(3/2)/2) + C`。

> **定义**：凑微分 = 把被积式写成 g(x) 的函数乘 g'(x)，`int f(g(x))g'(x)dx = int f(u)du`（第一类换元法）。
> **易错点**：换元步骤可不写，但心里要清楚 u 是谁；系数差常数倍没关系，乘回去即可；求导验证"剩余部分"是判断凑微分成功的可靠手段。

> ⚠️ **需回看视频 [00:09:00]**：疑似 ASR 识别错误 —— "是不是 arccos x 这个平方是这个表达式复杂吧"，题中被积函数是 `(arcsin x)^2`，与后文 "也是 d arccos x" 亦冲突，应为 `arcsin x`。

## 【视频03】凑微分法真题示例（例9.2）

[00:14:00 - 00:18:00]

例9.2（近几年真题大题的最后一步）：`int e^(sinθ/(cosθ+sinθ)) · 1/(cosθ+sinθ)^2 dθ`。识别乘积结构：复杂的显然是 `e^(...)`，令 `g=sinθ/(cosθ+sinθ)`，用商的求导验证 `g' = 1/(cosθ+sinθ)^2` 恰为剩余部分，凑微分成功，直接得 `e^(sinθ/(cosθ+sinθ)) + C`。很多同学大题分数就丢在这最后一步，恰恰考的是基本功。

> **易错点**：真题常把这种一元积分作为多元积分大题的收尾，方法仍是"找 g、求导验证"，不能到这一步才卡住。

> ⚠️ **需回看视频 [00:17:00]**：疑似 ASR 识别错误/公式残缺 —— "e的sin西塔cos西塔加上c"，正确结果应为 `e^(sinθ/(cosθ+sinθ)) + C`。

## 【视频03】换元法（第二类换元法）总论

[00:18:00 - 00:23:00]

当被积函数不能写成"某函数 × 该函数导数"时用第二类换元法：令 `x = g(t)`（新自变量），化为 `int f(g(t))g'(t)dt = int h(t)dt`，与凑微分法互为逆向。换元的目的是化解 f 的复杂性：典型困难是带根号（平方和/差之外的根号）、分母复杂、含反三角/对数/指数等复杂成分；多出的 `g'(t)` 不是负担，往往帮忙进一步约分化简（"分母变简单"常是解题关键）。要求 `x=g(t)` 单调可导（导数保号）以保证有反函数、能回代。

> **定义**：凑微分是把 g'(x) 往后放（中间变量 u），换元法是改换自变量 `x=g(t)`，二者方向相反、目的一致——回到基本积分表。
> **易错点**：方法是为题目服务的，不要硬套题型；命题围绕"去根号、简化分母"设计，顺着这个方向想。

## 【视频03】三角代换

[00:23:00 - 00:33:00]

被积函数含三种根式时做三角代换（a>0）：`sqrt(a^2-x^2)` 令 `x=a sin t`；`sqrt(a^2+x^2)` 令 `x=a tan t`；`sqrt(x^2-a^2)` 令 `x=a sec t`，依据是 `sin^2+cos^2=1`、`tan^2+1=sec^2`，目标是根号下凑成完全平方，开出来消掉根号。t 要取最简的单调区间（sin t、tan t 取 `(-π/2,π/2)`；x 要求为正时相应收窄），保证有反函数可回代；不定积分只找一个原函数，取 cos t 为正的区间后绝对值可不加。回代方法：把 t 当锐角画直角三角形，用边长比读出 sin t、cos t 等。例：`int sqrt(1-x^2) dx` 令 `x=sin t`，化为 `int cos^2 t dt`，降幂积分后回代，恰得第九组公式 `(1/2)arcsin x + (x/2)sqrt(1-x^2) + C`。

> **公式**：三种三角代换对应关系见上。
> **易错点**：换元必须能回代，故要取单调区间；不定积分别给自己找非单调区间制造绝对值讨论；回代用锐角三角形最省事。

> ⚠️ **需回看视频 [00:26:00]**：疑似 ASR 识别错误 —— "sine t 呢，稍微注意一下…如果这个 x 题目里面，在大于零的情况下才有意义…限定 t 在零到二分之派"，结合 `sqrt(x^2-a^2)` 语境应为 `x=a sec t` 的区间讨论，"sine t" 疑为 "sec t"。

## 【视频03】恒等变形后三角代换与根式代换

[00:33:00 - 00:36:00]

根号内不是现成的平方和/差时，先恒等变形（配方等）创造平方再三角代换，如 `sqrt(k^2+φ(x)^2)` 型令 `φ(x)=k tan t`。若造不出平方或很费劲（如 `sqrt(x/(1+x))`），用釜底抽薪的办法：根式整体代换，令整个根式 `=t`——"举重若轻"，复杂部分整体用一个小 t 代表，这是考研常出现的思路（打星）。有多个不同次根号（n 次、m 次）时，令指数为 n、m 最小公倍数的根式等于 t，可同时去根号。

> **易错点**：能造平方优先造平方（三角代换），造不出就整体代换；多根号取最小公倍数。

## 【视频03】倒代换

[00:36:00 - 00:39:00]

分母幂次比分子高出两次及以上时可考虑倒代换 `x=1/t`，但它往往不是第一步：常先做恒等变形（分子分母同乘 x 的幂、拆项）反而更快，例如分子分母同乘 x² 后把 x² 往后凑成 `d(x^3)`，拆成简单分式即出答案。倒代换真正的用武之地是出现 `f(x)+1/f(x)` 结构之类的情形。结论：倒代换有用但不重要，别见到分母次数高就机械套用。

> **易错点**：题型归纳靠不住，总有很多例外；方法为解题服务，思考的出发点应是"怎样让过程更简单"。

## 【视频03】复杂函数直接代换

[00:39:00 - 00:42:00]

被积式含指数、对数、反三角等复杂成分（且不是两类不同函数的乘积）时，直接令复杂部分 `=t`，与根式代换同属"令复杂部分等于 t"这一利器。换元法是解决积分问题最重要的手段（不是"之一"）。但注意例外：若复杂函数（对数、反三角、多项式）与 `e^(ax)`、三角函数做乘积，优先考虑分部积分法——数学之难正难在方法选择不唯一。

> **易错点**：乘积型先想分部积分，非乘积的复杂成分再整体代换，两类信号别混。

## 【视频03】分部积分法与"反对幂指三"选元原则

[00:42:00 - 00:47:47]

分部积分公式 `int u dv = uv - int v du`，适用于两类不同函数相乘且 `int u dv` 难、`int v du` 易的情形。选元口诀"反对幂指三"（反三角、对数、幂、指数、三角）：越靠左越复杂、越当 u（求导后变简单），越靠右求导积分都容易、当 v；常见组合：多项式 × ln/arcsin/arctan 时后者做 u；多项式 × e^x（或 sin/cos）时多项式做 u（多项式求导降次直到 0）；e^x 与 sin/cos 相乘谁当 u、v 都行（两者求导积分难度对等）。

> **公式**：`int u dv = uv - int v du`。
> **易错点**：u 的选择决定方向，选反了会越算越复杂；判停标准是"不再是两类不同函数的乘积"或已回到基本积分公式。

## 【视频04】分部积分法基本例题

[00:00:00 - 00:07:00]

例：`int ln(1+x^2) dx`，把 dx 看作 dv（v=x），对数函数当 u，一次分部后得 `x ln(1+x^2) - int 2x^2/(1+x^2)dx`，剩余积分用加一减一拆开：`= x ln(1+x^2) - 2x + 2 arctan x + C`。例：`int x^3 e^x dx`，三次幂当 u，每分部一次幂次降一，需连续三次分部直到幂函数求导至 0，最终 `x^3e^x - 3x^2e^x + 6xe^x - 6e^x + C`。分部积分的任务是"越做越简单"，若方向选错会越写越复杂。

> **易错点**：`int x^3 e^x` 这类要分部到底（到多项式消失）；符号正负相间最容易写错；`∫ 0 dx = C` 不是 0。

## 【视频04】分部积分法推广公式

[00:07:00 - 00:23:00]

对"多项式 × e^x（或 sin/cos）"型，反复分部慢且易错，于是有推广公式：`int u·v^(n+1) dx = Σ(-1)^k u^(k)·v^(n-k) + (-1)^(n+1) int u^(n+1)·v dx`（k 从 0 到 n）。通式不必背，只需理解判停标准：u 逐次求导，导到某一步后被积函数不再是两类不同函数乘积（多项式求导至 0，`int 0 dx = C`）即停；对 x³e^x 相当于 x³ 求三阶导，n=2 就够，一般三阶导足够。证明思路就是把分部积分连续做 n 次再联立，符号一项正一项负相间。

> **公式**：推广通式（了解即可，不必背）；判停看 u 求导后乘积类型。
> **易错点**：`∫0 dx = C` 而不是 0；最后一项积分前的符号与前一项相反。

## 【视频04】分部积分表格法及示例

[00:23:00 - 00:33:00]

表格法：u 写左上、v 的相应阶导数写右上，u 逐行求导、v 逐行积分成对进行，然后左上右下错位相乘，各项符号正负相间，最后一列两数相乘作积分（符号与前一项相反）。用表格法做 `int x^2 e^x dx`：`x^2e^x - 2xe^x + 2e^x + C`；`int x^3 e^x dx`：`x^3e^x - 3x^2e^x + 6xe^x - 6e^x + C`，与逐步分部一致但符号不会错（逐步分部时老师故意演示过一处符号错误）。"爱情故事"比喻：幂函数男生越求导越"冷淡"直至 0（热情归零、分部结束），指数函数女生积分始终如一，历程正负相间有甜有苦。

> **易错点**：表格法每步符号是"+ - + -"机械相间，比逐步分部可靠；最后一项是积分项，前面符号取相反数。

## 【视频04】恒等变形与常用公式小结（附录四）

[00:33:00 - 00:44:00]

积分小结第一点是恒等变形（含代数运算与公式储备），附录四要重点记：诱导公式八个（`sin(π/2±α)=cos α`，`sin(π±α)=∓sin α`，`cos(π/2±α)=∓sin α`，`cos(π±α)=-cos α`），常用换元 `x=π±t`、`x=π/2±t` 正是冲着它们去的；倍角公式第一行要记；降幂公式 `sin^2=(1-cos2α)/2`、`cos^2=(1+cos2α)/2` 必记（特殊值验证防混）；和差公式前三个要记（含 `tan(α±β)`，tan 45° 特值常用）；和差化积、积化和差查表即可，不必强背；万能公式是"万不得已才用"。另需：一元二次方程判别式与韦达定理、因式分解公式（记不清可用多项式竖式乘法验算）、二项式定理、阶乘与双阶乘（双阶乘 `n!!` 是后面点火公式的工具）。

> **易错点**：命题老师默认大家熟悉三角公式，实际很多考生已经生疏，这是信息不对称，务必把常用三角公式捡回来。

## 【视频04】基本积分方法选择小结

[00:44:00 - 00:49:00]

## 【视频05】有理函数与有理函数积分总框架

[00:00:00 - 00:08:00]

有理函数 `P_n(x)/Q_m(x)`：n<m 称真分式，n≥m 称假分式；由多项式除法，假分式必可写成"多项式 + 真分式"，多项式积分是幂函数积分，故只研究真分式。基本定理：真分式必可唯一地拆成若干最简分式之和；四种最简分式积分都做出来后，任何有理函数积分就都解决了——这是前面基本积分法的重要应用。有理函数一定有初等函数形式的原函数。

> **定义**：真分式 = 分子次数 < 分母次数；假分式 = 多项式 + 真分式。
> **易错点**：遇到假分式先分离出多项式，别硬拆；拆分理论保证"一定能拆且表示唯一"。

> ⚠️ **需回看视频 [00:01:00]**：疑似 ASR 识别错误 —— "有理函数呢是 p(x) 比上 q(mx)"，应为 `P_n(x)/Q_m(x)`。

## 【视频05】四种最简分式及其积分

[00:08:00 - 00:15:00]

四种最简分式（分母因式分解后）：①`A/(ax+b)`；②`A/(ax+b)^k`（k 重一次因式）；③`(Ax+B)/(px^2+qx+r)`（Δ=q²-4pr<0）；④`(Ax+B)/(px^2+qx+r)^k`。积分法：①直接 `ln|ax+b|`（配系数）；②化 `u^(-k)` 幂函数积分（一般 k=2 为止）；③把分子配成分母的导数得对数项，剩余常数经配方化 `arctan` 型——例 `int (x-1)/(x^2+1)dx = (1/2)ln(x^2+1) - arctan x + C`；④最难，用分部积分造递推。只要这四类会算，按理论任何有理函数积分都能写出来。

> **公式**：③的处理口诀——分子凑分母导数（出 ln）+ 剩余常数配方（出 arctan）。
> **易错点**：③要先验证 Δ<0（分母不可再分解且恒不为零）；`ln` 里二次式恒正可不加绝对值。

## 【视频05】k 重二次因式的递推积分

[00:15:00 - 00:22:00]

第四种最简分式（k 重二次因式）用分部积分造递推式解决。例：`I_2 = int dx/(1+x^2)^2`，由已知的 `I_1 = int dx/(1+x^2) = arctan x` 入手，把 `dx/(1+x^2)` 与 x 分部，加一减一拆项后建立 `I_1` 与 `I_2` 的关系，解出 `I_2 = x/(2(1+x^2)) + (1/2)arctan x + C`。一般情形可造出 `I_n = f(I_(n-1))` 型递推式。至此分部积分法的三种产出集齐：建方程（循环）、抵消、递推。

> **易错点**：递推过程中间不加 C，最后统一加；递推式从低阶（I_1=arctan x）推向高阶，方向别搞反。

## 【视频05】有理式的拆分方法（待定系数法）

[00:22:00 - 00:31:00]

拆分规则由分母因式决定：分母分解出一次单因式 `(ax+b)`，右边就有一项 `A/(ax+b)`；分解出 `(ax+b)^k`，右边就有 k 项（分母一次到 k 次、分子为常数）；分解出二次单因式 `(px^2+qx+r)`，右边有一项 `(Ax+B)/(...)`；分解出 k 次幂就写 k 项（分子一次式）。记忆通式：分母升幂、分子比降一次（底下一次上面零次，底下二次上面一次）。系数用待定系数法：通分后比较分子恒等式；优先用赋值法——令 x 取使某些因式为零的值消元（恒等式对任何 x 成立，可代使分母为零的点，不放心就取极限），再比较最高次系数定余下未知数。例9.8：`(4x^2-6x-1)/((x+1)(2x-1)^2)` 拆为 `A/(x+1)+B/(2x-1)+C/(2x-1)^2`，赋值 `x=1/2` 得 C=-2，`x=-1` 得 A=1，比较 x² 系数得 B=0。

> **易错点**：拆分只看分母结构、不看分子；赋值法合法（恒等式），不必展开成大方程组硬解。

## 【视频05】三角有理式的积分（万能代换与凑微分）

[00:42:00 - 00:51:00]

## 【视频06】牛顿-莱布尼兹公式及其证明

[00:00:00 - 00:06:00]

设 f(x) 在 [a,b] 上连续，F(x) 是 f 在 [a,b] 上的一个原函数，则 `int_a^b f(x)dx = F(b) - F(a)`，即牛顿-莱布尼兹公式——定积分计算的总开关，此后不定积分的方法全部平移过来。证明思路：令 `G(x)=int_a^x f(t)dt`（连续函数的原函数表达式），则 `G(a)=0`、`G(b)=int_a^b f`；又 `F'=f`，两原函数只差常数 `G(x)=F(x)+C`，故 `G(b)-G(a)=F(b)-F(a)`。用到三块基本功：原函数的表达式、原函数定义、原函数彼此差常数。

> **公式**：`int_a^b f(x)dx = F(b)-F(a)`。
> **易错点**：条件是"连续 + 找到一个原函数"；证明本身虽未考过，但属基本概念重点，最好掌握。

## 【视频06】牛顿-莱布尼兹公式的推广与分段处理

[00:06:00 - 00:17:00]

推广一（不加证明可直接用）：f 不必连续，只要在 [a,b] 上有原函数，公式仍成立——因为导函数允许有特殊的（有界、无限压缩型）震荡间断点，这类 f 也有原函数。推广二（黎曼思想，打星）：f 有跳跃间断点则整体无原函数，但可切开分段——每段上 f 连续、分别用牛顿-莱布尼兹公式再相加；改变有限个点的函数值不影响定积分值（一条线没有面积），间断点处只需左右极限存在。若某段上 f 无界，积分不存在（发散），那已属于反常积分。

> **易错点**：原函数定义不容妥协（处处可导且导数等于 f），放宽的只是 f 的条件；遇间断点先考虑分段处理，无界则是反常积分问题。

## 【视频07】定积分的换元积分法（换元三换）

[00:00:00 - 00:09:00]

定积分换元法与不定积分思路相同（`x=φ(t)` 化简被积函数），但有本质区别：换元要三换——①被积函数换 `f(φ(t))`；②积分元素换 `dx=φ'(t)dt`；③上下限换成对应的新限 α、β。三换之后直接对 t 用牛顿-莱布尼兹公式，不需要回代（不定积分才要回代）。充分条件：φ 在 [α,β] 上有连续导数、值域落在原区间内（后者可放宽，只要 h(t) 在新区间上有原函数即可）。积分换元本质是"一个定积分化为另一个相等的定积分"。

> **公式**：`int_a^b f(x)dx = int_α^β f(φ(t))φ'(t)dt`（三换）。
> **易错点**：只换被积函数不换上下限是最高频错误；定积分换元不回代。

## 【视频07】定积分的分部积分法与对称性、周期性结论

[00:09:00 - 00:14:00]

定积分分部积分法：`int_a^b u dv = uv|_a^b - int_a^b v du`，把上下限直接带进去即可。三条常用结论（考试可直接用）：①f 为连续奇函数，`int_-a^a f = 0`；②f 为连续偶函数，`int_-a^a f = 2 int_0^a f`（合称"偶被奇零"）；③f 以 T 为周期的连续函数，`int_a^(a+T) f = int_0^T f`（区间长度为一个周期，积分值与起点无关）。几何意义直观：对称区间两块面积相等或相反；周期函数平移一个周期，少算的一块与多算的一块恰好互补。

> **公式**：偶被奇零；`int_a^(a+T) f(x)dx = int_0^T f(x)dx`。
> **易错点**：定积分有几何意义可以借用，不定积分没有；周期性质要求区间长度恰为 T。

## 【视频07】区间再现公式及其应用

[00:14:00 - 00:22:00]

区间再现公式（可视为第五个基本方法）：`int_a^b f(x)dx = int_a^b f(a+b-x)dx`，证法是换元 `t=a+b-x`（换元三换：x 取 a 时 t 取 b，`dx=-dt`，负号交换上下限）。用法精髓：f(x) 与 f(a+b-x) 各自都不好积分，但两式相加往往大简化，于是 `I = (1/2) int_a^b [f(x)+f(a+b-x)]dx`。经典例：`int_0^(π/4) ln(1+tan x)dx`，再现后 `1+tan(π/4-x) = 2/(1+tan x)`，两式相加被积函数化为 `ln 2`，故 `I = (π/8) ln 2`。

> **公式**：`int_a^b f(x)dx = int_a^b f(a+b-x)dx`；`I = (1/2)int_a^b [f(x)+f(a+b-x)]dx`。
> **易错点**：相加除以 2 才等于原积分；换元法（定积分中）与分部积分法一样可能"积分再现建方程"。

## 【视频07】华里士公式（点火公式）

[00:22:00 - 00:35:00]

华里士（Wallis，牛顿的老师）公式，俗称点火公式，考场上直接用不推导：`int_0^(π/2) sin^n x dx = int_0^(π/2) cos^n x dx`，n 为正偶数时 `(n-1)!!/n!! · π/2`，n 为大于 1 的正奇数时 `(n-1)!!/n!!`。口诀：从 n 开始倒数（n 作分母、n-1 作分子）一直乘到 1——最后一项是 `1/2` 就"点火"乘 `π/2`（偶数情形）；奇数情形数到 `2/3` "发射失败"结束，不乘 `π/2`。推广：`int_0^π`：n 正偶数为 2×华里士，n 为大于 1 的奇数时 sin 为 2×华里士、cos 为 0；`int_0^(2π)`：n 正偶数为 4×华里士，n 正奇数为 0。例：`int_0^(π/2) sin^2 x cos^2 x dx` 把 cos² 换成 1-sin² 后拆两项分别点火，提公因式得 `π/16`。双阶乘 `n!!` 是这套公式的记法工具。

> **公式**：`int_0^(π/2) sin^n x dx = (n-1)!!/n!! · (n 偶乘 π/2，n 奇不乘)`；0 到 π、0 到 2π 的倍数与零值规则见上。
> **易错点**：sin 与 cos 在 0 到 π/2 上等值，但 0 到 π 上 cos 的奇次幂是 0（不是 2×华里士）；这是考研传统公式，几乎必考，务必背熟。

## 【视频09】变限积分求导公式

[00:00:00 - 00:06:00]

`d/dx int_{φ1(x)}^{φ2(x)} f(t)dt = f(φ2(x))·φ2'(x) - f(φ1(x))·φ1'(x)`（f 连续，φ1、φ2 可导）——上限代入乘上限导数减下限代入乘下限导数，百分之百必考。要点：求导变量是 x（积分限中的变量），积分变量是 t，公式只在被积函数仅含 t 时可用；若被积函数含 x（如 `f(t,x)`），必须先通过恒等变形、换元（如 `xt=u`、`x^2-t^2=u`，换元时 x 当常数）把 x 移出积分号再求导。可分离的 `g(t)h(x)` 型可直接把 h(x) 提出来按乘积求导。例：`int_{x^2}^{sin^2 x} f(t^2)dt` 求导得 `f(sin^4 x)·2sin x cos x - f(x^4)·2x`（代入时 t 换上限再平方）。

> **公式**：变限积分求导公式（见上）。
> **易错点**：被积函数含求导变量时公式失效，先换元移出；代入上限是把上限整个代进 t 的位置，复合别漏。

## 【视频09】重要结论：变限积分的奇偶性

[00:25:00 - 00:34:00]

三组重要结论（打星，必考）之一、二：①f 是可积的奇函数，则 `int_a^x f(t)dt`（a 任给，含 0）必为偶函数——奇函数的变限积分（不论下限）都是偶函数；②f 是可积的偶函数，则只有 `int_0^x f(t)dt` 必为奇函数，若下限 a≠0，`int_a^x = int_0^x + 常数`，奇函数加非零常数后图像上下平移，成为非奇非偶函数。与求导对照记忆：奇函数求导得偶函数、偶函数求导得奇函数。注意"可积"与"连续"的措辞差别：可积时只能叫变限积分；f 连续时才能称原函数——连续奇函数的全体原函数都是偶函数，连续偶函数的全体原函数中只有 `int_0^x f` 是奇函数。

> **公式**：奇 →（任意下限变限积分）偶；偶 →（仅零下限变限积分）奇。
> **易错点**：偶函数情形的零下限条件是命题热点；"可积"说变限积分、"连续"才能说原函数，措辞要严谨。

## 【视频09】重要结论：变限积分的周期性与三结论总结

[00:34:00 - 00:40:00]

结论③：f 可积且以 T 为周期，则 `int_0^x f(t)dt`（或 `int_a^x`，a 任给）仍以 T 为周期的充要条件是 `int_0^T f(x)dx = 0`——注意与求导对比：周期函数求导必仍同周期（无需附加条件），积分则必须加"一个周期积分值为 0"这一条件，二者不对称。三个结论合起来背：奇偶性看下限（奇任意、偶只零），周期性看一个周期的积分值；这一页是考研数学最重要考点之一，一定会出题。

> **公式**：`int_0^x f` 以 T 为周期 ⟺ `int_0^T f = 0`。
> **易错点**：只有周期条件推不出变限积分周期性；`int_a^x` 与 `int_0^x` 只差常数，常数不影响周期性，故 a 可任给。

## 【视频09】奇偶性与周期性结论的证明（例9.23、9.25①）

## 【视频10】伽马函数的定义域

[00:35:00 - 00:42:00]

补充讨论：Γ(α) 的定义域即"α 取何值时反常积分收敛"。拆 `int_0^1 + int_1^∞` 分别讨论：α≥1 时 x^(α-1) 在 0 附近无奇性，无穷端由 e^(-x) 决定（比任何幂次衰减都快，用比较法极限形式可证），收敛；0<α<1 时 x=0 是瑕点，`int_0^1 x^(α-1)dx` 是 p 积分，α>0 即收敛，无穷端依然收敛。综上 α>0 全部收敛，定义域为 (0,+∞)；实用计算常用 α≥1 的情形，但 (0,1) 内同样收敛。

> **易错点**：讨论收敛要同时看两个奇点（0 处瑕点 + ∞ 处）；结论：Γ(α) 定义域 (0,+∞)。

## 【视频10】费曼积分号下求导（介绍）

[00:42:00 - 00:47:59]

收尾介绍费曼（Feynman）的"积分号下求导"技巧：由 `int_0^∞ e^(-ax)dx = 1/a`（a>0）两边对参数 a 求导，得 `int_0^∞ x e^(-ax)dx = 1/a^2`，逐次求导可得 `int_0^∞ x^n e^(-ax)dx = n!/a^(n+1)`，令 a=1 即 `n!`，与例9.28 的递推结果一致。这种做法历史上被数学家批评为不严格，但常能出奇制胜；积分号下求导的理论（含参积分）超出考研范围，研究生阶段再学。咱们考试还是要按规范步骤写过程，答案对、过程也得对。

> **易错点**：费曼技巧仅供欣赏，考场上写不严谨过程会扣分；对 a 求导时 x 视为常数。
