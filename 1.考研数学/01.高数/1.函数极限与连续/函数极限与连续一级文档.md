## 【视频01】极限计算的方法体系与七种未定式

## 【视频02】函数的概念与单值函数的判别

[00:00:00 - 00:07:00]

函数描述两个变量按法则的对应：D 为给定数集，对每个 `x ∈ D` 按一定法则有确定的 y 与之对应，记 `y = f(x)`；定义域由实际背景（如时间非负）或法则要求（如分母不为零）确定，取值范围称值域。考研数学中默认讨论单值函数：每个 x 只对应一个 y（允许一对一、多对一，禁止一对多），一对多者称多值函数，不在考研范围内。判别单值/多值用铅垂画线法（数形结合）：任作铅垂线与曲线 `y = f(x)` 至多一个交点即为单值函数；出现两个交点即为多值函数。

> **定义**：对每个 `x ∈ D` 有唯一确定的 y 与之对应，则称 y 是 x 的函数 `y = f(x)`，D 为定义域，函数值全体为值域。
> **易错点**：除非特殊说明，考研中"函数"一律默认单值函数；"至多一个交点"包含无交点（该 x 处无定义）的情形，也算单值。

## 【视频02】由复合函数表达式求对应法则（例1.1）

[00:07:00 - 00:10:00]

给出 `f(x + 1/x)` 型复合表达式求 f，方法是对等式两边作恒等变形，把右端整体凑成中间变量 `x + 1/x` 的函数：分子分母同除 `x^2`，把 `x^2 + 1/x^2` 写成 `(x + 1/x)^2 - 2`（因两者互为倒数，`2ab = 2`）。例：题设右端推导中分子为 `x + x^3`、分母为 `1 + x^4`，得 `f(u) = u/(u^2 - 2)`，即 `f(x) = x/(x^2 - 2)`（题设原式转写缺失，见⚠️）。这类"给复合函数还原对应法则"是考研常用引子，后续会反复用到。

> **公式**：`(x + 1/x)^2 = x^2 + 1/x^2 + 2`，故 `x^2 + 1/x^2 = (x + 1/x)^2 - 2`
> **易错点**：凑中间变量后剩下的项必须继续恒等变形；减 2 来自倒数关系 `ab = 1`。

## 【视频02】由函数关系式求对应法则（例1.2）

[00:10:00 - 00:16:00]

关系式中同时含 `f(x)` 与 `f(1/x)`（括号内为倒数关系）时，把式中所有 x 换成 `1/x` 得第二个等式，两式联立消去 `f(1/x)` 解出 f。例1.2：解得 `f(x) = x/sqrt(1 + x^2)`。变形中 `sqrt(1 + 1/x^2) = sqrt(1 + x^2)/x`，平方开根号本应加绝对值，因 x > 0 故直接写 x。同类注：`f(x) + x f(-x) = x` 型（相反数关系）把 x 换成 `-x` 联立消去 `f(-x)`。符号复杂时务必把每步式子写清楚以免看错。

> **公式**：倒数关系型：作 `x -> 1/x` 建方程组；相反数关系型：作 `x -> -x` 建方程组；再加减消元
> **易错点**：老师强调这种"给关系式求 f"考得更多、要多练；`sqrt(x^2) = |x|`，仅当 x > 0 时才能写成 x。

## 【视频02】反函数的概念与图像关系

[00:16:00 - 00:21:00]

反函数的前提是单值（先符合铅垂画线法）：对每个 y 必存在唯一的 x 使 `y = f(x)`，则可定义新函数 `x = phi(y)`（即 `f^{-1}`）为反函数，原函数称直接函数。严格单调必有反函数，但这只是充分条件。反函数 `x = f^{-1}(y)` 与直接函数 `y = f(x)` 的图像完全重合——"反"指对应法则互为逆运算（如平方↔开方），不是图像反。只有把 x、y 字母对调后（如 `y = x^2` 与 `y = sqrt(x)`，x ≥ 0）才关于 `y = x` 对称，对称性来自互换字母，与是否叫反函数无关。

> **定义**：`y = f(x)` 为直接函数，由每个 y 有唯一 x 与之对应确定的 `x = f^{-1}(y)` 称反函数。
> **易错点**：不要认为"反函数图像与原函数图像关于 y = x 对称"；两图重合是常态，对称是换字母的结果。

## 【视频02】反函数存在性的判别（水平画线法）

[00:21:00 - 00:26:00]

严格单调必有反函数，但反函数不一定严格单调（如"斜直线 + 双曲线"拼成的分段函数不单调、不连续，其反函数是它本身）。判别有无反函数用水平画线法：在先满足铅垂画线法的前提下，任作水平直线与曲线至多一个交点，则 f 有反函数。口诀："铅垂直线定单多，水平直线定反值"。具体函数直接画线即可，不必用求导判别（导数正负只是充分条件，且函数可能不可导、不连续）。

> **易错点**：水平画线法的前提是先通过铅垂画线法（先保证单值）；两步顺序不能颠倒。

## 【视频02】反函数的恒等式与求法（例1.3）

[00:26:00 - 00:33:00]

复合恒等式 `f(f^{-1}(x)) = x`、`f^{-1}(f(x)) = x` 可消去外层；非 e 底常先化为 e 底（`2^x = e^(x ln 2)`）便于处理。求反函数的步骤：反解（必要时用对数运算规则）→ 交换 x、y 字母。对数三规则：`ln(ab) = ln a + ln b`（积变和）、`ln(a/b) = ln a - ln b`（商变差）、`ln(a^b) = b ln a`（幂次变倍数），命题老师偏爱对数表达式，不必害怕。例1.3：`y = ln(x + sqrt(x^2 + 1))` 不能直接反解，先取负号、倍数变幂次，再分子分母同乘共轭 `sqrt(x^2+1) - x` 有理化，取 e 后两式相减得 `e^y - e^{-y} = 2x`，反函数为 `y = (e^x - e^{-x})/2`，定义域为 R。

> **公式**：`f(f^{-1}(x)) = x`；`ln(a^b) = b ln a`；`e^y - e^{-y} = 2x <=> x = (e^y - e^{-y})/2`
> **易错点**：解出 x 后必须交换字母才是反函数表达式；共轭有理化是处理 `x + sqrt(x^2 + 1)` 的标准手法，幂次变倍数"倍数也可变幂次"反着用。

## 【视频02】双曲函数：反双曲正弦、双曲正弦与双曲余弦

[00:33:00 - 00:37:00]

三个必须掌握的函数：`ln(x + sqrt(x^2 + 1))`（反双曲正弦，奇函数）、`(e^x - e^{-x})/2`（双曲正弦，奇函数）、`(e^x + e^{-x})/2`（双曲余弦，偶函数）。双曲余弦用水平画线法可判无反函数（水平线可交两点），其图像是悬链线（a = 1 的特例）而非抛物线。名字不重要，要记住的是奇偶性与大致图形；反双曲余弦需重新定义后才有反函数，考试中也不重要。2023 年考研直接考过这类函数的展开式，在命题老师眼里它们与 sin、cos 同属最基本的函数。

> **易错点**：三个函数的奇偶性就是考点（前两个奇、第三个偶）；双曲余弦无反函数。

## 【视频02】反双曲正弦在微积分中的应用预告

[00:37:00 - 00:43:00]

注三预告 `ln(x + sqrt(1 + x^2))` 在后续课程的三重身份：① x → 0 时它与 x 是等价无穷小（从左、右趋于 0 的速度与 x 一致，证明见洛必达法则）；② 它的导数与不定积分互为逆运算，不定积分即该函数加 C（基本积分表的重要结论）；③ 它是奇函数，故对称区间 `[-1, 1]` 上其定积分为 0（面积 S 与 -S 抵消），同一积分中 `x^2` 部分为 `2/3`（左右各 `1/3`）。复杂表达式等价于简单 x，正是"化繁为简"的解题方向；基础扎实后极限、导数、积分、面积问题都可快速解决。

> **公式**：`ln(x + sqrt(1 + x^2)) ~ x` (x -> 0)；奇函数在对称区间上定积分为 0；`int(-1 to 1) x^2 dx = 2/3`
> **易错点**：该函数在等价无穷小、求导公式、积分公式里反复出现，务必掌握。

## 【视频02】复合函数的概念与复合方法（例1.4）

[00:43:00 - 00:48:00]

复合函数 `f(g(x))` 是一层套一层的对应法则（还可有第三层 `h(f(g(x)))`）；考研重点是掌握复合方法——把里层整体当"框框"代入外层法则。例1.4：已知 `f(x) = x^2`、`f(phi(x)) = -x^2 + 2x + 3` 且 `phi(x) >= 0`，则 `phi(x) = sqrt(-x^2 + 2x + 3)`（平方开根号因已知非负不加绝对值）；定义域由 `-x^2 + 2x + 3 >= 0` 得 `[-1, 3]`，值域 `[0, 2]`（x = 1 时取最大值 `sqrt(4) = 2`，x = -1 或 3 时取 0）。根号 u 与 u 的最值点位置相同，也可配方 `-x^2 + 2x + 3 = 4 - (x - 1)^2` 直接读出最值。

> **定义**：`f(u)` 与 `u = g(x)` 复合得 `f(g(x))`，g 为内层、f 为外层。
> **易错点**：平方开根号一般要加绝对值，只有已知被开方式非负才省略；复合函数题常是综合题的第一步。

## 【视频02】分段函数的复合（例1.5）

[00:48:00 - 00:51:41]

分段函数复合的关键是画出里层函数图形，由里层取值的符号决定外层用哪一段表达式。例1.5：`g(t) = 2 - t`（t ≤ 0）、`g(t) = 2 + t`（t > 0）；`f(x) = x^2`（x < 0）、`f(x) = -x - 1`（x ≥ 0）；由图读出 `f(x) <= 0 <=> x >= 0`，`f(x) > 0 <=> x < 0`，代入对应段得 `g(f(x)) = 3 + x`（x ≥ 0）、`g(f(x)) = 2 + x^2`（x < 0）。复合时不必两图都画，画里层函数即可一目了然。

> **公式**：`g(f(x))` 中先解不等式 `f(x) <= 0` 与 `f(x) > 0` 定 x 范围，再分别代入外层分段表达式
> **易错点**：最终填入的是 f(x) 的具体表达式（如 `-x - 1`）而不是 f(x) 记号本身；分段点的实心空心要与定义（≤ 0 用第一段）一致。

## 【视频03】隐函数的概念与判别

[00:00:00 - 00:04:00]

方程 `F(x, y) = 0` 中，若 x 在某区间内取值时总有满足方程的唯一 y 存在，则该方程确定隐函数 `y = y(x)`。能确定隐函数就必须不是多值函数：在某点邻域内用铅垂画线法，若铅垂线与曲线有两个交点（多值），则该处不能确定隐函数。有些隐函数可显化（如解出 y），但一般 `F(x, y) = 0` 多用于不易显化的情形；实际问题中还常用参数方程表达 x、y 的关系。隐函数存在定理及由它导出的公式法后续专门讲。

> **定义**：方程 `F(x, y) = 0` 确定隐函数 `y = y(x)`：x 在某区间取值时总有唯一的 y 满足方程。
> **易错点**：确定隐函数 ⇔ 该区间上不是多值函数，判别工具仍是铅垂画线法。

## 【视频03】隐函数求值的观察法

[00:04:00 - 00:11:00]

求 `y(x0)` 不必显化：直接把 `x = x0` 代入方程，得到只含 y 的方程再解出 y，这是考研常见问题。若不易解出，用观察法（"解无定法，观察得知"）：找显然使两边相等的 y 值，必要时画 `z = ln y` 与另一侧曲线看交点位置。例：x = 2 时由 `ln y = 2/y - 2` 观察出 y = 1（两边同为 0）；又例：x = 2 时由 `ln y + e^(y-1) = 1` 即 `ln y = 1 - e^(y-1)`，观察出 y = 1。超越方程可能只有数值解，但考题给出的必可求出；细致的画图分析放草稿纸，答题写"显然 y = 1"即可。

## 【视频03】函数的有界性

[00:11:00 - 00:17:00]

## 【视频03】奇偶性的定义与基本类型

[00:42:00 - 00:47:00]

> **易错点**：验证奇偶性先检查定义域是否关于原点对称；`f(x) + f(-x)`、`f(x) - f(-x)` 这两个组合的奇偶性是无条件结论。

## 【视频03】奇偶性与求导、变限积分

[00:50:00 - 00:55:00]

## 【视频04】指数函数 y=a^x 与 e^x 的性质

## 【视频05】绝对值函数与符号函数

[00:58:00 - 01:01:00]

`y = |x|` 是把 `y = x` 负的部分沿 x 轴翻折上来得到的折线；它既是分段函数又是初等函数（因为 `|x| = sqrt(x^2)`，由基本初等函数复合而得），是一个特例。几何意义：`|x|` 表示 x 到原点的距离，故为偶函数，取反例时经常用到。符号函数 `sgn x`：`x > 0` 取 1、`x < 0` 取 -1、`x = 0` 取 0，`x = 0` 是典型的跳跃间断点。恒等式：任何实数都可写成绝对值与符号函数之积 `x = |x| * sgn x`（正数、负数、0 逐一验证均成立）。

> **公式**：`|x| = sqrt(x^2)`；`x = |x| * sgn x`。
> **易错点**：`|x|` 的双重身份（分段函数 + 初等函数）是特例，一般分段函数不是初等函数；记住 `|x| = sqrt(x^2)` 在考研中使用极频繁。

## 【视频05】取整函数

## 【视频05】小数部分函数

[01:08:00 - 01:15:00]

小数部分 `{x} = x - [x]`，即实数减去自己的整数部分，值域 `[0, 1)`。由 `[x+1] = [x] + 1` 可验证 `{x+1} = {x}`，故它以 1 为周期，只画 `[0,1)` 上的一段（`{x} = x` 的斜线，左端实心、右端空心）再平移即得锯齿图像；它是周期函数，不是偶函数、不是单调函数。例：`{1.99} = 0.99`；`{-1.99} = -1.99 - (-2) = 0.01`——负数的小数部分仍是正数。一个锯齿下与 x 轴围成的面积是 1/2（底 1 高 1 的三角形）。

> **公式**：`{x} = x - [x]`；`{x+1} = {x}`；`{-1.99} = 0.01`。
> **易错点**：负数的小数部分为正（`{-1.99} = 0.01`，不是 0.99），依据是其整数部分取 -2。

## 【视频06】邻域的概念

[00:00:00 - 00:03:00]

邻域是描述极限定义所必需的专用区间概念。点 x0 的 delta 邻域是开区间 `(x0-delta, x0+delta)`，即到 x0 距离小于 delta 的全体 x 组成的集合。去掉中心点后称去心 delta 邻域，对应不等式还要加"大于零"。区间左、右两半分别称左邻域、右邻域。

> **定义**：设 `x0` 为实数、`delta > 0`，称开区间 `(x0 - delta, x0 + delta)` 为点 x0 的 delta 邻域，记 `U(x0, delta)`；去掉中心点 x0 后的集合称去心 delta 邻域。
> **公式**：delta 邻域 `|x - x0| < delta`；去心 delta 邻域 `0 < |x - x0| < delta`；左邻域 `(x0 - delta, x0)`，右邻域 `(x0, x0 + delta)`
> **易错点**：delta 邻域的不等式允许 `x = x0`（绝对值可为零，中心点在内）；只有去心邻域才要求 `|x - x0| > 0`。

## 【视频06】函数极限的定义（x→x0 的 epsilon-delta 语言）

[00:03:00 - 00:08:00]

delta 邻域是为极限定义专门引入的区间，delta 只说是"某一个正数"，"附近"有多近多远在经典体系下既说不清也不必说明，这正是 Weierstrass 定义回避之处。函数极限的定义：f 在 x0 的某去心邻域内有定义，若存在常数 A，使得到 A 的距离总能小于任给的尺度 epsilon。epsilon 是衡量 `f(x)` 与 A 距离的尺子，delta 由 epsilon 而定。该定义用严格不等式解决了牛顿、莱布尼茨终生未说清的无穷小描述问题。

> **定义**：设 f 在 x0 的某去心邻域内有定义，若存在常数 A，对 `forall epsilon > 0`，总存在 `delta > 0`，当 `0 < |x - x0| < delta` 时恒有 `|f(x) - A| < epsilon`，则称 x→x0 时 f(x) 的极限为 A，记 `lim(x->x0) f(x) = A`。
> **公式**：`lim(x->x0) f(x) = A  <=>  forall eps>0, exists delta>0: 0<|x-x0|<delta => |f(x)-A|<eps`
> **易错点**：定义中是去心邻域，不问 x = x0 处的函数值；delta 是"存在"的某正数，从不需要说明具体多大。

## 【视频06】epsilon-delta 定义的几何解释

[00:08:00 - 00:14:00]

几何上任给 `epsilon > 0`，在 `y = A` 上下作宽 `2*epsilon` 的带形区域，总能找到 x0 的一个 delta 邻域，使邻域内（除 x0 外）的曲线全部落在带内。epsilon 越小带越窄，所需的 delta 也越小，但对每个 epsilon 都找得到 delta。极限只关心 f(x) 唯一的目标值 A，完全不描述 f(x) 与 A 的距离，delta 在 x→x0 过程中趋于零。这就是 Weierstrass 定义"回避无穷小是什么、只给严格判据"的含义。

> **易错点**：epsilon 是任给的（先给），delta 是后找的（依赖 epsilon）；"趋向有多近"是定义刻意不回答的问题，不要试图去量它。

## 【视频06】极限只看归宿：无穷小距离不可度量与等价替换误区

[00:14:00 - 00:22:00]

x→0 时 x、sinx、x³ 等到 0 的距离都是无穷小，在实数轴上画不出来、彼此无从比较，但极限仍能算出确定结果。极限研究的是唯一归宿（结果），不管过程距离。等价无穷小 `sin x ~ x (x->0)` 只说明比值趋于 1（趋零速度一致），绝不表示两者长度相等。在加减法里把 sinx 直接换成 x，分子变成 0，会算出与真值完全不同的结果。

> **公式**：`lim(x->0) (x - sin x)/x^3 = 1/6`（老师直接给出的已知结论）
> **易错点**：加减法中严禁等价无穷小替换。例：把 sinx 换成 x 得 `0/x^3 = 0`（错），正确答案 `1/6`；等价刻画的是比值（速度）而非相等。

## 【视频06】数系的扩展与超实数系的引入

数系随问题不断扩展：有理数解决不了 `sqrt(2)`，扩展出无理数、实数；实数解决不了 `sqrt(-1)`，扩展出复数。无穷小、无穷大在实数轴上点不出位置，故再扩展出超实数系 `R*`，其中才有非零无穷小量与无穷大量。超实数系的严格建立依赖深刻的数理逻辑，故微积分教材不讲，这里只作直观理解。实数 x0 称"核"（核心），每个实数"自带光环"：以它为标准实数部分的超实数有无数个，簇拥在核的周围。

## 【视频06】超实数的标准部分分解与极限的唯一性

[00:27:00 - 00:35:00]

每个超实数可分解为"标准实数部分 + 非零无穷小量"，std 即 standard（标准部分）。例：x→0 时 `sinx/x` 是以 1 为核的超实数，其标准部分是 1，差 `sinx/x - 1` 就是它到 1 的无穷小距离。带 x→x0 条件的 `f(x)` 不再是实数而是超实数，其标准实数部分正是极限值 A。同一种趋向下以同一实数为核的超实数有无数个，但归宿唯一——这正是极限唯一性的直观来源。

> **公式**：`X = std(X) + (X - std(X))`，其中 `std(X)` 为实数（核），`X - std(X)` 为非零无穷小量；如 `lim(x->0) sin x / x = 1` 表示 `sin x / x` 以 1 为核
> **易错点**：超实数本身不等于极限值，极限值只是它的标准部分，两者差一个无穷小量。

## 【视频06】极限定义的量词符号与二十四种趋向形式

[00:35:00 - 00:44:00]

数理逻辑两个基本量词：任给（∀，arbitrary 首字母倒写）与存在（∃，exist 首字母翻写）。函数极限定义共 24 种：自变量趋向 6 种（`x->x0`、`x->x0+`、`x->x0-`、`x->∞`、`x->+∞`、`x->-∞`）× 函数值趋向 4 种（A、∞、+∞、−∞）。函数值趋于无穷改用大 M 语言：任给 `M > 0` 总有 `|f(x)| > M`；趋于正、负无穷则分别是 `f(x) > M`、`f(x) < -M`。自变量单侧趋向只需去掉绝对值改单边不等式，`x->∞` 用大 X 语言，任意组合照此拼装即可。

> **公式**：`lim(x->x0) f(x) = ∞  <=>  forall M>0, exists delta>0: 0<|x-x0|<delta => |f(x)|>M`；`lim(x->+∞) f(x) = +∞  <=>  forall M>0, exists X>0: x>X => f(x)>M`
> **易错点**："无穷大"包含正无穷与负无穷两种，说 `f(x)->∞` 时两侧行为都要考虑；单侧极限只看一侧邻域，不等式去掉绝对值并添相应符号。

## 【视频07】经典 epsilon-delta 定义的局限与实数系公理的矛盾

[00:00:00 - 00:06:00]

经典定义用 epsilon-delta 语言回避了"充分靠近到底是多少"，是完美但回避问题的方案；牛顿、莱布尼茨、柯西、Weierstrass 都没有回答"要多小有多小"究竟是多少。实数系公理：若实数 x 的绝对值小于任意自然数的倒数，则 x 只能是 0，即实数系中没有非零无穷小。但经典极限定义中"以 0 为极限的 x"恰恰是比任何 `1/n` 都小的非零量，两者矛盾。矛盾说明极限定义中的 x 不在实数系中——此 x 非彼 x，必须扩大数系。

> **公式**（实数系公理）：`(|x| < 1/n 对任意自然数 n)  =>  x = 0`
> **易错点**：实数系里"要多小有多小的实数只能是零"；既说 x→0 又允许 x 非零，讨论对象就已越出实数系。

## 【视频07】非零无穷小量与超实数系的定义

[00:06:00 - 00:15:00]

把实数系公理改造为：对任意大的自然数 n 均有 `|x*| < 1/n` 且 `x* ≠ 0`，则称 x* 为非零无穷小量，其倒数为无穷大量。实数 x0 与非零无穷小量之和 `x0 + x*` 一定不是实数（反证：实数减实数仍为实数），称为超实数。x0 有限时叫有限超实数，实数加无穷大量叫无穷超实数（即无穷大量）。超实数系记作 `R*`，是实数系加入非零无穷小量与无穷大量后的扩充；数系扩展史为有理数→实数→复数→超实数。

> **定义**：非零无穷小量：满足 `forall n∈N: |x*| < 1/n` 且 `x* ≠ 0` 的量；超实数：`x0 + x*`（`x0 ∈ R`），x0 称核；有限超实数的核为有限实数，无穷超实数 = 实数 + 无穷大量。
> **公式**：`R* = R ∪ {非零无穷小量} ∪ {无穷大量}`
> **易错点**：`x0 + x*` 一定不是实数；`1/x (x->0)` 在实数系中无定义（0 不能作分母），只有超实数系里才有意义。

## 【视频07】核、光环与标准部分

超实数 `x0 + x*` 以实数 x0 为核，围绕核形成无数个"光环"（光晕），每个光环与核恰差一个非零无穷小量，所以同一核的光环有无穷多个。记 `X* = x0 + x*`，`std(X*) = x0` 称标准部分（standard part），则超实数 = 标准部分 + 非零无穷小量。经典图示把 x→x0 画成实数轴上的点在逼近，在超实数系观点下并不准确：无穷小量根本不在实数轴上。

> **易错点**：核是实数、光环是超实数，二者不在同一数轴上；std 记号只需了解，不必掌握其数理逻辑推导。

## 【视频07】超实数与极限：先实数运算、后趋核运算

## 【视频07】等价替换的本质：趋核速度相同的乘除补偿

## 【视频08】无穷小的比较：同阶、高阶与低阶

[00:00:00 - 00:05:00]

同一核（如 0）周围无数个光环的本质区别，用趋核（趋零）速度来刻画。设 f、g 均以 0 为核：`lim f/g` 为非零常数时称 f 与 g 趋核速度相同，即同阶无穷小（为 1 时即等价）；为 0 时称 f 是 g 的高阶无穷小，说明 f 趋零更快（如 `x^2` 比 `x`）；为无穷大时称 f 是 g 的低阶无穷小，说明 f 趋零更慢。无穷小的倒数是无穷大，无穷大同样可以比阶。这就是后面"无穷小比阶"问题的概念基础。

> **定义**：`lim f/g = c ≠ 0`：f 与 g 同阶；`lim f/g = 0`：f 是 g 的高阶无穷小，记 `f = o(g)`；`lim f/g = ∞`：f 是 g 的低阶无穷小。
> **公式**：`lim(x->0) x^2/x = 0`（`x^2` 是 `x` 的高阶无穷小）；`lim(x->0) x/x^2 = ∞`（`x` 是 `x^2` 的低阶无穷小）
> **易错点**：比值极限是任意非零常数都算同阶，不必恰为 1；只有比值为 0 才叫高阶。

## 【视频08】极限的四则运算规则

[00:05:00 - 00:10:00]

## 【视频08】极限不存在的判定与"存在 ± 不存在 = 不存在"

[00:10:00 - 00:18:00]

## 【视频10】局部有界性及其证明

[00:00:00 - 00:07:00]

## 【视频10】局部有界性的四条注

[00:07:00 - 00:17:00]

第一，"极限存在 ⇒ 趋向过程中有界"是充分非必要：有界推不出极限存在，如 `sinx` 恒在 [-1,1] 内但 x->∞ 时极限不存在。第二，闭区间上的连续函数必有界（端点处分别为右连续、左连续，此为后续要讲的定理）；但开区间内连续推不出有界，如 `y = 1/x` 在 (0,+∞) 内无界。第三，若开区间 (a,b) 内连续且 `lim(x->a+) f(x)`、`lim(x->b-) f(x)` 都存在，则把区间分成"左端点附近 + 闭子区间 + 右端点附近"三段分别控制，开区间内必有界。第四，有界函数的和、差、积仍为有界函数，商没有这个结论（分母趋于零时商可为无穷大）；上界与下界都不唯一。

> **定义**：区间写成 a 到 b 时表示有限区间；开区间内连续函数有界需另加两端单侧极限存在的条件。
> **易错点**：逆命题不成立，有界不能反推极限存在；开区间连续必有界是典型错误结论，必须补两端极限存在。

## 【视频10】局部保号性与脱帽法、戴帽法

[00:30:00 - 00:43:00]

局部保号性是函数极限三大性质中最重要的一条，只在趋向过程（x0 的去心邻域）内成立：若 `lim f(x) = A > 0`，则在去心邻域内 `f(x) > 0`；A < 0 时同理 f(x) < 0。超实数理解：A 是核心（"光晕"），核心大于零则附近函数值都大于零。逆向命题必须带等号：若去心邻域内 f(x) >= 0 且极限存在，只能推出 `A >= 0`，因为 f(x) 严格大于零时极限仍可能等于零（如 x->+∞ 时 1/x）。术语：由极限不等式推出函数不等式称"脱帽法"（严格不等号），由函数不等式取极限得极限不等式称"戴帽法"（非严格不等号）。

> **定义**：保号性——极限值与函数值在趋向过程中保持关于零的同向大小关系（亦称保序性）。
> **公式**：`lim(x->x0) f(x) = A > 0 => 存在 δ>0, 0<|x-x0|<δ 时 f(x) > 0`；`f(x) >= 0 且 lim f(x) 存在 => lim f(x) >= 0`。
> **易错点**：脱帽法绝不带等号，戴帽法必须带等号；真题曾有同学一律写成严格不等号，恰好把等号处的答案丢掉。

## 【视频10】局部保号性的证明

[00:43:00 - 00:53:00]

证明从定义出发：任给 ε>0 存在 δ>0，当 0<|x-x0|<δ 时 |f(x)-A| < ε。取 `ε = A/2`（设 A>0），立即得 `f(x) > A - A/2 = A/2 > 0`，证明完毕。若取 ε=2A 虽不违反"任给"，但得到的 `-A < f(x) < 3A` 只是关于 f(x) 的一个不等式陈述，不是 f(x) 的取值范围，不能据此断言 f(x)>0。超实数意义下 f(x) 与 A 的距离是无穷小，任何有限实数 ε 都只能作"陈述"，无法给出精确范围。

> **公式**：`|f(x)-A| < A/2  =>  A/2 < f(x) < 3A/2`，故 `f(x) > A/2 > 0`。
> **易错点**：不等式陈述 ≠ 取值范围（例：2 大于 -1 小于 5 并不意味着 2 可取负值）；ε 要取使结论直接可得的值（如 A/2），不是越大越好。

## 【视频11】无穷小的定义

[00:00:00 - 00:07:00]

## 【视频11】无穷小的比阶

[00:19:00 - 00:24:00]

比阶用 0/0 型极限 `lim α/β` 刻画趋向零的速度：极限为 0 称 α 是 β 的高阶无穷小（α 趋零更快）；极限为 ∞ 称低阶无穷小；极限为非零常数称同阶（仅表示阶数相同、相差常数倍）；特例极限为 1 时称等价无穷小。若 `lim α/β^k = 非零常数`，则称 α 是 β 的 k 阶无穷小。同阶的"速度相同"只是常数倍意义上的相同，等价也只是趋向速度的刻画，等价绝不等于相等。

> **定义**：高阶、低阶、同阶、等价无穷小——由比值极限为 0、∞、非零常数、1 区分。
> **公式**：`lim α/β = 0 (高阶) / ∞ (低阶) / c≠0 (同阶) / 1 (等价)`；`lim α/β^k = c≠0 => α 是 β 的 k 阶无穷小`。
> **易错点**：等价不是相等，只是极限数量上的速度刻画；同阶不等于两者快慢完全一致。

## 【视频11】比阶失效：不可比阶的情形

## 【视频12】极限的四则运算规则与恒等变形原则

[00:00:00 - 00:07:00]

极限四则运算规则：f、g 在同一趋向下极限都存在时，其和、差、积的极限等于极限的和、差、积，商的极限等于极限的商（另要求分母极限不得零）；n 次方是乘法的推广，`lim f(x)^n = (lim f(x))^n`。计算极限的正确顺序是先在实数体系内做恒等变形（化简、通分），把式子变形到位后再套极限号取值，取极限后不得再做任何恒等变形。极限号下的表达式是超实数而非实数，无论它多么接近某个数都不相等，不能直接代入。例：`lim(x->0) (sinx/x - 1)/x^2`，初学者易把 `sinx/x` 换成 1 得 0；正确做法是先通分为 `lim(x->0) (sinx - x)/x^3`，结果为 `-1/6`。

> **定义**：极限四则运算规则——参与运算的各函数极限都存在时，加减乘除的极限等于极限的加减乘除（除法另要求分母极限不得零）。
> **公式**：`lim(f+g) = lim f + lim g`；`lim(f*g) = lim f * lim g`；`lim(f/g) = lim f / lim g`（`lim g != 0`）；`lim f^n = (lim f)^n`。
> **易错点**：加减法中不能对局部直接代入极限值或做等价替换；一切等号必须是恒等变形，否则不等；极限号下是超实数，不能做加减乘除运算，恒等变形只能在取极限之前完成。

## 【视频12】幂指函数极限与无穷大减无穷型未定式

## 【视频12】等价无穷小替换的原理

## 【视频12】洛必达法则的条件与后验逻辑

[00:26:00 - 00:38:00]

洛必达法则一（0/0 型）：`x->a`（含 `a+`、`a-`）或 `x->inf`（含正、负无穷）时 f、F 均趋于 0，且在 a 的某去心邻域内（或 |x| 充分大时）两者可导、分母导数不得 0，并且 `lim f'/F'` 存在（或为无穷大），则 `lim f/F = lim f'/F'`。可导只要求在去心邻域成立，极限值与该点处的函数值无关。该法则是后验逻辑：只能由求导后比值的极限存在，断定原式极限存在且相等，反向不成立。反例：`lim(x->0) x^2*sin(1/x)/x` 是 0/0 型，求导后得到 `2x*sin(1/x) - cos(1/x)` 因震荡极限不存在，但原式约分后 `x*sin(1/x) -> 0`。故求导后极限不存在时，既不能断定原极限不存在，也不能继续用洛必达，须改用其他方法；法则的证明用柯西中值定理（`(f(b)-f(a))/(g(b)-g(a)) = f'(ξ)/g'(ξ)`），待中值定理部分再讲。

> **定义**：洛必达法则用于计算 0/0 型未定式，以导数比值的极限代替原比值的极限。
> **公式**：`lim f/F = lim f'/F'`（0/0 型，`F' != 0`，且右端极限存在或为无穷大）。

## 【视频12】高阶无穷小 o(x) 的运算法则

[01:13:00 - 01:17:00]

> **公式**：`o(x^m) ± o(x^n) = o(x^min(m,n))`；`o(x^m) * o(x^n) = o(x^(m+n))`；`x^m * o(x^n) = o(x^(m+n))`；`c * o(x^m) = o(x^m)`（c 为非零常数）

## 【视频12】泰勒展开原则（一）：上下同阶原则（a/b 型）

[01:31:00 - 01:34:00]

## 【视频12】泰勒展开原则（二）：a±b 型展开到系数不相等的最低次幂

[01:34:00 - 01:38:00]

## 【视频12】夹逼准则与极限计算方法体系总结

## 【视频13】七种未定式与常考题型

[00:00:00 - 00:04:00]

考研函数极限计算题归纳为七种未定式；"未定"指结果是否存在、等于多少都要由考生按客观规律算出来，可能存在也可能不存在。七种未定式全是超实数的运算，计算的本质是判断该超实数有无标准实数部分，有则把标准实数部分求出来。七种依次为：无穷小比无穷小、无穷大比无穷大、无穷小乘无穷大、无穷大减无穷大、无穷大的无穷小次方、无穷小的无穷小次方、1 的无穷大次方。常考题型有四类：直接计算、反求参数（已知极限值反求表达式中未知参数，考研特别爱考）、已知某一极限求另一极限、无穷小比阶（考得最多，须重点掌握）。

> **定义**：未定式指极限结果尚待确定的超实数表达式，共七种；其中的"无穷""1"等都是趋近该值的超实数，不是真正的 0 或无穷。

## 【视频15】函数在一点连续的定义

[00:00:00 - 00:05:00]

连续不是几何上"连着不断"的直观印象，数学定义是：`f(x)` 在 `x0` 的某邻域内有定义且 `lim(x->x0) f(x) = f(x0)`，则称 `f(x)` 在 `x0` 处连续。用 epsilon-delta 语言即：任给 `epsilon > 0`，存在 `delta > 0`，当 `0 < |x-x0| < delta` 时恒有 `|f(x)-f(x0)| < epsilon`，无非是把极限定义中的常数 `a` 特殊化为 `f(x0)`，表达方式完全不变。必须区分"极限存在"与"连续"：极限存在只说明 `x0` 两侧附近的函数值充分接近某个 `a`，而 `a` 与 `f(x0)` 本身毫无关系，只有当 `a` 恰好等于 `f(x0)` 时才叫连续。连续是"点"的定义，函数在区间上连续是指区间内每一点都满足该条件。

> **定义**：设 `f(x)` 在点 `x0` 的某邻域内有定义，若 `lim(x->x0) f(x) = f(x0)`，则称 `f(x)` 在 `x0` 处连续。
> **公式**：`lim(x->x0) f(x) = f(x0)`
> **易错点**：极限存在 ≠ 连续；把极限值 `a` 误认作 `f(x0)` 是最常见的概念错误，二者本无关系。

## 【视频15】连续概念的辨析：有定义、连续与区间上连续

[00:05:00 - 00:11:00]

函数"有定义（存在）"只要求每个 `x` 有对应函数值，各点之间无任何约束；连续则要求 `x0` 与旁边各点的函数值之差 `|f(x)-f(x0)|` 是无穷小量（要多小有多小）。从超实数观点看，连续曲线并非真正连着，相邻点之间是趋于零的无穷小间隔，图上画出的距离只是形象比喻；所谓连续只是离散点靠得无穷近。这套理解直接决定对间断的认识：只要 `f(x)` 与 `f(x0)` 的距离无法描述成无穷小，就是间断。

> **定义**：连续的实质——`x0` 处的函数值与旁边各点函数值的距离是无穷小量；区间上连续 = 区间内每一点都连续。
> **易错点**：连续 ≠ 图形"连着不断"；"有定义"与"连续"是两个层次的要求，有定义只是连续的前提之一。

## 【视频15】一点连续的充要条件与连续函数的运算法则

[00:11:00 - 00:15:00]

间断点按大纲分为跳跃、可去、无穷、震荡四类，后面逐一讨论。点 `x0` 连续的充要条件是右极限、左极限与函数值三者相等（三人"聚会"在一处），否则不连续。连续函数的四则运算保持连续，商要求分母在该点不为零；复合函数：内层 `u=f(x)` 在 `x0` 连续、外层 `y=g(u)` 在对应点 `u0=u(x0)` 连续，则复合函数在 `x0` 连续；反函数：区间上严格单调连续的函数，其反函数在对应区间上连续且单调性相同。这些结论考研只要求会用，不要求证明。

> **公式**：`f(x)` 在 `x0` 连续 <=> `lim(x->x0+) f(x) = lim(x->x0-) f(x) = f(x0)`
> **易错点**：判定连续必须左右极限与函数值三者齐备，只算出极限还不够；四则运算的商要额外保证分母非零。

## 【视频15】连续函数的局部保号性

[00:15:00 - 00:18:00]

常用打星结论：若 `f(x)` 在 `x0` 连续且 `f(x0) > 0`，则存在 `delta > 0`，在 `x0` 的某邻域内恒有 `f(x) > 0`。它比极限的保号性更强：极限保号只保证去心邻域内为正、不含 `x0` 这一点；连续时因极限值恰等于函数值，故连 `x0` 本身也大于零，整个邻域（含该点）都保号。

> **公式**：`f` 在 `x0` 连续且 `f(x0)>0` => 存在 `delta>0`，当 `|x-x0|<delta` 时 `f(x)>0`
> **易错点**：极限保号性只给去心邻域，连续保号性才可把 `x0` 点一并包进来，两者条件和结论范围不同。

## 【视频15】间断点的讨论对象与讨论前提

[00:18:00 - 00:21:00]

初等函数在定义区间内处处连续，无需讨论；要检查的只有两类特殊点：无定义点必然间断，分段函数的分段点可能间断也可能连续。讨论间断的前提是 `f(x)` 在 `x0` 的某去心邻域内双侧都有定义；闭区间连续指左端点右连续、右端点左连续，区间端点因单侧无定义而根本不谈间断。考研数学不使用"单侧间断"的说法，端点是不是间断点一律拒绝回答。

> **定义**：讨论 `x0` 是否为间断点的前提——`f(x)` 在 `x0` 的某去心邻域内（双侧）有定义。
> **易错点**：无定义点必间断、分段点须检验；区间端点不讨论间断性，不要把单侧连续与间断混为一谈。

## 【视频15】第一类间断点：可去间断点与跳跃间断点

[00:21:00 - 00:26:00]

可去间断点：左右极限都存在且相等（极限存在为 `a`），但不等于 `f(x0)` 或 `f(x0)` 无定义；只要补充或修改 `f(x0)` 使函数值等于极限值即可使之连续，故又名可补间断点（可去即可补）。例：`sin x / x` 在 `x=0` 无定义，补充定义 `f(0)=1` 即连续。跳跃间断点：左右极限都存在但不相等，此时与 `f(x0)` 的取值完全无关。两类的判别方法相同：分别计算左右两侧极限，再看是否相等、是否等于函数值。

> **定义**：可去——`lim(x->x0+) f = lim(x->x0-) f` 但该值 `≠ f(x0)`（或 `f(x0)` 无定义）；跳跃——`lim(x->x0+) f = A1 ≠ A2 = lim(x->x0-)` 。
> **公式**：可去 <=> `lim(x->x0) f(x)` 存在但 `≠ f(x0)`；跳跃 <=> 左右极限均存在但不相等
> **易错点**：跳跃间断点与 `f(x0)` 无关；第一类间断点只有可去、跳跃两个成员，考研常直接问"可去/跳跃"而不提"第一类"。

## 【视频15】第二类间断点：无穷间断点与震荡间断点

[00:26:00 - 00:32:00]

无穷间断点：`x->x0` 时 `f(x)` 趋于无穷大，只要左右至少一侧趋于无穷即可，两侧全无穷、单侧无穷均可；例：`y = 1/x` 在 `x=0`。无穷大是极限过程而非该点的函数值，一个点不可能"等于无穷大"。震荡间断点：`x->x0` 时 `f(x)` 无限次上下振荡、极限不存在，如 `sin(1/x)` 在 `x->0` 时于 `-1` 与 `1` 间往复；也不是该点在震荡，而是点两侧附近的图形状态。无穷与震荡属于第二类（第二类还有其他情形，考研不讨论，超纲也命题不涉及），命题中通常直接称"第二类"，不必要求区分无穷与震荡。

> **定义**：无穷间断点——`x->x0`（或单侧）时 `f(x)->∞`，左右极限至少一个为无穷大；震荡间断点——`x->x0` 时 `f(x)` 振荡而极限不存在。
> **公式**：`lim(x->x0) f(x) = ∞` 或 `lim(x->x0±) f(x) = ∞`；`lim(x->0) sin(1/x)` 不存在（无限次振荡）
> **易错点**：无穷、震荡都是描述该点"旁边"的极限状态，不是该点取值为无穷大或该点在震荡；第一类是"统称"（只有两人），第二类是"属于"（还有其他成员）。

## 【视频15】间断点判别的一般步骤与由连续性求参数（例1.36）

[00:32:00 - 00:36:00]

间断点判别的研究对象只有三个：右极限、左极限、`f(x0)`。三者相等即连续；两侧极限存在且相等但不等于 `f(x0)` 是可去；两侧极限都存在但不相等是跳跃；至少一侧极限不存在（无穷大或振荡）即第二类，第二类不必再区分。反之，已知函数在某点连续时，可用 `f(x0) = lim(x->x0) f(x)` 由极限值反求函数值或参数，多元函数同样适用。例1.36：分段函数在 `x=0` 连续，算 `1^∞` 型极限 `lim(x->0) (cos x)^(1/x^2) = e^(-1/2)`，即得 `a = e^(-1/2)`——本质就是算极限再把值填进分段点。

> **公式**：`f(x0) = lim(x->x0) f(x)`（已知连续时由极限反求函数值/参数）
> **易错点**：讨论间断就是算左右两个极限，分类完全由这两个极限的结果决定；"连续"条件常被用来反求参数，别只会正向套定义。

## 【视频15】第二类间断点的判定（例1.37）

[00:36:00 - 00:44:00]

例1.37（呼应例1.15）：求函数第二类间断点的个数。方法：先找无定义点（分母为零、对数真数为零、指数中分母为零等），再逐点算左右极限分类。该函数有四个无定义点 `x = -1, 0, 1, 2`：`x=1` 处（例1.15 已算）`lim(x->1+) f = ∞`；`x=2` 处 `(x-2)->0` 而其余因子为非零常数，无穷小的倒数为无穷大；`x=-1` 处 `ln|1+x| -> -∞`（绝对值保证真数从零正方向趋于零），非零因子乘无穷大仍无穷大；`x=0` 处利用等价无穷小 `ln(1+x) ~ x`、`e^x-1 ~ x` 算得极限存在为 `-1/(2e)` 但该点无定义，是可去间断点。故三个第二类（无穷）间断点，个数为 3，选 C；判别第二类只需看是否无穷或不存在，无须区分正无穷与负无穷。

> **公式**：`lim(x->0) f(x) = -1/(2e)`（`x=0` 处左右极限存在相等但无定义，故可去）
> **易错点**：找间断点先找无定义点——初等函数在定义区间内连续，间断只可能出在无定义点与分段点；无穷小的倒数是无穷大，勿忘把非零常数因子分离出来。

## 【视频15】用极限定义的分段函数的间断点类型（例1.38）

[00:44:00 - 00:49:29]

例1.38（承例1.26）：`f(x)` 由 `n->∞` 的极限定义，`x` 为整数时取 `x^2`，`x` 非整数时取 `x - x^2`。易错警示：这里的 `x^2` 只代表离散的点（`(0,0)`、`(±1,1)`、`(±2,4)` …），绝不是一条抛物线；真正的连续部分是 `x - x^2`（顶点 `(1/2, 1/4)`）。`x=0` 处左右极限都是 `0` 且函数值恰为 `0`，故该点连续；其余整数点 `k≠0` 处极限为 `k-k^2` 而函数值为 `k^2`，二者不等，都是可去间断点（曲线上一个个"洞"被填到离散点上）。结论：该函数不处处连续，但没有第二类间断点，只有第一类且全是可去间断点，答案选 B。

> **易错点**：离散点集拼出的"抛物线"不是连续曲线；判连续要在该点同时核对左右极限与函数值，两者相等才连续。
