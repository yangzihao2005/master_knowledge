# 第4讲 线性方程组

## 【视频01】本讲知识结构与重点

[00:00:00 - 00:03:00]

本讲与第三讲向量组联系密切，务必掌握。全讲四大板块：齐次方程组、非齐次方程组、两方程组的公共解、同解方程组。齐次方程组涉及有解条件、解的性质、基础解系与解的结构、求解方法与步骤；重点把握基础解系与解的结构——无穷多解可用有限个解（基础解系）的线性组合表出，即用有限个向量代表整个解空间。非齐次方程组的有解条件、解的性质较简单，重点同样在求解方法与步骤，尤其三阶非齐次方程组须熟练掌握。

> **易错点**：本讲重点＝基础解系、解的结构，以及非齐次的求解方法与步骤。

## 【视频01】第四讲与向量组的联系、公共解与同解

[00:03:00 - 00:05:27]

`Ax=0` 按列分块即 `x1 alpha1 + x2 alpha2 + ... = 0`，把齐次方程组转化为"列向量的线性组合是否等于零"的问题，与向量组线性相关／无关对应（等于零是否要求系数全为零）。`Ax=b` 即 `x1 alpha1 + ... + xn alphan = beta`，转化为"`beta` 能否由 `alpha1..alphan` 线性表示"——能表示则有解，不能表示则无解，这就是第三讲与第四讲的联系。公共解＝两方程组解集的交集；同解＝两方程组的解空间完全相同。

> **公式**：`x1 alpha1 + x2 alpha2 + ... = 0`；`x1 alpha1 + ... + xn alphan = beta`

## 【视频02】系数矩阵与增广矩阵；方程组问题即向量组问题

[00:00:00 - 00:02:00]

系数 `aij` 组成的矩阵称系数矩阵；把右端自由项拼成一列并列后称增广矩阵（增广阵）。把 `alpha` 的线性组合写成 `beta`，方程组即写成向量组表示形式。`x1..xn` 在方程组中叫解，在向量组中叫表示系数——方程组问题与向量组问题是同一问题的两种表现形式，本质相同、解法相同。上一讲解决的是理论／形式问题，本讲落实具体数值计算。

> **易错点**：同一组数在不同场合名称不同（解／表示系数／坐标），实质是同一对象。

## 【视频02】求解思路与基础解系

[00:02:00 - 00:04:06]

解方程组的基本方法：对增广阵做初等行变换，化成行阶梯形矩阵后求解，此方法贯穿始终。无穷多解用解空间表示，解空间用线性无关的向量表示，即解向量的极大线性无关组（上一讲的"基"），在方程组中专门叫基础解系。同一事物在不同场合有不同名称：线性无关向量组 ↔ 某空间的基 ↔ 某方程组的基础解系 ↔ 某向量组的极大线性无关组。表示系数即 `beta` 在 `alpha1..alphan` 这组基下的坐标。

> **定义**：基础解系＝解向量的极大线性无关组＝解空间的一组基。

## 【视频03】齐次方程组的有解条件与自由度

[00:00:00 - 00:12:00]

`A` 为 `m×n`：`m` 是方程个数（行数，最多 m 行，可能含冗余行），`n` 是未知数个数（列数，不可变）。有解条件：`r(A)=n`（列满秩）时列向量线性无关，`x` 只能全为 0，方程组只有零解（即唯一解）；`r(A)<n` 时列向量线性相关，存在非零解，且非零解必为无穷多解，基础解系含 `s=n-r(A)` 个向量。`n` 是自由度（变量个数），`r(A)` 是真实约束个数（须用 `r(A)`，不能用 m），`s=n-r(A)` 是剩余自由度＝解空间维数。几何意义：无约束时为 n 维空间，每个真实约束降一维，解落在 `s` 维子空间上；`r(A)=n` 时约束数与自由度相同，解被固定为零点。

> **公式**：`s = n - r(A)`
> **易错点**：真实约束个数须用 `r(A)`，不能用方程个数 m。

## 【视频03】解的性质、基础解系与通解结构

[00:12:00 - 00:17:00]

解的性质：齐次方程组的解 `x1, x2` 的任意线性组合仍是其解。基础解系定义（`r(A)<n` 时）须满足三条：① 每个向量都是 `Ax=0` 的解；② 线性无关；③ 个数 `s=n-r(A)`；且任一解都能由其线性表示——即解向量的极大无关组。通解即基础解系的线性组合 `k1 xi1 + ... + ks xis`，其中 `ki` 为该解在基础解系（解空间的一组基）下的坐标。

> **定义**：基础解系三要素——是解、线性无关、个数 `s=n-r(A)`。
> **公式**：通解 `x = k1 xi1 + ... + ks xis`

## 【视频03】求解方法与步骤（三步曲）

[00:17:00 - 00:23:00]

第一步：只对系数矩阵 `A` 做初等行变换（只能行变换，保证同解）化成行阶梯形（行最简非必需），得与 `Ax=0` 同解的新方程组。第二步：数出台阶数即 `r(A)`（真实约束个数，"三秩相同"保证横竖看一致），再按列找出一个秩为 `r` 的子矩阵；未被选中的列所对应变量即自由变量，个数 `n-r(A)`。第三步：按基础解系定义反着写——先定个数 `s`，再赋值使其线性无关，最后回代求出其余变量。

> **易错点**：只做行变换；按列（纵向）找秩为 `r` 的子矩阵，未入选列对应变量即自由变量。

## 【视频03】例题4.1 求齐次方程组的通解

[00:23:00 - 00:48:00]

强调不要用中学消元代入法，要用线性代数的解空间方法。示例：系数矩阵行变换化行阶梯，台阶数为 3，则 `r(A)=3`；按列找出秩为 3 的子矩阵（如取第 1、2、4 列），未选的第 3、5 列对应变量 `x3,x5` 为自由变量，`s=n-r(A)=5-3=2`，解空间是五维空间中的二维子空间。写 `xi` 时横写加转置，用内积（对乘相加＝0）回代：自由变量取最简单的赋值 `(1,0)`、`(0,1)` 使二阶子式不为零以保证线性无关（原来无关、延长必无关）。求得 `xi1=(-1,1,1,0,0)`，`xi2=(7/6,5/6,0,1/3,1)`（可整体乘 6 得 `(7,5,0,2,6)` 或乘 3 得 `(7/2,5/2,0,1,3)`），通解 `k1 xi1 + k2 xi2`。

> **易错点**：按列选秩为 r 的子矩阵不唯一，自由变量选法不同结果不同，都正确。

## 【视频04】非齐次方程组：概念、有解条件、解的性质与求解步骤

[00:00:00 - 00:10:00]

非齐次方程组即自由项 `b1..bm` 不全为零；除系数矩阵外还有增广矩阵 `(A,b)`。通解＝对应齐次方程组（导出组）的通解 + 非齐次的一个特解。有解条件：`r(A)=r(A,b)` 时有解，即 `b` 可由 `alpha` 组线性表示、落在其张成的空间内；`r(A)≠r(A,b)`（必然 `r(A)+1=r(A,b)`）时无解。有解时：`r(A)=n` 唯一解；`r(A)<n` 无穷多解。解的性质：两非齐次解之差是齐次解；`k xi + eta`（`xi` 为齐次解、`eta` 为非齐次解）是非齐次解。求解步骤：先求导出组 `Ax=0` 的通解，再求一个特解（自由变量一律取 0 最简单），两者相加。

> **公式**：非齐次通解 ＝ 齐次通解 + 特解 ＝ `k1 xi1 + ... + ks xis + eta`
> **易错点**：`Ax=b` 有三类情形（无解／唯一解／无穷多解），`Ax=0` 只有两类（必有零解）。

## 【视频04】求满足 PA=B 的所有可逆矩阵 P

## 【视频04】例题4.6、4.7：有解条件的判定与最佳近似解

[00:24:00 - 00:43:00]

4.6（判定有解情形）：`r(A)=m`（行满秩）时添列不改变秩（行秩＝列秩），必 `r(A)=r(A,b)`，方程组必有解（选 A）；`r(A)=n`（列满秩）只保证 `Ax=0` 只有零解，`r(A,b)` 可能为 `n+1`，故非齐次可能无解（并非必有唯一解）；`m=n` 或 `r(A)<n` 都推不出唯一解／无穷多解，因为还需 `r(A)=r(A,b)`。

4.7（重要，打三星）：`Ax=b` 无解时求最佳近似解。几何上 `b` 不在 `A` 列空间内，找 `x0` 使 `A x0` 与 `b` 距离最小，即 `b` 在该空间上的投影；此时 `b - A x0` 垂直于该空间（与每个 `alpha` 正交），得 `A^T(b-Ax0)=0`，即 `A^T A x0 = A^T b`。该方程组必有解，其解 `x0` 即原方程组的最佳近似解。

> **公式**：`A^T A x = A^T b`
> **易错点**：`Ax=b` 无解不要停，立即改求 `A^T A x=A^T b`。

## 【视频05】公共解的本质与求法

[00:00:00 - 00:10:00]

公共解即两方程组解集的交集，本质是两方程组联立成一个方程组（未知数个数须相同）。`Ax=alpha` 与 `Bx=beta` 联立，得增广阵 `(A B | alpha beta)`，再判秩求解。反问题：只给一方的通解／基础解系、另一方给方程时，可将前者的通解代入后者，得到关于 `k` 的约束，由 `k` 之间关系求出公共解；若两方都只给基础解系，则令两组通解相等（`k` 与 `l` 联立）求出关系。原理：每增加一个方程就是增加约束、给解空间降维，新增约束个数由代入后实际独立方程数决定。

> **方法**：① 联立求解；② 通解代入另一方程组；③ 两组通解令相等。

## 【视频05】例题4.12 求两方程组的公共解

[00:10:00 - 00:19:12]

先求两方程组各自的基础解系（各含 2 个向量）。方法一：直接联立求公共解（则第一问白做）。方法二：取方程组一的通解 `k1 xi1 + k2 xi2` 代入方程组二，得两个实际相同的约束（只产生一个约束），得 `k1=2k2`，公共解即 `k2(2 xi1 + xi2)`。方法三：令两通解相等，比较分量得 `k` 与 `l` 的关系（同样得 `k1=2k2`），结果与前面一致。关键：新增约束个数取决于代入后方程组的实际独立方程数，不能只数方程条数。

> **易错点**：联立时是上下拼接（联立方程），不是按列拼接。

## 【视频06】同解的定义、判别及用同解证秩相等

[00:00:00 - 00:18:00]

同解＝两方程组解集完全相同（解空间相同）。判别法（充要）：`r(A)=r(B)` 且一方的解都是另一方的解（单方表出）——类似等价向量组，本质是三秩相同：`r(A)=r(B)=r(A;B)`（竖向拼接）。可由基础解系向量组等价推出：`n-r(A)=n-r(B)` ⇒ `r(A)=r(B)`，且一方解可由另一方表出。用同解可证秩相等（证 `Ax=0` 与 `Bx=0` 同解）。例题：两个方程组（第二个比第一个多一行）同解，即需 `r(A)=r(A,B)=r(A;B)`；行变换后第一系数阵秩为 3，故要求增广部分末项 `b-12-5a=0`，即 `b=5a+12`。

> **判别**：`r(A)=r(B)=r(A;B)`（三秩相同）。

## 【视频06】A^T A x=0 与 Ax=0 同解及其推广

[00:18:00 - 00:28:54]

证明 `A^T A x=0` 与 `Ax=0` 同解（`A` 为 n 阶实矩阵，实际对任意 `m×n` 矩阵也成立）：① 若 `Ax=0`，两边左乘 `A^T` 得 `A^T A x=0`；② 若 `A^T A x=0`，两边左乘 `x^T` 得 `x^T A^T A x=0`，用穿脱原则写成 `(Ax)^T(Ax)=0`，即 `|Ax|^2=0`，故 `Ax=0`（不能用 `A^T` 的逆，因 A 未必方阵／可逆）。由同解得 `r(A^T A)=r(A)`。因 A 任意，把 A 换成 `A^T` 又得 `r(A A^T)=r(A^T)`，结合 `r(A)=r(A^T)`，得四秩相同：`r(A)=r(A^T)=r(AA^T)=r(A^T A)`（`A^T A` 即 Gram 矩阵）。

> **公式**：`r(A)=r(A^T)=r(AA^T)=r(A^T A)`
> **易错点**：不能用 `(A^T)^{-1}` 消去，要左乘 `x^T` 构造内积。
