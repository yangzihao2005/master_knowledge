# 第2讲 矩阵

## 【视频01】第2讲知识结构：从加减乘逆到矩阵方程

[00:00:00 - 00:05:00]

第2讲知识点庞杂但成体系，可类比中学代数的「加减乘除→方程」来串主线：矩阵的加法、数乘、乘法、求逆，再到矩阵方程。矩阵不定义除法，除法改称「逆」：`A A^{-1} = E`，前提是 `|A| != 0`（即 A 可逆），且绝不能写成 `A^{-1} = 1/A`。类比顺序为：加法 → 数乘（由 `A + (-1)B = A - B` 得到减法）→ 乘法 → 逆 → 矩阵方程。矩阵乘法就是不断地做内积。

> **公式**：`A A^{-1} = E`，前提 `|A| != 0`
> **易错点**：没有 `1/A` 这种写法，只有 `A^{-1}`

## 【视频01】求逆的三种方法与本章重点

[00:05:00 - 00:08:43]

求逆共有三种方法：①定义法；②伴随矩阵法（任何方阵都有伴随矩阵 `A^*`，年年考）；③初等变换法（几乎年年考）。矩阵方程有三种基本型：`AX = B`、`XA = B`、`AXB = C`（X 为未知矩阵），要先化成这三种最简单的形式再解，是重中之重。本讲主线：加减乘逆 → 解矩阵方程 → 等价矩阵与矩阵的秩（两者都通过初等变换来研究）。三种求逆方法各有独立命题机会（如初等变换法可讨论等价与秩），故特别重要。

> **易错点**：伴随矩阵法、初等变换法都是必考方法

## 【视频02】矩阵的本质：表达系统信息、向量与基

[00:00:00 - 00:11:00]

矩阵是一个数表，本质是表达系统信息（systematical information）：数乘矩阵时必须把 k 乘到每一个元素上，才能保证各行、各列同等缩放、系统性不被破坏；这与行列式不同——`k|A|` 只需乘到某一行（列）。抽取数据得到的矩阵每一行是一个样本，`(1,0)`、`(0,1)` 相当于二维平面上的 i、j 两个基准向量（基），对基做线性组合即可表示平面上所有向量。两个向量只要不平行（即线性无关）就能张成一个二维平面。任何矩阵一定能通过代数方法找到它的基，其余信息都可由基线性表示，而「最简信息表达」就是矩阵的秩。

> **公式**：`|kA| = k^n |A|`（A 为 n 阶）；对比 `k|A|` 只需乘某一行
> **定义**：基——张成空间的一组基准向量

## 【视频02】任意形状矩阵、随机模拟求面积与Gram矩阵

[00:11:00 - 00:28:00]

矩阵不一定是方阵，1000×2 或 2×1000 都可能。举例说明矩阵的实用价值：像 `∫_0^1 f(x)dx` 这类定积分，原函数往往找不到，可框出 0~1 的正方形区域，在其中均匀撒入 N 个随机点，统计落在曲线下方的点数 `N_f`，则面积 ≈ `N_f / N`（数值模拟，精度随点数提高）。矩阵还可做信息转换与提取，最简单的办法是构造 Gram 矩阵 `A^T A`：对列向量 `alpha`，有 `alpha^T alpha = |alpha|^2`；对两个向量，`A^T A` 的每个元素都是内积，等于两向量模长之积再乘夹角的余弦，同时反映各向量的大小与两两之间的相似程度。

> **公式**：`alpha^T alpha = |alpha|^2`；`(A^T A)_{ij} = alpha_i^T alpha_j = |alpha_i||alpha_j| cos(theta)`；面积 ≈ `N_f / N`
> **易错点**：`A^T A` 中蕴含「向量长度」与「向量间夹角（相关程度）」两类信息
> ⚠️ **需回看视频 [00:24:00]**：讲述余弦相似度时口播自相矛盾（先说「cosθ 等于零」，随即改口「所以 cosθ 是等于一的」）；两向量重合时夹角为 0、余弦应为 1，转写疑有误 —— "如果它俩是一个向量，那么cosθ等于零啊……所以cosθ是等于一的，对吧？"

## 【视频02】矩阵的应用与两个重要观点

[00:28:00 - 00:33:33]

高维数据（四维、五维）无法靠画图看方向和夹角，但做 `A^T A` 这类运算就能得到长度与相似度；进一步的矩阵分解（特征值/特征向量、主成分分析）能找出主要数据与最值——工程上找最危险/最弱方向、经济上找极值都靠它。不同矩阵运算有对应含义：正交阵对应旋转、上下三角阵对应剪切变形、矩阵相减对应数据平移。本节两个重要观点：①矩阵是由向量拼成的；②矩阵本身不能运算（是变换/对应法则），但其内部若干向量之间存在关系，最简信息表达就是「基」，这个本质就是矩阵的秩。

> **易错点**：不要把矩阵当成一堆数去硬算，要抓住向量之间的关系

## 【视频03】矩阵的定义、同型矩阵及相等与加减数乘

[00:00:00 - 00:06:00]

矩阵由 `m × n` 个数排成 m 行 n 列，不必是方阵（如两个指标取数据根本凑不出方阵）。`m = n` 时称 n 阶矩阵（n 阶方阵）。`A^T A` 一定是方阵，这正是方阵如此重要的原因——只有方阵才有行列式、才能谈逆、谈特征值、谈矩阵分解。同型矩阵指行数、列数分别对应相等。基本运算：两矩阵相等的条件是数表完全相同；加法要求同型、对应元素相加；数乘要把 k 乘到每一个元素上；减法由 `A + (-1)B` 定义（故不单独定义减法）。加减、数乘满足交换律、结合律、分配律，与中学代数完全一致。

> **定义**：同型矩阵——行数、列数分别相等的两个矩阵
> **易错点**：数乘要乘到每一个元素，不是只乘某一行或某一列

## 【视频03】矩阵乘法：定义、内积与Gram矩阵

[00:06:00 - 00:16:00]

矩阵乘法：`A` 为 `m × s`、`B` 为 `s × n`，必须满足「左矩阵的列数 = 右矩阵的行数」，结果 `C` 为 `m × n`，其中 `c_{ij}` 是 A 的第 i 行与 B 的第 j 列的内积（对应相乘再相加）。即所谓「多行乘多列」，考试不必背展开式，会做每行乘每列的点积即可。乘出的每个元素一方面反映两个向量的大小，更重要的是反映它们的夹角余弦，即位置关系/相关程度。以 Gram 矩阵为典型：`A^T A` 的每个元素都是内积，能同时给出各向量的长度与两两相似度，这也是考研大题中常出现 `A^T A` 的原因。

> **公式**：`c_{ij} = sum_k a_{ik} b_{kj}`；可乘条件：左矩阵列数 = 右矩阵行数
> **易错点**：动手前一定先看形状能否相乘

## 【视频03】乘法的运算律、不能成立的规则与转置

[00:16:00 - 00:33:00]

乘法满足结合律、分配律、与数乘的结合律，但**不满足交换律**：`AB != BA`。由此推出两条必须牢记的规则：①`AB = O` 推不出 `A = O` 或 `B = O`（矩阵是变换，两个变换复合为 0 不等于本身为 0）；②消去律不成立，`AB = AC` 且 `A != O` 也不能约去 A（与②并不独立）。所有乘法派生公式因此不能照搬：`(A+B)^2 != A^2 + 2AB + B^2`、`(A-B)^2 != A^2 - 2AB + B^2`、`(A+B)(A-B) != A^2 - B^2`、`(AB)^m != A^m B^m`。转置即「行写列」，运算规律：`(A^T)^T = A`、`(kA)^T = k A^T`、`(A+B)^T = A^T + B^T`、`(AB)^T = B^T A^T`（穿脱原则：从左往右乘，取转置后从右往左写转置）。

> **公式**：`(AB)^T = B^T A^T`
> **易错点**：`AB != BA`；`(A+B)^2`、`(AB)^m` 等均不能展开

## 【视频03】多项式、方阵行列式与几种重要矩阵

[00:33:00 - 01:04:38]

若 `f(x)` 是 x 的 m 次多项式，则 `f(A)` 是把 x 换成 A、常数项 `a_0` 换成 `a_0 E`（要认识这种矩阵多项式的形式，考研不深究多项式理论）。方阵行列式：`|kA| = k^n |A|`；`|A+B| != |A| + |B|`；`A != O` 推不出 `|A| != 0`（如两行成比例的 A，是非零矩阵但 `|A| = 0`）；`|A^T| = |A|`；`|AB| = |A||B|`。

几种重要矩阵：①零矩阵（每个元素为 0，不一定是方阵，不一定有行列式）；②单位矩阵 E（主对角线为 1，建议写下标 `E_n`）；③数量阵 `kE`（与任何矩阵可交换）；④对角阵 `diag(lambda_1, ..., lambda_n)`（大家追求的最简形式）；⑤四类上下三角矩阵；⑥对称阵 `A^T = A`（即 `a_{ij} = a_{ji}`，考研大题十二分必涉及，能相似对角化，`A^T A` 必为对称阵）；⑦反对称阵 `A^T = -A`（主对角线全为零，`a_{ij} = -a_{ji}`，考研考得少）。

> **定义**：数量阵 `kE`；对角阵——除主对角线外元素全为 0
> **易错点**：`A != O` 不等于 `|A| != 0`；`|A+B| != |A| + |B|`
> ⚠️ **需回看视频 [00:54:00]**：讲对称阵充要条件时转写成「aij 等于 aij」，疑为 `a_{ij} = a_{ji}` 的漏字 —— "所以A转置等于A的对应的充要条件就是aij等于aij"

## 【视频04】行向量、列向量与分块矩阵及其运算

[00:00:00 - 00:16:00]

只有一行的矩阵是行向量（`1 × n`），只有一列的是列向量（`m × 1`）；代数中约定向量写成列向量，右肩打 T 表示转置成行向量。务必区分 `alpha^T alpha`（`1 × 1`，是一个数，即内积）与 `alpha alpha^T`（`n × n` 的大方阵）。

分块矩阵：用横竖线把矩阵分成若干小块（子块），把子块看作原矩阵的元素（豆腐块比喻）。分块后的加法、数乘、乘法（以及求逆）都可像普通元素那样运算，但乘法不能交换：`A` 乘 `X` 必须 A 在左、X 在右。特殊情形：`[[A,0],[0,B]]^n = [[A^n,0],[0,B^n]]`，分块对角阵求幂很方便。

> **公式**：`alpha^T alpha` 是数；`alpha alpha^T` 是 n 阶方阵
> **易错点**：分块矩阵相乘时子块顺序不能随意交换

## 【视频04】秩一方阵、迹与A^n的求法

[00:16:00 - 00:43:00]

形如 `A = alpha beta^T`（`alpha`、`beta` 为列向量）的方阵，各行成比例，称为秩一方阵。求 `A^n` 时用结合律把中间的 `beta^T alpha` 先结合成一个数：`A^n = (beta^T alpha)^{n-1} A`。又发现 `beta^T alpha` 恰等于 A 主对角线元素之和，称之为矩阵的迹 `tr(A)`，于是秩一方阵的幂公式写成 `A^n = [tr(A)]^{n-1} A`。几何意义：秩一方阵作用 n 次等价于作用一次再乘一个系数，因为它把空间压成一条一维直线（三维空间的一维子空间），故可极大简化计算。

> **公式**：`A = alpha beta^T => A^n = [tr(A)]^{n-1} A`；`tr(A) = sum a_{ii}`
> **定义**：迹 `tr(A)`——方阵主对角线元素之和

## 【视频04】A^n的试算法与二项展开法

[00:43:00 - 01:00:34]

`A^n` 的另外两种方法：①试算法——拿到矩阵先看是否秩一，不是就试算 `A^2`、`A^3`，看能否化成 `kE` 等简单形式。如 `A = [[0,-1],[1,0]]` 是旋转 90° 的正交阵，`A^4 = E`，于是 `A^9 = (A^2)^4 A`，可先用 `A^2 = 4E` 化简，避免硬算九次。②二项展开法——把 A 拆成 `A = kE + B`，因 `kE` 与任何同阶方阵可交换，二项展开式才能用；若 `B` 幂零（如某类上三角阵 `B^3 = O`），展开式只剩有限几项。这两种方法都有局限性（能否拆出数量阵、能否凑出简单形式），一般方法（相似对角化）留待相似理论。

> **公式**：`A^9 = (A^2)^4 A`；`(B+C)^n` 可用二项展开的前提是 `BC = CB`
> **易错点**：二项展开式只在两部分可交换（通常一个是数量阵 `kE`）时才可用

## 【视频05】可逆矩阵的定义与充要条件

[00:00:00 - 00:06:00]

矩阵没有除法，改用「逆」：`A` 的逆记作 `A^{-1}`，不写 `1/A`。定义：设 `A`、`B` 为 n 阶方阵，若 `AB = E`，则称 A 可逆、B 为 A 的逆矩阵，记 `B = A^{-1}`；此时必有 `BA = E`，即 `AB = BA`，矩阵与其逆矩阵的乘积可交换。只有方阵才谈逆（只有方阵才有行列式）。A 可逆的充要条件是 `|A| != 0`（类比数 a≠0 才有倒数，一阶时 `|a| = a`）。不是方阵就不谈逆，可用 Gram 矩阵 `A^T A` 造出方阵。

> **定义**：`A` 可逆 ⇔ 存在 B 使 `AB = BA = E` ⇔ `|A| != 0`
> **易错点**：只有方阵才谈可逆；`A^{-1}` 不能写成 `1/A`

## 【视频05】逆矩阵的性质与重要公式

[00:06:00 - 00:14:00]

逆矩阵性质（默认 A、B 同阶可逆，k≠0）：`(A^{-1})^{-1} = A`；`(kA)^{-1} = k^{-1} A^{-1}`（用定义法即可验证）；`(AB)^{-1} = B^{-1} A^{-1}`（穿脱原则）；`A^T` 也可逆且 `(A^T)^{-1} = (A^{-1})^T`；`|A^{-1}| = |A|^{-1}`。要注意四种运算里 k 提出方式各不相同：`(kA)^T = k A^T`、`|kA| = k^n |A|`、`(kA)^{-1} = k^{-1} A^{-1}`，可用对比联系法记忆。

> **公式**：`(AB)^{-1} = B^{-1} A^{-1}`；`(A^T)^{-1} = (A^{-1})^T`；`|A^{-1}| = |A|^{-1}`
> **易错点**：`(A+B)^{-1} != A^{-1} + B^{-1}`、`|A+B| != |A| + |B|`，只有转置满足 `(A+B)^T = A^T + B^T`

## 【视频05】定义法求逆与例题

[00:14:00 - 00:27:11]

定义法求逆：凑出「（方阵）（方阵）=（单位阵）」，则两者互为逆。例 2.4：由 `AB = A + B` 整理成 `(A - E)(B - E) = E`，从而 `A - E`、`B - E` 都可逆（关键用「E 的妙用」：`A = AE = EA`，并凑 `-B` 再加 `B`）。例 2.5：已知 A、B 可逆且 `A^{-1} + B^{-1}` 可逆，证 `A + B` 可逆并求逆。思路是把 `A + B` 提出公因式：`A + B = A(E + A^{-1}B) = (E + BA^{-1})B`，再利用 `E = AA^{-1} = B^{-1}B` 等恒等变形，最终 `(A+B)^{-1} = B (A^{-1} + B^{-1})^{-1} A^{-1}`。

> **公式**：`AB = A + B => (A - E)(B - E) = E`；`(A+B)^{-1} = B (A^{-1} + B^{-1})^{-1} A^{-1}`
> **易错点**：不能把 `(A^{-1} + B^{-1})^{-1}` 直接写成 `A + B`

## 【视频06】伴随矩阵的定义与基本公式

[00:00:00 - 00:12:00]

伴随矩阵：把行列式中每个元素 `a_{ij}` 的代数余子式 `A_{ij}`，按「行上的代数余子式竖着写」排成的矩阵，记作 `A^*`（念 A 星或 A 伴随）。核心恒等式：`A A^* = A^* A = |A| E`。由此可知矩阵与它的逆、与它的伴随都天然可交换。在 A 可逆时，由 `A A^* = |A| E` 两边左乘 `A^{-1}` 得 `A^* = |A| A^{-1}`，即 `A^{-1} = A^* / |A|`——伴随正是为求逆而出现的。

> **公式**：`A A^* = A^* A = |A| E`；`A^* = |A| A^{-1}`；`A^{-1} = A^* / |A|`

## 【视频06】伴随矩阵的性质与重要公式

[00:12:00 - 00:31:00]

伴随的重要公式：`|A^*| = |A|^{n-1}`；`A^* = |A| A^{-1}`（可逆时）；`(kA)^* = k^{n-1} A^*`；`(A^T)^* = (A^*)^T`；`(A^{-1})^* = (A^*)^{-1}`；`(AB)^* = B^* A^*`（穿脱原则）；`(A^*)^* = |A|^{n-2} A`（二阶时 `(A^*)^* = A`）。四种运算（取行列式、求转置、求逆、求伴随）的叠加要分清，只有 `(A^T)^T = A`、`(A^{-1})^{-1} = A` 会「回去」。k 提出时四种运算结果各不相同：`k^n |A|`、`k A^T`、`k^{-1} A^{-1}`、`k^{n-1} A^*`。

> **公式**：`|A^*| = |A|^{n-1}`；`(AB)^* = B^* A^*`；`(A^*)^* = |A|^{n-2} A`；`(kA)^* = k^{n-1} A^*`
> **易错点**：`|A^*| != |A|^*`；`(A+B)^* != A^* + B^*`

## 【视频06】用伴随求逆、求伴随的方法与例题

[00:31:00 - 01:00:28]

## 【视频07】三种初等变换与初等矩阵（倍乘初等阵）

[00:00:00 - 00:16:00]

初等变换三种：①倍乘——某行/列乘非零常数 k；②互换——某两行/列互换位置；③倍加——某行的 k 倍加到另一行。换成行叫初等行变换，换成列叫初等列变换。初等矩阵：由单位阵 `E` 经一次初等变换所得到的矩阵，地位相当于「基本初等函数」，是最基本的变换手段。`E(i,k)` 表示单位阵第 i 行（或第 i 列）乘非零 k。作用规律即「左行右列定理」：对于矩阵 A 做初等行变换，相当于在 A 左边乘相应初等矩阵；做初等列变换，相当于在 A 右边乘初等矩阵。单位阵作用在任何矩阵上等于不起作用。

> **定义**：初等矩阵——单位阵经一次初等变换所得
> **公式**：左乘 = 行变换，右乘 = 列变换（左行右列）
> **易错点**：倍乘阵既可念作第 i 行乘 k，也可念作第 i 列乘 k，作用结果由左/右位置决定

## 【视频07】互换初等阵与倍加初等阵

[00:16:00 - 00:26:00]

互换初等阵 `E(i,j)`：单位阵第 i、j 行（或列）互换，既可按行念也可按列念，作用结果同样遵循左行右列。倍加初等阵 `E(i,j,k)`：按北大五版记号读作「把第 j 行的 k 倍加到第 i 行」，从列念则为「把第 i 列的 k 倍加到第 j 列」。读音的记忆法：逆时针为正向且「行在前、列在后」，故先念行后念列。注意互换阵、倍乘阵的行念与列念是同一回事，而倍加阵的行念与列念方向相反、不是一回事。教材记号不统一，考试一般不写这些符号，只写可逆阵 P 并用文字描述变换，避免歧义。

> **定义**：`E(i,j)` 互换阵；`E(i,j,k)` 倍加阵
> **易错点**：倍加阵行、列两种念法方向相反，注意记号约定

## 【视频07】初等矩阵的性质：转置、行列式与逆

[00:26:00 - 00:41:00]

初等矩阵的性质：①转置——倍乘阵、互换阵转置后仍是自身（都是对称阵）；倍加阵 `E(i,j,k)^T = E(j,i,k)`（i、j 对调）。②行列式——`|E(i,k)| = k`、`|E(i,j)| = -1`、`|E(i,j,k)| = 1`，都非零，故初等阵都可逆。③逆——`E(i,k)^{-1} = E(i,1/k)`；`E(i,j)^{-1} = E(i,j)`；`E(i,j,k)^{-1} = E(i,j,-k)`。初等阵的逆仍是同类型初等阵。可理解为「复合与反复合」（求逆类似求反函数）。

> **公式**：`E(i,k)^{-1} = E(i,1/k)`；`E(i,j)^{-1} = E(i,j)`；`E(i,j,k)^{-1} = E(i,j,-k)`
> **易错点**：只有倍加阵转置要换 i、j（`E(i,j,k)^T = E(j,i,k)`）

## 【视频07】可逆矩阵的初等分解与初等变换法求逆

## 【视频08】分块矩阵求逆与初等变换的应用

[00:08:00 - 00:20:00]

分块矩阵求逆：主对角线分块阵 `[[A,0],[0,B]]^{-1} = [[A^{-1},0],[0,B^{-1}]]`（位置不变）；副对角线分块阵 `[[0,A],[B,0]]^{-1} = [[0,B^{-1}],[A^{-1},0]]`（求逆后两块要交换位置）。例题：把「A 的一二行互换得 B」翻译成左乘互换阵 `E(1,2)A = B`，再用穿脱原则求 `B^{-1}`；「A 的一二列互换再第二列加到第三列」对应右乘初等阵 `C = A E(1,2) E(2,3,1)`，所求 `Q = E(1,2) E(2,3,1)`，完整体现「左行右列」。

## 【视频09】矩阵方程的概念与三种基本型

[00:00:00 - 00:03:00]

含有未知矩阵的等式叫矩阵方程（类比：含未知函数的叫函数方程、含导数的叫微分方程、含积分的叫积分方程）。求解思路：先按题设与矩阵运算规则化简，化成三种基本型之一——`AX = B`、`XA = B`、`AXB = C`。若 A 可逆，`AX = B` 两边左乘 `A^{-1}` 得 `X = A^{-1} B`；`XA = B` 两边右乘 `A^{-1}` 得 `X = B A^{-1}`；`AXB = C` 且 A、B 可逆则 `X = A^{-1} C B^{-1}`。这再次说明矩阵乘法没有交换律，`AX = B` 与 `XA = B` 是两种不同情形。

> **公式**：`X = A^{-1}B`、`X = BA^{-1}`、`X = A^{-1}CB^{-1}`
> **易错点**：左乘/右乘必须分清，不能随意交换

## 【视频10】矩阵等价及其三条性质

[00:00:00 - 00:08:00]

定义：A、B 是 m×n 的同型矩阵，若存在可逆矩阵 P、Q 使 `PAQ = B`，则称 A 与 B 等价。因 P、Q 可分解为初等矩阵的乘积，故等价就意味着 A 可经若干次初等行变换与初等列变换变成 B。矩阵等价满足三条性质：①自反性（A 与自身等价，取 `P = E_m`、`Q = E_n`）；②对称性（`A ~ B ⇒ B ~ A`，由 `P^{-1} B Q^{-1} = A`）；③传递性（`A ~ B`、`B ~ C ⇒ A ~ C`，把中间表达式代入，`P_2 P_1` 与 `Q_1 Q_2` 仍可逆）。传递性在考研中多次考过，是重点思想方法。

> **定义**：`A` 与 `B` 等价 ⇔ 存在可逆矩阵 P、Q 使 `PAQ = B`（前提：同型）
> **易错点**：等价的前提是两矩阵同型

## 【视频10】矩阵的等价标准型

[00:08:00 - 00:17:00]

若 A 是 m×n 矩阵且 `r(A) = r <= min(m,n)`，则 A 一定等价于形如 `[[E_r,0],[0,0]]` 的矩阵，称为 A 的等价标准型，它具有唯一性（r 确定后 `E_r` 唯一）。当 `m = n = r`（满秩）时化为 `E_n`；一般情形只是把「1」集中在左上角 `E_r`，其余位置补零并按 m×n 形状补齐。由等价标准型可推出：同型矩阵 A、B 等价的充要条件是 `r(A) = r(B)`；不同型矩阵即使秩相等也不等价。等价标准型与传递性结合，可分析 A、B 各自与同一标准型之间的变换手段（P、Q）的关系。

> **公式**：`A` 等价于 `[[E_r,0],[0,0]]`，其中 `r = r(A)`；同型下 `A ~ B ⇔ r(A) = r(B)`
> **易错点**：不同型矩阵不能谈等价

## 【视频11】矩阵的秩的定义、理解与求法

[00:00:00 - 00:16:00]

秩的定义：设 A 是 m×n 矩阵，若存在 k 阶子式不为零，而所有 k+1 阶子式（若有）全为零，则 `r(A) = k`。k 阶子式是在 A 中任取 k 行 k 列、交叉位置元素按原相对位置组成的 k 阶行列式（子式一定是行列式，子矩阵才是矩阵）。等价理解：秩 = A 中线性无关向量（列/行）的个数——存在 k 个线性无关的向量，任加一个就线性相关（行列式为零即体积为零即线性相关）。从等价标准型看，`r(A)` 就是标准型中单位阵 `E_r` 的阶数 r。求法：用初等行变换化成行阶梯形，非零行数（台阶数）就是秩。

> **定义**：`r(A) = k` ⇔ 存在 k 阶子式非零、所有 k+1 阶子式全为零
> **易错点**：子式是行列式，子矩阵是矩阵，两者不要混

## 【视频11】关于秩的重要公式

[00:16:00 - 00:38:00]

重要公式：①`0 <= r(A) <= min(m,n)`，且 `r(A) = 0 ⇔ A = O`；②`r(kA) = r(A)`（k ≠ 0，数乘不改变秩）；③`r(AB) <= min(r(A), r(B))`（越乘秩越小/不增）；④`r(A+B) <= r(A) + r(B)`；⑤若 A 是 n 阶方阵：`r(A) = n`（满秩，等价于 A 可逆）时 `r(A^*) = n`；`r(A) = n-1` 时 `r(A^*) = 1`；`r(A) < n-1` 时 `r(A^*) = 0`（代数余子式全为零）；⑥初等行/列变换不改变秩，可逆矩阵左乘或右乘 A 都不改变 `r(A)`；⑦`AB = O ⇒ r(A) + r(B) <= A 的列数`；⑧「四秩相同」：`r(A) = r(A^T) = r(A^T A) = r(A A^T)`。其中③④⑤⑦⑧是必考重点。

> **公式**：`r(A) = r(A^T) = r(A^T A) = r(A A^T)`；`r(A^*)` = n（满秩）/ 1（`r(A)=n-1`）/ 0（`r(A)<n-1`）
> **易错点**：`r(kA) = r(A)`（k≠0），不能把 k 提出来影响秩
