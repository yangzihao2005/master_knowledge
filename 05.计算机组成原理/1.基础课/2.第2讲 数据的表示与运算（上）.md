## 【视频01】逻辑运算：与、或、非

[00:07:00 - 00:13:00]

逻辑运算又叫布尔运算，是计算机底层的运算方式；参与运算的变量是布尔变量，只有真/假（`1`/`0`）两种取值。

- **与**（`A·B` = `A AND B` = `A∧B`）：只有当 A、B 同时为真（都取 1）结果才为 1，否则为 0；类似串联电路，两开关都闭合灯才亮。
- **或**（`A+B` = `A OR B` = `A∨B`）：只要有一个为真结果就为 1，都取 0 结果才为 0；类似并联电路，任一开关闭合灯就亮。
- **非**（`\overline{A}` = `NOT A` = `¬A`）：取反，1→0、0→1；电路上用输出端的小圆圈表示。

> **易错点**：逻辑运算只有 0/1，`或`里 `1+1=1`，不会产生进位，不能套用算术加法。

## 【视频01】异或运算与二进制串逻辑运算

[00:13:00 - 00:23:00]

- **异或**（`A⊕B`）：A、B 取值不同时结果为 1，相同为 0；可由基础运算表示为 `A⊕B = ¬A·B + A·¬B`，也可写成 “A、B 是否相等” 再取非的形式。
- 写逻辑表达式的通法：找出所有使结果为 1 的情况，每种情况用一个“与”项表示，再把各“与”项整体“或”起来。
- 读电路图可从最外层输出（最后的“或”）开始逐层往前推，写出每段表达式。
- **二进制串逻辑运算**：按对应位逐位运算——与=逐位且、或=逐位或、非=逐位取反、异或=逐位比较（不同为 1、相同为 0）。
- **例**：要求 A=B 且 S 与 A、B 不同时 F 为真，满足条件的只有 `001`（`¬A¬B·S`）与 `110`（`A·B·¬S`），故 `F = ¬A·¬B·S + A·B·¬S`。

> **公式**：`A⊕B = ¬A·B + A·¬B`
> **易错点**：逻辑位运算是按位独立的，与算术加减不同。

## 【视频01】进位计数制：基数与位权

[00:23:00 - 00:31:00]

进位计数制是按进位方式计数的方法，三要素为：**基数 r**（每位可用数码的个数，逢 r 进一，十进制 r=10、二进制 r=2）、**位权**（每位代表的计量单位，小数点左边第 1 位（`k_0`）位权为 `r^0=1`，向左位权乘 r、向右位权除以 r，即 `k_i` 位权为 `r^i`）、**数位取值**（0 ~ r-1）。任一位的取值乘其位权再累加，即该数对应的十进制值。

- 二进制位权：个位是 `1`，向左为 `2、4、8、16…`，向右为 `0.5、0.25、…`。
- 例：`1000 1000.1001` 只需把非零位的位权相加即为十进制值。

> **易错点**：位权是“每向高位进一”所乘的基数幂，编号以小数点左边第一位为 `k_0`，向右编号递减。
> ⚠️ **需回看视频 [00:30:00]**：讲八进制位权时口播疑似 ASR 错误（应为“8 的幂”一类），转写为“左边就是8的r次方，右边也是8的r次方” —— "左边就是8的r次方，右边也是8的r次方，只不过一边是增，一边是减"

## 【视频01】进制转换与数的表示

[00:31:00 - 00:45:00]

- **任意进制→十进制**：各位数码乘以对应位权再求和。
- **二↔八**：每 3 位二进制对应 1 位八进制；**二↔十六**：每 4 位二进制对应 1 位十六进制（反过来即一位拆三/四位）。
- **十六进制数码**：10~15 依次用 `A`~`F` 表示。
- **数的书写**：`(数)_r`；另有前缀 `0b`/`0B`（二进制），前缀 `0x`/`0X` 或后缀 `H`（十六进制）。
- **十进制→r进制**：整数部分用**除基取余法**（除以基数取余数，先得的是最低位，最后倒序排列，商为 0 结束）；小数部分用**乘积取整法**（乘以基数取整数位，先得的是最高位，只用小数部分继续乘）。
- **例**：`123.45` 转二进制——整数 `123` 得 `1111011`；小数 `0.45`：`0.45×2=0.9→0`、`0.9×2=1.8→1`、`0.8×2=1.6→1`、`0.6×2=1.2→1`，得 `0.0111`；合并为 `1111011.0111`（转八进制为 `173.34`）。

> **易错点**：除基取余是“低位在前、需倒序”，乘积取整是“高位在前、只留小数继续乘”；十进制结果由整数部分与小数部分拼上小数点合并。

> ⚠️ **需回看视频 [00:39:00]**：除基取余的逐位播报混乱（商、余数读错），需回看核对 —— "十五除以一结果肯定是一"

## 【视频01】快速转换与进制加减运算

[00:45:00 - 00:53:00]

- 熟练后可直接用位权“凑数”求二进制：如目标 `123.45`，依次判断位权 `64、32、16、8、4、2、1` 取不取（取后从剩余值中减去），得整数 `1111011`；小数按 `0.5、0.25、0.125…` 凑得 `0.0111`。
- 进制的加减法与十进制同理，逐位运算、逢基数进一、借一当基数。
- **二进制**（设机器字长为 5 位）：超出字长的最高位会丢失（溢出），如加法中多出的进位被舍弃。
- **十六进制**可直接加减：逢十六进一、借一当十六；如 `B + C`（11+12=23）得 `7` 并向高位进 `1`。

> **易错点**：机器字长有限，最高位的进位会“溢出”丢失，不能保留。

## 【视频01】无符号数与有符号数概述

[00:53:00 - 00:58:00]

- **无符号数**：对应 C 语言 `unsigned`，只表示自然数（0 与正数），位数与机器字长一致；n 位无符号数可表示 `2^n` 个数，范围 `0 ~ 2^n-1`（8 位即 0~255，16 位即 0~65535）。其二进制形式可直接存入内存。
- **有符号数**：对应 C 语言 `int`，有正有负，由“符号 + 绝对值”两部分组成。
- 难点：机器内部没有正负号，绝对值可作自然数存入，但**符号无法直接存储**，因此需借机器数来表示有符号数——通常用 1 位二进制表示符号，`0` 为正、`1` 为负。

> **定义**：真值由“符号 + 绝对值”两部分构成；机器数则是内存中的一串 0/1。

## 【视频01】真值、机器数与映射思想（本章核心框架）

[00:58:00 - 01:15:00]

- **真值**：实际的取值（符号 + 绝对值的整体），可以是十进制，也可以是二进制、十六进制等，只要表示实际取值都叫真值——**真值 ≠ 十进制**。判断要点：带正负号（如 `-00000011`）的是真值，机器数里不可能有负号。
- **机器数**：内存/硬件中只有 0 和 1，任何存入内存或送入 ALU 的数都是机器数。
- 本章两大问题：① 真值↔机器数的相互转换（**编码 / 解码**），即“数据的表示”；② 设计与真值运算一一对应的机器数运算，即“运算”。
- **映射思想**：n 位机器数可直接“直译”的范围有限（如三位只能表示 `0~7`），负数、小数无法直译，需把不可直译的真值**映射**到可直译的自然数区间，使用时再反映射回真值；小数则可先右移若干位化归为整数再映射。

> **定义**：映射——把无法直接表示的负数（及小数）变换到一串可直接表示（可直译）的二进制机器数上，且要求机器数运算与真值运算一一对应。

## 【视频01】原码（整数与纯小数）

[01:15:00 - 01:40:00]

- **思路**：绝对值是正数、可直接表示，只有符号不可表示，于是专门取 1 位作符号位（正 `0`、负 `1`），数值位照抄绝对值。
- **整数原码**（机器字长 n+1，1 符号位 + n 数值位）：`[x]_原 = x`（x≥0）；`[x]_原 = 2^n - x`（x<0，即 `2^n + |x|`）。这里 `[x]_原` 表示“原码机器数直译（当无符号数解释）时的取值”。
- **整数性质**（n+1 位）：最小正整数 `1`、最大正整数 `2^n-1`；最大负整数 `-1`、最小负整数 `-(2^n-1)`；**0 有两种表示**（`+0`、`-0`）。
- **纯小数原码**：小数点固定在符号位之后（此小数点只存在于脑海中，机器数里并不存），符号位 + 小数绝对值；`[x]_原 = x`（正）、`[x]_原 = 1 + |x| = 1 - x`（负）。
- **小数范围**：最小正小数 `2^{-n}`、最大正小数 `1-2^{-n}`；最大负小数 `-2^{-n}`、最小负小数 `-(1-2^{-n})`；0 有两种表示。
- **例**：`+0.1101` → `0,1101`；`-0.1101` → `1,1101`。这些最值不要死记，要自己按 `2^k-1`、`1-2^{-k}` 的思路推导。

> **公式**：负数整数 `[x]_原 = 2^n - x`；负数纯小数 `[x]_原 = 1 - x`
> **易错点**：原码有 `+0`/`-0` 两个零；纯小数的“小数点”是虚构的，机器数中并不存储。
> ⚠️ **需回看视频 [01:29:00]**：讲原码零的个数时口误为“两个，五个”，应为“两个” —— "原码能表示的零有两个，五个，全零或者是正零和负零"
> ⚠️ **需回看视频 [01:34:00]**：转写把“`[x]_原`”记作“x元”，疑似 ASR 错字 —— "这个地方有个表示叫x元，它表示x"

## 【视频01】补码（求法与整数范围、性质）

[01:40:00 - 02:03:00]

- 有符号数默认用补码。规则：最高位为符号位（正 `0`、负 `1`）；正数数值位同真值绝对值；**负数数值位 = 绝对值各位取反、末位加一**。
- 求负数补码的快捷法：① 取反加一；② 从右往左找第一个 `1`，该 `1` 及其右侧照抄，左侧全部取反（含符号位）。
- **数学表达**（n+1 位）：`[x]_补 = x`（x≥0）；`[x]_补 = 2^{n+1} + x`（x<0，等价于 `2^n - |x| + 2^n`）。其含义同样是“补码机器数直译所得的取值”。
- “补”的含义：`|x|` 的二进制与它的补码相加刚好溢出（等于 `2^{n+1}`），故称互补。
- **性质**：0 唯一（全 `0`），无负零；整数补码**最小负数为 `-2^n`**，比最大正数 `2^n-1` 的绝对值大 1，值域关于零不对称（负数多一个）。
- **例**（1 符号位 + 4 数值位）：`-1101` 的补码 = `1101` 取反得 `0010` 再加 1 得 `0011`，机器数为 `1,0011`。

> **公式**：负数整数 `[x]_补 = 2^{n+1} + x`
> **易错点**：补码零唯一；最小负数 `-2^n`（如四位补码的 `-8`）没有对应的原码，故“原码↔补码”对某些值不成立。

> ⚠️ **需回看视频 [01:57:00]**：讲解求最大/最小负数时一度把公式搞混、自称“移项移错了”，需回看理清推导 —— "哦，不好意思，是我自己，是我是我这个地方移项移错了"

## 【视频01】纯小数的补码

[02:03:00 - 02:10:00]

- 纯小数补码：同样最高位为符号位、其后为小数位；正数数值位照抄绝对值；负数数值位取反加一（即对小数部分取反加一）。
- **数学表达**：`[x]_补 = x`（正）、`[x]_补 = 2 + x = 2 - |x|`（负）。
- **范围**：最小正小数 `2^{-n}`、最大正小数 `1-2^{-n}`；最大负小数 `-2^{-n}`、**最小负小数 `-1`**（机器数 `1,0000`）；零唯一。负向可多表示一个 `-1`。
- **例**：`-0.1101` 的补码 = `1101` 取反 `0010` 加 1 得 `0011`，即 `1,0011`（虚构小数点）。

> **公式**：负数纯小数 `[x]_补 = 2 + x`
> **易错点**：小数补码的最小值是 `-1`，值域同样不对称。

## 【视频01】补码的位权表示法

[02:10:00 - 02:16:00]

- 统一解释补码：把机器数各位按位权求和，**最高位（符号位）位权取 `-2^{n-1}`**（n 位整数），其余第 `i` 位位权仍为 `2^i`；这样无需区分正负，直接代入即得真值。
- **整数例**：4 位补码 `1011` → `-8×1 + 4×0 + 2×1 + 1×1 = -5`；`0111` → `7`。
- **小数位权**：小数点前那一位（原为权 `1`）改为位权 `-1`，其余位权不变。**小数例**：4 位纯小数补码 `1011` → `-1×1 + 0.25×1 + 0.125×1 = -0.625`；`0111` → `0.875`。

> **公式**：整数补码真值 = `-2^{n-1}·x_{n-1} + Σ_{i=0}^{n-2} 2^i·x_i`
> **易错点**：只有最高位位权取负，其余位权与无符号数一致。

## 【视频01】真题：位权法求补码真值范围

[02:16:00 - 02:24:00]

- **题**：8 位整数补码形如 `1X_1X_2…X_7`，要求其真值大于 `-32`，求 `X_1…X_7` 的可能取值。
- **位权展开**：真值 = `-128 + X_1·64 + X_2·32 + X_3·16 + X_4·8 + X_5·4 + X_6·2 + X_7·1`；要求 > `-32`，即后段须 > `96`。
- 逐位分析：`X_1` 必须为 `1`（否则后面全取 1 也只有 63 < 96）；此后余段须 > `32`，故 `X_2` 也必须为 `1`；剩下 `X_3…X_7` 只需不全为 `0`。
- **答案**：`X_1 = X_2 = 1`，且 `X_3 ~ X_7` 不全为 `0`。

> **易错点**：用位权法可免去“绝对值小于 32”的绕弯分析。

## 【视频01】反码及原/反/补码的转换关系

[02:24:00 - 02:32:00]

- **反码**：正数同原码（符号位 `0`、数值位照抄）；负数数值位 = 绝对值各位取反（补码则是取反加一）。`[x]_反 = x`（正）、`[x]_反 = 2^{n+1}-1 + x`（负）。反码考频很低。0 有两种表示（全 `0` / 全 `1`）。
- **四码关系**：真值→原码（仅符号位不同，数值位照抄绝对值）；原码→反码（负数数值位取反）；反码→补码（负数末位加一）；即原码→补码对负数数值位“取反加一”。正数时原、反、补完全相同。
- **相反数**：`[-x]_补` = 对 `[x]_补` **连同符号位**取反加一（或最右一个 `1` 及其右侧不变、左侧取反），前提是 x 在可表示范围内。
- **例**：4 位补码 `3` = `0011`，则 `-3` = `0011` 取反 `1100` 加 1 = `1101`。

> **易错点**：原码/反码有两个零，补码零唯一且能多表示一个最小负数，故“原码→补码”对某些值不成立；建议直接从真值推补码，而非依赖码间互转。

> ⚠️ **需回看视频 [02:25:00]**：反码数学表达式口播含糊、疑似 ASR 残缺（“二的n加一减一，然后加x”） —— "它就是二的n加一减一，然后加x"

## 【视频01】移码

[02:32:00 - 02:43:00]

- **移码** = 真值 + 偏移量，把真值整体平移到自然数区间，从而可用机器数表示。默认偏移量为 `2^n`（n+1 位：1 符号位 + n 数值位），也可取其他 d。
- **表示**：`[x]_移 = 2^n + x`（`2^n` 即最高位为 `1`）。**例**（1 符号位 + 4 数值位，偏移量 `16`）：`+1101` → `11101`；`-1101` → `00011`。
- **特点**：移码的直译值随真值**单调递增**（大小关系与真值一致，便于比较）；符号位与补码相反——**移码中 `1` 表示正/零、`0` 表示负**；偏移量为 `2^n` 时，同一真值的移码与补码仅符号位相反、其余位相同。
- **范围**：最大真值 `2^n-1`（机器数全 `1`），最小真值 `-2^n`（机器数全 `0`）；零唯一，即机器数 `2^n`（`1` 后接 n 个 `0`）。

> **公式**：`[x]_移 = 2^n + x`
> **易错点**：移码并非只有 `2^n` 一种偏移量。

## 【视频01】各码范围对比与机器数类型的识别

[02:43:00 - 02:49:00]

- **各码取值范围汇总**（n+1 位整数）：原码 `-(2^n-1) ~ 2^n-1`（两个零）；反码同范围（两个零）；补码 `-2^n ~ 2^n-1`（唯一零）；移码与补码真值范围相同（唯一零）。
- **计算机如何识别机器数类型**：内存中指令与数据都以二进制编码保存、不区分；送 IR 当指令，送运算部件当数据。
  - 送**浮点部件** → 当浮点数：尾数按纯小数（原码/补码）、阶码用移码（整数）。
  - 送**整数部件** → 无符号数 / 有符号数（有符号默认补码）。
  - 只有当编译器按 `unsigned` / `int` 等类型调用时，才按对应解码方式解析出真值。
- **结论**：寄存器、内存中的机器数无需区分类型，只有在使用时才按要求解析成对应真值。

> **结论**：机器数不区分“哪一种码”，由“被送到哪个部件 / 被编译器以何种类型调用”决定解析方式。

## 【视频01】定点数概念与算术移位

[02:49:00 - 03:10:00]

- **定点数**：小数点固定的数，分**定点小数**（纯小数）与**定点整数**，其原/反/补/移码表示前面已述，无需新学。
- **移位**即小数点移动：左移≈乘 2、右移≈除 2，是倍数变换。分**算术移位**（针对有符号数）与**逻辑移位**（针对无符号数）。
- **算术移位补位规则**（符号位不参与移位、保持不变）：
  - 正数：原/反/补码左移右移均补 `0`。
  - 负数：原码补 `0`；反码补 `1`；补码**左移补 0、右移补 1**（即“补码左移补 0、右移补符号位”）。
- **溢出 / 精度丢失判据**：真值的最高有效位（代表 `0.5` 的那一位）移出符号位消失 → **溢出**；最低有效位丢失 → **精度丢失**。
- **例**：有符号小数 `0.375`（原=反=补=`0,0110`）。左移 1 位得 `0.75`；左移 2 位（=×4=1.5）超出纯小数范围发生**溢出**；右移则逐步丢低位、产生**精度丢失**。负数同理，补码负数左移丢的是 `0`（对应真值 1）、右移丢 `1`。

> **易错点**：负数补码左移补 `0`、右移补 `1`（补符号位），不要与正数混淆；判定溢出/精度丢失以“真值的 1”为准。
> **补充**：符号位是否参与移位，不同教材（如袁春风）说法不同，但仅在不溢出的情况下等价，真题一般避开该分歧。

## 【视频01】逻辑移位与循环移位

[03:10:00 - 03:17:00]

- **逻辑移位**：把操作数视为无符号数（没有符号位），整体左移/右移，空位一律补 `0`（左移低位补 0、右移高位补 0）。
- **循环移位**：移出的数据从另一端循环回来，并配合进位标志位 `CF`；分带进位 / 不带进位 × 左移 / 右移 共四类。
  - **不带进位循环左移**：最高位在移入 `CF` 的同时移入最低位。
  - **带进位循环左移**：最高位移入 `CF`，原 `CF` 移入最低位（`CF` 作为序列的一部分参与循环）。
  - **不带进位循环右移**：最低位同时移入 `CF` 与最高位。
  - **带进位循环右移**：最低位移入 `CF`，原 `CF` 移入最高位。
- “不带进位”并非没有 `CF`，而是 `CF` 不参与循环序列。

> **易错点**：四种循环移位极易记混，务必多画图；考试常直接问“某机器数带进位循环右移两位后 CF 与机器数各是多少”。
