# 第9讲 总线

## 【视频01】本节概述与408考情分析

[00:00:00 - 00:09:00]

本节内容分四个部分：`总线基础`、`总线性能指标`、`总线分类`和`总线事务`，属于全课程中较轻松的一章。408 考情：每年平均约 1 道选择题（偶尔 2 道）；大题不单独考查总线，通常作为一道小问或题目的已知条件出现，最爱与`存储器`结合（以`突发传送`方式为主），其次与`CPU`章节结合（用于数据传输）。考查方式上，2019 年以前偏概念，2022 年新考纲改革后明显偏向计算（各种数据的最大传输速率，常结合突发传送）。本章需掌握两类知识点：计算类 3 个、概念类 3 个；另有"内功修炼"部分（同步/异步通信方式、现代多总线结构），不直接出题，但有利于理解各部件连接方式、建立整机观。

## 【视频01】总线的定义与分类：片内总线与系统总线

[00:09:00 - 00:14:00]

总线是计算机内数据传输的公共路径，用于实现两个或两个以上部件之间的信息交换，各层次上提供了部件间的连接与信息通路。

> **定义**：`片内总线`（又称内部总线）指芯片内部连接各元件的总线，如 CPU 内部各寄存器、ALU、指令部件之间的连接；`系统总线`指连接 CPU、存储器和各种 I/O 模块等主要部件的总线。通常所说的"总线"即指`系统总线`。

I/O 连接方式的演变：早期计算机的 CPU 可直接连接 I/O 接口，现（408 考查的）结构改为 CPU 经`I/O 总线`连接各 I/O 控制器，由专门 I/O 芯片处理并与 CPU 通信。系统总线由 `数据线`、`地址线`、`控制线` 三种信号线构成，可理解为一根大管子内部套三根小线。

## 【视频01】数据总线、地址总线与总线地址复用

[00:14:00 - 00:24:00]

`数据线`用于承载源部件与目的部件之间传输的信息，内容可为数据、`命令字`（复用时可传地址）。以 CPU 与主存交互为例：写时 CPU 把数据放入 `MDR`，按 `MAR` 中的地址写入主存；读时 CPU 把地址放入 `MAR`，主存把存储单元数据经数据线送回 CPU。`命令字`（如启动命令字、结束命令字）用于 CPU 控制 I/O 接口，经数据线传输，CPU 与主存之间不存在传命令字的过程。

`地址线`用于给出源数据或目的数据所在存储单元或 I/O 端口的地址，且为`单向`线——CPU 与主存交互时地址永远由 CPU 发往主存（经 `MAR`），从不由主存发向 CPU。

`总线地址复用`：原书规定为**取消`地址线`、保留`数据线`**，地址与数据都通过数据线分时顺序传输（先传地址，再传数据）。

> **易错点**：地址复用取消的是`地址线`、保留的是`数据线`（原书规定），不要记反。
> **定义**：地址复用两大优点——① 用数据线传地址，可不设地址线，减少信号线根数；② 提高数据线利用率（一次读过程中数据线被使用两次，而传统方式只用到一次）。

## 【视频01】控制总线、命令字辨析与片内总线传输示例

[00:24:00 - 00:30:00]

`控制线`用于传输定时信号和命令信号。除地址线、数据线以外的通信线都属控制线，如时钟线、复位线、`操作命令线`、总线请求线、总线回答线；408 需重点掌握 `操作命令线`（读/写等具体控制信号）。

> **易错点**：`命令字`（CPU 控制 I/O 端口的多比特信息，类似一条条指令）经`数据线`传输；而读/写等具体控制信号经`控制线`传输，两者不要混淆。

片内总线数据传输示例：把 `R2` 中的值送到 `MDR`——控制信号发生器**同时**发出 `R2 out` 与 `MDR in`，R2 把数据输出到片内总线的数据线上，MDR 从数据线上读入，两步是并行执行的（并非先后两步）。

## 【视频01】总线性能指标概述与总线宽度

[00:30:00 - 00:35:00]

`总线性能指标`的目的是评价总线的好与坏，共从五个方面评价。学习建议：先弄清一个知识点"做什么用、为达成什么目的"，再看具体实现，避免只顾刷视频、做题卡壳。

> **定义**：`总线宽度`指总线中数据线的条数，决定每次能同时传输的信息位数。真题中总线宽度常见为 8、16、32 位（并非只有这三种，也可能只有一根/两根数据线，I/O 总线实例中会遇到）。

在此默认"总线"多指`系统总线`。第二方面`总线时钟频率/工作频率`是本讲计算重点。

## 【视频01】总线时钟频率与总线工作频率

[00:35:00 - 00:43:00]

`总线时钟频率`指总线中主脉冲信号的频率，可类比 CPU 时钟频率，只是位置在总线部件；`总线时钟周期`为其倒数，表示理想状态下传送一次数据的`时间`。

> **公式**：早期总线一个时钟周期传送一次数据，故 `总线工作频率 = 总线时钟频率`；现代总线一个时钟周期内可传 2 次（时钟上、下沿各一次）甚至 4 次，则 `总线工作频率 = 总线时钟频率 × 每周期传送次数`。

**例**：时钟频率 800MHz，一周期传 1 次 → 工作频率 800MHz；传 2 次 → 1600MHz；传 4 次 → 3200MHz。**例（2019 真题背景）**：连接 DDR3 1333 内存条的存储器总线一个时钟周期传 2 次，故真题给出的是工作频率 1333MHz，其时钟频率 ≈ 1333 ÷ 2 ≈ 666MHz（真题用词严谨，区分了时钟频率与工作频率）。

## 【视频01】总线带宽及其计算

[00:43:00 - 00:49:00]

`总线带宽`可理解为总线的`最大数据传输速率`，即单位时间内总线上最多可传输的数据位数（或字节数），比特与字节为 8 倍关系，具体单位看真题。

> **公式**：`总线带宽 = 总线工作频率 × 总线宽度 ÷ 8`（按字节表示；若按比特表示则不除 8）。

**例（2014 真题）**：同步总线，数据线与地址线复用共 32 根，时钟频率 66MHz，每时钟周期传 2 次数据 → 工作频率 = 66M × 2 = 132MHz，带宽 = 132M × 32 ÷ 8 = 528MB/s（选 C）。

**例（2019 真题）**：三通道存储器总线，工作频率 1333MHz，总线宽度 64 位 → 单根带宽 = 1333M × 64 ÷ 8 ≈ 10.66GB/s；因三通道 ×3 ≈ 32GB/s（选 B）。注意若问"一根"存储器总线带宽则为 10.66GB/s。

## 【视频01】总线周期与总线时钟周期的辨析

[00:49:00 - 01:18:00]

按唐书定义，一个完整`总线周期`包含`申请`、`寻址`、`传输`、`结束`四个阶段，其长度近似等于一次`总线事务`，且内部包含多个`总线时钟周期`。（01:09:00 - 01:18:00 为课间休息，无讲授内容。）

**关键看场景**：若总线为连接 CPU 与主存的`系统总线`，则一个总线周期 ≈ 一次总线事务，因主存准备数据耗时，内部包含多个时钟周期；若为`片内总线`（两寄存器间传数据），申请/寻址可忽略，总线周期 ≈ 传输时间，而早期总线一个时钟周期传一次数据，故此时总线周期 ≈ 一个时钟周期。

**例（2009 真题）**：系统总线，一个总线周期含 2 个时钟周期，时钟频率 10MHz，每时钟周期传 4 字节 → 每秒读事务 = 10M ÷ 2 = 5M 次，带宽 = 5M × 4 = 20MB/s。**例（2013 真题）**：传送 32 比特需一个`总线时钟周期`，而完成一次`突发传送总线事务`包含多个时钟周期（约 85ns/90ns）。

## 【视频01】总线定时方式：同步通信与异步通信

[01:18:00 - 01:27:00]

总线定时方式分`同步通信`与`异步通信`两类（`半同步`为二者结合）。

`同步通信`由时钟信号统一同步，时标通常由 CPU 的总线控制部件发出；各部件时钟源须与 CPU 同步，但可以是 CPU 时钟的整数倍（如 CPU 800MHz，主存 100MHz，则 8 个 CPU 时钟 = 1 个主存时钟），各部件按自己的速度工作又不失同步。

`异步通信`无公共时钟标准，允许各模块速度不一致，给设计者充分灵活性；采用`应答（握手）方式`——主模块发出请求后，须等从模块反馈响应信号才开始通信，故需增加两条`应答线`。

> **易错点**：408 场景中约 90%~95% 都是同步通信；异步通信的例子多在计算机网络课程中补充。地址复用下判断传的是地址还是数据，靠固定的时间约定（同步时钟），**不是**看指令周期。

## 【视频01】同步总线及其传输协议与缺点

[01:27:00 - 01:35:00]

`同步总线`采用公共时钟信号定时（时钟源来自 CPU），挂接设备按整数倍自定分频，总线时钟与 CPU 保持一致；传输协议非常简单，只需规定在第几个时钟周期完成特定操作即可，且多数情况下采用`并行`方式（一次同时传多个比特）。

**例（同步总线读协议）**：设 6 个 CPU 时钟 = 1 个存储周期；第 1 个时钟周期 CPU 发出地址与存储器读命令，第 5 个时钟周期主存准备好数据放到系统总线上，第 6 个时钟周期 CPU 从 `MDR` 读出。CPU 只需规定何时放地址、何时取数据。

**缺点**：① 强行同步时定时以最慢设备为标准，只适用于速度相差不大的部件；② 存在`时钟偏移`问题，总线不能过长，否则降低传输效率；③ 并行传输要求各数据位信号定时一致，速率太快会产生`串扰`导致波形变形，故速率不能太高。

## 【视频01】异步总线与异步串行传输

[01:35:00 - 01:41:00]

`异步总线`克服同步总线的缺点，允许各模块速度甚至时钟都不一致（如两台计算机之间的通信一般采用异步），采用`应答（握手）方式`，无公共时钟标准。计算机内部系统总线仍多用同步，而计算机之间、主机与外设之间（尤其需要快速传输的场景）多用`异步串行`总线：数据在一根信号线上传输，无串扰，速率可提高很多、远高于并行总线。

异步串行传输须给数据添加`起始位`、`终止位`（必须有）以及`校验位`（通常有，题目明确说没有才可省略）。

**例**：一次传输 7 比特数据，加起始位、校验位、终止位后封装成 10 比特的`帧`，在一根数据线上传输；接收方检测到终止位即知该帧读取完毕。应用：`PCIe`、`USB` 等连接高速外部设备的总线采用异步串行方式，用于主机间或主机与外部 I/O 设备间连接。

## 【视频01】总线的分类、多通道结构与2019真题

[01:41:00 - 01:46:00]

总线分三类：`片内总线`（CPU 内部连接各寄存器）、`系统总线`（连接 CPU、存储器与各 I/O 模块）、`I/O 总线`（为各种 I/O 设备提供输入输出通路）。

早期计算机系统总线又分两种：`处理器总线`（CPU ↔ 内存控制器）和`存储器总线`（内存控制器 ↔ 内存存储体）。该`内存控制器`后被称作`北桥芯片`，具备两个功能：对 CPU 内部 Cache 提供主存块、对 CPU 寄存器提供数据；并作为 DMA 控制器，控制主存中数据与显卡的交互。

> **定义**：`存储器总线`实际上就是主板上的内存条卡槽，一个主板可有多个卡槽（即多根存储器总线），称为`多通道结构`（如双通道），带宽随之成倍增加。

**例（2019 真题完整解答）**：三通道存储器总线，单根带宽 1333M × 64 ÷ 8 ≈ 10.66GB/s，三通道 ×3 ≈ 32GB/s，故选 B。

## 【视频01】I/O 总线、总线标准与PCIe带宽计算

[01:46:00 - 01:59:00]

`I/O 总线`用于为各种 I/O 设备提供输入输出通路，物理上通常为主板上的 I/O 扩展槽；2000 年前后的奔腾系列以`南桥芯片`作 I/O 控制芯片，各类 I/O 控制器（USB 控制器、磁盘控制器等）挂接其上，再由南桥统一控制。

2022 新考纲改革前考`总线标准`（ISA、EISA、VESA、PCI、AGP 等）；改革后移出考纲，改为给出一段总线背景资料，考查数据的`最大数据传输速率`。2019、2020 真题分别套用袁春风教材第 313/315 页（三通道）与第 314 页（QPI）例题，本章共 3 个例题、已考 2 个，故补讲 `PCIe`。

`PCIe` 采用串行方式，两 PCIe 设备间以`链路`相连，每个链路可含多个`通路`，`PCIe×n` 表示 n 个通路；每条通路分发送、接收两个方向（差分线），每个数据字节实际被转换为 10 比特（8 比特数据 + 起始位 + 终止位）传输。

> **公式**：`PCIe 总带宽 = 单向速率 × 2（收发双向）× 通路数 ÷ 10`（除以 10 是因为每 8 比特有效数据实际发出 10 比特）。

**例**：PCIe 1.0 单通路，单向速率 2.5GB/s → 2.5 × 2 × 1 ÷ 10 = 0.5GB/s；`PCIe×2` = 1GB/s；`PCIe×16` = 8GB/s。考试若考 PCIe，一般会把公式一并给出。

## 【视频01】多总线结构与总线事务的概念

[01:59:00 - 02:06:00]

传统`多总线结构`三点：① 离 CPU 越近的总线速度越快（最快的是`处理器总线`）；② `南桥芯片`即 I/O 控制芯片，负责控制 I/O 设备；③ 总线之间必须通过`桥接器`相连。

**例（2017 真题）**：错误的是"PCIe×16 采用并行传输方式"（PCIe 为串行）；靠近 CPU 的总线越快、存储器总线支持突发传送、总线间须经桥接器相连均正确。

`总线事务`：由 CSAPP 给出概念（国内教材一般无此定义）——数据流通过总线的共享电子电路在 CPU 与主存之间来来回回，每次数据传送由一系列步骤完成，这些步骤即总线事务。读事务为总线送数据到 CPU，写事务为 CPU 传送数据到主存。其阶段为：`请求`、`仲裁`、`寻址`、`传输`、`释放`（与系统总线的总线周期相对应）。

## 【视频01】总线事务分离与未采用事务分离

[02:06:00 - 02:19:00]

**未采用事务分离**：CPU 获取总线控制权后，把地址经总线送给主存，在主存准备数据期间一直独占总线（空等，如同死循环等待），直到主存准备好数据并向 CPU 申请总线控制权，才传输数据，之后 CPU 从总线读出。

**采用事务分离**：CPU 发出地址后即释放总线控制权；主存准备好数据后向`总线控制器`（不再向 CPU）申请总线控制权，获得后传输数据，CPU 再按同步时钟从总线上读出。事务分离能提高总线利用率——CPU 释放总线后，其间其他设备也可申请使用总线。

**例（2009 真题，未采用事务分离）**：CPU 需给出 `MDR in E` 信号控制 MDR 从系统总线的数据线上取数，且全程等待主存。**例（2022 大题 43 题，采用事务分离）**：`MDR in` 表示片内总线数据写入 MDR、`MDR out` 表示 MDR 内容送片内总线；CPU 只需给出 `read` 信号，地址发出后不再管主存启动与数据读入。取指控制信号序列：`PC out, MAR in` → `read` → `MDR out, IR in`。

## 【视频01】SDRAM与DRAM：同步/异步与事务分离

[02:19:00 - 02:24:00]

传统 `DRAM` 与 CPU 采用异步方式交换数据：CPU 发出地址和控制信号后，经过时间延迟数据才能读出或写入，其间 CPU 不断采样 DRAM 的完成信号，未完成前插入等待而不能做其他工作——即采用`未采用事务分离`的方式。

`SDRAM` 由外部系统时钟（接入 CPU 时钟）控制读写，采用`同步方式`交换数据：将 CPU 或其他主设备发出的地址和控制信息锁存，经确定几个时钟周期后给出响应，其间主设备可安全进行其他操作——即采用`事务分离`的方式。

> **易错点**：原书中传统 DRAM 与 CPU 为异步，SDRAM 为同步；但 408 考试把 DRAM 与 SDRAM 的特性综合、不单独区分。SDRAM、DDR、DDR2/DDR3 的特性均**不需要**专门学习，只需掌握 DRAM；本讲介绍 SDRAM 仅为衬托`总线事务分离`。

## 【视频01】课程总结与答疑、真题巩固

[02:24:00 - 02:35:36]

**例（2016 真题）**：下列关于总线设计的叙述中错误的是——"并行总线传输比串行总线传输快"是错的（并行总线存在`串扰`问题，串行总线速率反而可传得更快）；信号线复用技术可减少信号线数量、`突发传送`可提高数据传输率、采用`事务分离`可提高总线利用率均正确，故选 A。
