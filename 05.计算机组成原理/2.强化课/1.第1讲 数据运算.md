# 计算机组成原理强化课 第1讲 数据运算

## 强化课定位与学习方法

[00:00:00 - 00:07:00]

强化课不再重复"知识点是什么"，而是在基础已掌握的前提下做细化和深化；数据运算是从整体中剥离出来的较孤立内容，所以本讲听感接近基础课，从第2讲起才会大量串联知识。每讲前会发讲义，预习时发现遗忘点就回基础课补，否则强化课的吸收率很低。

> **注意点**：强化课的前提是基础知识已掌握；讲义预习的作用是暴露遗忘点，而不是提前学新知识。

## 冯·诺依曼结构与指令、数据的区分

[00:07:00 - 00:10:00]

冯·诺依曼结构由运算器、控制器、存储器、输入设备和输出设备组成，以运算器为中心，运算器内的寄存器充当各部件之间交流的中介；现代计算机改为以存储器为中心，部件可与存储器直接交换数据（DMA、通道）。存储器既存数据又存指令，形式上没有任何差别。

> **重点**：区分指令和数据有两个角度——①按指令执行阶段：取指周期取出的按指令处理，执行周期取出的按数据（或地址）处理；②按去向部件：送入 IR 的作指令，送入运算器的作数据，送入 MAR 的作地址。
> **易错点**：不能答"靠存储器中二进制内容本身区分"，二进制信息本身没有属性。

## 机器字长

[00:10:00 - 00:14:00]

机器字长是计算机一次整数（定点整数）运算所能处理的二进制位数，通常与通用寄存器位数、加法器位数一致，也等于"32位计算机/32位微机"中的位数。字长越长，数的表示范围越大、精度越高；计算机字长通常取字节的整数倍。

> **公式**：机器字长 = 通用寄存器位数 = ALU 宽度 = 一次定点运算可处理的二进制位数
> **易错点**：定点小数同样能代表机器字长，因为定点整数与定点小数在 ALU 中使用同一套电路（补码加减、乘除规则完全相同），小数点位置只是人为约定、机器中并不存在小数点。

## 机器字长的易混概念与存储字长

[00:14:00 - 00:17:00]

机器字长不等于：任意寄存器的位数（如 IR 的位数对应的是指令字长）、寻址空间大小（由地址位数或主存空间决定，在操作系统中代表操作系统位数）、一次浮点运算能处理的二进制位数（浮点运算要分别处理阶码与尾数，需对阶、尾数相加、规格化等多步，不是一次运算完成）。存储字长是一个存储单元的位数，即 CPU 按地址访存一次能取走的数据量。

> **公式**：MDR 位数 = 数据总线宽度（真题依据：地址线20位、数据线8位时 MDR 为8位）；但 MDR 位数 ≠ 存储字长（真题中出现存储字长8位、数据线32位）。
> **易错点**：存储字长与数据线宽度常被混为一谈，二者不一定相等。

## 指令字长

[00:17:00 - 00:20:00]

指令字长是指令的二进制位数：定长指令时等于 IR 位数；指令长度可以不相等，但必须是字节的整数倍（真题算出23位可行，仍须扩展到24位）。按与字长的倍数关系可分为单字长、双字长、半字长指令等。

> ⚠️ **需回看视频 [00:18:00]**：单/双/半字长指令到底按"机器字长"还是"存储字长"的倍数划分，各教材说法不统一，老师也明确表示内容被模糊化 —— "我们借助了谭志虎老师的是书上的说法…具体的大家随机应变吧。这一块确实是模糊化了"

## 时钟周期

[00:20:00 - 00:27:00]

时钟周期是计算机中最小的时间单位，是同步各步微操作控制信号的定时基准。它有三个等价表述：时钟脉冲信号的宽度、主频的倒数、相邻状态单元之间组合逻辑电路的最大延迟（原书：数据经组合逻辑电路从一个状态元件流入另一个状态元件的时间）。

"最大延迟"保证任意两个状态元件之间一个周期都能完成传送，且数据只走一级、不会连跳两个状态元件；同时一个时钟周期内 CPU 发出的控制信号保持不变，下一周期才切换数据通路。

> **易错点**：2019真题的错误项是"一个时钟周期执行一条新指令"——一条指令需要多个时钟周期，二者不一一对应。

## 主频、CPI、MIPS 与 MFLOPS

[00:27:00 - 00:29:00]

主频是每秒包含的时钟周期数，与时钟周期互为倒数。CPI（Cycles Per Instruction）是每条指令平均所需时钟周期数，不同指令、不同机器都不同；对某个程序而言，CPI 指该程序全部指令执行所需的平均时钟周期数。MIPS 表示每秒执行多少百万条指令，MFLOPS 一类指标用于浮点运算。

> **公式**：MIPS = 指令条数 ÷ 执行时间(s) × 10^6；数量级记忆 M=10^6、G=10^9、T=10^12、P=10^15、E=10^18、Z=10^21

## 大题解题方法：题干信息的提取与重述

[00:29:00 - 00:35:00]

选择题会做、大题不会做通常有两种原因：知识点其实没掌握（靠选项提示反推、左右互补才选出来），或题干信息过多，做题时找不到、记错、带错条件。老师的对策是边读题边用自己的语言把关键信息逐条抄到纸上并编号，之后只看自己的信息清单，清单里没有的再回题干找。

> **方法**：信息清单化 → 按小问逐个匹配所需条件 → 只做该问需要的运算，避免"条件太多看到头晕""用到某个条件时忘了"。

## CPU 性能指标综合大题示例

[00:35:00 - 00:45:00]

题目条件：32位机、主频800MHz、Cache 命中时 CPI=4、Cache 块32B、八体交叉编址、每体存储字长32位、存储周期40ns、存储器总线宽32位、总线时钟200MHz、支持突发传送（每次32B，送地址/命令与传数据各占1个总线时钟周期）。

四问思路：①CPU 时钟周期 = 1/800MHz = 1.25ns，总线时钟周期 = 1/200MHz = 5ns，总线带宽 = 4B/5ns = 800MB/s；②Cache 块32B ÷ 每次突发32B = 1次读突发事务；③一次读突发时间按时空图算得 85ns（1个总线周期送首地址与命令，8个存储体按5ns间隔流水启动、各需40ns存储周期）；④执行时间 = 命中时执行时间 + 缺失处理时间 = 指令数×CPI×时钟周期 + 缺失次数×85ns，缺失次数 = 访存次数×缺失率。

> **重点**：访问缺失时"正常执行时间"与"缺失处理时间"是相加关系，缺失处理不改变命中部分的 CPI；缺失处理时间就是一次突发传送事务的时间。

## 定点数的概念

[00:45:00 - 00:48:00]

定点数指小数点位置固定的数：整数的小数点固定在数值末尾，纯小数固定在符号位之后。小数点位置是人为约定，机器中并不存储小数点，因此移动小数点只改变解释方式、不改变运算结果的二进制表示，整数与小数可以共用一套电路。

例：七位尾数（双符号位补码）11.01011 + 00.10101 = 00.00000，结果为全零说明两数互为相反数。

> **定义**：定点数 = 小数点位置固定不变的数，包括定点整数与定点小数（纯小数）。

## 数据对齐的动机与结构体对齐规则

[00:48:00 - 00:50:00]

对齐的目的是避免跨边界访问造成的性能损失（真题中未对齐使一次访存多花时钟周期）。结构体对齐有三条规则：①整个结构体的对齐方式与其对齐要求最严格的成员相同；②成员在满足自身对齐要求的前提下，取最小可用位置作为其在结构体中的偏移量；③结构体总大小必须是其对齐边界长度的整数倍。

> **定义**："最严格"指对齐字节数最大、最难满足的成员，例如按4B对齐的 int 决定了整个结构体按4B对齐。
> **易错点**：第三条常被忽略，导致 sizeof 结果与实际排布不符。

## 结构体对齐实例：基本类型成员

[00:50:00 - 00:56:00]

例1：struct{short a; char b; short c;}——a 占0~1，b 是 char，2 和 3 都可用，按"最小可用位置"取2；c 是 short，起始必须是2的整数倍，3 放不下，故从4开始占4~5；结构体按2B对齐，总大小6B。

例2：struct{int a; short b; char c; short d;}——a 占0~3，b 占4~5，c 占6，d 需2B对齐只能从8开始占8~9，尾部再补2字节使总大小为12B。

> **易错点**：尾部填充不能省；成员偏移取"满足对齐的最小可用位置"，而不是简单顺排。

## 结构体对齐实例：嵌套结构体

[00:56:00 - 01:11:00]

内层 struct{char; int; short} 自身按4B对齐、占12B。外层结构体中，紧跟 short a 的那个 char 虽然是1B对齐，但它代表整个内层结构体的起始位置，必须从4B整数倍处开始，所以只能另起一行；随后的 int 按4B对齐，两个 short 顺次排放。c 不能放进内层结构体尾部补出来的空隙，因为那块空间在分配时已归属内层结构体。

外层结构体的对齐边界取决于其最严格成员（4B），不是8B，所以总大小只需是4B的整数倍，答案为20B，不需要再补一行到24B。

> **易错点**：嵌套结构体的大小要按"自身对齐方式"取整，容易误按8B多算一行；被内层结构体占用的填充空间不能再分配外层成员。
> **补充答疑**：若内层结构体不含 int（最严格为2B），则其首成员 char 可直接接在 short 之后，不必另起一行。（具体偏移以讲义图为准）

## 补码的位权表示法

[01:11:00 - 01:14:00]

n 位补码按位权展开时，最高位位权为 −2^(n−1)，其余各位位权为 2^i，即补码可看作"最高位带负权的无符号数"。原码在 IEEE 754 中常用，反码考试不考，强化阶段不再花时间。

> **公式**：X = −x_{n−1}·2^{n−1} + Σ_{i=0}^{n−2} x_i·2^i
> 例：8位补码 1x₆x₅…x₀ 的真值 > −32，等价于低位权值之和 > 96；因 64+32=96，故 x₆、x₅ 必须为1，其余位不同时为零。

> ⚠️ **需回看视频 [01:13:00]**：疑似口误/ASR 错误，−2^7 被读成"负二百一十八"，正确值为 −128，影响例题结论 —— "最高位就是位权就是负的二的七次方，就是负的二百一十八"

## 移码的定义与性质

[01:14:00 - 01:19:00]

移码把机器数按无符号数解释后再减去偏置常数 bias，等价于"机器数 = 真值 + bias"。因此移码的机器数大小顺序与真值大小顺序完全一致（从全0开始编码），这正是浮点数阶码用移码、便于比较大小的原因。代价是把无符号数的低端范围平移到了负数区间，高端正数范围被牺牲。

> **公式**：真值 D = (机器数按无符号解释的值) − bias；n 位移码在 bias=2^(n−1) 时的范围是 [−2^(n−1), 2^(n−1)−1]，与补码相同（负数多一个）。
> 例：3位移码 110、bias=4 → 6−4 = 2。

## 补码与移码的关系（选择题辨析）

[01:19:00 - 01:26:00]

核心结论：同一真值、相同位数时，补码与移码的数值位相同、最高位（符号位）相反；bias=2^(n−1) 时二者表示范围完全相同。零的补码为全0，零的移码为 100…0，因此"零的补码与移码位级表示相同"是错的。移码表示浮点数阶码、补码表示定点整数属于约定俗成。

证明思路：d ≥ 0 时移码 = d + 2^(n−1)，相当于把补码最高位由0变1、低位不变；d < 0 时补码 = 2^n + d，移码 = 2^n + d − 2^(n−1)，恰好把最高位的1变0、低位不变。

> **易错点**：移码的"符号位"是正1负0，与补码相反；"位级表示"就是机器数本身。

> ⚠️ **需回看视频 [01:24:00]**：转写此段出现整段重复乱码，无法确认老师对负数情形证明的完整表述 —— "所以在当d是非负数的时候，我们说移码它对应的位数是，对应的就是最高位符号位是1，补码是0，然后后面是完全一样的"（连续重复数十次）

## 移码加减法公式及其证明

[01:26:00 - 01:37:00]

浮点加减的对阶要算阶差，即移码相减。做题时最稳妥的是先把移码译成真值再相减（408 已足够）；公式法的结论是：两个移码机器数直接相减，结果正好是两真值之差的补码；直接相加，结果是两真值之和的补码，但仅当 bias = 2^(n−1) 时成立，减法对任意 bias 都成立。

证明要点：相加时 [E1]移 + [E2]移 = 2·bias + (E1+E2)，模 2^n 后 2·bias = 2^n 被丢弃，余下即 E1+E2 的补码；相减先把减数取反加一（即 2^n − [E2]移）再相加，同样得到 E1−E2 的补码。

> **公式**：[E1]移 − [E2]移 = [E1−E2]补；[E1]移 + [E2]移 = [E1+E2]补（仅 bias = 2^(n−1)）
> **易错点**：机器数减法只能"取反加一"，不能理解成"加一个负数"——机器数按无符号数看待。

## 移位运算与算术移位的取整规则

[01:37:00 - 01:42:00]

无符号数：左移高位丢、低位补0；右移低位丢、高位补0；左移丢出的最高位为1即溢出。补码：左移低位补0、右移高位补符号位；算术左移若移位前后符号位不同则溢出。

> **重点**：算术右移等价于"除以 2^k 并向负无穷取整"，不是向零取整，所以 x>>2<<2 ≤ x（可能丢低位，负数还会更小）。
> **易错点**：负数 x/4 与 x>>2 不等价。如 x=−6：−6/4=−1（向零取整），−6>>2=−2（向负无穷取整）；而 x*4 与 x<<2 等价。

> ⚠️ **需回看视频 [01:38:00]**：补码算术移位存在"符号位不动、只移数值位"与"符号位随数值位一起移"两种教材规则，转写中教材名含混（"堂书""原书"） —— "有堂书和我们的原书两种不同的规则。我们在基础课的时候给大家讲的是堂书的规则，符号位不动"

## 有符号数与无符号数运算的位级等价性

[01:42:00 - 01:48:00]

对特定字长的整数，有符号数与无符号数的加、减、乘在模 2^n 意义下使用完全相同的机器数运算，操作数机器数相同则结果机器数也相同，只是解释方式不同。前提是"取模"：n 位运算的结果仍只保留 n 位，高位截断。

例：8位机中 unsigned x=128（10000000）、int y=7，分别按有符号/无符号求 x+y、x−y、x*y 两种解释下的真值。

> **重点**：无符号数本质是模 2^n 的环形运算，加减乘都能直接用取模算，比有符号乘除好算；这是后续简便解法的基础。

## 位级等价性例题：解法一（二进制直接运算）

[01:48:00 - 01:54:00]

在8位机器数上直接做二进制加减乘，结果一律截断到8位（模 2^8）。x+y：10000000+00000111=10000111 → 无符号135、补码−121；x−y：取反加一后相加得 01111001 → 121；x*y：竖式累加左移，高位全部截断，结果为 10000000 → 无符号128、补码−128。

> **方法**：乘法用竖式（即原码一位乘）逐位累加左移即可，移出的高位直接丢弃。
> **易错点**：题目只问运算结果，不必判断是否溢出；溢出由 CF/OF 等标志位反映。

## 位级等价性例题：解法二（取模后重新解释）

[01:54:00 - 01:57:00]

先按无符号数用模运算求结果：128+7=135、128−7=121、128×7=896 mod 256=128；再把结果写成机器数（无符号数的二进制就是机器数），最后按补码解释：135→−121、121→121、128→−128。

> **方法**：不知道有符号结果时，先转成无符号运算 → 取模 2^n → 写出机器数 → 按补码重新解释，这就是位级等价性的实用形态。

## 定点数的类型转换与位拓展

[01:57:00 - 02:01:00]

字长不变：实际存储的机器数不变，只改变解释方式（如 int↔unsigned）。字长变长：对真值做位拓展——被拓展数是无符号数则零拓展，是有符号数则符号拓展，与目标类型是否为无符号无关。字长变短：一律高位截断。

> **重点**：不同字长的两个数运算，必须先对较短的那个做位拓展再计算；拓展方式只看被拓展数原本的类型，不看运算结果的类型。
> **易错点**：混淆"被拓展数的类型"和"目标类型的符号性"是最常见的失分点。

## 真题：形式地址与基址相加中的符号拓展

[02:01:00 - 02:06:00]

32位大端机，形式地址 FF12H（补码）与基址 7F000000H（无符号）相加。解法一按真值：FF12H 为负数，用"按位取反、直到最后一个1"快速求绝对值，得 −00EEH（−238），再与基址相减：7F000000H − 000000EEH = 7EFFFF12H。

解法二按规则：两数位数不同，对被拓展的 FF12H（有符号数）做符号拓展成 FFFFFF12H，再与基址机器数直接相加，进位丢弃，结果同样是 7EFFFF12H。

> **方法**：负数求绝对值可用"从右往左，最后一个1及其右侧不变，左侧按位取反"的技巧，避免先转二进制再取反加一。
> **重点**：无符号数与有符号补码相加可以共用同一套加法器，靠符号拓展对齐位数。

## 无符号数与有符号数混合运算能否共用电路

[02:06:00 - 02:17:00]

要证：无符号 X 与有符号 Y 相加、结果按无符号解释时，可直接把两机器数相加。Y≥0 时 Y补 = Y无，显然成立；Y<0 时把 X+Y 写成 X−(−Y)，无符号减法相当于模 2^n 加 (−Y)的无符号表示，而 −Y>0 故 (−Y)无 = (−Y)补，最终得到 X无 + Y补，正是 (X+Y)的无符号表示。

> **结论**：无符号数 + 有符号数（结果按无符号解释）同样可以用同一套加法电路直接算机器数，无需按类型分路，这正是硬件只用一套 ALU 的依据。

## 溢出判断的基本方法

[02:17:00 - 02:20:00]

考试中最稳的做法：把操作数译成真值，按真值做加减（甚至乘）运算，再看结果是否超出该数据类型的表示范围。无符号加减超出 [0, 2^n−1] 即溢出（结果为负相当于又绕回一圈）；有符号加减则分上溢（> 最大值）与负溢出（< 最小值）两种情况。

> **易错点**：无符号数的"负结果"是绕回而非溢出到负区间；同样的机器数运算，按无符号可能溢出、按有符号可能不溢出，是否溢出必须结合数据类型判断。
> **公式**：n 位无符号 x−y = x + (2^n − y)（当 x<y）；有符号看真值是否落在 [−2^(n−1), 2^(n−1)−1] 外。

## 乘法的溢出判断与位级等价性验证

[02:20:00 - 02:23:00]

补码乘法可借无符号乘法验证位级等价：8位 FFH×FEH（即 −1×−2），按无符号 255×254 mod 256 = 2，机器数 00000010，按补码解释也是 2，与真值一致。乘法溢出判断同样依赖位级等价：n 位×n 位得 2n 位积，若高 n 位不全为零，截断后数值改变，即溢出。

> **方法**：补码乘法 → 无符号乘法 + 取模 + 重新解释，是乘法结果与溢出判断的通用套路。

## 标志位 OF/SF/ZF/CF 与乘除法溢出

[02:23:00 - 02:30:00]

ALU 内部无论有无符号都按机器数同一规则运算，是否需要报溢出由数据类型和标志位决定：OF 反映有符号数溢出，SF 是结果最高位（符号），ZF 表示结果全零，CF 反映无符号数运算的进位/借位。乘除法同样按高位是否有效来判断溢出。

> **公式**：OF = C_out ⊕ C_{n−1}（最高位进位异或次高位进位）；CF = C_out ⊕ Sub（减法时取反后最低位进位）；SF = 结果最高位；ZF = 1 当且仅当结果全0
> **重点**：无符号乘法中，2n 位积的高 n 位全为0才不溢出；只要高 n 位有一个1，截断后就改变了数值。

## 浮点数的规格化

[02:30:00 - 02:35:00]

规格化是在"不丢精度"与"不浪费尾数位"之间取平衡：尾数左移会丢失高位，右移会降低位数利用率，只有尾数真值绝对值达到 1/r（r 为基数）才是规格化数。判断时直接看尾数真值：基数为2时要求 |尾数| ≥ 1/2，基数为4时要求 ≥ 1/4。

例：1.1101×2² 逐步右移得到 1.101×2¹、1.01×2⁰、0.1×2⁻¹，尾数首位丢失后精度受损，故只有首位有效数字为1时才规格化。

> **定义**：规格化数 = 尾数绝对值 ≥ 1/r 的浮点数，此时既不浪费尾数位也不丢精度。

## IEEE 754 格式与四类数

[02:35:00 - 02:43:00]

单精度32位：1位符号 S、8位阶码 E、23位尾数 F；双精度64位：1+11+52。按 E、F 分四类：规格化数（E 非全0且非全1）、非规格化数（E 全0、F≠0）、无穷大（E 全1、F=0，由 S 定正负）、NaN（E 全1、F≠0）。

> **公式**：规格化数 = (−1)^S × 1.F × 2^(E−127)；非规格化数 = (−1)^S × 0.F × 2^(−126)
> **易错点**：阶码虽用移码但 bias=127（不是128）；非规格化数没有隐藏位1，且阶码固定取 −126 而不是 0−127；E 全1 是特殊编码，不代入公式。

## IEEE 754 极值计算

[02:43:00 - 02:49:00]

求极值的套路：符号位取最有利值，阶码在规格化范围内取边界（E∈[1,254]），尾数按需要取全0或全1，再代入公式。

最大规格化正数：S=0、E=254、F 全1 → (2−2⁻²³)×2¹²⁷；最小规格化正数：S=0、E=1、F 全0 → 1.0×2⁻¹²⁶；最大非规格化正数：E=0、F 全1 → (1−2⁻²³)×2⁻¹²⁶；最小非规格化正数：E=0、F 仅最低位为1 → 2⁻²³×2⁻¹²⁶ = 2⁻¹⁴⁹。

> **公式**：1.11…1（23个1）= 2 − 2⁻²³；0.11…1（23个1）= 1 − 2⁻²³
> **易错点**：规格化数的 E 不能取全0或全1（那是非规格化数/无穷），求"最大""最小"时容易误取边界。

## 非标准格式浮点数（IBM 370）

IBM 370 短浮点共32位：1位数符、7位阶码（移码，bias=64）、24位尾数（6位十六进制）；尾数用原码，规格化要求最高位十六进制数字非0，基数16。

## 浮点数加减三部曲与对阶

[02:53:00 - 02:55:00]

浮点加减三步：对阶、尾数加减、尾数规格化。对阶原则是小阶向大阶看齐，阶小的数尾数右移，右移位数等于阶差绝对值；阶差可用两真值直接相减，也可用移码相减再按补码解释。若阶差过大导致对阶"溢出"，说明小阶数相对太小，结果直接取大阶数。

> **易错点**：对阶只会把阶码提升到较大阶，不会产生阶码上溢；IEEE 754 尾数为原码，右移时符号位不参与、空位补0，移出的位含1即产生舍入信息。

## 尾数加减、规格化与真正的溢出

[02:55:00 - 02:58:00]

对阶后两数阶码相同，尾数按原码加减：同号相加，异号时绝对值大的减小的，因此原码加减需要真正的减法电路。尾数相加溢出（如 1.1+1.1=11.0）并不等于结果溢出，可通过右规恢复：尾数右移一位、阶码加一，右移丢出的非零位需舍入；若阶码加一时变成全1，才是真正溢出。

尾数最高位不是有效1时需要左规：尾数每左移一位、阶码减一；若阶码减到全0，则成为非规格化数甚至下溢。

> **重点**：只有阶码溢出才是真溢出；阶码没溢出而尾数被截断，只是精度丢失。

## 真题：对阶阶差溢出的判断

[02:58:00 - 03:03:00]

ΔE补 = [EX]移 − [EY]移，实现上是对 EY 取反加一（转写中的"负EY移补"即此意），再与 EX 相加。当 ΔE ≤ −129 或 ≥ 128 时阶差本身溢出，说明两数相差过大。

判符号位：正溢出（正减负得负）情形下 EXs=1（移码正为1）、EYs=1（负数取反加一后符号位变1）、ΔEs=1，三个符号位全为1；负溢出（负减正得正）则三个符号位全为0。三个标志位要分别判断后再组合，不是整体取反。

> **易错点**：移码的符号位是正1负0，与补码相反，判断时极易弄反。

## 真题：阶差多大时无需对阶

[03:03:00 - 03:10:00]

定性分析：阶差过大时，小阶数的尾数右移后有效位全部被移出，补进来的都是0，与大数相加等于没加，故结果直接取阶大的数。定量分析：单精度有效数字共24位（1位隐藏位+23位尾数），取小阶数尾数全1这一最坏情形——阶差为24时，隐藏位移到第24位，被舍去的最高位为1，会向前舍入，仍影响结果；阶差为25时被舍去的最高位为0，不产生舍入，结果不变。

> **结论**：加法情形下阶差 ≥ 25 时无需后续运算，结果直接取阶大的数；减法与乘法情形可自行按同样思路总结。
> **重点**：判断依据是"被舍去的最高位是否为1"，而不是阶差是否超过尾数位数。

## 单精度不能精确表示的最小正整数

[03:12:00 - 03:15:00]

不能精确表示只有两种可能：阶码不够（数太大）或尾数有效位不够。求"最小"的正整数必然是尾数不够的情形：需要24位有效数字的最小整数为 1.000…001（23个0后一个1）×2²⁴ = 2²⁴+1 = 16777217。

> **易错点**：单精度能精确表示所有 ≤ 2²⁴ 的整数，2²⁴+1 才是第一个不能精确表示的整数。

## 真题：浮点求和程序的溢出与舍入条件

[03:15:00 - 03:22:00]

程序用 power 每次乘2、sum 累加，实现 Σ2^i（i=0…n）= 2^(n+1)−1；不确定边界时可代入特殊值 n=1 验证得 1+2=3。该真值的规格化形式为 1.11…1（n 个1）×2^n，故阶码真值为 n、尾数有 n 个1。

"不发生溢出"即阶码不溢出：E = n+127 ≤ 254，得 n ≤ 127；"不发生舍入"即尾数够用：隐藏位之外的有效位不超过23位，得 n ≤ 23。

> **重点**："不溢出"不等于"结果不超过 float 上界"，而是阶码不溢出；阶码够用而尾数被截断属于精度丢失，不算溢出。

## int/float/double 之间的类型转换

[03:22:00 - 03:28:00]

int→float：不会溢出（int 最大 2³¹ 远在 float 阶码范围内），但 int 有效位可达31位 > 24位，可能精度丢失。float→int：既可能丢精度（截断小数）也可能溢出。int→double：既不溢出也不丢精度（52位尾数足够）。float→double：安全，按规则拓展。double→float：可能溢出、可能丢精度。

例：i=785、f=1.5678e3、d=1.5e100。①(float)i→int 结果不变；②f→int→float 丢小数，不等；③f→double→float 无损；④d+f−d ≠ f，因阶差过大，d+f 仍等于 d。

> **易错点**：(d+f)−d ≠ f 是"大数吃小数"的典型表现，与加法结合律失效同源。

## double 运算的精度陷阱

[03:28:00 - 03:40:57]

六个永真式判断：①dx*dx ≥ 0 恒真，平方非负且 2⁶² 远在 double 范围内；②(float)x 再转回 double 与原 dx 相等不一定真，int→float 可能丢精度；③dx+dy == (double)(x+y) 不一定真，int 相加可能溢出回绕，double 相加不会；④dx+dy+dz == dx+(dy+dz) 不一定真，阶差过大时两次加法都可能"吃掉"小数；⑤乘法结合/交换形式不一定真，int 相乘有效位可超52位，截断位置不同影响不同且不一定抵消（课上以实验验证）；⑥dx 自身的减、除运算恒为预期值（如 dx/dx=1，x≠0）。

> **易错点**：double 只有52位有效位，而 int 之间阶差可达60多位，加法可能整体失效；若出现 0，上述"不一定真"的结论还要重新判断。
